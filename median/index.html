중앙값·최빈값 계산기

자료를 정렬해 중앙값·최빈값·최솟값·최댓값을 확인합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

소수 결과는 유효숫자 12자리까지 표시합니다. 단위는 입력값끼리 통일해 주세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

치우친 자료의 중앙값과 가장 자주 나온 값 찾기.

짝수 개 자료의 중앙값은 가운데 두 값의 평균

입력 예시

1, 2, 2, 9의 중앙값 = 2

1, 2, 2, 100을 정렬하면 가운데 두 값은 2와 2이므로 중앙값은 2입니다. 2가 두 번 나와 최빈값도 2지만 산술평균은 26.25입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 숫자 목록 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

최빈값이 여러 개이거나 없을 수도 있나요?

최대 빈도로 반복된 값이 여러 개면 모두 표시합니다. 모든 값이 한 번씩 나오면 이 도구는 반복 값 없음으로 표시합니다. 중앙값은 자료 개수가 짝수면 가운데 두 값의 평균입니다.

이 도구의 계산식과 적용 범위는 위 설명에 공개되어 있습니다. 예시는 입력값을 공식에 대입하거나 명시된 문자열·달력 처리 규칙을 따라 확인할 수 있습니다.
