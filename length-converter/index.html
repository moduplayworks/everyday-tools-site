길이 단위 변환기

길이 값을 다른 단위로 바꾸고 단위별 결과를 비교합니다.

입력

최소 0

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

국제 inch는 정확히 0.0254m, 국제 foot는 0.3048m입니다. 결과는 유효숫자 12자리까지 표시합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

cm·m·인치·피트 길이 단위 바꾸기.

변환값 = 입력값 × 입력 단위의 기준 배율 ÷ 출력 단위의 기준 배율

입력 예시

1 m = 100 cm

1인치는 2.54cm이므로 10인치는 25.4cm입니다. 국제 피트와 인치를 기준으로 하며, 길이와 면적의 변환 배율은 다릅니다.

사용 방법

  1. 값, 입력 단위 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

인치 변환값을 화면 실측 크기로 봐도 되나요?

물리적 길이 단위만 변환합니다. 화면의 인치는 보통 대각선을 뜻하므로 가로 길이로 해석하지 마세요. 픽셀과 인치 사이에는 화면 밀도 정보도 필요합니다.
