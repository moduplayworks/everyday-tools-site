PDF를 이미지로

PDF에서 필요한 페이지를 PNG·JPG로 저장하세요. 페이지와 해상도를 고르고 개별 이미지 또는 ZIP으로 내려받습니다.

PDF를 이미지로 입력

PDF 1개 · 50MB·200페이지 이하

PDF 지원 범위

암호화·양식·서명 필드가 있는 PDF는 지원하지 않습니다. 최대 50페이지를 이미지로 저장합니다. 페이지당 2,400만 화소·한 변 10,000px, 전체 1억 2,000만 화소·결과 100MB 이하입니다.

파일은 브라우저에서 처리합니다. 원본은 유지되며 새로고침하면 작업이 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

PDF 페이지를 선택한 해상도로 렌더링해 이미지 사본을 만드는 작업입니다.

실제 예시

가로 612pt·세로 792pt인 Letter 페이지를 144dpi로 변환하면 1,224×1,584px 이미지가 됩니다. 3, 1을 입력하면 3쪽 다음 1쪽 순서로 결과를 표시하며 파일명에는 원본 쪽수가 들어갑니다.

자주 묻는 질문

PNG와 JPG 중 무엇을 고르면 되나요?

PNG는 글자·도형의 선을 선명하게 보존하지만 파일이 클 수 있습니다. JPG는 사진 위주의 페이지를 작게 저장할 때 사용할 수 있으며 품질 92%로 저장합니다. 두 형식 모두 페이지의 흰 배경을 포함합니다.

큰 PDF를 한 번에 변환할 수 있나요?

파일은 50MB·200페이지까지 열고 한 번에 최대 50페이지를 변환합니다. 한 페이지는 2,400만 화소·한 변 10,000px, 전체 결과는 1억 2,000만 화소·100MB 이하입니다. 한도를 넘으면 페이지 범위나 해상도를 줄이세요.
