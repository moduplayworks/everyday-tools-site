CSS 그라데이션 생성기

두 색상과 각도로 CSS 선형 그라데이션 코드를 만듭니다.

입력

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

6자리 HEX 색상 두 개를 사용합니다. 결과를 CSS background 속성에 붙여 넣으세요.

계산·변환 기준

두 색상과 각도로 CSS 선형 그라데이션 코드를 만듭니다.

linear-gradient(각도deg, 시작색, 끝색)

입력 예시

#000000 → #ffffff, 90도

사용 방법

  1. 시작 HEX, 끝 HEX, 각도 (도) 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.
