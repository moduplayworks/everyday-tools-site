순열·조합 계산기

서로 다른 n개 중 r개를 고르는 순열과 조합을 계산합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 0 · 최대 200

정수 · 최소 0 · 최대 200

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

중복 선택을 허용하지 않습니다. BigInt 정수 연산으로 계산합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

순서를 구분하는 순열과 구분하지 않는 조합 비교하기.

nPr=n!/(n−r)!, nCr=nPr/r!

입력 예시

5개 중 2개: 순열 20, 조합 10

5명에서 2명을 고르면 조합은 10가지입니다. 두 사람에게 서로 다른 역할을 주면 순서가 중요해 순열은 20가지입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 전체 n, 선택 r 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

같은 대상을 여러 번 고르는 중복조합도 계산하나요?

계산하지 않습니다. 이 도구는 n개의 서로 다른 대상에서 중복 없이 r개를 뽑는 경우이며 r은 n 이하여야 합니다. 0개를 고르는 경우는 한 가지로 계산합니다.
