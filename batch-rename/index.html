파일 이름 일괄 변경

여러 파일에 연속 번호를 붙이거나 이름을 치환하세요. 변경 이름을 미리 확인하고 ZIP 사본으로 저장합니다.

파일 이름 일괄 변경 입력

파일 1~200개 · 전체 50MB 이하

선택한 파일
앞·뒤 글자·번호·확장자

치환은 확장자를 제외한 이름에 적용합니다. 중복·위험한 이름은 저장 전에 알려드립니다.

원본 파일은 바뀌지 않습니다. 브라우저에서 처리하며 새로고침하면 작업이 초기화됩니다.

결과

파일을 선택하고 실행하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

파일들의 새 이름을 계산하고 변경 이름으로 담은 ZIP 사본을 만드는 작업입니다.

실제 예시

a.jpg와 b.jpg를 기본 이름 photo, 시작 번호 1, 자릿수 3으로 바꾸면 photo_001.jpg와 photo_002.jpg가 됩니다. 확장자 유지가 켜져 있으면 jpg 같은 원래 확장자는 그대로 붙습니다.

자주 묻는 질문

내 기기 파일 이름을 직접 바꾸나요?

원본 파일은 바꾸지 않습니다. 새 이름 미리보기를 확인한 뒤 ZIP 사본을 만들고 내려받습니다. 입력이 바뀌면 미리보기도 다시 확인해야 합니다.

중복 이름과 치환 범위는 어떻게 처리하나요?

치환은 확장자를 제외한 이름에서 찾은 글자 모두에 적용됩니다. 앞·뒤 글자는 변경한 이름에 붙고 확장자는 마지막에 붙습니다. 대소문자·유니코드 정규화 기준 중복과 위험한 경로 이름은 거부합니다.
