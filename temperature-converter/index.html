온도 변환기

섭씨·화씨·켈빈 온도를 서로 변환합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

절대영도 아래의 온도는 허용하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

섭씨·화씨·켈빈 온도 바꾸기.

F=C×9/5+32, K=C+273.15

입력 예시

섭씨 0도 = 화씨 32도 = 273.15 K

섭씨 20도는 20×9/5+32=화씨 68도이고 293.15K입니다. 온도의 절대값에는 눈금 간격뿐 아니라 기준점 차이도 반영합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 온도, 입력 단위 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

온도 차이 10도도 같은 방식으로 변환하나요?

아닙니다. 섭씨의 온도 차이 10도는 화씨 차이 18도이며 32를 더하지 않습니다. 이 도구의 입력은 온도 차이가 아닌 실제 온도입니다.
