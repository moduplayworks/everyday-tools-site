교재·문제 공부 분량 계획

페이지·문제와 완료 회독을 남은 공부 가능일에 나누세요. 날짜별 번호와 미배정 분량을 확인하고 CSV·캘린더로 저장합니다.

입력

예시값으로 바로 실행하거나 값을 바꿔 보세요.

1~100,000 정수. 서로 다른 난이도를 시간으로 환산하지 않습니다.

공부 요일·쉬는 날짜
공부 가능한 요일

YYYY-MM-DD 한 줄에 하나. 최대 366개.

포함 범위, 한 항목당 최대 100,000개

1회독 목표 · 0회독 완료 · 이번 회독 20개 완료

회독·완료 진도 기록

1~20

번호가 아닌 개수입니다. 예: 10~29번까지 했다면 20개.

입력 백업·복원

입력은 저장·자동 동기화하지 않습니다. 새로고침하면 예시값으로 돌아갑니다. JSON 백업에는 이름과 모든 입력이 포함됩니다. 복원은 현재 입력을 교체합니다.

결과

입력된 예시값으로 바로 결과를 확인하세요.

기본 결과 내보내기는 항목 번호를 사용합니다. 이름 포함을 켜면 공유할 내용과 파일에 이름이 들어갑니다.

ICS는 종일 일정 파일입니다. 캘린더에 직접 가져오세요. 자동 알림·동기화는 제공하지 않으며 반복 가져오기는 캘린더에 따라 중복될 수 있습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산 기준과 사용 방법

교재 페이지와 문제 번호를 회독별로 남은 공부 가능일에 배분하는 계획.

남은 분량 = 각 회독의 범위 − 기록한 완료 분량 · 수용량 = 가능일 × 하루 최대 분량

입력 예시

첫 교재 1~100페이지에서 이번 회독 20페이지를 끝냈고 두 번째 교재 1~60페이지가 남았다면 남은 분량은 80+60=140페이지입니다. 7일 모두 공부하고 하루 상한이 20페이지이면 하루 20페이지씩 배정됩니다. 첫날은 첫 교재 21~40페이지입니다. 하루 상한을 10페이지로 낮추면 70페이지만 배정되고 첫 교재 91~100페이지와 두 번째 교재 60페이지가 미배정으로 남습니다.

사용 방법

  1. 입력된 예시를 사용하거나 설정과 선택한 항목을 수정하세요. 항목 추가로 여러 평가·교재·주제를 순서대로 입력합니다.
  2. 진도 계획 만들기를 누르세요. 잘못된 입력은 해당 항목과 필드로 이동해 안내합니다.
  3. 결과를 확인하고 CSV로 저장하세요. 계획은 필요하면 ICS로 가져올 수 있습니다. 입력을 이어서 쓰려면 JSON 백업을 따로 저장하세요.

한계와 해석

페이지·문제 번호는 양 끝을 포함합니다. 목표 회독·끝낸 회독·이번 회독 완료 개수를 직접 기록하세요. 과거 계획은 자동 완료되지 않습니다. 최대 20개 항목·항목당 100,000개·20회독·기간 366일입니다. 난이도·학습 시간을 예측하지 않습니다.

자주 묻는 질문

완료 위치는 페이지 번호를 입력하나요?

이번 회독에서 끝낸 개수를 입력합니다. 범위가 10~29번이면 전체 20개입니다. 10~19번까지 마쳤다면 완료 개수는 10입니다. 전체 회독을 마친 경우 끝낸 회독 수를 올리고 이번 회독 완료 개수를 0으로 입력하세요.

마감일 전에 다 못 하면 날짜가 자동 연장되나요?

연장하지 않습니다. 가능한 날짜에 하루 상한까지만 순서대로 배정하고 나머지는 미배정 분량으로 표시합니다. 필요한 하루 분량을 확인한 뒤 상한이나 기간을 직접 수정하세요.

어제 계획을 못 끝냈을 때 어떻게 바꾸나요?

실제로 끝낸 회독과 이번 회독 완료 개수를 기록하고 시작일을 재시작일로 바꾼 뒤 다시 실행하세요. 과거 계획을 자동 완료하지 않으며 회독별 원본 번호를 유지합니다.
