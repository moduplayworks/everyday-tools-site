IPv4 서브넷 계산기

IPv4 주소와 CIDR 프리픽스로 네트워크·마스크·주소 범위와 호스트 수를 확인합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 0 · 최대 32

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

/0~30은 네트워크·브로드캐스트 주소를 제외한 호스트 수를 표시합니다. /31은 RFC 3021 점대점 링크에서 두 주소를 호스트로 셉니다. /32는 호스트 경로 하나로 셉니다. 주소의 사설·예약·특수 용도 여부는 분류하지 않으며, 장비별 동작을 판단하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

IPv4 주소와 CIDR 프리픽스를 입력해 해당 주소가 속한 네트워크와 범위·마스크·호스트 수를 확인합니다..

마스크 = 왼쪽부터 프리픽스 길이만큼 1인 32비트; 네트워크 = 주소 AND 마스크; 마지막 주소 = 네트워크 OR 와일드카드 마스크

입력 예시

192.168.1.37/24 → 네트워크 192.168.1.0 · 마스크 255.255.255.0 · 일반 호스트 254개

192.168.1.37/24는 마지막 8비트를 호스트 영역으로 둡니다. 따라서 네트워크는 192.168.1.0, 서브넷 마스크는 255.255.255.0, 주소 범위는 192.168.1.0~192.168.1.255이고, 일반 호스트 범위는 .1~.254로 254개입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 IPv4 주소, CIDR 프리픽스 길이 (/0~32) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

/24 프리픽스는 무엇을 뜻하나요?

IPv4 32비트 중 앞의 24비트가 네트워크 프리픽스라는 뜻입니다. 남은 8비트에서 네트워크와 브로드캐스트 주소를 뺀 254개를 일반 호스트 수로 표시합니다.

/31과 /32의 호스트 수는 어떻게 계산하나요?

/31은 RFC 3021에 따른 점대점 링크라는 가정에서 두 주소를 모두 호스트로 셉니다. /32는 단일 IPv4 호스트 경로로 한 주소를 셉니다. 네트워크 장비 설정은 해당 장비 문서를 확인하세요.

사설 IP인지 공인 IP인지 알려주나요?

이 계산기는 입력한 값의 CIDR 범위만 계산합니다. 사설·예약·특수 용도 주소인지 또는 실제 네트워크에 할당할 수 있는지는 판단하지 않습니다.

계산 기준과 참고 자료

  • RFC 4632 — Classless Inter-domain Routing (CIDR)

    IPv4 프리픽스 길이와 CIDR 주소 범위를 설명합니다. 계산기는 입력 주소의 32비트 마스크·네트워크·마지막 주소를 계산합니다.

  • RFC 3021 — 31-Bit Prefixes on IPv4 Point-to-Point Links

    점대점 링크에서 /31의 두 주소를 호스트 주소로 해석하며 directed broadcast를 사용하지 않는 조건을 설명합니다.
