목록 무작위 섞기

참가자나 할 일 목록을 무작위 순서로 섞습니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

명단 순서를 편향 없는 난수로 섞기.

Fisher–Yates 셔플, 각 입력 줄을 한 항목으로 처리

입력 예시

가 / 나 / 다의 순서를 무작위 변경

한 줄에 한 항목씩 입력하면 빈 줄을 제외한 목록의 순서를 섞습니다. 입력된 각 항목은 결과에 한 번씩 배치됩니다.

사용 방법

  1. 입력된 예시값을 사용하거나 한 줄에 한 항목 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

같은 이름이 두 줄이면 한 사람으로 합쳐지나요?

아닙니다. 각 줄이 독립 항목이므로 동명이인인지 중복 입력인지 먼저 확인하세요. 의도하지 않은 중복은 중복 줄 제거로 정리할 수 있습니다.
