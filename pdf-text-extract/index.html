PDF 텍스트 추출

PDF의 글자를 페이지별 텍스트로 추출하세요. 결과를 복사하거나 TXT로 저장합니다. 스캔 사진 OCR은 포함하지 않습니다.

PDF 텍스트 추출 입력

PDF 1개 · 50MB·200페이지 이하

선택 가능한 글자가 있는 PDF용입니다. 스캔 사진에는 OCR을 수행하지 않습니다.

PDF 지원 범위

암호화·양식·서명 필드가 있는 PDF는 지원하지 않습니다. 텍스트는 최대 200만 자입니다. 다단 문서·표·세로쓰기의 읽기 순서나 공백은 원문과 다를 수 있습니다.

파일은 브라우저에서 처리합니다. 원본은 유지되며 새로고침하면 작업이 초기화됩니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

PDF 안에 들어 있는 텍스트 객체를 페이지별 본문으로 추출하는 작업입니다.

실제 예시

1, 3-4를 입력하면 1쪽·3쪽·4쪽을 각각 페이지 구분선과 함께 추출합니다. 글자가 없는 페이지도 표시하므로 스캔본이나 빈 페이지를 확인할 수 있습니다.

자주 묻는 질문

스캔한 PDF나 사진에서 글자도 추출되나요?

이 도구는 PDF의 텍스트 정보를 읽으며 OCR을 수행하지 않습니다. 스캔 사진만 있는 페이지에서는 글자를 찾지 못했다고 표시합니다. 글자가 보이는데 결과가 비어 있으면 OCR 도구가 필요할 수 있습니다.

추출한 텍스트의 줄바꿈과 표가 원본과 다른 이유는 무엇인가요?

PDF의 문자 배치 순서와 위치를 이용해 줄바꿈·공백을 추정합니다. 다단 편집, 표, 세로쓰기, 특수 글꼴은 읽기 순서나 문자가 다를 수 있습니다. 최대 200만 자까지 추출하며 중요한 내용은 원문과 비교하세요.
