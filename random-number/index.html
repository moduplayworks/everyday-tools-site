랜덤 숫자 추첨

범위 안의 정수를 중복 없이 추첨합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 -1000000000 · 최대 1000000000

정수 · 최소 -1000000000 · 최대 1000000000

정수 · 최소 1 · 최대 1000

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

지정 정수 범위에서 중복 없이 여러 숫자 뽑기.

정수 구간에서 편향 없는 난수로 뽑고 중복 제외

입력 예시

1~45에서 6개 추첨 시 서로 다른 정수 6개

1부터 10까지 3개를 뽑으면 서로 다른 정수 세 개가 나옵니다. 최솟값과 최댓값도 후보에 포함되며 결과 순서는 오름차순 정렬이 아닙니다.

사용 방법

  1. 입력된 예시값을 사용하거나 최솟값, 최댓값, 뽑을 개수 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

후보 수보다 많이 뽑을 수 있나요?

중복을 허용하지 않으므로 불가능합니다. 1~10에서 11개를 요청하면 오류로 안내합니다. 반복 실행의 결과를 예측하거나 당첨을 보장하는 기능은 없습니다.
