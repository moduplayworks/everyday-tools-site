URL 구조 분석기

웹 주소를 프로토콜·호스트·포트·경로·쿼리·해시로 분해합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

주소에 접속하지 않고 문법만 분석합니다. 사용자명·비밀번호가 포함된 URL은 받지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

HTTP 주소의 호스트·경로·쿼리·해시 구분하기.

표준 URL 파서로 HTTP/HTTPS 주소의 구성 요소 추출

입력 예시

https://example.com/a?q=1#top → 경로 /a

https://example.com/a?x=1#part에서 경로는 /a, 쿼리는 ?x=1, 해시는 #part입니다. 구조만 읽으며 해당 주소로 접속하지 않습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 HTTP/HTTPS URL 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

분석이 성공하면 안전하거나 접속 가능한 URL인가요?

아닙니다. 문법을 읽을 수 있다는 뜻이며 보안·존재 여부를 검사하지 않습니다. 상대 주소와 HTTP/HTTPS 외 프로토콜, 계정 정보가 포함된 주소는 받지 않습니다.
