How to use and processing criteria

This is the process of calculating new names for files and creating a ZIP copy with the changed names.

Actual example

Change a.jpg and b.jpg to the default names photo, start number 1, and 3 digits, resulting in photo_001.jpg and photo_002.jpg. If “Keep original extension” is on, the original extension (e.g., jpg) is retained.

Frequently Asked Questions

Do I want to change the file name of my device directly?

The original file is not changed. Check the new name preview, then create and download a ZIP copy. The preview must be checked again if the input changes.

How should duplicate names and substitution ranges be handled?

The substitute applies to all characters found in the name except the extension. The first and last characters are added to the renamed name, and the extension is placed at the end. Duplicates and dangerous path names in case, case, Unicode normalization are rejected.
