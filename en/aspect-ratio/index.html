Calculation·conversion criteria

Calculate a new height while maintaining the original aspect ratio.

New height = new width × original height ÷ original width

Input example

Reduce 1920×1080 to 1280 width → 720 height

Reducing 1920×1080 to 1280 width gives 1280×1080÷1920=720 height. The aspect ratio between original and new sizes is the same.

How to use

  1. Use the entered example value or change the original width, original height, or new width items.
  2. Click Verify result and check the following result.
