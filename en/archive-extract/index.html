Frequently asked questions

What compression files and file name encoding are supported?

Supports general ZIP storage using Deflate method. Names with UTF-8 indication are read in UTF-8; if no indication, use default UTF-8 or the selected CP949·Windows-1252. Does not support RAR, 7z, encryption, splitting, ZIP64, or symbolic links.

When uncompressing, does the file automatically run or save to the original folder?

No auto execution or original folder writing is performed. Users only download files they select, and individual downloads include a number and a default filename. Up to 200 files, 50MB per file, total 100MB. Path, size, and CRC checks are not malware scans.
