How to use and processing criteria

A process of placing the same text or logo on multiple photos at roughly the same positions.

Actual example

Width 1,000px: when selecting 30% size in a photo, the horizontal width of text or logo becomes approximately 300px. The lower-right position is placed about 3% from the edge of the photo, and relative size is recalculated for each photo.

Frequently asked questions

What file types can be used for logo images?

JPG·PNG·WEBP supports logo; up to 2MB·4 million pixels or less. Use PNG or WEBP for transparent background. Select characters/logos with permission to use

Will adding watermarks to multiple photos overwrite the original?

Keep the original image and create a new image or ZIP file. The preview shows the first image; all images can be viewed in the save result. Water marks are not a way to completely prevent unauthorized use or removal.
