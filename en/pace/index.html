Calculation·conversion criteria

Find the pace per 1km based on distance and total time.

Speed = total time ÷ distance, speed = distance ÷ time

Input example

Traveling 5km in 30 minutes: 6 minutes/km, 10 km/h

If you run 10km in 50 minutes, 50÷10=5 minutes/km and the average speed is 12 km/h. The faster the number, the better the pace; the higher the number, the faster the speed.

How to use

  1. Use the provided example value or replace the distance (km) and total time (minutes) fields.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.
