Calculation·conversion criteria

JSON syntax checking and indentation cleanup

Validate with JSON.parse, then serialize with JSON.stringify.

Input example

{"a":1} is formatted with 2 indentation

Object keys and strings must be enclosed in double quotes. {"a":1} is valid, but {'a':1} is not JSON and does not allow comments or trailing commas.

Frequently asked questions

After organizing long number IDs, could the value change?

Large integers that cannot be represented as JavaScript numbers may lose precision during parsing. Handle identifiers as strings enclosed in quotes. This tool is not a parser that preserves original number formatting.

Does duplicate JSON keys also cause an error?

This tool follows JSON.parse behavior, so if the same key appears repeatedly in the same object, the last value may remain. Do not use it for duplicate key detection or preserving original text required for verification.

Does formatting JSON also validate an MCP server configuration?

JSON syntax checking and formatting do not guarantee correct configuration fields or paths. For the Claude Desktop local stdio profile, check command, args, env and path notation separately in Local MCP Configuration Checker. Neither tool installs, runs or tests a server connection.
