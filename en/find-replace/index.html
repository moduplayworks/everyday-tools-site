Calculation·conversion criteria

Replace all identical strings with different uppercase and lowercase versions.

Replace entire non-regular expression strings case‑sensitive

Input example

Apple juice → grape juice

Changing apple to pear in “apple apple” becomes “pear pear”. Replace non-overlapping matching parts in the entire string.

How to use

  1. Use the entered example value or change the original, text to find, or text to change items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can points or stars be used as a regular expression?

No. It finds actual points and stars. Case is distinguished, so changing A does not change a, and no empty search strings are accepted.
