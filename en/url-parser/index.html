Calculation·conversion criteria

Distinguish host, path, query, and hash in HTTP URLs.

Standard URL parser: extracts components from HTTP/HTTPS addresses

Input example

https://example.com/a?q=1#top → path /a

For https://example.com/a?x=1#part, the path is /a, the query is ?x=1, and the hash is #part. Only the structure is read; no access is made to the corresponding address.

How to use

  1. Use the provided example value or replace the HTTP/HTTPS URL field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

If the analysis succeeds, is it a safe or accessible URL?

No. It means the grammar can be read, but it does not verify security or existence. It does not accept addresses containing relative addresses, HTTP/HTTPS以外 protocols, or account information.
