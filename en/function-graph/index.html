    Calculation criteria and usage method

    Compare the shape and specific coordinates of multiple linear functions within a limited range.

    Default example: sin(x), cos(x), x/4 have values 0, 1, 0 when x=0 in radian mode. The intersection and height of the three curves are within −6.28 to 6.28 for x and −1.5 to 1.5 for y. Values can be read via the x slider on the graph.

    How to use

    1. Enter functions one line at a time. Use x as an independent variable, and compare up to three functions together.
    2. Define x·y display range and angle unit, then click result. Use graph slider to check value at a specific x.
    3. Check the lines and sample intervals for each function, then save as SVG.

    Supported range and boundaries

    Formulas are interpreted by a secure parser with limited operations and functions and are not executed as JavaScript code. The graph is an approximate value extracted from 401 points within a finite range, and each interval is further checked. Lines are cut at points near the tan asymptote, undefined points, outside the display range, or sharp jumps. If the phase of the trigonometric function changes beyond π radians between samples or the change rate cannot be safely limited, the curve is omitted and the x range is narrowed to avoid misunderstandings. It is not guaranteed that all narrow discontinuities are found. Only real values are processed; symbolic numbers, complex numbers, derivatives, and integrals are not supported.

    Frequently Asked Questions

    If the graph appears discontinuous, does that mean the function is discontinuous?

    Not necessarily. This graph creates a sample with 401 points and adds additional checks for each interval. Lines are cut at the tangent point, values that are undefined or outside the range, and large jumps. If the phase of the trigonometric function changes beyond π radians between samples or the rate of change cannot be safely defined, the corresponding curve is omitted and the range is narrowed. Since it’s a finite sample, narrow discontinuities may remain; directly check the domain and range of the formula.

    How is degrees radian used in graphs?

    In radian mode, x in sin(x) is in radians. Choosing degree mode reads trigonometric factors as degrees, and x-axis values are displayed in degree units. No angle conversion is applied for other arithmetic operations.
