Instructions and example

Open a PDF and mark page 1 at left 10%, top 10%, width 40% and height 10%. That rectangle turns black on the displayed page. Review other pages, then create the copy: all pages are rendered as 144dpi PNG images inside a new PDF. Original objects are not copied, so original text layers and attachments are absent. The source file is unchanged.

Frequently asked questions

Does original text remain behind the black box?

This tool does not merely add an overlay annotation. It paints selected pixels and embeds only the resulting images in a fresh PDF; original selectable text is not copied. Unmarked regions remain visible, and personal information is not detected automatically.

What features are lost?

Search, text selection, links, forms, bookmarks, attachments, original metadata, signatures and accessibility structure are not preserved. Rasterization may increase file size and blur small text. Zoom into the downloaded copy and check every page.

Can it process large files?

One PDF up to 25MiB and 30 pages, with up to 200 regions. Limits are 16 million pixels per page, 120 million total pixels and 100MiB output. Encrypted or damaged files may fail. Cancel and clear controls are available; reload clears files and results.
