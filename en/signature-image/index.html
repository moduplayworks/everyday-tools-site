How to create a transparent signature PNG

Input example

After loading Public example, click PNG create to generate a transparent image with 20px margin around the signature stroke. At 2x output, pixel size and margin also double. The example stroke is for action verification and is not your signature.

The drawing area remains at 1,000×400 coordinates, so the stroke doesn’t change when the screen size changes. For cutting around each stroke, 20px padding is added outside the edge, including the stroke thickness. To prevent cutting at the edges, 6px padding is added to create a 1,012×412px file. 2printing doubles the stroke by drawing it twice the pixel size.

Supports up to 256 pixels·100,000 coordinates. Draws one stroke at a time. If input is canceled, only the ongoing stroke is canceled. No change in thickness based on pen pressure. Used for inserting images into transparent PNG documents. Not a self-verification or digital signature verification service.

Frequently Asked Questions

Does the white check pattern appear in the file?

No. Check marks are screen indicators that separate transparent areas. PNG includes only green strokes and transparent pixels.

Can it continue from another device?

The signature is not saved to the server or browser storage. Download the required PNG directly. It will be deleted after reloading, leaving the page, or returning from records.

Is legal electronic signature completed with this file?

This tool is a handwriting image generator. It does not provide self-verification, document signature authentication, digital signature verification, or legal validity judgment functions.

How to draw on mobile phone and keyboard?

On mobile phone, move one finger or pen within the drawing area. Outside the area, scroll the page. On keyboard, focus on the drawing area, use arrow keys to move, Space to start/end stroke, Enter to end, Escape to cancel ongoing stroke. Press Shift and arrow keys together to move larger.
