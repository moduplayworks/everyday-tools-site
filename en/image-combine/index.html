Merge multiple photos into vertical, horizontal, or grid formats. Adjust order, spacing, and background, then save as a single image.

Supported range and original storage

Input is up to 24 million pixels per unit and 50MB total. The original file is not changed. Moving images are treated as static images, and HEIC is not supported. Frequently asked questions

Will the order and photo ratio be preserved during merging?

You can reorder items in the selection list using the Next/Previous buttons. Maintain the ratio based on common horizontal/vertical dimensions. The grid fits within the cell without cutting the original, and the remaining part is filled with background color.

Are there size limits when creating long photos?

The result is up to 16,000px per side and 24 million pixels. Up to 2–10 photos, 20MB per photo, 24 million pixels, total up to 50MB. If too long, reduce the common size or the number of photos.
