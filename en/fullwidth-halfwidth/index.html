Calculation·conversion criteria

Swap halfwide alphanumeric characters and ASCII alphanumeric characters.

Halfwide U+FF01~FF5E ↔ ASCII U+0021~007E, halfwide spaces ↔ spaces

Input example

ＡＢＣ１２３ → ABC123

Converting ＡＢＣ１２３ to half-width produces ABC123. The conversion also includes supported symbols and full-width spaces.

How to use

  1. Use the provided example value or change the text and direction items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Is Hangeul also converted as a half-kana?

No. This tool only handles ASCII equivalents of letters, numbers, symbols, and spaces. For broader Unicode normalization, check the impact of Unicode normalization.
