Calculation·conversion criteria

Calculate the number of days between two dates, including both start and end dates.

Default difference = end date − start date, including both ends = |difference| + 1

Frequently Asked Questions

What if start and end dates are the same or in reverse order?

The same day has a difference of 0 days and 1 day of included days. If the end date comes before, the date difference is negative; the end includes both ends, resulting in a positive number of days unrelated to direction.

Does the time zone cause differences in dates?

This tool calculates the difference between calendar dates without visual cues. Do not use it for calculating actual elapsed time, including flight time or summer time.
