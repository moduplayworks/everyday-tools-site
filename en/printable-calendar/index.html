Calculation·file generation criteria

Print the monthly calendar with selected notes and start date, then save the image.

Difference between the day of the first month and the chosen week start date → empty space in front → date of the month and user note added

Input example

October 1, 2026 is Thursday. The Monday start calendar leaves 3 empty slots before October 31. February reflects whether it’s a leap year for the selected year.

October 1, 2026 is Thursday. Choosing Monday as the start fills the 3 empty slots. Click the date in the result to edit notes and verify again. February 2024 has 29 days, and February 2100 has 28 days.

How to use

  1. Type the provided example or change the required value. Expand additional settings for verification.
  2. After checking the result, review the city, schedule, calendar, and time blocks. Errors are not excluded; corrections are provided.
  3. Copy the result or save as a real file. Import and print use device support functions.

Supported range and boundaries

From 2000 to 2100, print and save as PNG or SVG monthly. Notes are 28 characters per date, up to 366, and placed in each cell. Public holidays, lunar dates, and country-specific holidays are not provided. Notes are only retained in browser memory and return to public examples on refresh.

Frequently asked questions

Do holidays also auto-display?

No holiday data included. Enter notes directly for the required date. A note for a single date has up to 28 characters, and notes for other months remain until refresh.

What if printing and PNG saving are different?

PNG·SVG printing uses the last verification result. The print is sized for A4 width and may vary depending on browser margins, header, and scaling settings. The input returns to the public example on refresh.
