Calculation·conversion criteria

Calculate the trapezoid area using two parallel sides and height.

Width=(top+bottom)×height÷2

Input example

Top edge 3, bottom edge 7, height 4: area = 20

If top edge 4, bottom edge 8, and height 3, the average base edge is 6 and the area is 6×3=18. Height is the vertical distance between two parallel edges

How to use

  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can the length of the tilted side edge be written as height?

No. The oblique side angle and vertical height are generally different. Even if the trapezoid is shifted sideways, if the two base lengths and vertical height are the same, the width is the same.
