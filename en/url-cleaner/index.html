Remove UTM Tracking Parameters

Remove utm_ parameters from a URL while preserving other query values, encoding, duplicates and fragments. No link fetching or redirects.

Remove UTM Tracking Parameters

The current values are editable public examples. Replace them with real information before generating.

Only names starting with utm_ are removed, case-insensitively. Other parameters and fragments are preserved. This is not anonymization or a security check. Keep originals; do not modify signed, payment or login links.

How it works and limits

The example https://example.com/product?id=42&utm_source=newsletter&utm_medium=email#details keeps id=42 and #details while removing two UTM parameters. Names are percent-decoded and checked for the utm_ prefix without case sensitivity. Other values retain their order, duplicates, plus signs and percent-encoding without reserialization. No URL is fetched and no redirect is followed.

Frequently asked questions

Does it remove all tracking?

No. Only query names starting with utm_ are removed. gclid, fbclid, ad IDs, cookies, paths, fragments and personal information embedded in a URL are not inspected or removed.

Should I use it on login or payment links?

Use signed, payment and login links unchanged: altering parameters can invalidate them. This tool does not check link safety or whether the cleaned destination works.

Is the original URL stored or opened?

No. Inputs and results stay in the current page memory. Check the result before copying and retain your original separately. Without UTM parameters, only surrounding whitespace is trimmed.
