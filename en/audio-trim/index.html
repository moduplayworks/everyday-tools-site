How to use audio trimming·merging

Playing the 0–3-second segment of the 3-second public audio sample creates a WAV that is about 3 seconds long. Select two files to join them in list order, and adjust each start and end time separately. The default 0.3-second fade at each segment boundary reduces abrupt transitions and slightly shortens the output.

Check the segments in the waveform and connect them in order.

Adjusts the start and end times of each file to leave a window of 0.25 seconds or more. When selecting multiple files, they are concatenated in the selected order, and short fade effects can be applied per window. The result is WAV PCM 16-bit; ID3 and album information are not preserved.

Mobile processing range

It supports up to 3 files at a time, each up to 50MB and 3 minutes, and the total audio up to 3 minutes. If the browser cannot decode or if memory is insufficient, the previous result is retained and an error is displayed.

Frequently Asked Questions

How are multiple files combined?

Follow the order shown in the file selection list. Check the start and end times for each file before running. Removing one item from the list keeps the rest intact.

Can it be stored in MP3 or M4A format?

This editor creates 16-bit WAV PCM that can be read anywhere. For compressed format storage, check the result supported by the current browser in a separate audio format converter.

Can long music files be edited?

Only MP3 and WAV files are accepted to allow verification of channel count before decoding; only 1–2 channels can be trimmed. Supports 50MB per file and 3 minutes, with a total limit of 3 minutes.

Calculation criteria and reference materials

  • MDN — Web Audio API full file decoding

    Action of decoding a complete file as an AudioBuffer and resampling at the AudioContext sample rate. This implementation limits input length, file size, and number of channels.

  • MDN — OfflineAudioContext output rendering

    A method of rendering the cut audio as a new AudioBuffer without sending it to a playback device. Segment fade-in and out are applied during this local rendering process.

  • Microsoft Learn — RIFF resource exchange file format

    Refer to RIFF chunk-based structure of WAV container. Output is 16-bit PCM and does not preserve album·ID3 metadata.
