Calculation·conversion criteria

Read 6-digit HEX colors as RGB and HSL.

Normalize sRGB channels to 0–1 and calculate HSL using max and min channels

Input example

#ff0000 → rgb(255, 0, 0), hsl(0, 100%, 50%)

#FF0000 is rgb(255, 0, 0), hsl(0, 100%, 50%). 50% brightness in HSL is not the same as relative luminance used by WCAG.

How to use

  1. Use the provided example value or replace the HEX color field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Do you support transparent colors or short HEX codes?

This tool accepts only a 6-digit HEX code without alpha. Enter it as plain, unencoded values, such as #F00 or #FF0000. It does not provide transparency or other color space conversions.
