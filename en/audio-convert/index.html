How to use audio format conversion

Selecting the 3-second public example audio without conversion saves it as WAV or a compressed format supported by the current browser. The compression format takes the same playback time, and 128kbps is the default quality. The result shows the actual format, playback time, and file size.

Re-encode into a supported format

WAV is saved as PCM 16-bit in the browser. Compression formats are only displayed as reported by MediaRecorder; they may fail due to insufficient encoding resources. Compression conversion takes as long as playback time, and sample rate·channel·metadata may change.

Limitations on files and devices

Up to 50MB·Process 3-minute input in the browser. Although MP3 files can be read and converted, MP3 output is not guaranteed. Verify the result format and actual playback before saving.

Frequently Asked Questions

MP3 M4A Can it be converted to WebM?

MP3·M4A·WAV·OGG etc. The browser accepts inputs that can be played. Compressed output displays only the format reported by the MediaRecorder as supported by the current device. WAV PCM 16-bit output supports only MP3·WAV input to safely verify channels and memory before decoding. MP3 output is not guaranteed.

Does the kbps setting in audio quality guarantee the result size?

No. The value selected in the compression format is the bitrate target sent to the encoder. It does not guarantee actual size, codec, or playback compatibility. Play the result and check the file size.

Do you need to wait during conversion?

WAV output decodes input and creates a PCM file immediately. Compression output records audio in real time, so close delays close to playback time are required. Maximum input is 50MB·3 minutes.

Calculation criteria and reference materials

  • MDN — Web Audio API full file decoding

    Action of decoding a complete file as an AudioBuffer and resampling at the AudioContext sample rate. This implementation limits input length, file size, and number of channels.

  • MDN — AudioContext media element connection

    Connect the audio and video elements of the selected local audio/video to the browser audio graph and stream target. Video frames are not included in audio output.

  • MDN — MediaRecorder format support verification and recording

    A criterion to first check the MediaRecorder output format of each device. Support reports do not guarantee actual encoding success or resource availability.

  • Microsoft Learn — RIFF resource exchange file format

    Refer to RIFF chunk-based structure of WAV container. Output is 16-bit PCM and does not preserve album·ID3 metadata.
