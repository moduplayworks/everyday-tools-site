Calculation·conversion criteria

Get the sum and arithmetic average of a number list.

Average = total ÷ number of items

Input example

The average of 10, 20, and 30 is 20.

The sum of 10, 20, and 90 is 120, and there are 3 data points, so the average is 40. If one large value has a large impact, check the median too.

How to use

  1. Use the entered example value or change the number list (separated by commas, spaces, or line breaks) item.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

How are empty items and number 0 reflected in the average?

Items with no content are not counted, but the number 0 counts as one value. The average of 0 and 10 is 5. Use a weighted average if the importance of each item differs.
