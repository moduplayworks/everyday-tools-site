    How to add text, shapes, and highlights to a PDF

    Input example

    In a public document 600pt wide, 3% of the text size is 18pt. Add the text at the center of 50% of the page width and 30% of the height on one page, and add a separate highlight, and both highlights will be saved. Edit and delete from the list and check the layout with a real PDF preview.

    After selecting a PDF, select text, rectangular borders, and transparent highlights, then enter the page to apply. You can add up to 50 highlights and edit or delete them from the list. The added highlights appear above. During editing, you must click to apply changes to reflect in the list.

    The preview renders a real PDF. Check the result in the page list and save a copy. The position is based on the upper-left corner of the visible page; convert the rotated or cut page area to the original coordinate. Text size is a percentage of page width, so it varies on different pages. The original page is not converted to an image.

    Hangul is embedded as a font in this service for PDF embedding. The font is downloaded from the same site when the text is first processed, and no documents or input text are sent. It supports Hangul, English, and basic punctuation; unsupported characters such as emojis and Chinese characters will be indicated as errors. Line breaks are preserved as entered; automatic line breaks are not applied. If the length exceeds a page, reduce the size or adjust the line breaks.

    Encrypted, corrupted, or form/signature fields in PDFs are not supported. It does not reedit the text or safely delete sensitive content. Emphasis and shapes remain in the original text. It does not guarantee the validity of the certificate signature, and PDF extra information, links, and attachments are preserved. Keep the original. Display support up to 1,000 total pages, results up to 100MB.

    Frequently Asked Questions

    Can the text in the existing PDF be edited or the content deleted?

    I add new characters, shapes, and highlights above the existing text. The original characters are not re-edited, and the original text remains below the shapes. This is not a tool for safely deleting personal information.

    Does it support multiple pages?

    Hangul fonts are embedded in PDFs, so they can be displayed on other devices. Enter the entire text or a section of the page for each display. It supports up to 50 displays and 1,000 pages, and unsupported characters are indicated as errors.
