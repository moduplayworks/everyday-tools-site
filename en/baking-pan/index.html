Baking pan size conversion

Adjust ingredient ratios based on the existing pan shape and new pan bottom area. Supports round, square, and rectangular pans.

Calculation·conversion criteria

Adjust the material ratio to maintain the same batter height for round, square, and rectangular pans.

Mix multiplier = new fan area ÷ existing fan area; for a circle: π×(diameter÷2)², for a rectangle: width×height

Input example

Changing from a diameter of 18cm to 20cm pan adjusts materials by approximately 1.2346 times.

Diameter 18cm. Changing from a circular pan to a circular pan with 20cm diameter increases the area from 254.47cm² to 314.16cm². The material ratio with the same thickness is 20²÷18²≈1.2346. You can start with about 23.46% more materials.

How to use

  1. Use the provided example value or replace the existing fan shape, existing fan size (cm, rectangular is width×height), new fan shape, and new fan size (cm, rectangular is width×height) fields.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

For a round pan, do you input the diameter or the radius?

Enter the diameter. For example, if the pan is 18cm, enter 18. The circle area is calculated as π×(diameter÷2)².

Can it be changed from a 18cm circle to a 20cm square?

It will be done. Select the desired fan shape, then enter the diameter for circular fans, a side length for squares, and the width and height for rectangles. Assuming straight walls and equal dough height, the ratio of the new fan’s floor area to the existing one is calculated.

If I increase the ingredient amount, should the cooking time also increase by the same ratio?

No. The pan area ratio is a value to determine the amount of dough needed for a same height. Baking time depends on dough depth, ingredients, pan material, and oven, so follow the recipe temperature first and check the baking time.

Does it calculate oval or sloped fans?

This tool supports only circles, squares, and rectangles. Ellipses or tilted walls may not fit the simple floor area calculation, so they are not supported.
