Calculation·conversion criteria

Generating a UUID v4 identifier in the browser.

Generate RFC 9562 UUID v4 using crypto.randomUUID

Input example

Format: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx

UUID v4 is a 16-digit string in the 8-4-4-4-12 format with a hyphen. Multiple UUIDs can be created and copied one per line.

How to use

  1. Use the provided example value or replace the count field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Is there no duplication in UUIDs? Can it be used as a password?

It is a identifier with very low collision risk, but absolute uniqueness is not guaranteed. Keep unique constraints in the database separate. The design treating the UUID authentication password as separate requires further review
