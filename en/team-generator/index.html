Random team division

After mixing the roster, divide the teams so that the number of members differs by less than 1.

Input

The example value has been entered. Check it immediately or change the value.

Integer · minimum 1 · maximum 100

Run with Ctrl or ⌘ + Enter

Input is processed in the browser. Refreshing returns a sample value.

Result

Check or change the value using the example value result.

Browser uses Web Crypto random numbers. Generation results are not saved, and the fairness of the draw is not publicly verified.

Calculation·conversion criteria

Randomly mix the roster to create teams with similar member counts.

Shuffle the roster and assign team numbers cyclically

Input example

Dividing 5 people into 2 teams gives 3 people and 2 people

When dividing 10 people into 3 teams, the numbers are 4, 3, and 3. After mixing the list and assigning them evenly to each team, the difference in numbers is at most 1.

How to use

  1. Use the provided example value or change the number of people per line and team count items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Is a balanced team created considering skill or gender?

Not considered. Randomly assign the entered row; only ensure the number of people matches. Same names are treated as separate items, so use unique markers. For team assignments with conditions, review directly.
