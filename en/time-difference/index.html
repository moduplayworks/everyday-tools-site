Calculation·conversion criteria

Calculate the elapsed time between start and end time.

End time – start time, 24 hours added on the next day

Input example

23:00 to the next day 01:30 equals 2 hours 30 minutes

From 23:30 to 01:15, selecting the next day gives 1 hour 45 minutes. Selecting the same day ends earlier, so it prompts you to adjust the input.

How to use

  1. Use the entered example value or change the start time, end time, or expiration date items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

If start and end are the same, is it 0 hours or 24 hours?

Selecting the same day results in 0 hours; selecting the next day results in 24 hours. It is based on a fixed 24-hour clock that does not calculate dates and daylight saving time.
