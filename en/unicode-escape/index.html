Calculation·conversion criteria

Convert characters to UTF-16 escape strings.

UTF-16: 4-digit hexadecimal escape for each unit.

Input example

Ka → \uac00

Hangul is represented in UTF-16 code unit AC00. Characters outside the basic multilingual plane can be represented in two code units even if they are a single character.

How to use

  1. Use the entered example value or change the input or direction items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Why does one emoji appear as two escapes?

UTF-16: Some characters are represented as double-byte pairs. This tool’s decoding input consists of consecutive backslashes u and 4-digit hexadecimal format; it does not execute arbitrary JavaScript code.
