Calculation·conversion criteria

Calculate what percentage of the total value it is.

Part = Total × ratio ÷ 100

Input example

200 × 15% = 30

200 × 15% is 200×0.15=30. The value excluding 15% is 170, and the added value is 230. Read separately the amount corresponding to the ratio and the value after application.

How to use

  1. Use the entered example value or change the total value or percentage (%) items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Is 15% discount and 15% increase calculations that reverse each other?

No. 200 minus 15% equals 170, and 170 plus 15% equals 195.5. The reference value in the second calculation changes.

What is the difference between percentage and percent point?

When the ratio rises from 20% to 30%, it increases by 10 percentage points, and the relative increase is 50%. Separate the difference in the ratio itself from the change relative to the reference value.
