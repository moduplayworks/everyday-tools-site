How to use and processing criteria

A process of putting multiple files into a single ZIP file and saving as a copy.

Actual example

Select the note TXT image and PNG, then save as archive.zip. Both original files will be in the same name inside the ZIP file. Using regular compression may result in little or no size reduction for already compressed images or videos.

Frequently Asked Questions

Can the ZIP password be set, or can the folder be included?

Currently, files are created as a standard ZIP file; no encryption or folder selection features are available. The selected original file will not be changed. If file names are duplicate, change the name or use the file name batch change tool.

Can you select compression speed and size?

General compression uses Deflate and bundles without compression as a fast save method. Supports 200 files·50MB total and can be canceled during processing.
