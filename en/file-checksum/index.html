How to use and processing criteria

Calculates the SHA-2 hash of file bytes and compares it with the expected value provided.

Actual example

UTF-8 text abc has a SHA-256 hash of ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad. If the content is the same, the hash remains the same even if the file name changes.

Frequently Asked Questions

If the hashes match, does that mean the file is safe?

It means the entered expected value matches the calculation result. The expected value must be verified on a reliable distribution path. Hash match does not guarantee the presence or absence of malware or the distribution provider’s identity.

Can large files be viewed without uploading to the server?

A single file is read in 1MB chunks up to 2GB during the browser work thread. The entire file is not loaded into memory at once, and the work thread ends if canceled. Processing time depends on device performance and file size.
