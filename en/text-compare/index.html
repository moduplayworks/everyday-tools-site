Text line comparison

Compare the same line positions in two texts to find the changed line.

Calculation·conversion criteria

Compare two texts based on the same line number.

If lines at the same position differ, show previous and next values

Input example

Indicates change from b to c in the second line

If the second line of the original is B and the second line of the modified version is C, it is marked as a change. The same line is removed from the difference list.

How to use

  1. Use the entered example value or change the original or text to compare items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

If a line is inserted and all subsequent lines have changed, will it appear?

Possible. This tool compares the same positions, so all line numbers after insertion are shifted. It differs from professional diff algorithms that find the minimum difference in code changes.
