Save only the segment you need from the video

Choose a file or start with a sample video, then enter the start and end times. It will be re-encoded into a short video. For example, if you cut 0 to 2 seconds from a 4-second video, a 2-second file will be created.

The browser plays the video and re-encodes it.

The save format and codec depend on the browser: MP4 or WebM. The original format and quality cannot be guaranteed, and it may take longer depending on the device. Play the result to verify. 4K videos are saved reduced to 1920px or less.

Personal information and restrictions

Selected video is not uploaded or sent to the server. It processes 0.5–30 seconds of up to 100MB·10 minutes long videos. The processing stops when the browser tab is closed. Some files may not be processed depending on device memory and browser support

Frequently Asked Questions

Does the original file change when cutting the video segment?

The original image is not edited. Select the part and re-encode it as a separate file for download. The input video is processed in the browser.

Is the quality and length of the extracted video the same as the original?

The segment length follows the specified start and end times, but may vary slightly due to browser re‑encoding. The longest side is displayed at 1,920px with 30 frames per second, and 4K sources may be downsized. No guarantee is given for file size or lossless output.

Can all MP4·WebM·MOV files be opened?

Both the file container and video codec must be supported by the current browser. Unopenable files should be selected again as a standard MP4(H.264)·WebM(VP8) file in another browser. Output is MP4 or WebM supported by the browser.

Will you send selected video or file name to the server?

No. Video and file names are used only for browser local processing. Usage statistics record only the tool usage fact, excluding file content, names, and selected segments.

Calculation criteria and reference materials

  • MDN — MediaRecorder

    Re-encoding the capture stream using the browser’s supported container and codec. The supported format and output quality depend on the browser.

  • MDN — Canvas captureStream

    Draw the current video frame onto the local Canvas and capture it as a video stream for browser recording.

  • MDN — AudioContext createMediaElementSource

    Connect the audio of video elements to the local Web Audio stream and re-encode it together with the video.

  • WebKit — MediaRecorder API

    Describes Canvas·Web Audio stream recording and format detection in WebKit implementation. Current device codec support is detected during execution.
