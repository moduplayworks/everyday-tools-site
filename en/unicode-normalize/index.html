Input example

e + combining accent → NFC é

A single character é followed by a combining accent can represent different code representations. NFC is the combined form, while NFD is the split form.

Frequently Asked Questions

Can using NFKC change the meaning of the original characters?

Compatibility normalization can integrate representations like Hangul or original characters. It is useful for searching and comparison, but original formatting may be lost, so verify the results for document preservation.
