How is the calculation performed?

Counts each visible character cluster, including Hangul, English letters, and emoji, as one character. For example, a Korean word followed by A has 4 characters including the space, 3 excluding the space, and 8 UTF-8 bytes.

Number of characters excluding spaces = characters after removing spaces, tabs, and line breaks
UTF-8 byte = size when text is encoded in UTF-8

It unifies line breaks and single CR LF in Windows, allowing calculation based on a single character. Hangul typically uses 3 bytes, while English does 1 bytes. Combined characters and emojis can have significantly different character counts and bytes. Input limits are based on the browser’s UTF-16 input unit.

Frequently asked questions

How much room is left in a 500-character personal statement?

Set the limit to 500 and choose characters with spaces, without spaces, or UTF-8 bytes to match your destination. For example, 420 characters including spaces leaves 80 characters. If you exceed the limit, the counter shows the excess without cutting your text.

Why is the submission site for a personal statement different from the character count?

The submission site may have different byte encoding standards for emojis, combined characters, and line breaks. This tool uses visible character sets and UTF-8, so check actual submission constraints.

How are words and lines counted?

The number of words is the number of morphemes separated by spaces. Empty lines are counted as 0, and empty lines separated by line breaks and the last empty line each count as one line.

Is the inserted text saved or sent externally?

Text is calculated only in the memory of this page and is not stored in localStorage·analysis events·URL. It disappears when refreshed. Visit statistics and advertising processing can be checked separately in personal information settings.
