Calculation·conversion criteria

Extract multiple numbers without duplicates from a specified integer range.

Select a random number without bias from an integer range; duplicates are excluded

Input example

When 6 numbers are drawn from 1 to 45, it selects 6 different integers.

When 3 distinct integers are selected from 1 to 10, the minimum and maximum values are included, and the results are not sorted in ascending order.

How to use

  1. Use the provided example value or change the minimum value, maximum value, and number of picks items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can more candidates be selected than the candidate pool?

It is not possible because duplicates are not allowed. Requesting 11 items between 1–10 will trigger an error. There is no feature to predict results of repeated executions or guarantee a win.
