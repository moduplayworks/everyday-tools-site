Calculation·file generation criteria

edit day and time blocks to create a weekly schedule image.

Each block’s day, start, and end time → placement proportional to the height of the selected time range. Segments on the same day that start < previous end overlap.

Input example

Monday 09:00–10:30 lectures are 90 minutes. The 10:30–11:00 block does not overlap, but if starting at 10:00, 30 minutes will overlap and an error message will appear.

Monday 09:00–10:30 lecture block is 90 minutes. If the next block on the same day starts at 10:30, it can continue; if at 10:15, it overlaps. Create blocks of 15 minutes or more within the displayed time range and check again.

How to use

  1. Type the provided example or change the required value. Expand additional settings for verification.
  2. After checking the result, review the city, schedule, calendar, and time blocks. Errors are not excluded; corrections are provided.
  3. Copy the result or save as a real file. Import and print use device support functions.

Supported range and boundaries

Add 1–40 manual time blocks, each with a title of up to 28 characters and a duration of at least 15 minutes. Blocks cannot cross midnight or overlap. Titles shortened in the chart appear in full in the numbered list below the image. Use the course completion planner to distribute study time automatically.

Frequently Asked Questions

Does it automatically distribute lectures by date?

No. This is a weekly timetable where you edit each time block yourself. Use the course completion planner to distribute remaining lectures automatically through the deadline. You can add up to 40 blocks and undo the most recent deletion once.

If a long name is cut off in a small block, will the saved file also be cut?

The time cell shows a number and a short name, along with the full name and time in the list at the bottom of the image. The result text includes all blocks. Refreshing clears the personal block and output.
