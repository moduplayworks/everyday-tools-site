Calculation criteria and usage method

Plan to distribute textbook pages and problem numbers among remaining study days by session.

Remaining quantity = range of each section − recorded completed quantity − capacity = possible days × maximum daily quantity

Input example

For the first textbook 1~100 pages, if 20 pages have been completed and 1~60 pages remain, the remaining amount is 80+60=140 pages. If 7 days are spent studying, and the upper limit is 20 pages, 20 pages are allocated per day. The first day is for 21~40 pages of the first textbook. If the upper limit is lowered to 10 pages, only 70 pages are allocated, and 91~100 pages of the first textbook and 60 pages of the second textbook remain unallocated.

How to use

  1. Use the provided example or modify the settings and selected items. Add items to enter multiple evaluations, textbooks, and topics in order.
  2. Click Create Progress Plan. Incorrect inputs are moved to the relevant item and field for guidance
  3. Check the result and save as CSV. You can import the plan as ICS if needed. If you want to continue input, save a separate JSON backup.

Limitations and interpretation

Page and problem numbers include both ends. Directly record the target page count, the completed page count, and the number of completed revisions. Past plans are not automatically completed. Up to 20 items, 100,000 items per item, 20 revisions, 366 days. It does not predict difficulty or study time.

Frequently asked questions

Enter page number for completion location?

Enter the number of errors completed this time. If the range is 10–29, it’s 20 in total. If 10–19 have been completed, the completed count is 10. If the entire exercise is completed, increase the number of errors completed and enter 0 for the number of errors completed this time.

If something is not done by the deadline, does the date automatically extend?

No extension is provided. Only one day is assigned sequentially within the available date range; the rest is marked as unassigned. Check the required number of days and modify the limit or duration directly.

How do you change after failing to complete yesterday’s plan?

Record the completed and finished sections of the cycle, change the start date to a new start date, and run again. Past plans are not automatically completed, and the original number is retained for each cycle.
