Calculation·conversion criteria

Find the median value and most frequent value in skewed data.

For even numbers, the median is the average of the two middle values

Input example

The median of 1, 2, 2, and 9 is 2

When 1, 2, 2, and 100 are sorted, the two middle values are 2 and 2, so the median is 2. Since 2 appears twice, the mode is also 2, but the arithmetic mean is 26.25.

How to use

  1. Use the entered example value or change the number list item.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Could there be multiple or none of the most frequent values?

If multiple values repeat at the maximum frequency, all are displayed. If every value appears exactly once, this tool shows ‘no repetition’. The median is the average of the two middle values when the data count is even.
