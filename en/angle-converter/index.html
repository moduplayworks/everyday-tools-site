Calculation·conversion criteria

Convert degrees to deciradians and gradians.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 degree = 0.01745329252 radian

A full circle of 360 degrees is 2π radians, so 180 degrees is π, and 90 degrees is π/2 radians. The radian result is displayed as the approximate value of π.

How to use

  1. Use the provided example value or replace the value and input unit field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Does it automatically reduce the angle if it exceeds 360 degrees?

No. It converts the angle including the number of rotations directly. 720 degrees is two revolutions or 4π radians. To compare only directions, calculate the remaining one revolution separately.
