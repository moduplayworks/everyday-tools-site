Usage examples and processing criteria

Enter address https://example.com/guide?lang=ko#start source=newsletter, medium=email, campaign=autumn_launch; utm_source, utm_medium, utm_campaign are added while lang=ko and #start are preserved. Hangul, spaces, and & are encoded as query values, so they do not get misplaced as new parameters.

Frequently asked questions

What are the other UTM queries?

The lowercase utm_source·utm_medium·utm_campaign·utm_term·utm_content 5 units are replaced with new input values, and duplicate entries for the same key are consolidated into one. If term·content is empty, the existing value is also removed. Other query values and #positions remain unchanged, but due to URL serialization, encoding may vary. Be careful with encoded addresses.

Is there a rule for the input name?

source·medium·campaign are required; term·content is optional. Case is distinguished, and automatic lowercase conversion is not applied. Establish a consistent name like newsletter or email by team. Each value is less than 500 characters. Do not include personal information such as email or full name.

Will statistics be collected only if I create this link?

No. Appropriate analysis settings on the landing page are required to measure campaign traffic. This tool generates an HTTP(S) URL but does not test access or tracking. A completed URL can be copied directly or saved as TXT.
