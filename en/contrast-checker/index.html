Calculation·conversion criteria

Check WCAG text contrast between character color and background color.

Contrast ratio = (bright relative luminance + 0.05)/(dark relative luminance + 0.05)

Input example

Black and white = 21:1

Ratio of black #000000 to white #FFFFFF is 21:1. Separate 4.5:1 for normal text AA and 3:1 for large text AA.

Frequently asked questions

Does the contrast ratio meet all web accessibility requirements?

No. It only checks the contrast between two opaque monochrome texts. Actual background images, opacity, state-based colors, and keyboard operations require separate verification. Boundary values are determined based on the ratio before rounding.

What size does large text represent?

WCAG large text criteria are general font 18pt or more, or bold font 14pt or more. Approximately 24 CSS px or bold 18.67 CSS px; check actual font and display status.
