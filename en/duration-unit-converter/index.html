Calculation·conversion criteria

Convert time lengths from seconds, minutes, hours, days, weeks.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 second = 0.01666666667 minute

90minutes is 90÷60=1.5hours. Note that the fractional 0.5 of 1.5hours is 50minutes, not 30minutes.

How to use

  1. Use the provided example value or replace the value and input unit field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can it be moved to the beginning of a month or a 1-year period?

Months and years in the calendar have irregular lengths, so they are excluded from this tool. Days are calculated as fixed 24 hours, and the number of days between actual dates is calculated using a date difference calculator.
