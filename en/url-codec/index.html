Calculation·conversion criteria

Performs percent encoding on individual URL values.

encodeURIComponent / decodeURIComponent

Input example

One space → %20

Encoding A&B as components becomes A%26B. Used when passing & as part of a value instead of as a separator.

Frequently Asked Questions

Why does the plus sign not become a space?

This tool uses decodeURIComponent rules to keep the + unchanged. To interpret + in form query as a space, use the query string analyzer. It is not intended for encoding the entire URL at once.
