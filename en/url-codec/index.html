Frequently asked questions

Why does the plus sign not become a space?

This tool uses decodeURIComponent rules to keep the + unchanged. To interpret + in form query as a space, use the query string analyzer. It is not intended for encoding the entire URL at once.

Does this tool also escape URL characters for use in HTML?

This tool handles percent encoding of URL components. Use the HTML entities tool separately to represent basic special characters as entities in HTML text. These are different encoding rules; neither tool replaces full HTML parsing or input sanitization.
