How to use and processing criteria

Tool that modifies spreadsheet tables into Markdown format using cell units.

Actual example

Copy two columns—item and quantity—from the spreadsheet, paste them, and click Import. Using the first row as a header turns data like “notebook·2” into a | notebook | 2 | line in Markdown. If the quantity column is right-aligned, the separator line becomes ---:. A pipe in cell A | B prevents adding a new column.

Frequently Asked Questions

What paste formats are supported?

Select a spreadsheet table divided by Tab or the delimiter of a CSV enclosed in double quotes. Read the delimiter, line breaks, and double quotes. You can choose to include a header row; missing cells are filled with blanks. Supports 101 rows × 20 columns with a header, 2,000 cells, and 100,000 input characters.

Can cells be edited on mobile phone?

After selecting a row and column, edit one selected cell, so no wide input table is needed to be dragged horizontally. Provides moving between previous/next rows, adding and removing rows and columns, left, center, or right alignment by column. The last edit can be undone up to 10 steps. If the paste content changes, it must be reloaded.

What are HTML, line breaks, and Markdown symbols?

HTML Markdown symbols in cells are escaped so they appear as text. Cell line breaks are output as <br>; whether they are displayed depends on the HTML permit settings of the service used. The table preview in the tool shows the original cell line breaks. Output is a Markdown file and does not execute spreadsheet formulas.
