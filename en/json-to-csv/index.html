Calculation·conversion criteria

Convert an object array into a CSV for spreadsheet use.

Use the union of all object keys as a header and apply CSV double quotes escaping

Input example

[{"name":"A","score":1}] → name,score row

[{"name":"A"},{"name":"B","score":10}] creates two columns: name and score. The missing score in the first row is left blank. Values containing commas or quotes are formatted according to CSV rules.

Frequently Asked Questions

If you convert then convert back to JSON, will the original type be restored?

No. CSV does not have type information for numbers, booleans, or nested structures. Nested values become JSON strings, and values interpretable as formulas may have protective double quotes added.
