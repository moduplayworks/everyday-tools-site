How to add watermarks to a PDF

Input example

In a 2-page public document, select the whole text and set transparency to 20%, center to 50% and 50%, and rotate 30 degrees counterclockwise. This creates a watermark in both pages. Text size 8% is 48 pt on a 600 pt wide page. The logo becomes 240 pt wide when at 40% width, while maintaining the original image ratio.

Select a PDF and prepare text or JPG/PNG logos. Apply the same watermark to the whole or specified page in terms of center position, size, angle, and opacity. Do not remove the logo background, and maintain the original aspect ratio of the image.

The preview renders a real PDF. Check the result in the page list and save a copy. The position is based on the upper-left corner of the visible page; convert the rotated or cut page area to the original coordinate. Text size is a percentage of page width, so it varies on different pages. The original page is not converted to an image.

Hangul is embedded as a font in this service for PDF embedding. The font is downloaded from the same site when the text is first processed, and no documents or input text are sent. It supports Hangul, English, and basic punctuation; unsupported characters such as emojis and Chinese characters will be indicated as errors. Line breaks are preserved as entered; automatic line breaks are not applied. If the length exceeds a page, reduce the size or adjust the line breaks.

Encrypted, corrupted, or form/signature fields in PDFs are not supported. It does not reedit the text or safely delete sensitive content. Emphasis and shapes remain in the original text. It does not guarantee the validity of the certificate signature, and PDF extra information, links, and attachments are preserved. Keep the original. Display support up to 1,000 total pages, results up to 100MB.

Frequently Asked Questions

Can both text and logo be added simultaneously?

Select one text or logo at a time to apply it to multiple pages. To include both types together, apply the other type again on a copy of the first result. The original file is not changed.

Does adding a watermark prevent copying or content leakage?

Only adds visible markers; no copy, editing protection, or copyright verification features. The original document content remains unchanged. Distribute with low opacity to ensure readability.
