    Frequently asked questions

    Does this find similar photos or documents?

    No. Only completely identical file bytes match. Visually identical photos can differ in metadata, compression or size. Names, dates and visual similarity do not determine matches.

    Are duplicate files deleted automatically?

    Original files are only read, never deleted or modified. Extra-copy bytes are arithmetic estimates over selected entries, not proof of separate physical files or recoverable disk space.

    Which files and sizes can be checked?

    Select up to 100 files, at most 50MiB each and 250MiB in total; empty files are supported. Folders and entire drives are not searched. A downloaded report includes filenames, so review it before sharing.

    Calculation criteria and reference materials

    • noble-hashes — Incremental hashing

      Reference for updating SHA-256 incrementally as file chunks are read. Same-hash candidates are also confirmed by byte comparison.

    • MDN — SubtleCrypto.digest

      Explains that digest does not support streaming input. This tool uses incremental hashing and chunked comparison instead of whole-file buffers.
