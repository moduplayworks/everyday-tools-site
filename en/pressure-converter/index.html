Calculation·conversion criteria

Pa·kPa·bar·atm·psi Convert pressure units.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 Pa = 0.001 kPa

1atm standard atmospheric pressure is 101,325Pa or 101.325kPa. This is a unit-only conversion for values under the same pressure standard.

How to use

  1. Use the provided example value or replace the value and input unit field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently asked questions

Can convert gauge pressure to absolute pressure?

No. Barometric pressure and absolute pressure have different reference points. This tool keeps the input reference unchanged, so adding or removing ambient atmospheric pressure requires separate action.
