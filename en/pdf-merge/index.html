Merge PDFs

Rearrange and merge a PDF file into one. Up to 20–200 pages can be processed in the browser and a copy is saved.

Enter PDF merge input

2–20 files · Total 50MB·Up to 200 pages. Summed together in file order.

    Encrypted or form PDFs are not supported. Documents requiring signature, bookmark, and attachment preservation should be worked on as regular copies.

    Input and file are processed in this browser. It resets when refreshed.

    How to use and processing criteria

    A process of combining multiple normal PDF pages into a new document in the desired file order.

    Actual example

    Select 2-page PDF and 3-page PDF in this order to get a total of 5 pages. You can swap the order using the up/down buttons next to the file. The original file remains unchanged.

    Frequently Asked Questions

    What happens when merging PDFs with passwords or signatures?

    Encrypted or corrupted PDF form fields indicate errors. Digital signature, attachment, and bookmark preservation are not supported; work on a regular document copy and verify the results.

    Are there limits on the number of pages or files during PDF merge?

    Supports 2–20 files, total 50MB·up to 200 pages. Processes files sequentially; stop by clicking cancel. Files are not sent to the server.
