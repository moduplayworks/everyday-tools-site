How to fill out PDF form

Enter standard AcroForm input fields and select fields in PDF in browser and save a copy of the entered values.

  1. Select my PDF or use the public sample form immediately
  2. Enter the input fields, checkboxes, and selection items recognized in the document.
  3. Save a copy of the completed PDF to verify in a PDF viewer.

Example

For the first visit, a name input field, purpose dropdown, and consent checkbox in the public example format are pre-set. The example values can be changed in the browser and saved directly on first use. Selecting a real PDF changes the fields recognized from the document to the same input screen.

Supported range and personal information

Standard AcroForm supports single-line and multi-line text, checkboxes, dropdowns, list items, and radio items. XFA, digital signatures, and button fields, as well as encrypted or corrupted files, are not processed. The field remains editable in PDF after filling. This tool only works in the browser, but does not guarantee preservation of additional information such as PDF attachments, bookmarks, and digital signature validity.

Frequently asked questions

Which PDF form fields can be filled?

Standard AcroForm supports text fields, checkboxes, dropdowns, list selections, and radio items. The PDF form must be editable. Scanned paper or blank PDFs cannot be manually text-filled; XFA, button, and digital signature fields are not processed.

What if the format is XFA or no fields are indicated?

Some government or business documents are created in XFA format, or the fields shown on the screen aren’t actual PDF input fields. This tool only reads standard AcroForm. Check if the provider can provide an AcroForm or a copy of the regular PDF.

Is the entered personal information sent to the server?

Opening and saving PDFs are handled by the browser. Do not enter file, field name, or input values in the server, analysis event, or sharing URL. Download the results directly, and verify the saved copy for sensitive documents.

Does Hangul appear in other PDF viewers?

If a Hangul font containing supported characters is needed, include it in the PDF copy. The field shape and character size may vary by PDF format, so use the PDF viewer that stores the document to verify.

Can you edit the saved PDF again?

Since values are saved without flattening the input field, the input field can be edited in a regular PDF viewer. The original e-signature validity, attachments, and bookmarks may not be preserved, so do not use the e-signed original.
