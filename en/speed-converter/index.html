Calculation·conversion criteria

Convert average speed from km/h·m/s·kn.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 m/s = 3.6 km/h

36 km/h is 36,000 m÷3,600 sec=10 m/s. Changing the time unit when dividing by distance means converting to length alone does not result in the same speed.

How to use

  1. Use the provided example value or replace the value and input unit field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Do pace and speed increase in the same direction?

No. The higher the speed, the shorter the time to 1km. 12 km/h means 5 minutes per 1km. If the form/km format is needed, use a speed calculator.
