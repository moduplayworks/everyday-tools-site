Processing method and criteria

A tool that renders user photos in square icon size and creates a website installation package.

Actual example

320×240 Keep the entire image with 0% padding and create an 32px icon. The content is 32×24px with 4px padding on top and bottom. Choosing center cut fills a square while cutting both sides.

Frequently Asked Questions

What files are in the ZIP?

7 PNG files at 16·32·48·180·192·256·512px, an ICO compressed with 16·32·48·256px, site.webmanifest, head-tags.txt, README.txt are included. The original photo file is not included.

How to apply it to the site?

Unzip the ZIP package and place the files at your site root. Add the tags from head-tags.txt to the HTML head. If you place the files in a subfolder, update the href paths and change the Website name in the manifest. The manifest alone does not create a complete PWA.

Is there any limitation regarding transparency, cutouts, or compatibility?

Total maintenance or center cut, outer padding 0–30%, select transparent·white·user background color. For Apple, 180px fills the transparent area with white. Small original zoom does not improve clarity. PNG compressed ICO may not open in very old Windows or editors.
