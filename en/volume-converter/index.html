Calculation·conversion criteria

Change volume units: liter, cubic meter, US gallon.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 L = 1000 mL

1L is 1,000mL and 1m³ is 1,000L. Cups, ounces, and gallons vary by country and use, so this tool uses the indicated US liquid units.

How to use

  1. Use the provided example value or replace the value and input unit field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently asked questions

Is volume ounce and weight ounce the same value?

No. fl oz is volume, oz is mass. Without material density, conversion is not possible. Use a weight converter to change weight units.
