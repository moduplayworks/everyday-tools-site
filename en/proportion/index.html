Calculation·conversion criteria

Finding the unknown value in proportion A:B=C:X.

X = B × C ÷ A

Input example

2:3 = 8:12

If 2:3=10:X, then X=3×10÷2=15. Equal amounts of the same type must be placed in the same position for the ratio to remain consistent.

How to use

  1. Use the example value or change items A, B, C.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can I use a proportion formula when increasing ingredient amounts?

2 portions require 300 g of ingredient, which if increased to 5 portions gives A=2, B=300, C=5 and yields 750 g. This does not mean the amount increases by the same ratio until cooking time.
