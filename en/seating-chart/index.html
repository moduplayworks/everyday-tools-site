Calculation criteria and usage method

Blank space·fixed position: Generates a random layout with fixed blank space constraints and an actual grid image.

Available seats = rows × columns − empty slots · Keep fixed seats and mix the rest in order

Input example

Placing six people in 2 rows and 3 columns places one person in each of six seats. Changing to five people and setting the 6th seat empty uses only the remaining five seats. Fixing Student 2 in seat 1 again mixes Student 2 back into seat 1, while other students are shuffled.

How to use

  1. Use the sample value or change the content, then click ‘Create placement’.
  2. Apply the settings for the empty seat or fixed seat of the desired seat and rearrange it.
  3. You can share the result and tool link together. Personal inputs are not included in the link.

Limitations and interpretation

Each row and column is 1–12; capacity is 1–144 people; name length is 60 characters. Same names are distinguished by person numbers. Fixed seats are one per person and cannot overlap with empty seats. Remaining seats are marked as empty. No inference of relationships, gender, or vision, nor determination of optimal placement. Names are exported only when separately included in files or shares. Long names are truncated from images; the full CSV is preserved.

Frequently Asked Questions

Can assignments remain after selecting fixed seats and re-selection?

If a row, column, or name is the same, it remains unchanged. Changing the name order or row/column may cause the existing number to refer to a different person or seat, so reset constraints after verification during grid renewal.

How are the remaining seats marked?

Each person is distinguished by the student number in the input order. The same name is also displayed with a number in the fixed seat selection. All remaining seats beyond the assigned capacity are marked as empty, and one person uses only one seat.

Does the student’s name go into the shared text?

The preview shows the entered name, but the default result file and share only include the student number. To include the name, enable it directly; the entered JSON contains all names and constraints.
