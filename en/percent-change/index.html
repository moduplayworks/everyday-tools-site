Calculation·conversion criteria

Determine the increase and decrease rates compared to the previous value.

Percentage change = (current − previous) ÷ previous × 100

Input example

Increase from 80 to 100: 25%

If 80 changes to 100, the change is 20, and the increase rate is 20÷80×100=25%. Conversely, if 100 becomes 80, it decreases by 20%, so determine and enter the direction.

How to use

  1. Use the entered example value or change the previous value or next value items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can the change rate be calculated based on negative values or 0?

0 cannot be the denominator, so an error message is displayed. Negative values are interpreted as the absolute value of the previous value as per this tool’s rules, so they are distinguished from typical positive growth rates.
