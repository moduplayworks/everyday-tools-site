Calculation·conversion criteria

Display the text's UTF-8 bytes as hexadecimal.

Converts each byte in UTF-8 to a 2-digit hexadecimal value.

Input example

A → 41

A is represented as bytes 41, Hangeul EA B0 80. Not every character is one byte.

How to use

  1. Use the entered example value or change the input or direction items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Is the hexadecimal code point the same as the UTF-8 byte?

No. The Ka code point is U+AC00, but the UTF-8 byte is EA B0 80. This tool is byte-based and checks whether the decoding matches the correct UTF-8.
