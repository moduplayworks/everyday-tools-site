SSID allows up to 32 UTF-8 bytes. WPA passwords allow 8–63 printable ASCII characters or 64 hexadecimal digits. Enterprise, WPA3-only and WEP are not supported.

Anyone with the QR code can read the password. Share only a guest network and test with a real phone.

How it works and limits

Generate the editable Cafe Example / example-pass-123 example to get a PNG containing WPA personal network settings. Replace these values before sharing. Semicolons, commas, colons, quotes and backslashes are escaped for the ZXing format; hidden networks add H:true. The tool neither connects to the network nor verifies the password.

Frequently asked questions

Does the QR hide the Wi-Fi password?

No. The QR contains readable network credentials. Use a guest network and check who can see the image before posting it.

Does it support WPA3 or enterprise Wi-Fi?

Only WPA/WPA2 Personal and open networks are offered. WPA3-only, enterprise authentication, WEP and router configuration are excluded. Test your phone/router combination.

Does the Wi-Fi QR expire?

This creates a static PNG without an account or short link. The image has no expiry, but changing the SSID or password requires a new QR. Inputs are not stored or sent.
