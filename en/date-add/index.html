Calculation·conversion criteria

Find the date N days before or after the standard date.

Result date = reference date + days

Input example

2026–10–02 plus 30 days = 2026–11–01

Adding 10 days to 2026-10-02 gives 2026-10-12. To count 10 days with the reference date as day 1, add 9 days.

How to use

  1. Use the entered example value or change the start date, additional days (subtracting is negative) items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Will weekend and holidays be skipped?

Skips. Adds or subtracts whole days including all calendar dates. Negative days move to the past; check the number of weekdays separately in the weekday tool.
