Two ways to reduce a PDF

Maintain document structure

Save the PDF structure again to maintain selectable characters, standard form fields, and links. Optimized files may remain the same size or increase in size. No size reduction guaranteed; verify the result size and decide whether to save.

Image quality selection, image compression

Create a white-background JPG of the page to reduce file size. Since text and shapes become images, they cannot be selected or searched, and links, forms, bookmarks, attachments, and electronic signatures are not preserved. Small characters may become blurred; compare the original and saved PDF after expansion for verification. OCR is not performed.

Actual example

The sample PDF contains selectable text, input fields, links, and image pages. Selecting ‘Structure preservation’ saves the PDF structure while keeping the text, form, and links intact. Selecting ‘Size priority’ converts it to a 144dpi JPG, removing the text selection, links, and form features while preserving the visual appearance. Both methods clearly indicate if the output file size is unchanged or increased compared to the original.

Encrypted or damaged PDFs may not open. The structure-preserving mode supports up to 200 pages. Image compression supports up to 50 pages and 120 million output pixels. Files and results are processed in your browser, not sent to a server.

Frequently Asked Questions

Can you continue to write characters·links·input fields after PDF compression?

‘Structure preservation·text retention’ stores the object structure of PDF again, so the function is maintained by checking AcroForm·links. Results vary per file and size may increase. ‘Size priority·quality selection’ flattens each page into JPG images, excluding text selection·searching, links, input fields, bookmarks, and attachments. Do not edit the signed original; directly check the result copy.

Does the text get blurred during image compression?

Image compression redraws each page at 96dpi or 144dpi and JPG quality. Small text and thin lines may become blurred; compare the first page on the screen and check the saved PDF when enlarged. OCR is not performed, and the text inside the image cannot be searched.

Is the PDF file sent to an external server?

File reading and conversion run in your browser. File names and contents are not sent in URLs or usage analytics. Files up to 50 MB can be opened. The structure-preserving mode supports 200 pages; image compression supports 50 pages and up to 120 million pixels. Encrypted or damaged PDFs may not open.
