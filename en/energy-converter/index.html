Calculation·conversion criteria

Convert energy units from J·kJ·kcal·kWh.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 J = 0.001 kJ

1kWh is 3,600,000J of energy used at 1,000W for 3,600 seconds. According to thermochemical calories, 1kcal is 4,184J.

How to use

  3. Result can be copied if needed.

Frequently Asked Questions

Can kW and kWh be converted to the same unit?

kW is power per unit; kWh is energy. Energy = power per unit × time, so usage time is required for connection. Use W unit notation for devices.
