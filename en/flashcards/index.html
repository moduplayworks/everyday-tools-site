Calculation criteria and usage method

Words and definitions created manually — paired cards for quiz and repetition practice.

Direct input: remove spaces from start and end·normalize with NFC·compare after normalization·Repetition of errors: only the incorrect cards this round

Input example

Three cards are obtained by tabbing apple and apple, book and book, window and window each on a separate line. If you know both cards and assess book as a practice exercise, the correct answer for the first round is 2/3, and wrong answers show only one book card. The manual input mode normalizes the combination format of spaces at both ends of the answer before comparison.

How to use

  1. Use the sample value or change the content, then click ‘Start card exercise’.
  2. Check and evaluate the answer or enter it directly. After the session ends, only wrong answers can be practiced again.
  3. You can share the result and tool link together. Personal inputs are not included in the link.

Limitations and interpretation

1–500 text cards, 400 characters each for front and back. Self-assessment or direct answer input; does not predict learning effectiveness or adaptive review intervals. No account, server storage, images, or sound. Small quotes are added for safety when starting CSV formatting. Use JSON to accurately preserve the original text.

Frequently asked questions

Does it automatically suggest review dates like Anki?

This tool repeats the self-assessment or directly entered errors. It does not provide adaptive review or account synchronization based on memory status to determine the date. You can directly plan the desired date in a separate review schedule tool.

Will the card return unchanged if the CSV is imported again?

Read two columns: front and back. Supports commas and line breaks inside quotes; directly select whether the first row is a column header. Characters that could be interpreted as formulas require additional single quotes for accurate export; use a JSON backup to preserve the original text.

Can this tool check Anki cloze text?

This tool practices front/back card pairs and does not parse Anki cloze syntax. Check the original {{c1::...}} text separately in Anki Cloze Checker for numbering, nesting and closing delimiters. This does not mean that these practice cards export Anki files or reproduce Anki rendering.
