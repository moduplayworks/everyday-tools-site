How to use and processing criteria

It is a process of selecting a page from a PDF and extracting, or splitting multiple PDFs.

Actual example

In a six-page PDF where printed page 1 is physical PDF page 3, set the anchors to 1 and 3. Extracting printed pages 3, 1-2 produces physical PDF pages 5, 3 and 4 in that order.

Frequently asked questions

How do I enter a page segment?

In extraction mode, ranges are separated by commas like 1-3, 5. For segmented ranges, separate PDFs like 1-3; 4-6. Duplicates or reverse ranges within the same range are indicated as errors.

Can all pages be saved individually or the original be preserved?

Use the page division mode to get a full ZIP file of each page as PDF. The original remains unchanged. Input limits are 50MB and 200 pages, with a total of 200 pages; encryption and form documents are not supported.

What if printed and physical PDF page numbers differ?

In printed-page mode, specify one printed page and its physical PDF page. Physical page = entered printed page − printed anchor + PDF anchor. Restarted, skipped or Roman numbering is not detected; handle those sections separately and verify them.
