    What to check before uploading a PDF to NotebookLM

    Google's Gemini Notebook help lists a per-source limit of 200MB or 500,000 words. This tool checks actual file bytes and PDF structure; it does not certify Google's word-count decision or upload success.

    To protect device memory, this tool processes up to 50MiB and 200 pages. This is a local limit distinct from the service’s 200MB. MB means 1,000,000 bytes and MiB means 1,048,576 bytes here.

    What does the text inspection check?

    Reads PDF text from the beginning, up to 20 pages and 200,000 characters, and displays only the checked range and presence of text. Original text and filenames are not sent to analytics. Scanned images, font encoding, tables and columns may prevent extraction or change reading order. This is not OCR and does not mean the entire document was read.

    Split by actual file size

    Copies PDF pages, serializes the result and compares actual bytes with the target. Oversized ranges are halved and checked again. Output files need not have equal page counts, and the minimum number of files is not guaranteed. If one page exceeds the target, choose a larger size or compress it.

    Page graphics and text are not rasterized. PDFs with form or signature fields are not split. Preservation of bookmarks, attachments, document-wide links and electronic signature validity is not guaranteed. The original is unchanged.

    Example: split 4 pages into 2-page files

    The public example is a 4-page PDF with text. Splitting at 2 pages per file creates two copies: pages 1–2 and pages 3–4. Save each file and check page order and content.

    Even when a file meets the limits, uploads can fail because of account limits, the network, supported formats or service status. Avoid unnecessary splitting and check Google’s latest guidance.

    Frequently Asked Questions

    Why will this tool not open a file smaller than 200MB?

    This tool has its own limit of 50MiB and 200 pages. It also cannot process encrypted or damaged PDFs. These limits are separate from Google’s upload requirements.

    Does missing text mean the PDF cannot be uploaded?

    No. It means no extractable text was found on the checked pages. If needed, check text with an OCR tool and review the upload service’s actual processing results.

    Does splitting improve AI answer accuracy?

    Improved accuracy is not guaranteed. Splitting helps manage file size or selected pages, and can interrupt context.

    Where does the PDF get uploaded?

    This tool does not upload PDFs. It checks them in your browser and saves copies. It does not connect to a Google account or NotebookLM.
