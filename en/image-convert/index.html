Frequently asked questions

Can I convert AVIF to JPG?

Yes. Recent Chrome, Firefox, and Safari browsers can read still AVIF images. If your browser cannot read the file, update it or check whether the file is damaged. JPG turns transparent pixels white.

Are AVIF transparency, HDR, and photo details preserved?

No. The output is a newly encoded still image; source photo metadata and animation are not copied. HDR and wide-gamut color may change with browser rendering and color conversion, so inspect the result for color-critical work.

Can I convert HEIC photos too?

HEIC is not supported yet. Unsupported files are reported as a format error rather than silently skipped. Choose AVIF, JPG, PNG, or WebP instead.

Will the quality and file size always improve after conversion?

No. JPG/WEBP encoding may cause loss, and PNG size may increase. Keep the original file and check the result. It is not intended to preserve motion and original metadata.
