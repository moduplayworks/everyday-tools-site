How to use and processing criteria

This is the conversion of the image’s actual encoding format to one of JPG·PNG·WEBP.

Actual example

If saved as transparent PNG JPG, the transparent area turns white. If saved as WEBP or PNG, the transparency is preserved. It creates a new image file format instead of just changing the file extension.

Frequently Asked Questions

Can HEIC photos be converted to JPG?

Current supported inputs are JPG, PNG, and WEBP. HEIC is not supported yet, so unsupported files are silently skipped. Save a copy as JPG or PNG on your device and choose it.

Will the quality and file size always improve after conversion?

No. JPG/WEBP encoding may cause loss, and PNG size may increase. Keep the original file and check the result. It is not intended to preserve motion and original metadata.
