Number Base Converter

Converts an integer to a binary representation 2·8·10·16.

Input

The example value has been entered. Check it immediately or change the value.

Run with Ctrl or ⌘ + Enter

Input is processed in the browser. Refreshing returns a sample value.

Result

Check or change the value using the example value result.

Negative values are also supported. Whole numbers are excluded; up to 1,000 digits can be entered.

Share result

Share the tool link and result text together. No URL is included in the result. Check the below content and then share it.

Calculation·conversion criteria

Convert large integers 2·8·10·16into binary.

Parse as a BigInt integer and output as each decimal character string

Input example

10-digit 255 = 16-digit ff

Decimal number 255 is represented as binary 11111111, octal 377, and hexadecimal FF. It is a whole number expressed in a different number system.

How to use

  1. Use the provided example value or change the integer or input base item.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Are values with a decimal or 0x prefix also converted?

Decimals are not supported. Enter only numbers in the selected base system and exclude prefixes such as 0x·0b. Integers are processed as BigInt, supporting negative numbers and up to 1,000 digits.
