Calculation·conversion criteria

Convert large integers 2·8·10·16into binary.

Parse as a BigInt integer and output as each decimal character string

Input example

10-digit 255 = 16-digit ff

Decimal number 255 is represented as binary 11111111, octal 377, and hexadecimal FF. It is a whole number expressed in a different number system.

Frequently asked questions

Are values with a decimal or 0x prefix also converted?

Decimals are not supported. Enter only numbers in the selected base system and exclude prefixes such as 0x·0b. Integers are processed as BigInt, supporting negative numbers and up to 1,000 digits.

Where can I find an IPv4 mask and network range?

This tool only changes how an integer is written in different bases. Enter IPv4 address 192.168.1.37 and prefix 24 separately in the IPv4 subnet calculator below to find the mask, network and address range. Do not paste a dotted address into this integer field for network calculations.
