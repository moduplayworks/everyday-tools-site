How to open and edit a CSV table

Opens UTF-8·EUC-KR CSV or tab-separated TSV to edit cells and column names, and saves search results as a new file.

For the sample product, quantity, and notes, ‘Apples, 3,’ ‘Market, envelope included’ results in 3 columns and 2 data rows. Commas are inside double quotes, so they are not separated into separate columns.

  1. Check file encoding and delimiter, then select a file or paste into CSV.
  2. Click Open Table to edit headers and rows, and use Search for Table content to locate the required rows.
  3. Click Save search results as CSV to include the matching row and full header in a new CSV file.

Supported range and boundaries

Handle commas, line breaks, and double quotes inside double quotes, and fill empty cells based on the widest row for short or long lines. Add protection characters for values that can be executed by formulas to prevent errors when viewed in a spreadsheet. Not all spreadsheets and subsequent data processing will behave identically. The maximum input size is 1MB.

Files and table content are processed on this device and are not included in sharing previews or visit statistics.

Frequently Asked Questions

Will send CSV content to the server?

No. File decoding, table editing, searching, and saving are handled in the browser. Addresses, analysis events, and sharing previews do not include cell content.

What if Hangul breaks?

Check file encoding. You can choose UTF-8 or EUC-KR·CP949, and encoding is not auto-detected.

Which row appears after saving search results?

Save only rows matching the current search and keep the header. If the search term is empty, save all data rows. Save matching rows that are not visible on the page.

Do you want to change the value in the formula protection tab?

Insert a tab before a cell that can be interpreted by a formula to reduce execution risk when opening in a spreadsheet. This tab may remain in the data after import and varies by app. Do not use this protection file directly in the original data processing. There is no universal CSV protection method for all apps.
