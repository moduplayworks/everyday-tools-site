Calculation·conversion criteria

Convert Celsius·Fahrenheit·Kelvin temperatures

F=C×9/5+32, K=C+273.15

Input example

Celsius 0°C = Fahrenheit 32°F = 273.15 K

Celsius 20°C = 20×9/5+32=Fahrenheit 68°F = 293.15 K. The absolute value of temperature includes both the scale interval and the reference point difference

How to use

  1. Use the entered example value or change the temperature or input unit items.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Does it convert a 10-degree temperature difference in the same way?

No. A 10°C difference in Celsius is a 18°F difference, and 32 is not added. The input of this tool is the actual temperature, not temperature differences.
