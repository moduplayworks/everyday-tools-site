Calculation·conversion criteria

Convert square meters and square feet to square feet.

Conversion value = Input value × Base ratio of input unit ÷ Base ratio of output unit

Input example

1 m² = 10000 cm²

Since 1m=100cm, 1m²=10,000cm². Applying this tool’s standard of 400/121m², 30ping is approximately 99.1736m².

How to use

  1. Use the provided example value or replace the value and input unit field.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Does the square-meter conversion also calculate the difference between usable area and allocated area?

No. It only changes the unit of the input area value. To compare included spaces like supply or allocation with other areas, the area type of the original material must be matched.
