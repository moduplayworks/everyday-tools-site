How to use and processing criteria

A tool to read Markdown without external resources and create an HTML copy.

Actual example

# Enter a title, **bold text**, list, code block, or pipe table, then click Preview to view the document format. Direct‑entered HTML like <script> is displayed as text. ![Photo](https://example.com/photo.png) appears as a photo description and URL; no image is requested from the server.

Frequently Asked Questions

What is the difference between supported Markdown and others?

Supports title, list, quotation, emphasis, code, links, tables, and backticks as basic markdown syntax. Does not support formulas, footnotes, Mermaid, or task list extensions. The title level in the preview is adjusted to match the tool interface, but HTML retains its original title level.

How are HTML, images, and links processed?

Displays as text nodes instead of running HTML. Does not load images, videos, scripts, or external fonts. HTTP(S) links without login information become new tab links that can be explicitly clicked. Relative addresses and different protocols are displayed as text. Image placeholders are retained in the HTML copy.

What files can be received?

You can save an independent HTML file containing the original Markdown, preview, and other content. HTML includes a policy to block external requests and scripts. If you apply the original MD to another service, that service’s rendering policy applies. Input limits 100,000 characters, and the preview has a maximum of 20,000 components.
