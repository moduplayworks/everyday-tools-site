Calculation·conversion criteria

Based on the measured adult leg length, confirm the closest official shoe size in KR·US·EU·Asia from Nike and Crocs’ different official size charts.

Find in the official adult height table of each brand the row with the height closest to the entered height. If the difference exceeds 5mm, it is marked as outside the range.

Input example

Adult female, foot length 240mm: The Nike chart shows 241mm·KR 245mm·US 8·EU 39. The Crocs chart shows both the same closest row of 238mm (US 7·EU 37.5·Asia 23cm) and 242mm (US 7.5·EU 38·Asia 23.5cm).

If adult female foot length is entered as 240mm, the Nike official chart will show the closest row with a foot length of approximately 241mm (KR 245mm·US 8·EU 39). The Crocs official chart will display both the same closest row of 238mm (US 7·EU 37.5·Asia 23cm) and 242mm (US 7.5·EU 38·Asia 23.5cm). Since the numbers differ between the two brands, KR Asia labeling is not treated as the same unit or the same product size.

Frequently Asked Questions

Can this result be directly selected as the purchase size?

No. The displayed value is a row close to the brand’s official table. Foot length, shoe model, material, and desired space are not calculated, and no fit feeling is guaranteed. Check the latest size guide and exchange conditions for the model before purchasing.

Is KR(mm) and length the same for Nike?

Different. The Nike table provides a separate column for foot length (in) in addition to KR(mm) sizes. Calculations find the reference row based on the foot length column, and KR notations are displayed as separate results.

Is Crocs' Asia(cm) a Korean shoe size?

This tool displays the names and values in the Asia(cm) column of the Crocs official table exactly as they are. It does not assume that KR(mm) notation is directly equivalent.

Calculation criteria and reference materials

  • Nike Korea — Adult shoe size chart

    Foot length (in), KR(mm), compares brand formulas for US and EU sizes. The KR notation on shoe boxes and labels differs from actual foot lengths; if the foot length is mid-size, it indicates a size up one size.

  • Crocs Korea — shoe size chart

    Compare the adult female·male foot length (mm), US, EU Asia(cm) columns directly based on brand labeling. This is not a guaranteed accurate fit due to style differences in fit and width.
