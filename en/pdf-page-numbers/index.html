Add PDF page numbers

Set the start number and position of the PDF, then add page numbers. Specify pages excluding the cover, and save a new copy.

Enter PDF page numbers

PDF 1 piece · 50MB·up to 200 pages

Excluded page and character settings

Enter consecutive numbers in the order of the document on the remaining selected pages. Add a black number above the existing text without creating new margins.

PDF support range

PDFs with encryption, format, and signature fields are not supported. Additional information such as digital signature validity, attachments, and bookmarks are not preserved. Check the number and content of the saved copy.

The file is processed in the browser. The original remains, and the process resets on refresh.

How to use and processing criteria

Adds continuous page numbers as actual text on the selected page of the original PDF.

Actual example

Select all pages in a 5-page document, exclude page 1, and set the start number to 1. Pages 2–5 will include 1–4. If the last number is enabled, it shows 1/4 to 4/4.

Frequently Asked Questions

How are the page number‑excluded page and the start number applied?

In page selection, exclude the specified pages and assign sequential numbers to the remaining document pages. The excluded pages remain unchanged in the PDF. Numbers increase consecutively from the starting number selected.

Does the page number overlap or misalign on the rotated page?

The count is added in black at a selected position 18pt inside the edge of the visible page. It does not increase existing margins, so it can overlap with the text. It reflects 90-degree rotation and cutting areas, and all corresponding pages of the saved copy should be checked.
