    Calculation criteria and usage method

    Calculates precedence of error formulas, trigonometric functions, and log results in angle units.

    In the off-mode, sin(30)^2 + cos(60)^2 equals 0.5²+0.5²=0.5. sin(30)^2 is 0.25 and cos(60)^2 is 0.25. Change the example value on the screen and the previous formula can be restored from recent records.

    How to use

    1. Enter a formula and select the angle unit for the trigonometric function.
    2. Calculated based on parentheses and operator precedence.
    3. Recent results are retained only in the current tab. Click an item to reload the formula.

    Supported range and boundaries

    Uses approximate decimal values for errors. Limits formula length to 240 characters, operation tokens to 96, function nesting to 24 levels, and absolute result to 10¹⁰⁰. Does not support complex numbers, symbolic notation, or unit conversion. Trigonometric and inverse trigonometric functions follow the selected angle unit.

    Frequently Asked Questions

    Where is the calculation record stored?

    The last 20 items are stored only in the current tab’s memory. They are erased when refreshing or leaving the page, and are not recorded in account, server, or browser storage.

    Calculates fractions, complex numbers, and equations?

    This tool calculates the floating-point results of limited operations and functions. Fractions are expressed as integer divisions, and symbolic, complex, and variable equations are not supported. Input is interpreted only using safe mathematical syntax, and code execution is not performed.
