Calculation·conversion criteria

Encodes and restores UTF-8 text as Base64.

Converts UTF-8 bytes to Base64 and vice versa.

Input example

Hello → SGVsbG8=

UTF-8 bytes of English A in uppercase is represented as QQ== in Base64. Korean is processed as UTF-8 bytes; use this method to distinguish from ASCII-only methods.

Frequently Asked Questions

Can hiding a secret be done by converting to a Base64 string?

No. It is a representation that anyone can decode. This tool supports restoring valid UTF-8 text, not binary files, and does not verify encryption or signatures.

Can Base64 and Base64url be entered the same way?

This tool uses a standard Base64 alphabet browser decoder. Differentiate strings using safe hyphens and underscores in URLs. It does not restore if it is not correct UTF-8 text.
