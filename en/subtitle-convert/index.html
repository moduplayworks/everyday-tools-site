      Supported range and limitations

      Read SRT·VTT·SMI and output as SRT·VTT. File size: 2 MiB, text length: 1,000,000 characters, total for all languages: 10,000 units. One unit: 10,000 characters, time range: 99:59:59.999 supported. SMI last paragraph requires a blank SYNC end point of the same language class. ASS·image subtitles·video auto recognition·HLS X-TIMESTAMP-MAP·SMI continuous ID=Source is not supported.

      Auto-encoding only performs BOM or UTF-8 validation and does not guess the language. Supports reference amp·lt·gt·quot·apos·nbsp·lrm·rlm and numeric references. Does not continue conversion for unsupported tags or character references. Ruby pronunciation is replaced with brackets. Check the preview and warning before output and keep the original file.

      Frequently Asked Questions

      What if the Korean characters in SMI subtitles break?

      In file import, select EUC-KR/CP949 and reload. Auto selection performs only UTF-8 validation without BOM. Broken characters are not replaced manually.

      Convert multilingual SMI together at once?

      We separate visual and content for each language class and verify them. Select the class to use and output only one language. After the last marker, a blank SYNC endpoint of the same class is required.

      Are style, location, and original text files preserved?

      Converted to general text, so color·position·speaker metadata and VTT annotations are removed and a warning is shown. The original file is not modified. Downloading yields a separate UTF-8 SRT or VTT file.

      Can this converter check ASS fonts and styles?

      This converter handles plain-text subtitles in SRT, VTT and SMI. Check font dependencies, undefined styles and style differences across original ASS files in ASS Font and Style Checker. It does not guarantee video rendering or successful font installation.

      Calculation criteria and reference materials

      • U.S. Library of Congress — SubRip SRT format

        Segment number, start/end time, text, empty line, and description of an SRT file without fixed encoding standards

      • W3C — WebVTT subtitles format

        Milliseconds, start order, overlapping intervals, and comparison basis for subtitles. This tool outputs regular text and does not maintain rendering style.

      • Microsoft — SAMI 1.0 subtitles structure

        SYNC Start in milliseconds, language segmentation for P class, and blank paragraph handling. Video player·continuous speaker ID=Source is not implemented.

      • WHATWG — Encoding Standard

        Strict error mode of TextDecoder and BOM·UTF-8·UTF-16·EUC-KR decoding. Does not guarantee automatic encoding determination.
