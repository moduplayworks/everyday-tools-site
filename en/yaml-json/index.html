Frequently asked questions

Which YAML types are supported?

YAML 1.2 core supports string, numbers, booleans, null, arrays, and string key objects. It supports numeric and complex object keys, .inf, .nan, custom tags, object creation tags, and merge keys <<. YAML 1.1 and multiple document streams are reported as errors. Duplicate keys are silently overwritten.

Are notes and anchors retained?

JSON is non-significant; remove or expand as a standalone value with processing instructions. Cyclic aliases are rejected; expansion is limited to 50 items or 10,000 values. Large integers and decimals maintain original precision but may change formatting such as indentation, quotes, or hex notation.

What are the document size limits and storage methods?

The input is 100,000 characters or less, the conversion depth is 80 or less, and the output is 1,000,000 characters or less. The execution of a separate Worker takes up to 3 seconds, and the module preparation takes up to 10 seconds. If there is an error or cancellation, the previous normal result is retained. After reviewing the result, save it to a JSON or YAML file, but do not store the input in a browser storage.
