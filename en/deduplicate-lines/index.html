Calculation·conversion criteria

Keep only one line of identical text.

If the string is identical, only the first occurrence is retained

Input example

Apple / banana / apple → apple / banana

Entering A, B, and A as separate lines keeps A and B in the order they appear. Since they are not sorted, the original order is preserved.

How to use

  1. Use the entered example value or change the input text item.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Why is the same line that looks the same not removed repeatedly?

Accurately compare the entire string including uppercase, lowercase, and spaces. A and a, A with a space after are different. If needed, clean spaces or perform Unicode normalization first.
