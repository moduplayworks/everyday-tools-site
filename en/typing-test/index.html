Calculation criteria and usage method

Measure speed, cumulative errors, and accuracy of completed characters in Korean and English sentences.

CPM = current correct characters ÷ elapsed minutes · WPM = CPM ÷ 5 · accuracy = (total input − total typo) ÷ total input × 100

Input example

1 minutes, if 30 characters match the current sentence, CPM is 30 and WPM is 30÷5=6. When a total of 32 characters are entered and 2 characters are incorrect, the accuracy is 30÷32×100=93.75%. Even if the incorrect characters are removed, the cumulative typo remains, and Korean syllables are not converted into keyboard keystrokes.

How to use

  1. Use the example value or change the content and click the start typing button.
  2. Measurement begins from the first character. Check the result when the sentence is completed or the setting time is reached.
  3. You can share the result and tool link together. Personal inputs are not included in the link.

Limitations and interpretation

A character is a normalized NFC character unit. Korean syllables are not converted into physical key input counts. Spacing and punctuation also accumulate errors; since it’s a position comparison, inserting or deleting characters affects subsequent matches. Paste and drop cannot be used for measurement, and if outside the tab, practice stops. Results depend on keyboard assistance such as auto-complete. Up to 1,000 display characters are measured, with a minimum of 1 second.

Frequently Asked Questions

Can it be compared to existing typing rates like 300 Hangul types?

Do not compare manually. This tool counts visible characters, spaces, and punctuation marks, but does not count physical consonants and vowels. CPM and WPM definitions are displayed near the results.

Can the results measured on mobile differ from those on PC?

The screen keyboard, auto-complete, auto-correction, and input methods differ. Select the keyboard used in this exercise directly to retain it in the result, then compare with the same sentence, device, and conditions. Disable paste and drop, and stop when moving to another tab.

If you remove typos, will accuracy return to 100%?

The number of characters in the current text may change, but cumulative typos and newly entered characters remain. Therefore, corrections after errors also affect accuracy. Mid‑combination letters are not counted twice as confirmed inputs.
