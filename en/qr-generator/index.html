Frequently Asked Questions

Can the address of the created QR code be changed later?

Since it’s a static QR code, you cannot change the content of the already distributed code. If you modify the content, you must create a new code. No shortened URL or tracking server is used.

If sharing Wi-Fi QR code, can I see the password too?

Yes. Wi-Fi QR codes contain connection information and a password. Check the sharing target. In result and link sharing, no input is entered; you can save the QR image itself for transmission.
