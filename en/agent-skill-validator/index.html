    What the validator checks

    Check SKILL.md YAML frontmatter, required metadata and body against the public Agent Skills specification, and check local links in a selected folder.

    The public example uses name: weekly-summary and includes summary instructions. Check it in a `weekly-summary/SKILL.md` folder to confirm the name matches its parent folder and see zero errors. Without a folder, the tool checks the name, YAML and body, and reports that it could not compare the parent folder or verify referenced files.

    Validation scope

    It checks YAML frontmatter, whether name and description are present and within their length limits, name characters and hyphens, optional field types, and a nonempty Markdown body. With a folder selected, it also checks whether name matches the parent folder and whether Markdown relative links point to selected files. It does not assess writing quality or every agent-specific extension field.

    Limits and safety

    No. The browser checks filenames and sizes in the selected folder and reads only the root SKILL.md. It does not open or run the other files; it only compares Markdown relative-link paths with the selected file list.

    When you select a folder, the tool checks filenames and whether Markdown relative links exist. It does not read or run the other files. Review the instructions, scripts, external connections and required permissions before installing a skill.

    Frequently asked questions

    Which Agent Skills rules does it check?

    It checks YAML frontmatter, whether name and description are present and within their length limits, name characters and hyphens, optional field types, and a nonempty Markdown body. With a folder selected, it also checks whether name matches the parent folder and whether Markdown relative links point to selected files. It does not assess writing quality or every agent-specific extension field.

    Does selecting a folder read every file?

    No. The browser checks filenames and sizes in the selected folder and reads only the root SKILL.md. It does not open or run the other files; it only compares Markdown relative-link paths with the selected file list.

    Does this page replace the official CLI's full validation?

    The public specification documents running skills-ref validate ./my-skill against a skill folder to check SKILL.md frontmatter and naming conventions. This page is a quick browser precheck for a subset of SKILL.md rules and selected-folder Markdown paths. It does not run the official CLI or replace other validation results.

    Can I safely install a skill if there are no errors?

    No. This check covers format and some file paths only. It does not analyze prompt injection, external connections, script behavior, permissions, package origins or dependencies, and does not certify safety. Review all instructions and files before installing or running a skill.
