Add Text to Leading and Trailing Lines

Adds fixed characters at the beginning and end of each line.

Input

The example value has been entered. Check it immediately or change the value.

Run with Ctrl or ⌘ + Enter

Input is processed in the browser. Refreshing returns a sample value.

Result

Check or change the value using the example value result.

Up to 50,000 characters. Input and results are processed in this page’s memory and not saved. Line breaks use LF.

Share result

Share the tool link and result text together. No URL is included in the result. Check the below content and then share it.

Calculation·conversion criteria

Add the same prefix or suffix to all lines.

Result line = prefix + original line + suffix

Input example

Apple → [apple]

Adding “[” as a prefix and “]” as a suffix makes A and B become [A] and [B] respectively. Can be used when adding fixed phrases to a file list.

How to use

  1. Use the provided example value or replace the list, preceding character, and following character fields.
  2. Click Verify result and check the following result.
  3. Result can be copied if needed.

Frequently Asked Questions

Can adding quotes complete JSON or CSV?

No. It is a simple string combination without escaping quotes or delimiters within the line. Use a dedicated converter if you need valid JSON·CSV.
