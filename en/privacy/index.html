Personal information processing guidance

Information reviewed: October 6, 2026

Enter course and plan details

The course name, length, viewing location, submenu, and study schedule are calculated in the browser. It does not implement the function of sending input values to a URL, analysis event, or operator’s server. It does not directly collect user accounts and emails.

Photo · file input

Remove photo background processes the image file via browser worker. When using for the first time, download the person separation model and executable file from the same site. The selected photo and file name are not included in this request or analysis. No upload, account saving, or device synchronization is possible. Results and inputs are cleared from memory when leaving the page or resetting, and the saved PNG is managed directly by the user.

Browser save

When completed, inputs for each tool are stored in localStorage. Tool transfers use sessionStorage for the same tab. Records are limited to the browser and URL; no device‑to‑device synchronization. Browser data can be deleted. Usage instructionsCheck how to back up and delete JSON.

Connection information and visit statistics

Host providers can handle connection information such as IP addresses during web request processing. Therefore, it is not accurate to describe this service as one that does not transmit all data externally.

If you allow usage statistics, we use Google Analytics 4. If you decline or make no choice, the GA script is not loaded and you can still use the tools.

Collected data includes the page URL and title, referring site, browser and device information, visit and usage times, tool type and whether it was used, and whether a calculation, plan, or backup action occurred. We do not send lecture titles, durations, playback speeds, schedules, pasted text, or file contents. Query parameters and fragments are removed from page URLs; referrers are limited to the site origin.

Google processes IP addresses and other data needed for network requests, and data may be processed on servers outside your country. We do not use automatic form collection, User-ID, advertising personalization signals, or Google Signals. Google Privacy PolicyYou can read it.

Google Analytics user and event data retention is set to 2 months; this period may not apply to aggregated standard reports. Your choice is stored in this browser for up to 180 days. If you allow collection, a tool-specific analytics cookie is used for up to 180 days. You can change your choice to decline at any time using “Usage statistics settings” at the bottom of the page. Declining stops further GA collection and deletes the tool-specific analytics cookie. Data already sent is not automatically deleted.

Analytics consent is separate from ad consent. To delete all browser data, Usage instructionsyou can do this here. For questions about analytics or data-deletion requests, use the Contact channelPlease use it.

Advertising

Advertising scripts are enabled. The advertising provider’s data processing and required regional consent procedures follow the advertising policies in use.

This site uses Adsterra banner advertising. Advertising scripts do not load until you allow advertising. If you allow it, the advertising provider processes your IP address, browser, device information and other data, which may be processed on servers overseas.

Banners run in an area isolated from tool inputs, calculated results and selected files. You can use the tools if you decline advertising. You can decline at any time using Advertising preferences at the bottom of the page.

Your advertising choice is kept in this browser for up to 180 days. Declining removes the current banner and stops new advertising requests. Information already sent and cookies set by the advertising provider are not automatically deleted.

Adsterra privacy policydescribes the provider’s data processing and contact options.
