Service usage instructions

Guidance reference date: October 2, 2026

Features provided

Free tools to calculate online lecture playback time and plan course completion. No signup, payment, external lecture-platform connection, or automatic collection.

Range of calculation result

This result uses the lecture durations, playback speed, and schedule you entered. Actual time may vary with the playback environment, pauses, note-taking, and review. The extra-time percentage is your own estimate; it does not predict learning outcomes or guarantee that you will finish the course.

Store records

Records are stored in the browser and may disappear due to device changes or site data deletion. Backup required records as a JSON file. If an error is suspected, keep the existing backup. ContactPlease do it.

Change and operation

Features and interfaces can be changed to improve accuracy and usability. Major format changes require compatibility verification and prior notice. Automated requests or ad click manipulation that disrupts service operation are not allowed
