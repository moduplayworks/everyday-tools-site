줄 번호 붙이기

시작 번호와 구분자를 지정해 각 줄에 번호를 붙입니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 -100000 · 최대 100000

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

시작 번호와 구분자로 목록에 줄 번호 붙이기.

줄 번호 = 시작 번호 + 줄 위치

입력 예시

가 / 나 → 1. 가 / 2. 나

시작 번호 1과 구분자 “. ”를 선택하면 첫 줄 A는 “1. A”가 됩니다. 다음 줄은 시작 번호에 1씩 더해 번호를 붙입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 목록, 시작 번호, 번호 뒤 구분자 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

빈 줄에도 번호가 붙나요?

붙습니다. 입력의 각 줄을 한 항목으로 세므로 마지막 줄바꿈 뒤의 빈 줄도 포함됩니다. 내용 있는 줄만 번호를 매기려면 먼저 빈 줄을 제거하세요.
