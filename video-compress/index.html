동영상 용량 줄이기

영상 해상도와 인코딩 비트레이트를 조절해 더 작은 파일을 만들고 실제 출력 크기를 비교하는 작업

MP4·WebM·MOV · 최대 100MB·60초. 영상은 이 브라우저에서 처리합니다.

예시 영상으로 첫 실행을 확인할 수 있어요.

출력 설정

예상 크기는 인코딩 비트레이트에 따른 추정치입니다. 실제 크기와 화질은 영상 내용·브라우저에 따라 달라집니다.

처리 결과

동영상 저장
결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

동영상 용량 줄이기를 브라우저에서 실행하세요

공개 예시 영상은 640×360px, 약 4초입니다. 기본 균형 설정은 최대 720p를 목표로 하지만 작은 원본은 확대하지 않습니다. 실제 압축률은 영상 움직임·브라우저 인코더·입력 코덱에 따라 달라지며, 원본보다 파일이 커질 수도 있습니다.

새 동영상으로 다시 인코딩합니다

선택한 파일을 서버로 올리지 않습니다. 새 컨테이너와 코덱으로 저장하므로 입력 형식·화질·파일 크기가 달라질 수 있습니다. 예상 크기와 원본을 비교하고 결과를 직접 재생해 확인하세요.

비트레이트 설정은 출력 크기 추정에 쓰는 목표값입니다. 브라우저 인코더가 이를 정확히 지키거나 항상 더 작은 파일을 만든다고 보장하지 않습니다.

파일과 기기 제한

최대 100MB·60초 영상에서 실행합니다. 브라우저가 지원하는 저장 형식을 감지해 MP4 또는 WebM으로 출력합니다. 인코딩 중에는 탭을 열어 두세요. 기기의 메모리와 코덱 지원에 따라 일부 파일이 처리되지 않을 수 있습니다.

자주 묻는 질문

원하는 파일 크기를 정확히 지정할 수 있나요?

목표 파일 크기를 보장하지 않습니다. 화면의 예상치는 설정한 비트레이트로 계산한 참고값이며, 실제 크기는 재생 후 측정합니다. 더 작게 만들려면 낮은 품질을 다시 선택해 비교하세요.

압축하면 화질이 반드시 좋아지거나 파일이 작아지나요?

아닙니다. 영상을 브라우저에서 새로 인코딩하며 결과가 더 커지거나 원본보다 흐릴 수 있습니다. 저장 전에 결과를 재생하고 원본과 크기를 비교하세요.

동영상이 서버에 업로드되나요?

아니요. 예시 파일만 같은 사이트에서 내려받고, 사용자가 고른 영상은 브라우저 메모리에서 처리합니다. 통계에는 성공적으로 도구를 사용했다는 정보만 보내며 파일명과 영상 내용은 포함하지 않습니다.

계산 기준과 참고 자료

  • MDN — MediaRecorder

    브라우저가 지원하는 컨테이너·코덱으로 캡처 스트림을 재인코딩합니다. 지원 형식과 출력 품질은 브라우저에 따라 달라집니다.

  • MDN — Canvas captureStream

    현재 영상 프레임을 로컬 Canvas에 그리고 브라우저 내 녹화용 영상 스트림으로 캡처합니다.

  • MDN — AudioContext createMediaElementSource

    영상 요소의 소리를 로컬 Web Audio 스트림에 연결해 영상과 함께 다시 인코딩합니다.

  • WebKit — MediaRecorder API

    WebKit 구현에서 캔버스·Web Audio 스트림 녹화와 형식 기능 감지를 설명합니다. 현재 기기의 코덱 지원 여부는 실행 중 기능 감지합니다.
