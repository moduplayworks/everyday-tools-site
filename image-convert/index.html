이미지 형식 변환

JPG·PNG·WEBP를 원하는 형식으로 바꾸세요. 여러 장을 한 번에 변환하고 투명도와 실제 파일 형식을 확인해 저장합니다.

이미지 형식 변환 입력

최대 10장 · 장당 20MB·2,400만 화소 · 전체 50MB 이하

이미지 지원 범위

JPG·PNG·WEBP만 지원하며 HEIC는 지원하지 않습니다. 정지 이미지로 저장합니다. JPG는 투명 영역이 흰색이 됩니다. 원본과 메타데이터는 별도로 보관하세요. 결과는 가로·세로 6,000px, 2,400만 화소 이하입니다.

입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

이미지의 실제 인코딩 형식을 JPG·PNG·WEBP 중 하나로 변환하는 작업입니다.

실제 예시

투명 PNG를 JPG로 저장하면 투명 영역이 흰색으로 바뀝니다. WEBP 또는 PNG로 저장하면 투명도를 유지합니다. 확장자만 바꾸는 것이 아니라 새 형식의 이미지 파일을 생성합니다.

자주 묻는 질문

HEIC 사진도 JPG로 변환할 수 있나요?

현재 지원 입력은 JPG·PNG·WEBP입니다. HEIC는 아직 지원하지 않으며 지원하지 않는 파일을 조용히 건너뛰지 않습니다. 기기에서 JPG나 PNG 사본으로 저장한 뒤 선택하세요.

변환하면 화질과 파일 용량이 항상 좋아지나요?

아닙니다. JPG·WEBP는 선택 품질로 다시 인코딩되어 손실이 생길 수 있고 PNG는 용량이 커질 수 있습니다. 원본 파일을 보관하고 결과를 확인하세요. 움직임과 원본 메타데이터를 유지하는 용도는 아닙니다.
