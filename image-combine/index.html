사진 합치기

여러 사진을 세로·가로·격자로 합치세요. 순서·간격·배경을 조절하고 한 장의 이미지로 저장합니다.

사진 합치기 입력

JPG·PNG·WEBP · 장당 20MB 이하

간격·배경·격자 설정

파일 목록의 앞·뒤 버튼으로 순서를 바꿉니다. 격자는 정사각형 칸에 비율을 유지해 넣습니다.

첫 사진 미리보기입니다. 저장 결과에서 모든 사진을 확인하세요.

지원 범위와 원본 보관

입력은 장당 2,400만 화소·전체 50MB 이하입니다. 원본 파일은 바꾸지 않습니다. 움직이는 이미지는 정지 이미지로 처리하며 HEIC는 지원하지 않습니다. 결과는 2,400만 화소·한 변 6,000px(합치기 16,000px)까지입니다. 가리기 결과는 PNG로 저장합니다. 원본 메타데이터·편집 기록은 결과에 보존하지 않습니다.

입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

여러 사진을 원하는 순서로 이어 붙이거나 격자에 배치하는 작업입니다.

실제 예시

800×400px 사진 두 장을 공통 가로 800px, 간격 10px로 세로 배치하면 결과는 800×810px입니다. 가로 배치는 공통 세로를 맞추고, 격자는 정사각형 칸 안에 사진 비율을 유지합니다.

자주 묻는 질문

사진 합칠 때 순서와 사진 비율은 유지되나요?

선택 목록의 앞으로·뒤로 버튼으로 순서를 바꿀 수 있습니다. 세로는 공통 가로, 가로는 공통 세로에 맞춰 비율을 유지합니다. 격자도 원본을 자르지 않고 칸 안에 맞추며 남는 부분은 배경색으로 채웁니다.

긴 사진을 만들 때 크기 제한이 있나요?

결과는 한 변 16,000px 및 2,400만 화소까지입니다. 사진은 2~10장, 장당 20MB·2,400만 화소, 전체 50MB까지 선택할 수 있습니다. 너무 길면 공통 크기나 사진 수를 줄이세요.
