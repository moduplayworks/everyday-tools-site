유니코드 정규화

결합 문자와 호환 문자를 NFC·NFD·NFKC·NFKD 형식으로 정규화합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

NFKC/NFKD는 호환 문자의 모양·의미를 바꿀 수 있으므로 결과를 검토하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

겉모양이 같은 문자의 유니코드 표현 통일하기.

Unicode normalize 형식 적용

입력 예시

e + 결합 악센트 → NFC é

é 한 글자와 e 뒤에 결합 악센트가 붙은 문자열은 서로 다른 코드 표현일 수 있습니다. NFC는 가능한 결합형으로, NFD는 분해형으로 맞춥니다.

사용 방법

  1. 입력된 예시값을 사용하거나 텍스트, 정규화 형식 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

NFKC를 쓰면 원래 글자의 의미가 바뀔 수 있나요?

호환 정규화는 전각 문자나 원문자 같은 표현을 통합할 수 있습니다. 검색·비교에는 유용하지만 원본 표기 구분을 잃을 수 있으므로 문서 보존 목적이라면 결과를 확인하세요.
