파일 해시 확인

파일의 SHA-256·SHA-512를 계산하고 기대값과 비교하세요. 큰 파일도 나누어 읽고 처리 중 취소할 수 있습니다.

파일 해시 확인 입력

파일 1개 · 2GB 이하 · 1MB씩 나누어 읽기

선택한 파일
기대 해시와 비교

대소문자는 구분하지 않습니다. 해시 일치는 제공받은 값과의 동일성 확인이며 파일의 안전성·배포자 신원을 보증하지 않습니다.

원본 파일은 바뀌지 않습니다. 브라우저에서 처리하며 새로고침하면 작업이 초기화됩니다.

결과

파일을 선택하고 실행하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

파일 바이트의 SHA-2 해시를 계산하고 제공받은 기대값과 비교하는 작업입니다.

실제 예시

UTF-8 텍스트 abc의 SHA-256은 ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad입니다. 내용이 같다면 파일 이름이 달라도 같은 알고리즘의 해시는 같습니다.

자주 묻는 질문

해시가 일치하면 파일이 안전하다는 뜻인가요?

입력한 기대값과 계산 결과가 같다는 뜻입니다. 기대값은 신뢰할 수 있는 배포 경로에서 확인해야 합니다. 해시 일치만으로 악성코드 유무나 배포자 신원을 보증하지 않습니다.

큰 파일도 서버에 업로드하지 않고 확인할 수 있나요?

파일 하나를 최대 2GB까지 브라우저 작업 스레드에서 1MB씩 나누어 읽습니다. 전체 파일을 한 번에 메모리에 올리지 않으며 취소하면 작업 스레드를 종료합니다. 계산 시간은 기기 성능과 파일 크기에 따라 달라집니다.
