자막 싱크 조절

자막을 앞뒤로 이동하거나 두 기준점으로 점점 어긋나는 싱크를 보정하세요. 음수 시각·겹침을 확인하고 SRT·VTT로 저장합니다.

입력

입력된 예시로 바로 실행할 수 있습니다. 파일은 아래에서 불러오세요.

여러 언어는 섞지 않습니다. 한 언어를 선택하고 다시 실행하세요.

양수는 늦게, 음수는 빨리 표시합니다. 소수 3자리까지.

HH:MM:SS.mmm 형식. 원문 자막 시각에 대응하는 영상 시각을 입력하세요.

자막 파일 불러오기·인코딩

문자가 깨지면 인코딩을 선택하고 파일을 다시 불러오세요. 내용을 검증한 뒤 교체 여부를 확인합니다. 파일명과 원문은 전송하지 않습니다.

음수 시각 처리

종료도 0초 이전이거나 구간이 사라지면 중단합니다. 자막은 자동 삭제하지 않습니다.

Ctrl 또는 ⌘ + Enter로 실행. 원문은 저장하지 않습니다. 새로고침하면 공개 예시로 돌아갑니다.

      계산 방법과 사용 예시

      전체 이동에서 +1.5초를 입력하면 예시의 1~3초 구간은 2.5~4.5초가 됩니다. 음수는 더 일찍 표시합니다. 앞·뒤 기준점 보정은 t′ = d₁ + (t − s₁) × (d₂ − d₁) ÷ (s₂ − s₁)로 모든 시작·종료를 바꿉니다. 원문 1초가 영상 2초, 원문 10초가 영상 12초에 맞으면 두 점이 정확히 맞고 중간 시각은 같은 비율로 변합니다. 정수 밀리초와 정확한 정수 비율로 계산한 뒤 마지막에 한 번 반올림합니다.

      지원 범위와 제한

      SRT·VTT·SMI를 읽고 SRT·VTT로 출력합니다. 파일은 2 MiB, 원문은 1,000,000자, 모든 언어 합계 10,000구간, 한 구간은 10,000자, 시각은 99:59:59.999까지 지원합니다. SMI의 마지막 문단에는 같은 언어 클래스의 빈 SYNC 종료점이 필요합니다. ASS·이미지 자막·영상 자동 인식·HLS X-TIMESTAMP-MAP·SMI의 지속 ID=Source 표시는 지원하지 않습니다.

      인코딩 자동 선택은 BOM 또는 UTF-8 유효성 검사만 수행하며 언어를 추측하지 않습니다. 주요 문자 참조 amp·lt·gt·quot·apos·nbsp·lrm·rlm와 숫자 참조를 지원합니다. 지원하지 않는 태그나 문자 참조는 변환을 중단합니다. 루비 발음은 괄호로 바뀝니다. 출력 전 미리보기와 경고를 확인하고 원본을 보관하세요.

      자주 묻는 질문

      자막이 일정하게 빠르거나 늦을 때 어떤 방식을 쓰나요?

      전체 시간 이동을 사용하세요. +2초는 자막을 2초 늦추고 −2초는 2초 앞당깁니다. 초 단위 소수는 3자리까지 입력합니다.

      처음은 맞지만 끝으로 갈수록 어긋나면 어떻게 하나요?

      앞·뒤 기준점 보정을 선택하세요. 서로 다른 원문 자막 시각 두 개와 각각 대응하는 영상 시각을 입력합니다. 뒤 기준점은 앞보다 늦어야 하며 전체 자막의 시각을 같은 선형 비율로 보정합니다. 영상의 중간 편집·구간별 변화는 자동 복원되지 않습니다.

      음수 시각이나 겹치는 자막은 자동 삭제하나요?

      삭제하지 않습니다. 음수 시작은 기본적으로 오류이며 원하면 시작을 0으로 자를 수 있습니다. 종료가 0 이하이거나 구간이 사라지면 중단합니다. 겹침은 개수를 경고하고 원문 순서를 유지합니다.

      계산 기준과 참고 자료

      • 미국 의회도서관 — SubRip SRT 형식

        구간 번호·시작/종료 시각·텍스트·빈 줄과 고정 인코딩 표준이 없는 SRT 파일의 설명

      • W3C — WebVTT 자막 형식

        밀리초 시각, 시작 순서, 겹치는 구간과 자막 텍스트의 비교 기준. 이 도구는 일반 텍스트 출력이며 렌더링 스타일을 유지하지 않습니다.

      • Microsoft — SAMI 1.0 자막 구조

        SYNC Start 밀리초, P 클래스의 언어 구분과 빈 문단 처리. 영상 플레이어·지속 화자 ID=Source는 구현하지 않습니다.

      • WHATWG — Encoding Standard

        TextDecoder의 엄격한 오류 모드와 BOM·UTF-8·UTF-16·EUC-KR 디코딩. 무조건적인 인코딩 자동 판별을 보장하지 않습니다.
