제공하는 기능

인강 배속 계산과 완강 계획 도구를 무료로 제공합니다. 회원가입, 결제, 외부 강의 플랫폼 연결과 자동 수집은 지원하지 않습니다.

계산 결과의 범위

결과는 사용자가 입력한 길이·배속·일정에 따른 계산값입니다. 실제 재생 환경과 일시정지, 필기·복습 시간에 따라 소요 시간이 달라질 수 있습니다. 추가 시간 비율은 사용자의 가정이며 학습 효과나 완강을 보장하지 않습니다.

기록 보관

기록은 브라우저에 저장되므로 기기 변경이나 사이트 데이터 삭제로 사라질 수 있습니다. 필요한 기록은 JSON 파일로 백업해 주세요. 오류가 의심되면 기존 백업을 보관하고 문의해 주세요.

변경과 운영

정확성과 사용성을 개선하기 위해 기능과 화면을 변경할 수 있습니다. 중요한 저장 형식 변경은 호환성 검증과 이전 안내를 준비합니다. 서비스 운영을 방해하는 자동 요청이나 광고 클릭 조작은 허용하지 않습니다.
