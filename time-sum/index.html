시간 합산 계산기

여러 작업의 소요 시간을 더해 총시간과 분·초를 계산합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

숫자만 쓰면 분, 콜론 2개는 시:분:초입니다. 분·초는 0~59이며 시간은 음수가 될 수 없습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

여러 작업이나 영상의 총시간 합산하기.

각 줄의 시간을 초로 바꾼 뒤 합산

입력 예시

1:30:00 + 0:45:00 = 2:15:00

45와 0:30:00을 각각 한 줄에 넣으면 45분+30분=1:15:00입니다. 숫자만 입력하면 분으로 해석하며 H:MM:SS의 분·초는 0~59여야 합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 시간 목록 (한 줄씩 H:MM:SS 또는 정수 분) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

1:30은 1시간 30분으로 입력할 수 있나요?

이 도구는 모호한 두 부분 형식을 받지 않습니다. 1시간 30분은 1:30:00 또는 90으로 입력하세요. 인강 배속 계산기의 MM:SS 입력 규칙과는 다릅니다.

계산 기준과 참고 자료

이 도구의 계산식과 적용 범위는 위 설명에 공개되어 있습니다. 예시는 입력값을 공식에 대입하거나 명시된 문자열·달력 처리 규칙을 따라 확인할 수 있습니다.

계산 기준 확인: 2026-10-02 · 계산·검증 원칙 · 오류 제보
