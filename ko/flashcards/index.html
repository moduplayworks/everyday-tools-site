단어장·암기카드

앞뒤 쌍으로 암기카드를 만들고 직접 평가하거나 답을 입력하세요. 이번 회차 오답만 다시 연습하고 CSV·JSON으로 백업합니다.

입력

예시값으로 바로 시작하세요. 한 줄에 앞면과 뒷면을 탭으로 구분합니다. 1~500개.

순서·비교 설정

답의 양끝 공백은 제외합니다. CSV는 따옴표 안의 쉼표·줄바꿈을 지원합니다.

카드 백업·복원

파일에는 카드 원문이 들어갑니다. 가져오기는 확인 후 현재 카드·연습을 교체합니다. 새로고침하면 예시로 돌아옵니다.

카드 연습

입력된 카드로 바로 연습을 시작하세요.

Enter는 줄바꿈, Ctrl 또는 ⌘ + Enter는 답 확인입니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산 기준과 사용 방법

직접 만든 단어·정의 앞뒤 쌍으로 카드 퀴즈와 오답 반복 연습.

직접 입력: 앞뒤 답의 공백 제거·NFC 정규화 후 비교 · 오답 반복: 이번 회차에서 틀린 카드만

입력 예시

apple과 사과, book과 책, window와 창문을 한 줄씩 탭으로 나누면 카드 3개입니다. 두 카드를 알고 있고 book을 다시 연습으로 평가하면 첫 회차 정답은 2/3이며 오답 반복은 book 한 카드만 보여줍니다. 직접 입력 모드는 답의 양끝 공백과 같은 글자의 조합 형식을 정규화한 뒤 비교합니다.

사용 방법

  1. 예시값을 사용하거나 내용을 바꾼 뒤 카드 연습 시작 버튼을 누르세요.
  2. 답을 확인하고 평가하거나 직접 답을 입력하세요. 회차가 끝나면 오답만 다시 연습할 수 있습니다.
  3. 결과와 도구 링크를 함께 공유할 수 있습니다. 개인 입력은 링크에 들어가지 않습니다.

한계와 해석

텍스트 카드 1~500개, 앞·뒤 각각 400자입니다. 자기 평가 또는 직접 답 입력이며 학습 효과·적응형 복습 주기를 예측하지 않습니다. 계정·서버 저장·이미지·소리는 없습니다. CSV 수식 시작 문자는 안전을 위해 작은따옴표가 추가됩니다. 원문을 정확히 보존하려면 JSON을 사용하세요.

자주 묻는 질문

Anki처럼 복습 날짜를 자동으로 추천하나요?

이 도구는 이번 회차의 자기 평가 또는 직접 입력 오답을 반복합니다. 기억 상태에 따라 날짜를 정하는 적응형 복습·계정 동기화는 제공하지 않습니다. 별도 복습 일정 도구에서 원하는 날짜를 직접 계획할 수 있습니다.

CSV를 다시 가져오면 카드가 그대로 돌아오나요?

앞뒤 두 열을 읽습니다. 따옴표 안의 쉼표·줄바꿈을 지원하며 첫 행이 열 제목인지 직접 선택합니다. 수식으로 해석될 문자는 내보내기에 작은따옴표를 추가하므로 원문을 정확히 보존하려면 JSON 백업을 사용하세요.
