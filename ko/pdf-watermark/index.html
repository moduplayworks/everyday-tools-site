PDF 워터마크 넣기

PDF 여러 페이지에 문구·로고 워터마크를 넣으세요. 위치·각도·불투명도를 조정하고 실제 결과를 확인한 뒤 사본을 저장합니다.

PDF 준비

50MB · 1~200페이지 · 암호화·양식 필드가 없는 일반 PDF

PDF를 선택하거나 공개 예시로 시작하세요.

워터마크 설정
표시 종류

한글·영문·기본 문장부호 · 최대 1,000자·12줄. 지원하지 않는 글자는 안내합니다.

정지 이미지 5MB · 한 변 3,000px·200만 화소 이하. 배경은 그대로 유지합니다.

로고를 선택하세요.

크기 3%는 600pt 너비 페이지에서 18pt입니다. 큰 값은 진하게 보이며, 강조 표시는 불투명도 50% 이하로 설정하세요.

전체 또는 1-3, 5처럼 입력하세요. 페이지를 보는 것만으로 적용 범위가 바뀌지 않습니다.

위치·크기·각도 조정

왼쪽 위에서 표시 중심까지의 위치입니다. 로고 높이는 원래 비율을 유지합니다. 페이지 밖으로 나가면 저장하지 않습니다.

원본 페이지입니다. 미리보기로 적용 결과를 확인하세요.

파일·글자·위치는 브라우저에서 처리합니다. 새로고침·페이지 이동 시 입력·결과가 지워집니다.

표시를 넣은 PDF 사본

PDF와 설정을 준비한 뒤 사본을 만드세요.

원본 내용에 표시를 추가한 사본입니다. 기존 글자 편집·정보 삭제 기능이 아니며, 공유에는 문서·문구·로고·파일명을 넣지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

PDF에 워터마크를 넣는 방법

입력 예시

2페이지 공개 문서에서 전체를 선택하고 검토용을 불투명도 20%, 중심 50%·50%, 반시계 각도 30도로 넣으면 두 페이지에 같은 워터마크가 생깁니다. 글자 크기 8%는 너비 600pt 페이지에서 48pt입니다. 로고는 너비 40%일 때 240pt이고 원래 이미지 비율을 유지합니다.

PDF를 선택하고 문구 또는 JPG·PNG 로고를 준비하세요. 전체 또는 지정한 페이지에 같은 중심 위치·크기·각도·불투명도의 워터마크를 반복합니다. 로고 배경은 제거하지 않으며 이미지의 원래 가로세로 비율을 유지합니다.

미리보기는 실제 생성한 PDF를 렌더링합니다. 페이지 목록에서 적용 결과를 확인한 뒤 사본을 저장하세요. 위치는 보이는 페이지 왼쪽 위 기준의 중심 좌표이고, 회전·잘린 페이지 영역을 원래 좌표로 변환합니다. 글자 크기는 페이지 너비의 비율이므로 다른 크기의 페이지에서는 달라집니다. 원래 페이지를 이미지로 바꾸지 않습니다.

한글은 이 서비스에 포함된 글꼴을 PDF에 임베딩해 넣습니다. 글꼴은 처음 글자 작업을 할 때 같은 사이트에서 내려받으며 문서나 입력 문구를 보내지 않습니다. 한글·영문·기본 문장부호를 지원하고 이모지·한자 등 지원하지 않는 글자는 오류로 안내합니다. 줄바꿈은 입력대로 유지하며 자동 줄바꿈은 하지 않습니다. 길이가 페이지를 넘으면 크기를 줄이거나 줄바꿈하세요.

암호화·손상·양식 또는 서명 필드가 있는 PDF는 지원하지 않습니다. 본문을 재편집하거나 민감한 내용을 안전하게 지우는 기능이 아닙니다. 강조·도형 아래 원문은 남습니다. 인증서 서명 유효성을 보장하지 않고 PDF의 부가정보·링크·첨부도 유지합니다. 원본을 보관하세요. 표시는 전체 페이지 합계 1,000회까지, 결과는 100MB까지 지원합니다.

자주 묻는 질문

문구와 로고를 동시에 넣을 수 있나요?

한 번에 문구 또는 로고 하나를 선택해 여러 페이지에 적용합니다. 두 종류를 함께 넣으려면 첫 결과 사본에 다른 종류를 다시 적용하세요. 원본 파일은 변경하지 않습니다.

워터마크를 넣으면 복사나 내용 유출을 막나요?

눈에 보이는 표시를 추가할 뿐 복사·편집 방지나 저작권 증명 기능이 아닙니다. 원래 문서 내용은 그대로 남습니다. 낮은 불투명도로 본문 가독성을 확인하고 배포하세요.
