정해진 글자 수만 남기고 생략 표시를 붙입니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 0 · 최대 50000

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

계산·변환 기준

긴 글의 앞부분만 남기고 생략 표시 붙이기.

앞쪽 grapheme N개 + 생략 표시 (초과할 때만)

입력 예시

abcdef를 3글자로 → abc…

ABCDE를 3글자로 제한하고 …를 붙이면 ABC…가 됩니다. 원문이 제한 이하이면 생략 표시를 추가하지 않습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 텍스트, 남길 글자 수, 생략 표시 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

결과 전체 길이가 입력한 제한보다 길어질 수 있나요?

가능합니다. 제한은 보존할 원문 글자 묶음 수이고 생략 표시는 그 뒤에 추가됩니다. 결과 전체 글자 수 제한을 맞추려면 생략 표시의 길이도 고려하세요.
