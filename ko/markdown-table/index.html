자주 묻는 질문

어떤 붙여넣기 형식을 지원하나요?

탭으로 구분한 스프레드시트 표 또는 쉼표 CSV를 선택합니다. 큰따옴표로 감싼 셀의 구분자·줄바꿈과 두 번 쓴 따옴표를 읽습니다. 첫 행을 머리글로 쓸지 선택할 수 있고 부족한 칸은 빈칸으로 채웁니다. 머리글 포함 101행·20열, 셀 2,000자, 입력 100,000자까지 지원합니다.

휴대폰에서도 셀을 편집할 수 있나요?

행과 열을 고른 뒤 선택한 셀 하나를 편집하므로 넓은 입력 표를 가로로 밀 필요가 없습니다. 이전·다음 행 이동, 행·열 추가와 삭제, 열별 왼쪽·가운데·오른쪽 정렬을 제공합니다. 마지막 편집은 최대 10단계까지 되돌릴 수 있습니다. 붙여넣기 내용이 바뀌면 다시 불러와야 합니다.

HTML·줄바꿈·Markdown 기호는 어떻게 되나요?

셀의 HTML과 Markdown 기호는 텍스트로 보이도록 이스케이프합니다. 셀 안 줄바꿈은 <br>로 내보내며 표시 여부는 사용하는 서비스의 HTML 허용 설정에 따라 다릅니다. 도구 내 표 미리보기는 원래 셀의 줄바꿈을 보여줍니다. 출력은 Markdown 파일이며 스프레드시트 수식을 실행하지 않습니다.
