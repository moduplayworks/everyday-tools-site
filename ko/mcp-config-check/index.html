지원 문법과 처리 방법

Claude Desktop 설정에서 JSON 구문과 로컬 stdio 서버의 주요 값 형식을 미리 확인하는 도구입니다. 명령 실행, 패키지 설치, 서버 연결이나 비밀값 전송은 하지 않습니다.

mcpServers 객체 아래 각 서버의 command는 비어 있지 않은 문자열, args는 선택 문자열 배열, env는 선택 문자열 값 객체인지 검사합니다. 중복 JSON 키와 예약된 프로토타입 키는 거부합니다. JSON에서 Windows 경로의 역슬래시는 두 번 작성해야 합니다. command의 제어문자는 오류이며, args의 경로처럼 보이는 제어문자는 원문 확인 안내로만 표시합니다.

입력 예시

공개 예시에는 로컬 서버 1개, args 문자열 1개, env 문자열 값 1개가 있습니다. 점검 결과는 이 개수와 지원 범위를 보여 주며 node나 server.js를 실행하지 않습니다. env 값을 숫자로 바꾸면 문자열 값이 필요하다는 오류가 납니다.

지원 범위와 한계

JSON 50,000자·서버 1~50개를 처리합니다. 서버별 command는 2,048자, args는 200개·각 2,048자, env는 100개·값 8,192자 이하입니다. 서버 필드 command·args·env 외에는 점검 범위 밖으로 안내합니다. 다른 최상위 앱 설정은 개수만 알리고 검사하지 않습니다. VS Code·Cursor·원격 HTTP 설정, 파일 존재, 명령의 안전성, 권한과 통신 성공은 확인하지 않습니다.

입력과 결과는 내 브라우저에서만 처리합니다. 저장하거나 URL·통계로 보내지 않으며, 페이지를 떠나거나 새로고침하면 공개 예시로 돌아갑니다.

자주 묻는 질문

VS Code나 Cursor 설정도 검사하나요?

현재는 Claude Desktop의 mcpServers 로컬 stdio 기본형만 지원합니다. 다른 클라이언트의 servers 키나 원격 URL 설정은 오류로 단정하지 않고 지원 범위 밖으로 안내합니다.

정상 결과이면 서버가 안전하게 연결되나요?

아닙니다. 문자열과 배열 같은 정적 형식만 확인합니다. 파일 경로·실행 권한·의존성·패키지 신뢰성·서버 응답은 직접 확인해야 합니다. 이 도구는 설정을 설치하거나 실행하지 않습니다.

API 키나 명령 내용이 결과에 남나요?

결과에는 서버 이름·명령·인자·환경변수 값 대신 개수와 일반 안내만 표시합니다. 입력은 브라우저 안에서만 처리하며 저장하지 않습니다. 초기화·새로고침·페이지 이동 시 공개 예시로 돌아갑니다.
