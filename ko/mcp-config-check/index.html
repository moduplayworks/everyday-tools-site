지원 문법과 처리 방법

Claude Desktop 로컬 stdio 설정의 주요 JSON 형식이나 MCP 2026-07-28 요청의 필수 envelope 메타데이터를 브라우저 안에서 확인하는 도구입니다. 명령 실행, 패키지 설치, 서버 연결이나 비밀값 전송은 하지 않습니다.

Claude Desktop 설정 모드에서는 mcpServers 객체 아래 각 서버의 command·args·env 형식과 Windows 경로 이스케이프를 검사합니다. MCP 2026-07-28 요청 모드에서는 JSON-RPC 2.0의 요청 필드, params._meta 안의 프로토콜 버전과 clientCapabilities 형식을 확인하고 제거된 초기화 핸드셰이크 메서드를 표시합니다. 공개 예시는 현재 개정판의 tools/list 요청입니다.

입력 예시

Claude Desktop 설정 모드에는 로컬 서버 1개, args 문자열 1개, env 문자열 값 1개인 공개 예시가 있습니다. MCP 2026-07-28 요청 모드로 바꾸면 공식 사양 형식의 tools/list 예시가 열리고, params._meta의 protocolVersion과 clientCapabilities를 확인합니다. 예시 요청은 서버에 전송되지 않습니다.

지원 범위와 한계

JSON 50,000자 이하를 처리합니다. 설정 모드는 서버 1~50개, command 2,048자, args 200개·각 2,048자, env 100개·값 8,192자 한도입니다. 요청 모드는 JSON-RPC envelope와 현재 개정판의 필수 메타데이터 일부만 검사하며 메서드별 전체 스키마는 검사하지 않습니다. HTTP MCP-Protocol-Version 헤더와 본문 일치, 연결·서버 응답, 인증, 명령 실행 및 안전성은 확인하지 않습니다. 입력 값은 결과에 다시 표시하지 않습니다.

입력과 결과는 내 브라우저에서만 처리합니다. 저장하거나 URL·통계로 보내지 않으며, 페이지를 떠나거나 새로고침하면 공개 예시로 돌아갑니다.

자주 묻는 질문

VS Code나 Cursor 설정도 검사하나요?

Claude Desktop 설정 모드는 mcpServers 로컬 stdio 기본형만 지원합니다. 별도 요청 모드는 MCP 2026-07-28 요청의 공통 envelope만 검사하며, 다른 클라이언트의 로컬 설정 파일 형식은 검사하지 않습니다.

MCP 2026 요청 검사는 무엇을 확인하나요?

JSON-RPC 2.0의 기본 요청 형태와 params._meta의 현재 protocolVersion, clientCapabilities 객체를 확인합니다. initialize와 notifications/initialized는 이전 핸드셰이크 방식으로 표시합니다. 메서드별 전체 스키마나 서버가 모든 버전을 지원하는지는 확인하지 않습니다.

필수 필드가 맞으면 연결도 정상인가요?

아닙니다. 이 검사는 본문에 붙여 넣은 정적 요청 형식만 봅니다. HTTP 버전 헤더 일치, 전송, 인증, 메서드별 스키마와 서버 응답은 확인하지 않으며, 설정 모드도 명령을 실행하지 않습니다.

설정이나 요청에 비밀값을 넣어도 결과에 표시되나요?

결과에는 입력한 서버 이름·명령·환경변수 값·요청 ID·메서드·메타데이터를 다시 표시하지 않습니다. 처리는 브라우저 안에서만 하며 입력을 저장하거나 통계·URL로 보내지 않습니다.
