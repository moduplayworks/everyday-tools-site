지원 문법과 처리 방법

Claude Desktop 로컬 설정, MCP 2026 요청 envelope, MCP Apps 도구 선언과 UI 리소스 메타데이터를 브라우저에서 정적으로 확인합니다. 명령·HTML을 실행하거나 MCP 서버에 연결하지 않으며, 입력 값은 결과나 통계로 보내지 않습니다.

Claude Desktop 설정 모드는 mcpServers 아래 서버의 command·args·env 형식과 Windows 경로 이스케이프를 확인합니다. MCP 2026-07-28 요청 모드는 JSON-RPC 요청 envelope와 params._meta의 현재 프로토콜 버전 및 clientCapabilities를 확인합니다. MCP Apps 도구 모드는 tools/list의 도구 객체 한 개에서 _meta.ui.resourceUri와 visibility를, UI 리소스 모드는 resources/read의 contents 항목 한 개에서 ui:// URI·HTML MIME 형식·텍스트 또는 base64 콘텐츠·선택적 CSP와 권한 필드를 확인합니다.

입력 예시

MCP Apps 도구 선언 모드에는 _meta.ui.resourceUri가 ui:// 리소스를 가리키는 예시가 있습니다. UI 리소스 모드로 바꾸면 같은 URI와 text/html;profile=mcp-app 형식, 예시 CSP·권한이 있는 resources/read contents 항목이 열립니다. 두 입력은 각각 따로 검사하며 실제 서버에서 URI가 연결되는지는 확인하지 않습니다.

지원 범위와 한계

JSON은 50,000자 이하입니다. 설정 모드는 서버 1~50개, command 2,048자, args 200개·각 2,048자, env 100개·값 8,192자 한도입니다. 요청 모드는 envelope 일부만 검사합니다. Apps 모드는 도구 객체와 리소스 contents 항목을 각각 따로 검사하므로 URI 간 일치나 서버에 리소스가 존재하는지 확인하지 않습니다. HTML5 문법, HTML 실행, CSP의 호스트별 허용 여부, 연결, 메서드별 전체 스키마와 인증은 확인하지 않습니다. 명령을 실행하지 않고 입력 값은 결과에 다시 표시하지 않습니다.

입력과 결과는 내 브라우저에서만 처리합니다. 저장하거나 URL·통계로 보내지 않으며, 페이지를 떠나거나 새로고침하면 공개 예시로 돌아갑니다.

자주 묻는 질문

MCP Apps 도구 모드에는 어떤 JSON을 붙여 넣나요?

tools/list 결과의 tools 배열에서 확인할 도구 객체 하나를 붙여 넣습니다. _meta.ui.resourceUri는 해당 MCP Apps UI 리소스를 가리키는 ui:// URI여야 합니다.

UI 리소스 모드에는 어떤 JSON을 붙여 넣나요?

resources/read 결과의 contents 배열에서 UI 리소스 항목 하나를 붙여 넣습니다. URI는 ui://로 시작하고 mimeType은 text/html;profile=mcp-app이어야 합니다. HTML 원문은 실행하지 않습니다.

도구와 리소스 URI가 실제로 연결되는지 확인하나요?

아닙니다. 두 JSON 항목은 별도로 확인하므로 resourceUri가 실제 서버에 존재하는지, 도구와 리소스의 URI가 서로 같은지 연결 시험하지 않습니다. 서버나 호스트에 연결하지 않습니다.

CSP와 브라우저 권한도 안전한지 확인하나요?

현재 MCP Apps 사양에서 CSP 필드의 문자열 배열, 권한 이름과 객체 형식만 확인합니다. 도메인의 안전성, HTML 코드, 호스트별 CSP 적용이나 사용자의 권한 승인은 확인하지 않습니다.

붙여 넣은 설정과 HTML은 어디로 전송되나요?

전송하지 않습니다. JSON 검사는 브라우저에서만 실행합니다. 결과에 서버 이름·URI·HTML·CSP 값 같은 입력 내용을 다시 표시하거나 통계와 URL에 넣지 않습니다.

    MCP Apps의 ui:// 리소스 URI와 text/html;profile=mcp-app MIME 형식, 도구의 _meta.ui.resourceUri·visibility, 리소스의 CSP·권한 메타데이터 위치와 지원 필드를 확인합니다. 이 도구는 서버나 HTML 실행을 검사하지 않습니다.
