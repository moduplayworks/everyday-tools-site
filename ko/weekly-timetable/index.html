계산·파일 생성 기준

요일·시각별 블록을 편집해 주간 시간표 이미지 만들기.

각 블록의 요일·시작·끝 시각 → 선택한 시간 범위의 높이에 비례한 배치. 같은 요일의 구간은 시작 < 이전 끝이면 겹침입니다.

입력 예시

월요일 09:00~10:30 강의는 90분입니다. 이어지는 10:30~11:00은 겹치지 않지만 10:00부터 시작하면 30분이 겹쳐 오류로 안내합니다.

월요일 09:00~10:30 강의 뒤에 10:40 수업이 있다면 빈 시간은 10분입니다. 앞 강의의 다음 이동 시간을 20분으로 입력하면 10분 부족으로 안내합니다. 실제 수업 시간이 겹치면 기존처럼 오류가 됩니다. 교시별 학습 점검 예시에서 09:00~09:40, 09:40~09:50 휴식, 09:50~10:30을 입력하고 독해 60분은 분할 허용, 오답 확인 20분은 분할 금지로 두면 독해가 40분+20분, 오답 확인이 10:10~10:30에 배정됩니다. 휴식 10분은 가용 시간에 포함하지 않습니다. 위 시간표와 별도 입력이며 자동으로 가져오지 않습니다.

사용 방법

  1. 입력된 예시를 쓰거나 필요한 값을 바꾸세요. 추가 설정은 펼쳐서 확인합니다.
  2. 결과를 확인한 뒤 도시·일정·달력·시간 블록을 검토하세요. 오류는 제외하지 않고 수정을 안내합니다.
  3. 결과를 복사하거나 실제 파일을 저장하세요. 가져오기·인쇄는 기기의 지원 기능을 사용합니다.

수동 시간 블록 1~40개, 각 제목 28자, 블록 최소 15분. 하루를 넘는 블록과 겹치는 블록은 지원하지 않습니다. 차트에 짧게 표시한 제목은 이미지 하단 번호 목록에 모두 보존합니다. 자동 공부량 배분은 완강 계획 도구를 사용하세요.

자주 묻는 질문

강의를 자동으로 날짜에 배분하나요?

아닙니다. 요일별 블록을 직접 편집하는 시간표입니다. 남은 강의를 마감일까지 자동 배분하려면 완강 계획 계산기를 사용하세요. 블록은 최대 40개이며 마지막 삭제 한 번을 취소할 수 있습니다.

작은 블록에서 긴 이름이 잘리면 저장 파일도 잘리나요?

시간 칸은 번호와 짧은 이름을 보여주며 이미지 하단 목록에 전체 이름과 시각을 포함합니다. 결과 텍스트도 모든 블록을 포함합니다. 새로고침하면 개인 블록과 출력은 지워집니다.

이동 시간은 자동으로 계산하나요?

아닙니다. 각 블록 뒤에 필요한 이동 시간을 0~180분으로 직접 입력합니다. 같은 요일의 다음 블록까지 빈 시간과 비교하며 마지막 블록은 비교하지 않습니다. 장소 이름만으로 경로·거리를 추정하지 않습니다.

분할하지 않는 작업이 한 교시에 들어가지 않으면 어떻게 되나요?

작업 전체가 들어가는 다음 공부 교시로 이동합니다. 앞 교시에 남은 공간을 뒤 작업으로 채우지 않아 입력 순서를 지킵니다. 해당 요일의 어떤 교시에도 들어가지 않으면 그 작업과 뒤 작업을 미완료로 표시합니다.

여러 교시의 작업을 계산할 때 쉬는 시간과 이동 시간은 어떻게 반영하나요?

직접 입력한 휴식 블록과 교시 사이 빈 시간에는 작업을 배정하지 않습니다. 이동이 필요하면 그 시간을 휴식 블록이나 빈 구간으로 입력하세요. 위 시간표의 이동시간을 자동으로 가져오거나 중복 차감하지 않습니다. 다른 요일로 자동 이월하지 않습니다.

결과의 모든 작업을 파일로 저장할 수 있나요?

SVG와 PNG는 선택한 출력 페이지만 저장합니다. 모든 교시와 작업의 배정·미완료 분량은 전체 TXT와 전체 인쇄에 포함됩니다. 입력을 수정하면 다시 계산하기 전까지 이전 결과 저장을 막습니다.
