동일 파일 찾기

선택한 파일의 내용을 비교해 완전히 같은 파일을 찾으세요. SHA-256 후보 검사 후 바이트를 확인하며 업로드하거나 원본을 삭제하지 않습니다.

선택한 파일 비교

최대 100개 · 파일당 50MiB · 전체 250MiB. 빈 파일도 비교합니다.

공개 예시 파일 3개가 준비되어 있습니다. 첫 실행에서 실제 비교합니다.

선택한 파일

    크기와 SHA-256을 확인한 뒤 실제 바이트를 비교합니다. 비슷한 사진 찾기나 파일 삭제는 하지 않습니다.

    선택한 파일은 브라우저 안에서 처리하며 업로드하거나 저장하지 않습니다. 보고서를 내려받으면 파일 이름이 포함됩니다.

    자주 묻는 질문

    비슷한 사진이나 문서도 찾나요?

    아니요. 파일 전체 바이트가 같은 경우만 찾습니다. 눈으로 같아 보이는 사진도 메타데이터·압축·크기가 다르면 별개입니다. 이름·날짜나 사진의 시각적 유사성으로 판정하지 않습니다.

    중복 파일을 자동으로 지우나요?

    원본 파일은 읽기만 하며 삭제하거나 수정하지 않습니다. 추가 사본 용량은 선택 항목 기준의 산술 추정치이며 서로 다른 실제 파일이나 회수 가능한 디스크 공간을 보증하지 않습니다.

    어떤 파일과 크기를 검사하나요?

    직접 선택한 파일 최대 100개, 파일당 50MiB, 전체 250MiB를 지원하며 빈 파일도 검사합니다. 폴더나 드라이브 전체를 탐색하지 않습니다. 보고서 저장을 누르면 파일 이름이 보고서에 포함되므로 공유 전에 확인하세요.

    계산 기준과 참고 자료

    • noble-hashes — Incremental hashing

      파일을 조각별로 읽어 SHA-256을 갱신하는 구현의 근거입니다. 같은 해시의 후보도 바이트 비교로 다시 확인합니다.

    • MDN — SubtleCrypto.digest

      digest API가 스트리밍 입력을 지원하지 않음을 설명합니다. 이 도구는 전체 파일 버퍼 대신 점진적 해시와 분할 비교를 사용합니다.
