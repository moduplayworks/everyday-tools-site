자주 묻는 질문

어떤 JSON Schema 버전을 지원하나요?

JSON Schema Draft 2020-12의 핵심·검증 키워드를 사용합니다. $ref와 $dynamicRef는 입력 스키마 안의 # 로 시작하는 로컬 참조만 해석하며 URL을 요청하지 않습니다. 다른 초안과 사용자 정의 어휘는 지원하지 않습니다.

format: email이나 date도 검사하나요?

아니요. Draft 2020-12에서 format은 기본적으로 주석 어휘입니다. 이 페이지는 format 형식 검사를 비활성화하므로 실제 이메일 배달 가능성이나 날짜의 업무상 유효성을 확인하지 않습니다.

입력·숫자·실행 시간 제한은 무엇인가요?

스키마와 데이터는 각각 100,000자, 깊이 100, 값 20,000개까지입니다. 중복 키와 유한한 JavaScript 정수 범위를 벗어난 정수는 거부합니다. JSON 소수는 JavaScript 부동소수점으로 처리하며, 검증은 작업자에서 2초 뒤 중단됩니다.

오류 보고서에 입력값이 포함되나요?

입력값과 실제 데이터, 객체 키, JSON 경로는 보고서나 분석 이벤트에 넣지 않습니다. 첫 오류의 스키마 키워드만 보여 줍니다. 검사 내용은 브라우저에서 처리하며 저장·전송하지 않습니다.

계산 기준과 참고 자료

  • JSON Schema — Draft 2020-12 명세

    Draft 2020-12 코어·검증 어휘의 기준입니다. 이 도구는 format 어휘를 주석으로 취급하고 입력 스키마의 로컬 참조만 해석합니다.

  • Ajv — JSON Schema 보안 고려사항

    사용자 스키마의 컴파일·패턴·uniqueItems 실행 시간 위험을 설명합니다. 이 도구는 입력 한도, 단일 오류, 별도 작업자와 실행 시간 제한으로 범위를 제한합니다.
