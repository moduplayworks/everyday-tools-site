스타일 비교의 범위

Format 열 순서가 달라도 이름으로 대응합니다. 같은 이름의 숫자 필드는 앞 0과 불필요한 소수 0을, 16진 색상은 대소문자와 앞 0을 정리한 값으로도 비교합니다. 글꼴명과 알 수 없는 필드는 양끝 공백만 제거합니다. 원본 값도 함께 보여 줍니다.

공개 예시의 Default는 Fontsize 24와 28이 충돌합니다. Aside는 18과 018.0, 색상 표기만 달라 비교 값은 같습니다. 같은 파일의 중복 정의나 정의되지 않은 참조는 별도로 표시합니다.

같은 정의가 같은 영상 모양을 뜻하지는 않습니다. 해상도·스크립트 설정·인라인 태그·렌더러 차이는 비교하지 않습니다. 숫자의 범위나 모든 ASS 문법을 검증하는 도구가 아닙니다.

ASS 글꼴을 확인하는 방법

V4+ 스타일의 Fontname과 대사의 \fn·\r 태그를 읽습니다. 실제 텍스트 구간에서 사용한 글꼴과 사용하지 않은 스타일을 구분하며, 그림 명령 구간은 글꼴 사용으로 세지 않습니다.

선택한 TTF·OTF 파일의 family name과 typographic family name을 읽어 대소문자 구분 없이 대조합니다. 설치된 글꼴을 검색하거나 글꼴을 내려받지 않습니다. ASS에 첨부된 글꼴도 추출하지 않습니다.

공개 예시의 대사에는 Example Sans, Example Mono, Example Serif 세 글꼴이 사용됩니다. 글꼴 파일을 고르지 않아도 사용 목록을 확인할 수 있으며, 파일을 고르면 그 파일의 family name과 대조합니다. 공개 예시의 Default는 Fontsize 24와 28이 충돌합니다. Aside는 18과 018.0, 색상 표기만 달라 비교 값은 같습니다. 같은 파일의 중복 정의나 정의되지 않은 참조는 별도로 표시합니다.

지원 범위는 V4+ ASS·UTF-8·스타일 500개·사용 글꼴 500개입니다. 누락된 스타일과 깨진 태그는 오류로 안내합니다. 변환 애니메이션 안의 글꼴 변경은 지원하지 않습니다. 이 점검은 전체 ASS 문법 검사나 재생기가 아닙니다.

자주 묻는 질문

없다고 나온 글꼴이 컴퓨터에도 없는 건가요?

아닙니다. 직접 선택한 TTF·OTF의 이름과 일치하지 않았다는 뜻입니다. 설치된 글꼴은 검색하지 않으며 파일 이름으로 글꼴을 판단하지 않습니다.

이름이 일치하면 영상에서도 정확히 나오나요?

보장하지 않습니다. 글자별 지원 범위, 굵기·기울임, 플레이어 대체 글꼴과 렌더링 차이는 확인하지 않습니다. 영상의 실제 재생 결과도 확인하세요.

어떤 ASS와 글꼴 파일을 지원하나요?

UTF-8 V4+ ASS의 스타일·대사와 fn·r 태그를 점검합니다. 일반 TTF·OTF 이름 테이블을 읽으며 TTC·WOFF, ASS 첨부 글꼴 추출, 설치 검색은 지원하지 않습니다.

계산 기준과 참고 자료

  • Aegisub — ASS 글꼴·스타일 태그

    fn 글꼴 변경과 r 스타일 초기화, 그림 모드의 공식 설명입니다. 이 도구는 글꼴 의존성만 점검하며 전체 ASS 재생을 구현하지 않습니다.

    선택한 글꼴 파일의 family name ID 1과 typographic family name ID 16을 대조하는 기준입니다. 이름 일치가 글자 지원이나 렌더링 성공을 뜻하지는 않습니다.
