사용 방법과 처리 기준

YAML 1.2 설정과 JSON 문서를 타입을 확인하며 양방향으로 변환하는 도구입니다.

실제 예시

YAML의 name: 도구, active: true, id: 9007199254740993을 변환하면 name은 문자열, active는 불리언, id는 반올림되지 않은 숫자로 JSON에 나타납니다. yes는 YAML 1.2에서는 문자열입니다. JSON을 YAML로 바꿀 때는 키와 문자열에 따옴표를 붙여 yes, null 같은 글자의 타입이 바뀌지 않게 합니다.

자주 묻는 질문

어떤 YAML 타입을 지원하나요?

YAML 1.2 core의 문자열·숫자·불리언·null·배열·문자열 키 객체를 지원합니다. 숫자·복합 객체 키, .inf·.nan, 사용자 지정 태그·객체 생성 태그, 병합 키 <<, YAML 1.1과 여러 문서 스트림은 오류로 알려드립니다. 중복 키도 조용히 덮어쓰지 않습니다.

주석·앵커와 큰 숫자는 유지되나요?

JSON에는 주석·앵커 표현이 없어 제거하거나 독립 값으로 펼치고 처리 안내를 제공합니다. 순환 별칭은 거부하며 확장은 50회·전체 10,000개 값까지 제한합니다. 큰 정수와 소수는 원래 숫자 정밀도를 유지하지만 들여쓰기·따옴표·16진수 표기 등은 바뀔 수 있습니다.

문서 크기 제한과 저장 방식은 무엇인가요?

입력은 100,000자 이하, 변환 깊이는 80 이하, 출력은 1,000,000자 이하입니다. 별도 Worker의 실행은 3초, 모듈 준비는 10초까지 기다립니다. 오류나 취소 시 이전 정상 결과를 유지합니다. 결과를 검토한 뒤 JSON·YAML 파일로 저장하며 입력을 브라우저 저장소에 보관하지 않습니다.
