URL 추적 매개변수 제거

공유할 URL에서 utm_로 시작하는 매개변수를 제거하세요. 다른 검색 매개변수·중복 값·해시의 원래 표기를 유지하며 주소를 열거나 전송하지 않습니다.

URL 추적 매개변수 제거

현재 값은 수정할 수 있는 공개 예시입니다. 실제 정보로 바꾼 뒤 실행하세요.

utm_로 시작하는 이름만 대소문자 구분 없이 제거합니다. 나머지 매개변수와 해시는 유지합니다. 익명화·보안 검사 도구가 아닙니다. 서명·결제·로그인 링크는 수정하지 말고 원본을 보관하세요.

사용 방법과 계산 기준

예시 주소 https://example.com/product?id=42&utm_source=newsletter&utm_medium=email#details에서 실행하면 id=42와 #details는 유지하고 UTM 두 항목만 제거합니다. 매개변수 이름은 percent-decoding 후 대소문자 구분 없이 utm_ 접두사를 확인합니다. 다른 값의 순서·중복·더하기 기호·percent-encoding은 다시 직렬화하지 않습니다. 주소를 가져오거나 리디렉션을 따라가지 않습니다.

자주 묻는 질문

모든 추적 정보를 없애나요?

아니요. utm_로 시작하는 쿼리 이름만 제거합니다. gclid·fbclid·광고 ID·쿠키·주소 경로·해시와 URL에 직접 들어 있는 개인정보는 확인하거나 제거하지 않습니다.

로그인·결제 링크에도 써도 되나요?

서명·결제·로그인 링크는 매개변수 변경으로 작동하지 않을 수 있으므로 원본 그대로 사용하세요. 이 도구는 링크 안전성이나 정리한 주소의 작동 여부를 확인하지 않습니다.

원본 URL을 저장하거나 열어 보나요?

아니요. 입력과 결과는 현재 페이지 메모리에서만 처리합니다. 복사 전에 결과를 확인하고 원본을 별도로 보관하세요. UTM이 없으면 입력의 앞뒤 공백 외에는 바꾸지 않습니다.
