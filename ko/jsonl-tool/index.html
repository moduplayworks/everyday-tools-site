JSONL 검사·JSON 변환

JSONL 문법을 검사하고 JSON 배열과 변환하세요. 큰 숫자의 원래 표기를 유지하며 중복 키와 오류 위치를 확인하고 브라우저에서 저장합니다.

JSONL 입력

입력은 UTF-16 20만자·UTF-8 1,000,000바이트 이하, 깊이 100·전체 값 20,000개 이하입니다. JSONL은 결과 배열 1개를 포함하여 계산합니다. 출력은 2MiB 이하입니다.

1줄에 JSON 값 1개를 입력하세요. 빈 줄·BOM·중복 객체 키는 거절하며 마지막 줄바꿈 1개는 허용합니다. 큰 정수·소수·지수의 숫자 표기는 그대로 유지하지만 문자열 이스케이프와 들여쓰기는 정리될 수 있습니다. 검사는 스키마나 업무상 정확성을 보증하지 않습니다.

입력과 결과는 브라우저 메모리에만 둡니다. 새로고침·이동 시 지우며 내용이나 파일명은 통계·URL로 보내지 않습니다. 저장한 파일은 기기에 남습니다.

자주 묻는 질문

큰 숫자와 소수 표기를 보존하나요?

9007199254740993·-0·1.2300·1e400 같은 숫자 토큰을 그대로 출력합니다. 문자열 값과 키 순서도 유지하지만 공백과 문자열 이스케이프 표기는 정규화될 수 있습니다. 전체 문서를 JavaScript 숫자로 변환하지 않습니다.

문법 통과가 데이터의 정확성을 뜻하나요?

아니요. 스키마나 업무 규칙은 검사하지 않습니다. 객체의 중복 키는 호환성 문제를 피하려고 모든 깊이에서 거절합니다. 오류 줄과 열은 1부터 시작하며 열은 UTF-16 코드 단위입니다.

빈 배열과 처리 한도는 어떻게 되나요?

빈 JSONL은 거절하지만 빈 배열 []은 레코드 0개의 빈 JSONL로 변환합니다. 입력은 UTF-16 200,000단위와 UTF-8 1,000,000바이트, 깊이 100, 전체 구조 값 20,000개로 제한합니다. JSONL은 결과 배열의 값 하나를 예약하므로 스칼라 최대 19,999개입니다. 출력은 2MiB 이하입니다.
