상품사진 일괄 편집

단색 배경 상품사진의 배경을 지우고 여백·크기·파일 용량을 맞춰 JPG·PNG와 ZIP으로 저장하세요. 사진은 브라우저에서만 처리합니다.

상품사진과 출력 설정

상품사진 설정

JPG·PNG·WEBP · 장당 12MB·1,200만 화소, 총 48MB 이하. 선택 없이 실행하면 공개 예시를 만듭니다.

사진 가장자리와 연결된 비슷한 색만 지웁니다. 복잡한 배경·그림자·상품과 비슷한 배경색은 정확히 분리하지 못합니다.

JPG는 품질을 낮추며 목표 용량을 시도합니다. PNG는 용량을 보장하지 않습니다. 목표를 넘으면 결과에 표시합니다.

처리 크기와 개인정보

파일은 서버로 보내지 않습니다. 처리 중 긴 변을 최대 1,600px로 줄인 뒤 출력 크기에 맞춥니다. 작은 상품은 확대되어 흐려질 수 있습니다. 원본은 바꾸지 않으며 새 파일에 원본 EXIF를 복사하지 않습니다. 새로고침하면 입력과 결과가 지워집니다.

원본과 결과 확인

첫 번째 원본과 모든 결과를 비교하세요. 상품까지 지워지면 허용 오차를 줄이거나 배경 제거를 되돌린 뒤 다시 만드세요.

단색 배경 상품사진 일괄 편집 방법

흰 배경 사진에서 남은 상품 영역이 100×200px이고 출력을 1,000×1,000px, 최소 여백을 10%로 설정하면 상품은 400×800px로 맞춰집니다. 위아래 100px, 좌우 300px 여백이 생깁니다. JPG는 흰 배경, PNG는 제거한 배경의 투명도를 유지합니다.

가장자리에서 시작해 지정한 배경색과 허용 오차 안에 있는 연결된 픽셀을 투명하게 만듭니다. 남은 불투명 영역을 기준으로 상품을 가운데 배치하고 지정한 최소 여백을 확보합니다. 상품 내부에 갇힌 같은 색은 보존하지만 가장자리와 이어진 같은 색 상품 부분은 지워질 수 있습니다.

출력은 장당 400만 화소, 합계 1,600만 화소까지입니다. 판매처별 업로드 규정이나 배경 제거 품질을 보장하지 않습니다. 저장 전에 모든 결과를 확인하세요.

자주 묻는 질문

복잡한 배경도 자동으로 지우나요?

아니요. 지정한 색과 비슷하고 사진 가장자리와 연결된 배경만 지웁니다. 무늬·그림자·상품과 같은 색 배경은 남거나 상품이 지워질 수 있습니다. 미리보기를 확인하고 허용 오차를 낮추거나 배경 제거를 꺼 주세요.

목표 용량을 반드시 맞추나요?

JPG는 출력 크기를 유지하며 품질을 단계적으로 낮춥니다. 목표를 맞추지 못하면 초과 상태를 표시합니다. PNG는 품질을 낮추지 않으므로 크기를 줄이거나 JPG를 선택해야 할 수 있습니다.

사진을 올리면 서버에 저장되나요?

사진은 이 브라우저에서만 처리하며 업로드하지 않습니다. 원본은 그대로 두고 새 이미지와 ZIP을 만듭니다. 새로고침·페이지 이동 후에는 개인 사진과 결과를 복원하지 않습니다.
