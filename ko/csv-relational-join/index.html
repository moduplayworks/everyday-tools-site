CSV 키 관계 조인

두 개의 CSV 표를 지정한 키로 연결해 내부·왼쪽·전체 조인 결과를 만듭니다. 중복 키의 모든 조합을 보존하고 미일치 셀은 JSON null로 구분합니다.

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

사용 방법과 예시

문자열 키가 정확히 같은 행 쌍을 출력하고 모드에 따라 미일치 행을 null 셀과 함께 남깁니다.

기본 왼쪽 조인은 Pen과 재고 5를 연결하고 Book의 오른쪽 셀은 null로 표시하여 2행을 만듭니다.

각 표 100행·12열, 결과 1000행까지입니다. 모든 입력 셀은 문자열이며 빈 키도 서로 일치합니다. SQL NULL 키와 같지 않습니다.
