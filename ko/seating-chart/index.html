자리 배치표 만들기

좌석 격자에 빈자리·고정석을 설정하고 이름을 배치하세요. 실제 행·열의 배치표를 PNG·SVG·CSV로 저장합니다.

입력

빈자리·고정석 설정

격자를 누르고 아래에서 빈자리 또는 고정할 사람을 선택하세요. 행·열이나 이름을 바꾸면 격자를 갱신하며 이전 제약은 확인 후 초기화합니다.

배치 설정 백업·복원

이름과 고정석·빈자리를 포함합니다. 추첨 결과는 저장하지 않습니다. 새로고침하면 예시로 돌아옵니다.

결과

입력된 이름으로 바로 배치를 만드세요.

기본 내보내기는 학생 번호를 씁니다. 켜면 이름이 파일과 공유에 들어갑니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

광고

광고 설정

Adsterra 광고를 허용하면 광고 제공자가 IP 주소·브라우저 정보 등을 처리할 수 있습니다. 거절해도 도구는 그대로 사용할 수 있습니다.

광고 사용을 선택해 주세요.

계산 기준과 사용 방법

빈자리·고정석 제약을 유지한 무작위 자리 배치표와 실제 격자 이미지 생성.

사용 가능석 = 행 × 열 − 빈자리 · 고정석 유지 후 나머지 사람을 섞어 순서대로 배정

입력 예시

2행 3열에 여섯 명을 넣으면 여섯 좌석에 한 명씩 배치됩니다. 다섯 명으로 바꾸고 6번을 빈자리로 설정하면 나머지 다섯 좌석만 사용합니다. 1번에 학생 2를 고정하면 다시 추첨해도 학생 2는 1번에 남고 다른 학생들만 섞입니다.

사용 방법

  1. 예시값을 사용하거나 내용을 바꾼 뒤 자리 배치 만들기 버튼을 누르세요.
  2. 원하는 좌석의 빈자리·고정석 설정을 적용하고 다시 배치하세요.
  3. 결과와 도구 링크를 함께 공유할 수 있습니다. 개인 입력은 링크에 들어가지 않습니다.

한계와 해석

행·열 각각 1~12, 인원 1~144명, 이름 60자입니다. 같은 이름도 사람 번호로 구분합니다. 고정석은 한 사람당 하나이며 빈자리와 겹칠 수 없습니다. 남는 좌석은 빈자리로 표시합니다. 관계·성별·시력 등을 추정하거나 최적 배치라고 판단하지 않습니다. 이름은 파일·공유에 별도로 포함할 때만 내보냅니다. 긴 이름은 이미지에서 줄이고 전체 CSV에는 보존합니다.

자주 묻는 질문

고정석을 지정한 뒤 다시 추첨해도 유지되나요?

입력한 행·열·이름이 같으면 유지합니다. 이름의 순서 또는 행·열을 바꾸면 기존 번호가 다른 사람·좌석을 가리킬 수 있어 격자 갱신 시 확인 후 제약을 초기화합니다.

동명이인과 남는 좌석은 어떻게 표시하나요?

각 사람은 입력 순서의 학생 번호로 구분합니다. 같은 이름도 고정석 선택에서 번호가 함께 표시됩니다. 정해 둔 빈자리와 인원보다 남는 좌석은 모두 빈자리로 표시하고 한 사람은 한 좌석만 사용합니다.

공유할 때 학생 이름도 들어가나요?

화면 미리보기에는 입력한 이름이 보이지만 기본 결과 파일·공유는 학생 번호만 포함합니다. 이름 포함을 직접 켜야 파일·공유에 이름이 들어갑니다. 입력 JSON에는 모든 이름과 제약이 들어갑니다.
