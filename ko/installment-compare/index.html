계산·변환 기준

결제 금액을 일시불 할인과 사용자가 입력한 할부 수수료 조건으로 비교해 예상 수수료·월 납부 범위·총액을 확인합니다..

월 수수료율 = 연 수수료율 ÷ 12; 매월 수수료 = 남은 원금 × 월 수수료율; 원금은 할부 개월로 균등 분할하고 남는 원은 앞 회차에 배분; 수수료는 회차별 원 단위 반올림

입력 예시

결제 1,000,000원 · 6개월 · 연 수수료율 15% · 일시불 할인율 0.5% → 할부 수수료 43,750원 · 할부 총액 1,043,750원 · 일시불 995,000원

결제 1,000,000원, 6개월, 연 수수료율 15%, 일시불 할인율 0.5%라면 원금은 회차당 166,666~166,667원으로 나뉩니다. 연율을 12로 나눈 월 비율을 남은 원금에 적용하면 반올림한 할부 수수료는 43,750원, 할부 예상 총액은 1,043,750원입니다. 일시불 할인 후 금액은 995,000원이며 차액은 48,750원입니다. 첫 달 예상 납부액은 179,167원, 마지막 달은 168,749원입니다.

자주 묻는 질문

할부 수수료는 어떻게 계산하나요?

연 수수료율을 12로 나눈 월 비율을 회차 시작 시 남은 원금에 곱합니다. 원금은 균등하게 나누고 남는 원은 앞 회차에 배분하며 회차별 수수료를 원 단위 반올림합니다.

카드 명세서 금액과 왜 다를 수 있나요?

실제 수수료율, 이용일수, 결제일, 원금 배분, 무이자 행사와 카드사별 청구 규칙이 다를 수 있습니다. 실제 조건은 카드사 앱이나 이용대금명세서에서 확인하세요.

무이자 할부나 일시불 혜택도 비교할 수 있나요?

무이자라면 연 수수료율을 0으로 입력하고, 일시불 할인은 일시불 할인율에 넣으세요. 포인트·캐시백·할부 행사·기회비용은 자동으로 계산하지 않습니다.

계산 기준과 참고 자료

  • 여신금융협회 소비자지원센터 — 신용카드 이용 안내

    카드 할부 수수료와 실제 적용률 확인 경로를 안내합니다. 계산기는 사용자가 입력한 연 수수료율만 사용하며 카드사 요율을 조회하지 않습니다.

  • 여신금융협회 — 신용카드 상품 공시

    카드 상품의 금리와 수수료율 공시 정보로 연결됩니다. 특정 카드의 최신 할부 조건을 이 계산기에 자동 입력하지 않습니다.
