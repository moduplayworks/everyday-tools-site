지원 문법과 처리 방법

반복해서 쓰는 프롬프트의 {{name}} 자리에 직접 정한 문자열을 한 번만 대입하고, 빠진 값과 불필요한 키를 확인하는 도구입니다. AI 모델에 내용을 전송하지 않습니다.

변수 이름은 공백 없이 영문·밑줄로 시작하고 영문·숫자·밑줄 64자 이하입니다. 값은 같은 이름을 키로 하는 JSON 문자열입니다. 대소문자를 구분하며 같은 이름은 모두 같은 값으로 바꿉니다. 삽입된 값 속의 {{other}}나 $&·HTML은 다시 해석하지 않고 그대로 남깁니다.

입력 예시

공개 예시는 tone에 short, topic에 a daily walking plan을 넣어 Write a short summary about a daily walking plan.을 만듭니다. topic 키를 지우면 {{topic}}가 미리보기에 남고 누락 목록에 표시됩니다. 값이 모두 있어야 완성된 결과로 처리합니다.

지원 범위와 한계

템플릿 20,000자·변수 표시 500개, 값 JSON 50,000자·키 100개·각 값 20,000자, 결과 100,000자가 한도입니다. 중복 키와 프로토타입 예약 키는 지원하지 않습니다. 조건문·반복문·함수·중첩 경로·공백을 넣은 변수 문법·이중 괄호 이스케이프는 지원하지 않습니다. 코드를 평가하거나 AI 요청을 보내지 않습니다.

입력과 결과는 내 브라우저에서만 처리합니다. 저장하거나 URL·통계로 보내지 않으며, 페이지를 떠나거나 새로고침하면 공개 예시로 돌아갑니다.

자주 묻는 질문

JSON 값에 숫자나 객체를 넣어도 되나요?

값은 문자열만 지원합니다. 숫자는 큰따옴표로 감싼 문자열로 바꾸세요. 객체·배열을 자동으로 문자열로 바꾸지 않으므로 의도하지 않은 값이 들어가는 것을 막습니다.

값이 없거나 사용하지 않은 키는 어떻게 되나요?

값이 없으면 원래 {{name}} 표시를 남기고 미완성으로 안내합니다. 사용하지 않은 키는 목록으로 알려 주며 결과에 삽입하지 않습니다. 원본 템플릿과 JSON은 자동으로 수정하지 않습니다.

다른 템플릿 엔진이나 AI 서비스와 같은 문법인가요?

이 도구가 명시한 {{name}} 한 번 치환 규칙만 적용합니다. Jinja·Mustache 같은 엔진의 전체 문법이나 특정 AI 서비스의 변수 규칙을 구현하지 않습니다. 결과를 사용할 서비스의 규칙도 확인하세요.
