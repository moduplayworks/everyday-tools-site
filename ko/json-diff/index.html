자주 묻는 질문

줄 비교와 무엇이 다른가요?

JSON 구문을 먼저 읽고 객체의 키·배열의 위치·값의 타입을 비교합니다. 공백과 객체 키 순서는 무시합니다. 문자열 "1"과 숫자 1은 다르고, 배열은 순서를 유지해 위치별로 비교하므로 중간 삽입 시 뒤 항목도 변경으로 나올 수 있습니다.

큰 정수와 소수는 정확히 비교하나요?

숫자 토큰을 부동소수점으로 바꾸지 않습니다. 9007199254740992와 9007199254740993은 다르며 1, 1.0, 1e0은 같습니다. -0과 0도 같은 값으로 비교합니다. 비교하는 숫자 지수는 절댓값 99,999,999까지 지원합니다.

JSON 경로와 제한은 무엇인가요?

경로는 JSON Pointer이며 /는 ~1, ~는 ~0으로 이스케이프합니다. 빈 경로는 문서 전체입니다. 각 입력 200,000자·깊이 100·값 20,000개까지 읽으며 중복 키는 거부합니다. 화면은 차이 100개, 보고서는 1,000개까지 표시하며 전체 차이 개수와 잘림 여부를 따로 알립니다.
