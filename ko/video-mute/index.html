MP4·WebM·MOV · 최대 100MB·60초. 영상은 이 브라우저에서 처리합니다.

예시 영상으로 첫 실행을 확인할 수 있어요.

출력 설정

영상 화면은 다시 인코딩하고 오디오 트랙은 결과에서 제거합니다.

재생 볼륨만 낮추는 기능이 아닙니다. 결과 영상에는 오디오 트랙을 넣지 않습니다.

동영상 소리 제거를 브라우저에서 실행하세요

공개 예시에는 영상과 소리가 함께 있습니다. 소리 제거를 누르면 다시 인코딩한 결과에 영상 트랙만 담깁니다. 결과 설명에 오디오 트랙 없음이 표시되고, 저장 전에 새 파일을 재생해 확인할 수 있습니다.

새 동영상으로 다시 인코딩합니다

선택한 파일을 서버로 올리지 않습니다. 새 컨테이너와 코덱으로 저장하므로 입력 형식·화질·파일 크기가 달라질 수 있습니다. 예상 크기와 원본을 비교하고 결과를 직접 재생해 확인하세요.

결과 스트림에는 영상 트랙만 포함합니다. 영상은 새로 인코딩되므로 원본의 화질·메타데이터·코덱을 그대로 보존하지 않습니다.

파일과 기기 제한

최대 100MB·60초 영상에서 실행합니다. 브라우저가 지원하는 저장 형식을 감지해 MP4 또는 WebM으로 출력합니다. 인코딩 중에는 탭을 열어 두세요. 기기의 메모리와 코덱 지원에 따라 일부 파일이 처리되지 않을 수 있습니다.

자주 묻는 질문

기존 영상의 재생 볼륨만 낮추나요?

아닙니다. 결과를 구성하는 스트림에 오디오 트랙을 넣지 않습니다. 영상도 브라우저에서 새로 인코딩하므로 일부 화질이나 메타데이터는 달라질 수 있습니다.

소리 제거 후 원본 파일도 바뀌나요?

원본 파일은 수정하지 않습니다. 오디오 트랙을 제외한 새 영상을 만들고 별도 파일로 저장합니다.

영상과 파일 이름을 서버로 보내나요?

보내지 않습니다. 선택한 영상과 파일명은 브라우저에서만 사용합니다.

계산 기준과 참고 자료

  • MDN — MediaRecorder

    브라우저가 지원하는 컨테이너·코덱으로 캡처 스트림을 재인코딩합니다. 지원 형식과 출력 품질은 브라우저에 따라 달라집니다.

  • MDN — Canvas captureStream

    현재 영상 프레임을 로컬 Canvas에 그리고 브라우저 내 녹화용 영상 스트림으로 캡처합니다.

  • WebKit — MediaRecorder API

    WebKit 구현에서 캔버스·Web Audio 스트림 녹화와 형식 기능 감지를 설명합니다. 현재 기기의 코덱 지원 여부는 실행 중 기능 감지합니다.
