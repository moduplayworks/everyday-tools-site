입력 크기 (UTF-16 코드 단위): 0 / 100,000

입력 형식이나 모델별 차이를 고려해 직접 여유량을 더할 수 있습니다.

자주 묻는 질문

어떤 토크나이저를 사용하나요?

OpenAI의 o200k_base 또는 cl100k_base 인코딩으로 입력한 일반 텍스트를 셉니다. 인코딩 선택만으로 특정 모델의 전체 API 요청을 정확하게 계산하지는 않습니다.

API 사용량과 모델의 남은 컨텍스트를 정확히 알 수 있나요?

아니요. 컨텍스트 한도와 출력 예약량은 사용자가 직접 입력합니다. 시스템·개발자 메시지 형식, 도구 정의, 이미지·파일, 서비스가 추가하는 토큰과 모델별 제한은 포함하지 않으므로 API 응답의 사용량 정보를 대체하지 않습니다.

입력 텍스트가 서버로 전송되거나 저장되나요?

아니요. 토크나이저는 페이지에서 선택한 파일 묶음과 함께 브라우저의 별도 작업자에서 실행됩니다. 입력 내용을 저장하거나 URL·분석 이벤트·서버 요청에 넣지 않습니다. 결과 공유에는 토큰 수 요약만 들어갑니다.

계산 기준과 참고 자료

  • OpenAI 개발자 문서 — 토큰 계산

    API 요청에는 일반 텍스트 외에 메시지 형식, 이미지, 파일, 도구 정의 등이 포함될 수 있어 로컬 텍스트 계산만으로 전체 요청 토큰 수를 알 수 없습니다.

  • OpenAI — tiktoken 인코딩 설명

    o200k_base와 cl100k_base를 포함한 OpenAI 토큰 인코딩 구현·설명. 이 도구는 이 두 인코딩으로 일반 텍스트만 셉니다.

  • js-tiktoken — JavaScript 토크나이저와 MIT 라이선스

    브라우저에서 선택 인코딩의 텍스트 토큰 수를 계산하는 MIT 라이선스 JavaScript 포트입니다. 네트워크 API 호출은 사용하지 않습니다.
