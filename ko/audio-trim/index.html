오디오 자르기·합치기

오디오 파형에서 구간을 잘라 여러 파일을 순서대로 연결하고 페이드 적용

MP3·WAV · 1~2채널 · 파일당 50MB·최대 3분, 합계 3분 이하. 결과는 WAV입니다.

파일을 고르지 않고 실행하면 공개 예시를 사용합니다.

저장 설정

MP3·WAV의 채널과 길이를 디코딩 전에 확인합니다. 첫 파일부터 순서대로 연결하고 시작·끝과 짧은 페이드를 조정합니다.

입력을 바꾼 뒤 다시 실행하기 전까지는 이전 결과입니다.

오디오 자르기·합치기 사용 방법

3초 공개 음 예시의 0~3초를 실행하면 약 3초 길이 WAV가 만들어집니다. 두 파일을 고르면 목록 순서대로 이어지고 각 시작·끝 시각을 따로 조정할 수 있습니다. 구간 앞뒤의 기본 0.3초 페이드는 연결부의 급격한 소리를 줄이며 파일 길이는 조금 짧아집니다.

파형에서 구간을 확인하고 순서대로 연결합니다

각 파일의 시작·끝 시각을 조정해 0.25초 이상 구간을 남깁니다. 파일을 여러 개 고르면 선택 순서대로 이어 붙이고, 구간마다 짧은 페이드를 적용할 수 있습니다. 결과는 WAV PCM 16-bit이며 ID3·앨범 정보는 보존하지 않습니다.

모바일 처리 범위

한 번에 최대 3개 파일, 각 50MB·3분 이하, 전체 오디오 3분 이하를 지원합니다. 브라우저가 디코딩하지 못하거나 메모리가 부족하면 이전 결과를 유지하고 오류를 표시합니다.

자주 묻는 질문

파일 여러 개는 어떤 순서로 합쳐지나요?

파일 선택 목록에 표시된 순서를 따릅니다. 각 파일의 잘라낼 시작·끝 시각을 확인한 뒤 실행하세요. 목록에서 하나를 지우면 나머지 입력은 유지됩니다.

MP3나 M4A 형식으로 저장할 수 있나요?

이 편집기는 어디서나 읽을 수 있는 WAV PCM 16-bit를 만듭니다. 압축 형식 저장은 별도 오디오 형식 변환기에서 현재 브라우저가 지원하는 결과를 확인하세요.

긴 음악 파일도 편집할 수 있나요?

채널 수를 디코딩 전에 확인할 수 있도록 MP3·WAV만 받으며 1~2채널만 자를 수 있습니다. 파일당 50MB·3분, 전체 합계 3분까지 지원합니다.

계산 기준과 참고 자료

  • MDN — Web Audio API 전체 파일 디코딩

    완전한 파일을 AudioBuffer로 디코딩하고 AudioContext 샘플레이트로 다시 샘플링하는 동작. 이 구현은 입력 길이·파일 크기·채널 수를 제한합니다.

  • MDN — OfflineAudioContext 출력 렌더링

    재생 장치로 보내지 않고 잘라낸 오디오를 새 AudioBuffer로 렌더링하는 방식. 구간별 페이드와 연결은 이 로컬 렌더링 과정에 적용합니다.

  • Microsoft Learn — RIFF 리소스 교환 파일 형식

    WAV 컨테이너의 RIFF 청크 기반 구조를 참고합니다. 내보내기는 16-bit PCM이며 앨범·ID3 메타데이터를 보존하지 않습니다.
