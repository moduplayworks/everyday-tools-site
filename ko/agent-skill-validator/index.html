    어떤 Agent Skills 규칙을 확인하나요?

    공개 사양의 YAML frontmatter, name·description 필수 여부와 길이, name 문자·하이픈 규칙, 선택 필드의 자료형, Markdown 본문을 확인합니다. 폴더를 선택하면 name이 부모 폴더와 같은지, 본문 Markdown 상대 링크가 선택한 폴더에 있는지도 확인합니다. 본문 문장 품질이나 모든 에이전트 제품별 확장 필드까지 검증하지는 않습니다.

    폴더를 선택하면 파일 내용을 모두 읽나요?

    아닙니다. 브라우저는 선택한 폴더의 파일 이름과 크기를 확인하고 루트의 SKILL.md만 읽습니다. 다른 파일은 열거나 실행하지 않으며, Markdown 상대 링크의 경로가 선택된 파일 목록에 있는지만 비교합니다.

    이 페이지가 공식 CLI 전체 검증을 대신하나요?

    공개 사양은 스킬 폴더에서 skills-ref validate ./my-skill 명령을 실행해 SKILL.md frontmatter와 이름 규칙을 검사하는 방법을 안내합니다. 이 페이지는 업로드 없이 브라우저에서 SKILL.md 규칙 일부와 선택한 폴더의 Markdown 상대 경로를 빠르게 확인하는 사전 점검입니다. 공식 CLI를 실행하거나 다른 도구의 검사 결과를 대신하지 않습니다.

    오류가 없으면 스킬을 안전하게 설치해도 되나요?

    아닙니다. 이 검사는 형식과 일부 경로만 확인합니다. 프롬프트 인젝션, 외부 연결, 스크립트 동작, 권한, 패키지 출처와 의존성을 분석하지 않으며 안전성을 보증하지 않습니다. 스킬을 설치하거나 실행하기 전에 모든 지침과 파일을 직접 검토하세요.
