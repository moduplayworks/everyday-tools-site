동전 던지기

동전을 여러 번 던져 앞면·뒷면 결과와 횟수를 집계합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 1 · 최대 1000

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

광고 설정

계산·변환 기준

여러 번 동전을 던져 앞면·뒷면 횟수 확인하기.

각 시행에서 0 또는 1을 독립 추출

입력 예시

10회 던지면 앞면+뒷면 횟수 = 10

10번 던지면 앞면과 뒷면 횟수의 합은 10입니다. 5회씩 나오지 않아도 오류가 아니며 각 시행 결과도 순서대로 표시합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 던질 횟수 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

앞면이 연속해서 나오면 다음에는 뒷면이 더 잘 나오나요?

아닙니다. 각 시행을 독립적으로 추출하므로 이전 결과 때문에 다음 확률이 바뀌지 않습니다. 적은 시행에서는 두 면의 횟수가 크게 달라질 수 있습니다.
