사용 방법과 예시

각 묶음을 4의 배수로 채우고 바깥쪽 페이지와 안쪽 페이지를 대칭 쌍으로 배치합니다.

8페이지 묶음의 바깥 용지는 앞면 8,1·뒷면 2,7이고 안쪽 용지는 앞면 6,3·뒷면 4,5입니다.

1~512페이지, 묶음은 4~64페이지의 4배수입니다. 왼쪽 제본 기준이며 PDF 파일 재배열·프린터 급지 방향은 처리하지 않습니다. 소수 결과는 최대 유효숫자 12자리로 표시합니다.

자주 묻는 질문

마지막 묶음의 페이지가 부족하면 어떻게 되나요?

필요한 빈 페이지를 추가해 4의 배수로 만듭니다. 내용 페이지 번호를 바꾸지는 않습니다.

이 표대로 양면 인쇄하면 방향도 보장되나요?

아니요. 좌우 페이지 쌍만 지정합니다. 작은 시험 묶음으로 급지와 넘김 방향을 먼저 확인하세요.
