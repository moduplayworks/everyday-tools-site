텍스트의 UTF-8 바이트를 16진수로 보기.

UTF-8 각 바이트를 2자리 16진수로 변환

입력 예시

A → 41

A는 바이트 41, 한글 가는 EA B0 80으로 표현됩니다. 한 글자가 항상 한 바이트인 것은 아닙니다.

  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

16진수 코드 포인트와 UTF-8 바이트는 같은가요?

아닙니다. 가의 코드 포인트는 U+AC00이지만 UTF-8 바이트는 EA B0 80입니다. 이 도구는 바이트 기준이며 디코딩 시 올바른 UTF-8인지 검사합니다.
