사진 표 엑셀 변환

같은 간격의 표 사진을 셀별로 읽고 교정하여 엑셀 XLSX·CSV로 저장합니다. 한국어·영어 OCR을 브라우저에서 처리합니다.

사진과 인식 설정

JPG·PNG·WEBP · 12MB·6,000px·1,200만 화소 이하. 큰 사진은 최대 2,200px·400만 화소로 축소합니다.

한 칸에 한 줄인 같은 너비·높이의 곧은 표만 지원합니다. 표의 바깥 테두리에 맞춰 먼저 잘라 주세요. 행 1~12, 열 1~8, 합계 48칸 이하. 병합 셀·기울어진 표는 지원하지 않습니다.

공개 예시를 편집하거나 사진을 골라 주세요. 인식 전에도 예시 결과를 저장할 수 있습니다.

사용 방법과 범위

공개 예시는 품목·수량·가격의 3행×3열 표입니다. 품목 행을 포함해 행 3, 열 3으로 두고 사진에서 읽기를 누르면 9칸을 실제 OCR로 읽습니다. 연필 수량 3과 가격 1500이 맞는지 원본과 대조한 뒤 셀을 수정하고 XLSX를 저장하세요. 입력 사진은 표 바깥 테두리에 맞춰 잘라야 하며 각 행 높이와 열 너비가 같고 각 셀은 한 줄이어야 합니다. 12MB·한 변 6,000px·1,200만 화소 이하의 JPG·PNG·WEBP만 지원하고, 인식 전 2,200px·400만 화소 이하로 축소합니다. 최대 48칸이며 병합 셀·기울어진 표·손글씨·일본어 인식은 지원하지 않습니다.

자주 묻는 질문

표 구조를 자동으로 찾나요?

아니요. 직접 입력한 행·열 수대로 사진을 동일 간격으로 나눠 각각 읽습니다. 불규칙한 표는 먼저 잘라 여러 번 처리하거나 셀을 직접 수정하세요.

엑셀에 숫자와 수식이 들어가나요?

XLSX의 모든 셀은 텍스트로 저장해 선행 0과 수식처럼 보이는 글자를 보존합니다. 계산이 필요하면 엑셀에서 검토 후 숫자로 변환하세요. CSV는 수식 시작 문자를 작은따옴표로 보호하여 원문과 차이가 생길 수 있습니다.

사진이나 OCR 결과를 서버로 보내나요?

사진과 결과는 브라우저에서만 처리합니다. OCR 프로그램과 한국어·영어 언어 자료만 같은 사이트에서 내려받으며 결과는 새로고침하면 지워집니다.

계산 기준과 참고 자료

  • Tesseract.js — 브라우저 OCR API와 Worker 설정

    브라우저 Worker에서 이미지를 인식하고 worker·core·언어 파일 경로를 같은 사이트로 고정하는 API. 인식 결과의 정확도를 보장하지 않습니다.
