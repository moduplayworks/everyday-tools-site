계산·변환 기준

URL 쿼리의 키와 값을 반복 항목까지 분리하기.

URLSearchParams로 디코딩하고 같은 키의 값을 모두 보존

입력 예시

?a=1&a=2 → a: [1,2]

a=1&a=2&name=A+B는 a의 두 값과 name의 A B를 보존합니다. 모든 값은 문자열 배열로 표시됩니다.

사용 방법

  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.

자주 묻는 질문

같은 키가 반복되면 마지막 값만 남나요?

아닙니다. 입력 순서대로 모두 보존합니다. 전체 주소 대신 물음표 뒤의 쿼리 부분을 입력하세요. 이 도구는 폼 쿼리 규칙에 따라 +를 공백으로 해석합니다.

UTM 캠페인 값을 수정한 링크도 만들 수 있나요?

여기서는 입력한 쿼리의 키와 값을 확인합니다. 캠페인 값을 붙인 새 주소는 UTM 링크 만들기에서 따로 작성하세요. 링크를 만든다고 방문이나 광고 성과가 측정되는 것은 아니며, 실제 유입은 대상 사이트의 분석 설정과 데이터로 확인해야 합니다.
