자주 묻는 질문

선택 속성은 어떻게 판단하나요?

같은 배열 안의 객체 예시들을 비교해 일부 객체에 실제로 없는 속성에만 ?를 붙입니다. 단일 객체나 배열 밖의 중첩 객체는 관측된 키를 필수로 표시합니다. 제공하지 않은 API 응답에서 필드가 누락될 가능성까지 알아내지는 못합니다.

빈 배열과 빈 객체는 어떻게 표시하나요?

요소가 없는 배열은 Array<unknown>, 키가 없는 객체는 Record<string, unknown>으로 표시합니다. 값이 없는 예시만으로 구체적인 타입이나 키를 추측하지 않습니다.

생성한 타입이 JSON 유효성도 검사하나요?

아니요. 출력은 정적 TypeScript 타입 선언이며 브라우저에서 실제 JSON을 검사하는 기능이 아닙니다. 신뢰할 수 없는 입력을 런타임에서 검사하려면 JSON Schema 검증기와 같은 별도 검증기가 필요합니다.

붙여 넣은 JSON이 전송되거나 저장되나요?

아니요. 입력은 브라우저 작업자에서만 처리하고 주소, 저장소, 분석 이벤트에 넣지 않습니다. 생성 코드를 복사하는 작업은 사용자가 직접 선택해야 합니다.
