팁 계산기

세전 금액·직접 입력한 세율과 팁 비율로 팁과 총액을 계산하고 인원별 최소 통화 단위까지 정확히 나눕니다. 입력은 브라우저에서만 처리합니다.

금액과 비율 입력

예시값은 직접 바꿀 수 있습니다. 통화·세율·팁 비율은 계산 예시이며 권고가 아닙니다.

팁 계산 입력값

환전하지 않습니다. JPY·KRW는 정수, 나머지는 소수점 이하 2자리로 계산합니다.

영수증의 세전 금액과 세율을 입력하세요. 세금을 모르면 0을 입력하세요.

Ctrl 또는 ⌘ + Enter로 계산

금액과 결과는 선택한 통화 단위로 표시합니다. 입력은 이 브라우저 안에서만 처리합니다.

계산 방법

세전 금액과 사용자가 입력한 판매세율·팁 비율을 적용해 세금·팁·총액과 인원별 결제액을 계산합니다.

세금 = 세전 금액 × 세율 · 팁 = 선택한 기준 금액 × 팁 비율 · 총액 = 세전 금액 + 세금 + 팁

사용 방법

  1. 영수증의 세전 금액과 통화 코드를 입력하세요.
  2. 적용할 세율과 팁 비율을 입력하고 팁을 세전·세후 중 어디에 적용할지 고르세요.
  3. 인원수를 정하고 계산하기를 누르면 세금·팁·총액과 정확히 합산되는 인원별 금액을 확인합니다.

입력 예시

세전 금액 USD 80.00, 판매세 8.25%, 팁 18%, 3명으로 계산하면 세금은 USD 6.60, 세전 기준 팁은 USD 14.40, 총액은 USD 101.00입니다. 두 명은 USD 33.67, 한 명은 USD 33.66을 내면 합계가 정확히 USD 101.00이 됩니다.

세율과 팁 비율은 지역·서비스·영수증마다 다를 수 있습니다. 이 도구는 비율을 추천하거나 세금을 조회하지 않습니다.

자주 묻는 질문

세전 금액과 세금 포함 금액 중 어떤 팁 기준을 고르나요?

영수증이나 본인이 따르는 기준에 맞춰 직접 선택하세요. 지역과 서비스에 따라 관행이 다를 수 있어 이 계산기는 한 가지 방식을 권하지 않습니다.

통화와 판매세율을 자동으로 찾나요?

아닙니다. 통화 코드는 표시 형식과 소수 자릿수에만 사용하고 환전하지 않습니다. 영수증의 세전 금액과 세율을 직접 입력하며, 입력은 브라우저 안에서만 처리합니다.

인원별 금액을 더하면 총액과 다를 때는 어떻게 하나요?

통화 최소 단위로 균등하게 나눈 뒤 남은 최소 단위를 앞쪽 인원부터 하나씩 더해 총액과 일치시킵니다. 이름을 입력하거나 특정 사람에게 추가 금액을 지정하지는 않습니다.

영수증의 세금 포함 합계만 알고 있어도 계산할 수 있나요?

세전 금액 입력란에 알고 있는 금액을 넣고 판매세율을 0으로 두면 해당 금액을 기준으로 팁을 계산할 수 있습니다. 세전 금액을 알고 있다면 영수증의 실제 세율을 따로 입력하세요.
