PDF 텍스트 비교

PDF 두 버전에서 페이지별 글자 변경을 확인하고 차이 보고서를 저장하세요. 이미지·서식 비교나 스캔 문서 OCR은 수행하지 않습니다.

비교할 PDF

PDF 2개 · 각각 20MiB·50페이지·추출 문자 20만자 이하. 암호화 PDF는 지원하지 않습니다.

파일 없이 편집해 보는 공개 예시

같은 페이지 번호의 텍스트만 비교합니다. 추출 조각 사이에는 공백·줄바꿈을 넣고 페이지 끝 공백은 제거합니다. 공통 앞뒤를 제외한 한 구간을 변경 범위로 표시하므로 중간의 같은 글자도 포함될 수 있습니다. 페이지 삽입·줄 재배치로 차이가 커질 수 있습니다. 이미지·서식·전자서명은 비교하지 않으며 문서 전체의 동일성을 보증하지 않습니다.

파일과 추출 내용은 브라우저 메모리에서만 처리하며 새로고침·페이지 이동 시 지웁니다. 파일명이나 내용은 통계로 보내지 않습니다.

페이지별 비교 결과

아직 비교 결과가 없습니다.

텍스트가 없는 페이지는 스캔·그림·빈 페이지일 수 있어 비교하지 못했습니다. 추출 텍스트가 같아도 그림 속 글자는 확인되지 않습니다. 원본을 직접 확인하거나 OCR 도구를 사용하세요.

자주 묻는 질문

차이가 없으면 같은 문서인가요?

아닙니다. 비교하는 것은 추출된 텍스트뿐입니다. 사진·글꼴·배치·주석·전자서명·숨은 객체의 동일 여부나 문서의 법적 효력을 판단하지 않습니다.

스캔 PDF나 빈 페이지는 어떻게 표시하나요?

글자 층이 없는 페이지는 비교하지 못한 페이지로 표시합니다. 글자가 없다는 이유로 동일하다고 판단하지 않으며 OCR을 자동 실행하지 않습니다. 텍스트와 스캔 페이지가 섞여 있으면 결과가 문서 전체를 평가한 것이 아닙니다.

페이지가 추가되거나 큰 PDF라면 어떻게 하나요?

파일당 20MiB·50페이지·추출 문자 20만자 이하를 지원합니다. 같은 페이지 번호끼리 비교하므로 앞쪽에 페이지가 추가되거나 글이 다음 페이지로 흐르면 이후 차이가 크게 표시될 수 있습니다. 암호화·손상 문서는 처리하지 못할 수 있습니다.
