복습 일정 만들기

학습일과 직접 정한 복습 간격으로 날짜표를 만드세요. 쉬는 날짜를 반영하고 CSV·ICS 캘린더 파일로 저장합니다.

입력

예시값으로 바로 실행하거나 값을 바꿔 보세요.

쉼표로 1~12개, 각 1~3,650일. 학습일 기준은 오름차순으로 입력하세요.

공부 요일·쉬는 날짜
공부 가능한 요일

YYYY-MM-DD 한 줄에 하나. 불가능한 날은 다음 가능한 날로 이동합니다.

입력 백업·복원

입력은 저장·자동 동기화하지 않습니다. 새로고침하면 예시값으로 돌아갑니다. JSON 백업에는 이름과 모든 입력이 포함됩니다. 복원은 현재 입력을 교체합니다.

결과

입력된 예시값으로 바로 결과를 확인하세요.

기본 결과 내보내기는 항목 번호를 사용합니다. 이름 포함을 켜면 공유할 내용과 파일에 이름이 들어갑니다.

ICS는 종일 일정 파일입니다. 캘린더에 직접 가져오세요. 자동 알림·동기화는 제공하지 않으며 반복 가져오기는 캘린더에 따라 중복될 수 있습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산 기준과 사용 방법

사용자가 정한 복습 일차·간격으로 학습 주제별 날짜표와 캘린더 파일 생성.

학습일 기준: 학습일 + 일차 · 앞 복습일 기준: 실제 앞 복습일 + 간격

입력 예시

2026년 10월 5일에 배운 주제에 1,3,7을 입력하면 학습일 기준 복습은 10월 6일·8일·12일입니다. 앞 복습일 기준으로 바꾸면 각 간격이 누적되어 10월 6일·9일·16일이 됩니다. 쉬는 날은 다음 가능한 날로 이동하며 앞 복습일 기준에서는 실제 이동한 날짜에서 다음 간격을 셉니다.

사용 방법

  1. 입력된 예시를 사용하거나 설정과 선택한 항목을 수정하세요. 항목 추가로 여러 평가·교재·주제를 순서대로 입력합니다.
  2. 복습 일정 만들기를 누르세요. 잘못된 입력은 해당 항목과 필드로 이동해 안내합니다.
  3. 결과를 확인하고 CSV로 저장하세요. 계획은 필요하면 ICS로 가져올 수 있습니다. 입력을 이어서 쓰려면 JSON 백업을 따로 저장하세요.

한계와 해석

간격은 사용자가 정한 계획입니다. 학습 효과나 최적 복습 시점을 보장하지 않습니다. 최대 50개 주제·12개 간격, 학습 후 3,650일까지 생성합니다. 불가능한 날짜는 앞으로 이동하고 같은 날짜에 겹친 복습도 별도로 유지합니다.

자주 묻는 질문

1·3·7일은 효과가 검증된 추천 주기인가요?

입력 방법을 보여주는 공개 예시입니다. 원하는 간격을 직접 정해 날짜를 만드는 도구이며 기억 유지율이나 최적 간격을 예측하지 않습니다. Anki처럼 회상 응답에 따라 주기를 자동 조정하지 않습니다.

주말 때문에 두 번의 복습이 같은 날이면 어떻게 되나요?

학습일 기준의 각 예정일을 각각 다음 가능한 날로 이동하므로 같은 주제의 복습이 겹칠 수 있습니다. 겹친 차수는 삭제하지 않고 안내와 함께 유지합니다. 주기·요일을 바꾸거나 앞 복습일 기준으로 계획을 비교하세요.

캘린더에 넣으면 알림이나 자동 변경도 되나요?

종일 일정 ICS 파일을 직접 가져오는 방식입니다. 알림과 실제 가져오기 동작은 사용하는 캘린더에서 설정하세요. 입력 변경은 기존 캘린더를 자동 변경하지 않고 반복 가져오기는 앱에 따라 중복될 수 있습니다.

    일정 시작·종료, 종일 날짜, 반복 날짜와 UTF-8 콘텐츠 줄

  • Anki — 회상 응답과 다음 복습

    회상 응답에 따른 복습과 사용자가 정한 고정 간격 계획의 차이. 이 도구는 Anki의 자동 주기 조정을 구현하거나 학습 효과를 예측하지 않습니다.
