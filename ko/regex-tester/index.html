정규식 테스트

JavaScript 정규식의 매칭·캡처 그룹·치환을 확인하세요. 오래 걸리는 패턴은 중단하고 입력은 브라우저에서 처리합니다.

정규식 테스트 입력

/ 구분자 없이 입력 · g: 모두 찾기 · i: 대소문자 무시

치환·플래그 도움말

m: 줄별 시작·끝, s: 줄바꿈 포함 점(.), u: 유니코드, y: 이어지는 위치만. JavaScript 정규식으로 실행합니다.

$&: 매칭 전체, $1: 첫 그룹, $<name>: 이름 그룹, $$: 달러 기호. 치환문을 비우면 매칭 부분을 삭제합니다.

입력은 저장·전송하지 않습니다. 결과 공유에는 요약만 포함됩니다.

결과

입력 후 실행하면 여기에 결과가 표시됩니다.

사용 예시와 처리 기준

패턴 (?<name>[가-힣]+), 플래그 g와 텍스트 “서울 12, 부산 34”를 입력하면 서울(0~2), 부산(7~9) 두 번 매칭합니다. 치환문 [$<name>]을 쓰면 “[서울] 12, [부산] 34”가 됩니다. 위치는 0부터 시작하는 UTF-16 인덱스이며 끝 위치는 포함하지 않습니다.

자주 묻는 질문

다른 언어의 정규식도 같나요?

현재 브라우저의 JavaScript 정규식 엔진을 사용합니다. Python·PCRE 등과 문법이나 결과가 다를 수 있습니다. / 구분자를 빼고 g·i·m·s·u·y 플래그를 입력하세요.

무한 실행이나 매우 많은 결과는 어떻게 처리하나요?

실행은 별도 Worker에서 수행하고 준비 후 750ms를 넘으면 중단합니다. 대상 200,000자, 패턴 2,000자, 수집 1,000개·매칭 문자열 합계 1,000,000자까지입니다. 제한 시 일부 결과임을 표시하며 치환은 중단합니다. 처리 중 취소할 수 있습니다.

빈 매칭과 치환 그룹은 어떻게 보이나요?

빈 매칭은 미리보기에 ∅로 표시하고 다음 UTF-16 위치로 이동합니다. u 플래그에서는 보충 평면 문자를 둘로 나누지 않습니다. 미참여 그룹은 null입니다. $&, $1, $<name>, $$와 앞·뒤 문맥 치환을 지원하며 결과는 1,000,000자까지입니다.
