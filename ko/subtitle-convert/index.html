      계산 방법과 사용 예시

      예시의 첫 구간은 SRT 00:00:01,000~00:00:03,000입니다. VTT로 바꾸면 00:00:01.000~00:00:03.000이 되며 자막 내용과 줄바꿈은 유지됩니다. 원문을 붙여 넣거나 인코딩을 선택한 뒤 파일을 불러오고, 입력·출력 형식을 확인해 실행하세요. 여러 언어가 있는 SMI는 한 클래스를 선택해 다시 실행합니다. 원본 구간 순서와 시각은 유지하며 SRT 번호는 1부터 다시 매깁니다.

      지원 범위와 제한

      SRT·VTT·SMI를 읽고 SRT·VTT로 출력합니다. 파일은 2 MiB, 원문은 1,000,000자, 모든 언어 합계 10,000구간, 한 구간은 10,000자, 시각은 99:59:59.999까지 지원합니다. SMI의 마지막 문단에는 같은 언어 클래스의 빈 SYNC 종료점이 필요합니다. ASS·이미지 자막·영상 자동 인식·HLS X-TIMESTAMP-MAP·SMI의 지속 ID=Source 표시는 지원하지 않습니다.

      인코딩 자동 선택은 BOM 또는 UTF-8 유효성 검사만 수행하며 언어를 추측하지 않습니다. 주요 문자 참조 amp·lt·gt·quot·apos·nbsp·lrm·rlm와 숫자 참조를 지원합니다. 지원하지 않는 태그나 문자 참조는 변환을 중단합니다. 루비 발음은 괄호로 바뀝니다. 출력 전 미리보기와 경고를 확인하고 원본을 보관하세요.

      자주 묻는 질문

      SMI 자막의 한글이 깨지면 어떻게 하나요?

      파일 불러오기에서 EUC-KR / CP949를 선택하고 다시 불러오세요. 자동 선택은 BOM이 없으면 UTF-8 검증만 수행합니다. 깨진 문자를 임의로 대체하지 않습니다.

      다국어 SMI를 한 번에 섞어서 변환하나요?

      언어 클래스별 시각과 내용을 분리해 검증합니다. 사용할 클래스를 선택해 한 언어만 출력하세요. 마지막 표시 자막 뒤에는 같은 클래스의 빈 SYNC 종료점이 필요합니다.

      스타일·위치와 원문 파일이 보존되나요?

      일반 텍스트로 변환하므로 색상·위치·화자 메타데이터와 VTT 주석은 제거되며 경고로 알립니다. 원본 파일은 수정하지 않습니다. 다운로드는 별도의 UTF-8 SRT 또는 VTT 파일입니다.

      계산 기준과 참고 자료

      • 미국 의회도서관 — SubRip SRT 형식

        구간 번호·시작/종료 시각·텍스트·빈 줄과 고정 인코딩 표준이 없는 SRT 파일의 설명

      • W3C — WebVTT 자막 형식

        밀리초 시각, 시작 순서, 겹치는 구간과 자막 텍스트의 비교 기준. 이 도구는 일반 텍스트 출력이며 렌더링 스타일을 유지하지 않습니다.

      • Microsoft — SAMI 1.0 자막 구조

        SYNC Start 밀리초, P 클래스의 언어 구분과 빈 문단 처리. 영상 플레이어·지속 화자 ID=Source는 구현하지 않습니다.

      • WHATWG — Encoding Standard

        TextDecoder의 엄격한 오류 모드와 BOM·UTF-8·UTF-16·EUC-KR 디코딩. 무조건적인 인코딩 자동 판별을 보장하지 않습니다.

      계산 기준 확인: 2026-10-03 · 계산·검증 원칙 · 오류 제보
