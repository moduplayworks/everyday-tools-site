함수 그래프 그리기

sin·cos·tan과 다항함수를 한 화면에서 비교하세요. x·y 범위와 각도 단위를 정하고 슬라이더로 좌표를 확인한 뒤 SVG로 저장합니다.

수식 입력

예시 함수로 바로 그리거나 x 범위와 확인할 x를 바꾸세요.

변수 x, π, e, 괄호, + − × ÷ ^와 sin·cos·tan·sqrt·ln·log·abs를 지원합니다. 2x와 2sin(x)처럼 곱셈 기호를 생략할 수 있습니다.

범위·각도 조정 · 기본 x −6.28~6.28, y −1.5~1.5

x축의 숫자도 선택한 각도 단위를 사용합니다.

수식은 이 브라우저에서 계산하며 주소나 방문 통계에 넣지 않습니다. 새로고침하면 예시로 돌아갑니다.

    계산 기준과 사용 방법

    여러 실수 함수의 모양과 특정 좌표를 제한된 범위에서 비교하기.

    기본 예시 sin(x), cos(x), x/4는 라디안 모드에서 x=0일 때 각각 0, 1, 0입니다. x 범위 −6.28~6.28, y 범위 −1.5~1.5에서 세 곡선의 교점과 높이를 확인하고, 그래프의 x 슬라이더로 값을 읽을 수 있습니다.

    사용 방법

    1. 함수를 한 줄씩 입력하세요. x를 독립변수로 사용하며 최대 세 함수를 함께 비교합니다.
    2. x·y 표시 범위와 각도 단위를 정하고 결과를 누르세요. 그래프의 슬라이더로 특정 x에서의 값을 확인합니다.
    3. 함수별 선과 표본 구간을 확인하고 SVG로 저장할 수 있습니다.

    지원 범위와 한계

    수식은 안전한 자체 파서로 제한된 연산과 함수만 해석하며 JavaScript 코드로 실행하지 않습니다. 그래프는 유한한 범위에서 401개 점을 표본 추출한 근삿값이며 각 구간도 추가 검사합니다. tan 점근선과 정의되지 않거나 표시 범위를 벗어난 점, 급격한 점프에서는 선을 끊습니다. 삼각함수 위상이 표본 사이에서 π 라디안 이상 바뀌거나 변화율을 안전하게 한정할 수 없으면 오해를 막기 위해 곡선을 생략하고 x 범위를 좁히도록 안내합니다. 유한 표본이므로 좁은 불연속을 모두 찾아낸다고 보장하지 않습니다. 실수 값만 다루며 기호식·복소수·도함수·적분은 지원하지 않습니다.

    공유 텍스트에는 사용자가 작성한 수식과 계산 결과가 들어갑니다. 공유 전에 내용을 확인하세요.

    자주 묻는 질문

    그래프가 끊겨 보이면 함수가 불연속이라는 뜻인가요?

    반드시 그렇지는 않습니다. 이 그래프는 401개 점으로 표본을 만들고 각 구간도 추가 검사합니다. tan 점근선, 정의되지 않거나 범위를 벗어난 값과 큰 점프에서 선을 끊습니다. 삼각함수 위상이 표본 사이에서 π 라디안 이상 바뀌거나 변화율을 안전하게 한정할 수 없으면 해당 곡선을 생략하고 범위를 좁히도록 안내합니다. 유한 표본이므로 좁은 불연속은 남을 수 있어 수식의 정의역과 범위를 직접 확인하세요.

    도와 라디안은 그래프에서 어떻게 쓰이나요?

    라디안 모드에서는 sin(x)의 x가 라디안입니다. 도 모드를 고르면 삼각함수 인수를 도로 읽으며 x축 숫자도 도 단위로 표시합니다. 다른 산술 연산에는 각도 변환을 적용하지 않습니다.
