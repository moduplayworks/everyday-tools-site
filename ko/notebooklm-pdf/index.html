    NotebookLM PDF 업로드 전에 확인할 것

    Google의 Gemini Notebook 도움말에서 안내하는 소스당 제한은 200MB 또는 50만 단어입니다. 이 도구는 파일의 실제 바이트 수와 PDF 구조를 점검하며, Google의 단어 수 판정이나 업로드 성공을 인증하지 않습니다.

    기기 메모리를 보호하기 위해 이 도구는 50MiB·200페이지까지 처리합니다. 서비스의 200MB와 다른 자체 한도입니다. MB는 1,000,000바이트, MiB는 1,048,576바이트로 표시합니다.

    텍스트 점검은 무엇을 확인하나요?

    앞에서부터 최대 20페이지·20만 글자까지 PDF 텍스트를 읽고, 확인한 페이지와 글자 유무만 표시합니다. 원문이나 파일명은 통계에 보내지 않습니다. 스캔 이미지, 글꼴 인코딩 문제, 표·다단 편집 때문에 텍스트가 없거나 순서가 다를 수 있습니다. 이 점검은 OCR이 아니며 문서 전체를 읽었다는 뜻도 아닙니다.

    실제 파일 크기로 나누기

    PDF 페이지를 복사한 뒤 실제 저장된 바이트 수를 목표와 비교합니다. 크면 구간을 반씩 나누어 다시 확인합니다. 결과 파일의 페이지 수가 같을 필요는 없으며 최소 파일 개수를 보장하지 않습니다. 한 페이지가 목표보다 크면 더 큰 크기를 선택하거나 압축하세요.

    페이지의 그림과 텍스트를 이미지로 바꾸지 않습니다. 양식·서명 필드는 분할하지 않으며 책갈피·첨부·문서 전체 링크 구조·전자서명 유효성은 보존을 보장하지 않습니다. 원본은 변경하지 않습니다.

    예시: 4페이지를 2페이지씩 나누기

    공개 예시는 글자가 있는 4페이지 PDF입니다. 파일당 2페이지로 나누면 1~2페이지와 3~4페이지 사본 두 개가 생성됩니다. 각 파일을 저장해 페이지 순서와 내용을 확인하세요.

    파일 조건을 만족해도 계정 한도, 네트워크, 지원 형식 또는 서비스 상태 때문에 업로드가 실패할 수 있습니다. 필요 없는 분할은 피하고 Google의 최신 안내도 확인하세요.

    자주 묻는 질문

    200MB보다 작은데 왜 이 도구에서 열리지 않나요?

    이 도구의 자체 한도는 50MiB·200페이지입니다. 암호화되거나 손상된 PDF도 처리하지 않습니다. 이 한도는 Google의 업로드 조건과 별개입니다.

    텍스트가 없으면 업로드할 수 없나요?

    그렇게 단정할 수 없습니다. 확인한 페이지에서 추출 가능한 텍스트를 찾지 못했다는 뜻입니다. 필요한 경우 OCR 도구로 글자를 확인하고 업로드 서비스의 처리 결과를 직접 확인하세요.

    분할하면 AI 답변이 더 정확해지나요?

    정확도가 좋아진다고 보장하지 않습니다. 분할은 파일 크기나 필요한 페이지를 관리하는 작업이며, 문맥이 끊길 수도 있습니다.

    PDF를 어디에 업로드하나요?

    이 도구는 PDF를 업로드하지 않습니다. 내 브라우저에서 점검하고 사본을 저장합니다. Google 계정이나 NotebookLM과 연결하지 않습니다.

    계산 기준과 참고 자료

    • Google — NotebookLM 파일과 소스 제한

      제공자의 소스당 파일 크기와 단어 수 제한을 확인하는 공식 도움말입니다. 로컬 점검은 계정·네트워크·제공자 처리 결과를 확인하지 않으며 업로드 성공을 보장하지 않습니다.
