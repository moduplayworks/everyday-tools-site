개인정보 안내

영상 화면 비율 변경를 브라우저에서 실행하세요

640×360 가로 영상에서 세로 9:16을 선택하면 세로 프레임을 만듭니다. 가운데 자르기는 좌우 영역을 버리고, 전체 보이기는 영상 전체를 축소해 남는 공간을 어두운 여백으로 채웁니다. 피사체를 따라 화면을 이동하지 않으므로 결과를 확인한 뒤 저장하세요.

새 동영상으로 다시 인코딩합니다

선택한 파일을 서버로 올리지 않습니다. 새 컨테이너와 코덱으로 저장하므로 입력 형식·화질·파일 크기가 달라질 수 있습니다. 예상 크기와 원본을 비교하고 결과를 직접 재생해 확인하세요.

자르기는 화면 중앙을 기준으로 바깥 영역을 버립니다. 전체 보이기는 원본을 축소해 어두운 여백을 추가합니다. 이동 가능한 피사체 추적이나 자동 재구성은 하지 않습니다.

파일과 기기 제한

최대 100MB·60초 영상에서 실행합니다. 브라우저가 지원하는 저장 형식을 감지해 MP4 또는 WebM으로 출력합니다. 인코딩 중에는 탭을 열어 두세요. 기기의 메모리와 코덱 지원에 따라 일부 파일이 처리되지 않을 수 있습니다.

자주 묻는 질문

화면 비율을 바꾸면 사람이나 물체 위치도 자동으로 따라가나요?

자동 추적은 하지 않습니다. 가운데 자르기는 프레임 중앙을 기준으로 자르고, 전체 보이기는 원본 전체를 유지하며 여백을 추가합니다.

세로 영상으로 바꿀 때 화면이 잘리나요?

전체 보이기를 고르면 전체 장면을 보여 주고 남는 부분을 어두운 여백으로 채웁니다. 화면 채우기를 고르면 비율이 맞지 않는 가장자리를 중앙 기준으로 잘라냅니다.

내 영상은 어디에서 처리하나요?

영상은 서버에 업로드하지 않고 브라우저에서 새 프레임으로 인코딩합니다. 기기 성능과 브라우저가 지원하는 저장 형식에 따라 결과 화질과 처리 시간은 달라집니다.

계산 기준과 참고 자료

  • MDN — MediaRecorder

    브라우저가 지원하는 컨테이너·코덱으로 캡처 스트림을 재인코딩합니다. 지원 형식과 출력 품질은 브라우저에 따라 달라집니다.

  • MDN — Canvas captureStream

    현재 영상 프레임을 로컬 Canvas에 그리고 브라우저 내 녹화용 영상 스트림으로 캡처합니다.

  • WebKit — MediaRecorder API

    WebKit 구현에서 캔버스·Web Audio 스트림 녹화와 형식 기능 감지를 설명합니다. 현재 기기의 코덱 지원 여부는 실행 중 기능 감지합니다.
