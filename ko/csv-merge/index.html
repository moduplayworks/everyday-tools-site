자체 서비스 홍보

CSV 파일 합치기

같은 헤더를 가진 CSV 파일이나 텍스트를 합치세요. 열 순서를 맞추고 모든 행을 유지하며 브라우저에서 미리보기와 CSV 저장을 제공합니다.

CSV 합칠 내용

    파일과 내용은 이 브라우저에서만 처리합니다. 쉼표 구분 UTF-8 CSV를 지원합니다.

    공개 예시는 첫 실행에서 데이터 3행을 합칩니다.

    형식과 처리 한도

    입력당 1,000,000바이트·헤더 포함 10,000행·셀당 10,000자, 전체 10MiB·100,000셀·최대 100열입니다. 헤더는 공백만으로 구성되지 않은 고유 이름이어야 하며 대소문자와 공백을 포함해 일치해야 합니다. 다른 인코딩은 UTF-8로 변환하세요.

    합친 결과

    아직 결과가 없습니다.

    미리보기는 처음 20행입니다. 저장에는 전체 행이 포함됩니다. 선택 순서와 원본 행 순서를 유지하며 중복 행도 남깁니다.

    저장은 BOM 포함 UTF-8, 따옴표 처리, CRLF 줄바꿈이며 최대 2,000,000바이트입니다. 수식처럼 보이는 값과 헤더 앞에 탭을 붙여 스프레드시트 실행 위험을 줄입니다. 보이는 값이 달라질 수 있고 모든 앱의 안전을 보장하지 않습니다.

    사용 방법과 예시

    공개 예시의 첫 입력에는 001·002 행이 있고 두 번째에는 열 순서가 다른 003 행이 있습니다. 합치기를 누르면 id·item·amount 순서의 데이터 3행이 나옵니다. UTF-8 CSV 파일 2–20개도 선택할 수 있으며 뒤쪽 파일의 열을 첫 헤더에 맞춥니다. 중복 행과 앞자리 0을 유지하고 날짜·숫자로 변환하지 않습니다. 미리보기는 처음 20행이며 저장에는 전체 결과가 포함됩니다.

    자주 묻는 질문

    열이 다르면 합칠 수 있나요?

    열 순서는 달라도 이름 집합은 정확히 같아야 합니다. 헤더의 대소문자와 공백을 구분하며 빈 이름·중복 이름·열 개수가 다른 행을 거절합니다. 누락된 열을 자동으로 채우거나 키를 기준으로 조인하지 않습니다.

    저장한 값이 스프레드시트에서 달라질 수 있나요?

    수식처럼 보이는 값과 헤더 앞에 탭을 추가합니다. UTF-8 BOM·따옴표·CRLF 줄바꿈도 적용합니다. 이 보호 처리는 표시값을 바꿀 수 있고 모든 앱의 수식 실행을 막지는 못하므로 가져오기 설정과 결과를 확인하세요.

    크기 제한과 지원 인코딩은 무엇인가요?

    쉼표 구분 UTF-8만 지원합니다. 입력당 1,000,000바이트, 헤더 포함 10,000행, 셀당 10,000자이며 전체 10MiB·100,000셀·100열로 제한합니다. 저장 결과는 BOM과 보호 처리를 포함해 2,000,000바이트 이하입니다.
