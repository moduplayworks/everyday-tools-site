자주 묻는 질문
이미지와 표 모양도 유지되나요?
아니요. PDF의 텍스트 층만 읽습니다. 다단 편집·표의 순서가 달라질 수 있으며 이미지·스캔·첨부는 포함하지 않습니다. 빈 페이지는 제외되므로 원문과 비교하세요.
모든 AI에서 같은 토큰 수인가요?
아니요. 선택한 o200k_base 또는 cl100k_base 인코딩으로 저장할 Markdown 전체를 계산합니다. 서비스의 다른 인코딩·시스템 지시·메시지 포장·출력 예약량은 포함하지 않습니다. 실제 서비스 한도에서 여유를 두세요.
파일이 자동으로 AI에 전송되나요?
아니요. 처리와 ZIP 생성은 브라우저에서 이루어집니다. ZIP에는 입력 파일명과 추출한 내용이 들어가므로 외부 서비스에 올리기 전에 개인정보를 검토하세요. 최대 10개·합계 25MiB·전체 200페이지·20만자이며 PDF당 100페이지까지 지원합니다.
