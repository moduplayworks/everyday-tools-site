마라톤 컷오프·페이스밴드

총성 시각과 실제 출발 지연, 휴식 시간을 반영해 구간 통과 시각과 컷오프 여유를 계산하세요. 계산한 계획을 인쇄용 페이스밴드 PDF로 저장합니다.

입력

가상 예시 · 공식 시간표가 아닙니다.

대회 안내의 총성·칩 기준을 직접 확인하세요. 중간 지점도 같은 기준으로 계산합니다.

중간 지점과 제한시간 설정

한 줄에 거리 또는 거리, 제한 분을 입력하세요. 예: 10, 90. 거리는 오름차순 최대 49개이며 완주 지점은 자동으로 추가합니다. 제한 분은 선택한 기준부터 경과한 시간입니다.

통과 계획

공개 예시로 바로 계산할 수 있습니다.

휴식은 거리에 비례하여 고르게 배분한 가정입니다. 실제 보급 위치·언덕·혼잡은 반영하지 않습니다.

계획용 예시 계산이며 공식 통과 판정이 아닙니다. 대회별 기준을 확인하세요.

이동 페이스는 반올림 표시입니다. 통과 판정은 반올림 전 값으로 비교합니다.

출발 지연과 휴식 계산 방법

실제 출발이 늦었을 때 남은 제한시간과 구간 통과 시각을 계산하고, 같은 결과를 인쇄용 페이스밴드로 저장하는 도구입니다.

총성 기준 남은 시간 = 완주 제한 − 실제 출발 지연 / 목표 이동 페이스 = (목표 시간 − 전체 휴식) ÷ 거리

입력 예시

가상 예시에서 총성은 07:30, 실제 출발 지연은 18분, 총성 기준 완주 제한은 300분입니다. 실제 출발 07:48부터 남은 시간은 282분(4시간 42분)입니다. 휴식 7분을 포함한 목표 280분이면 12:28 도착으로 12:30 제한까지 2분의 여유가 있습니다. 같은 300분을 실제 출발 기준으로 바꾸면 제한은 12:48입니다.

사용 방법

  1. 대회의 총성 시각과 제한시간 기준을 확인하고, 실제 출발 지연과 휴식을 포함한 목표 시간을 입력하세요.
  2. 중간 지점의 공식 제한이 있으면 거리와 제한 분을 함께 입력하세요. 모든 제한은 선택한 총성 또는 실제 출발 기준입니다.
  3. 통과 시각과 여유를 확인한 뒤 PDF를 만드세요. 100% 크기로 인쇄하고 테두리를 따라 잘라 페이스밴드로 사용할 수 있습니다.

지원 범위와 한계

1~300km, 중간 지점 49개와 완주 지점, 총성 후 72시간까지 지원합니다. 자정을 넘는 시각에는 며칠 뒤인지 표시합니다. 날짜·시간대·서머타임 전환과 코스 고도는 계산하지 않습니다.

일정한 이동 페이스와 거리 비례 휴식 배분을 가정합니다. 구간별 보급 계획이나 실제 달리기 능력을 예측하지 않으며, 제한시각과 정확히 같은 도착은 여유가 없는 상태입니다. 주최 측의 통과 판정·변경 안내가 우선입니다.

입력과 PDF는 브라우저에서 처리합니다. 서버 업로드와 자동 저장은 하지 않으며, 새로고침하거나 페이지를 떠나면 공개 예시로 돌아갑니다.

자주 묻는 질문

총성 기준과 실제 출발 기준은 어떻게 다른가요?

총성 기준 제한은 총성이 울린 시점부터 흐르므로 출발 지연만큼 사용할 시간이 줄어듭니다. 실제 출발 기준 제한은 본인이 출발선을 통과한 시점부터 흐릅니다. 이 도구가 대회의 기준을 자동으로 정하지는 않습니다.

휴식은 통과 시각에 어떻게 들어가나요?

목표 시간은 휴식을 포함한 실제 출발 후 전체 시간입니다. 이동 시간은 목표 시간에서 휴식을 빼며, 각 지점의 누적 휴식은 전체 휴식에 거리 비율을 곱합니다. 실제로 특정 보급소에서 쉬는 계획과는 다를 수 있습니다.

중간 지점과 완주 제한의 시간 기준이 다르면 어떻게 하나요?

현재는 모든 제한에 하나의 기준을 적용합니다. 서로 다른 기준을 섞어 입력하면 안 됩니다. 대회 안내에 따라 한 기준의 경과 분으로 먼저 환산하거나, 해당 기준별로 나누어 계산하고 공식 안내를 확인하세요.
