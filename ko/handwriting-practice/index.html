사용 방법과 처리 기준

내 문장을 연한 따라쓰기 줄과 빈 연습 줄이 번갈아 있는 PDF로 만듭니다. 용지 크기, 글자 크기, 기준선 사이 간격을 조절할 수 있습니다. 입력 문장은 브라우저 안에서 처리하며 업로드하거나 보관하지 않습니다.

실제 예시

공개 예시의 두 문장을 A4, 18pt, 줄 간격 12mm로 만들면 한 페이지에 따라쓰기 2줄과 빈 연습 2줄이 나옵니다. 기준선 사이는 12mm이며 한 쌍은 24mm를 사용합니다. 빈 줄을 직접 넣으면 그 위치도 유지되고, 긴 문장은 용지의 36pt 여백 안에서 표시 글자 단위로 나뉩니다.

최대 표시 글자 2,000자·20페이지·결과 50MiB입니다. 한글·영문·가나·지원 한자를 사용하며 이모지와 지원하지 않는 글자는 오류로 알립니다. 줄바꿈을 유지하고 긴 줄은 표시 글자 단위로 나눕니다.

글꼴은 Noto Sans KR에 Noto Sans JP의 누락 글자를 보완해 만든 고정 글꼴입니다. 일부 한자는 한국 지역 자형으로 표시됩니다. 일본어의 정확한 자형·필순을 가르치는 교본은 아닙니다.

자주 묻는 질문

굿노트나 다른 필기 앱에서 사용할 수 있나요?

일반 PDF로 저장하므로 PDF 가져오기를 지원하는 필기 앱에서 열 수 있습니다. 앱 전용 템플릿이나 앱과의 연동은 제공하지 않습니다. A4·A5 세로 용지이며 화면 비율과 인쇄 여백은 사용하는 앱이나 프린터에서 확인하세요.

일본어와 한글을 함께 넣어도 되나요?

지원하는 한글·영문·가나·한자를 함께 입력할 수 있습니다. Noto Sans KR을 기본으로 누락된 일본어 글자를 Noto Sans JP로 보완한 고정 글꼴이므로 일부 한자는 한국 지역 자형을 사용합니다. 일본어 자형이나 필순을 가르치는 교본은 아니며, 지원하지 않는 글자는 오류로 알립니다.

긴 글과 빈 줄은 어떻게 처리하나요?

NFC로 정규화한 표시 글자를 기준으로 줄바꿈을 포함해 최대 2,000자를 받습니다. 명시한 줄바꿈과 빈 줄을 유지하고 긴 줄은 글자를 자르지 않고 다음 줄로 넘깁니다. 최대 20페이지·50MiB이며 제한을 넘으면 일부 내용을 버리지 않고 오류를 표시합니다.

문장이 서버에 저장되나요?

입력 문장은 이 브라우저에서만 PDF로 처리합니다. 사이트가 문장을 업로드하거나 저장하지 않으며 초기화·새로고침·페이지 이동 시 지웁니다. 직접 다운로드한 파일은 기기에 남으므로 필요 없으면 직접 삭제하세요.

책의 문장을 자동으로 가져올 수 있나요?

책 본문이나 유료 필사 자료는 제공하지 않습니다. 직접 쓴 글이나 사용할 권리가 있는 문장을 입력하세요. 공개 예시는 이 도구를 위해 직접 작성한 문장입니다.

계산 기준과 참고 자료

  • Unicode — 문자 묶음과 텍스트 경계

    결합 문자를 하나의 글자 묶음으로 다루는 기준입니다. 실제 글리프 지원 범위와 줄바꿈 결과는 사용하는 글꼴과 입력 문장에 따라 달라집니다.

  • Google Fonts — Noto Sans KR 원본과 글꼴 라이선스

    PDF에 포함하는 정적 CJK 글꼴의 원본과 SIL Open Font License입니다. 글꼴이 지원하지 않는 문자는 출력 전에 안내합니다.

  • Google Fonts — Noto Sans JP 원본과 글꼴 라이선스

    기본 글꼴에 없는 일본어 글자를 보완하는 원본과 SIL Open Font License입니다. 일부 한자는 기본 글꼴의 한국 지역 자형을 유지합니다.
