양면 포토카드 인쇄

앞뒤 사진을 A4 양면 인쇄 PDF로 배치하세요.

사진을 선택하지 않으면 직접 만든 앞뒤 공개 예시를 사용합니다. 같은 앞뒤 한 쌍을 모든 칸에 반복합니다.

장당 10MiB·한 변 3,000px·400만 화소 이하. 비율을 유지해 칸 안에 넣으며 남는 공간은 여백입니다.

사진 자체는 좌우 반전하거나 회전하지 않습니다. 프린터에서도 같은 넘김 방향을 선택하세요.

시험 인쇄에서 측정한 오차

오른쪽·아래쪽으로 밀렸으면 양수, 왼쪽·위쪽이면 음수입니다. 설계 위치와 인쇄 위치의 차이를 mm로 입력하세요.

뒷면 PDF를 똑바로 보는 방향에서 뒷면 오차를 측정하세요. 보정은 뒷면에만 적용합니다.

입력 파일과 설정은 업로드하거나 저장하지 않습니다. 페이지 이동·새로고침·초기화 시 지웁니다.

인쇄 PDF 결과

A4 세로·실제 크기 100%로 인쇄하세요. 자동 맞춤·축소를 끄고 일반 용지 한 장으로 먼저 확인하세요. 프린터 급지 오차는 보장하지 않습니다.

사용 방법과 처리 기준

같은 앞뒤 사진 한 쌍을 A4 한 장의 여러 칸에 반복 배치하는 도구입니다. PDF 1페이지는 앞면, 2페이지는 뒷면입니다. 긴 쪽 넘김에서는 뒷면 x = 210 − 앞면 x − 카드 너비, 짧은 쪽에서는 뒷면 y = 297 − 앞면 y − 카드 높이로 짝을 맞춥니다. 사진 자체를 거울처럼 반전하지 않습니다.

실제 예시

기본 54×86mm 카드 3열·3행은 A4에 9장을 배치합니다. 긴 쪽 넘김에서 앞면 왼쪽 21mm 칸은 뒷면 왼쪽 135mm에 놓입니다(210−21−54). 뒷면을 똑바로 보고 오른쪽으로 2mm 밀렸다면 오른쪽 오차에 +2를 넣어 뒷면 PDF를 왼쪽으로 2mm 옮깁니다.

위쪽 12mm는 안내 문구를 위해 남기며 나머지 가장자리에는 5mm 안전 여백을 둡니다. 보정 후에도 모든 칸이 이 영역 안에 있어야 하며 최대 100칸·결과 50MiB입니다.

자주 묻는 질문

긴 쪽과 짧은 쪽 넘김은 무엇이 다른가요?

A4 세로를 기준으로 긴 쪽은 책처럼 옆으로, 짧은 쪽은 달력처럼 위아래로 넘기는 방향입니다. PDF에서는 긴 쪽에 열 위치를, 짧은 쪽에 행 위치를 반전해 앞뒤 칸을 맞춥니다. 프린터의 양면 옵션을 같은 방향으로 선택하고 공개 예시로 실제 방향부터 확인하세요.

서로 다른 사진 여러 쌍을 한 번에 넣을 수 있나요?

현재는 같은 앞면·뒷면 한 쌍을 모든 칸에 반복합니다. 앞면과 뒷면을 모두 선택하거나 둘 다 비워 공개 예시를 사용하세요. 사진 비율을 유지하며 칸 안에 맞추므로 자르지 않고 여백이 생길 수 있습니다.

왜 앞뒤가 조금씩 어긋나나요?

프린터의 급지, 양면 정렬, 용지 두께와 확대·축소 설정에 따라 실제 위치가 달라집니다. A4·실제 크기 100%로 일반 용지에 시험 인쇄한 뒤 뒷면을 똑바로 보는 방향에서 오차를 입력하세요. 기울기나 인쇄할 때마다 달라지는 오차는 보정하지 않습니다.

사진과 파일명은 어디로 전송되나요?

사진·파일명을 서버로 보내거나 통계에 넣지 않습니다. 선택한 사진은 이 브라우저에서 PNG로 다시 만들어 PDF에 넣으며 다운로드 파일에는 사진 픽셀이 포함됩니다. 페이지 이동·초기화 때 기기 메모리의 입력과 결과를 지우지만 이미 다운로드한 PDF는 직접 삭제해야 합니다.
