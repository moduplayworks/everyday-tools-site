계산 기준과 사용 방법

한글·영문 문장에서 조합 완료 글자의 속도·누적 오타·정확도 측정.

CPM = 현재 맞는 글자 ÷ 경과 분 · WPM = CPM ÷ 5 · 정확도 = (누적 입력 − 누적 오타) ÷ 누적 입력 × 100

입력 예시

1분 동안 현재 문장에 맞는 표시 글자가 30개라면 CPM은 30이고 WPM은 30÷5=6입니다. 누적 32글자를 입력하며 2글자가 틀렸다면 정확도는 30÷32×100=93.75%입니다. 틀린 글자를 지워도 누적 오타는 남으며 한글 음절은 키보드 타수로 변환하지 않습니다.

사용 방법

  1. 예시값을 사용하거나 내용을 바꾼 뒤 타자 연습 시작 버튼을 누르세요.
  2. 첫 글자부터 측정합니다. 문장을 마치거나 설정 시간이 되면 결과를 확인하세요.
  3. 결과와 도구 링크를 함께 공유할 수 있습니다. 개인 입력은 링크에 들어가지 않습니다.

한계와 해석

글자는 NFC 정규화된 표시 글자 단위입니다. 한글 음절을 물리적 키 입력 횟수로 환산하지 않습니다. 띄어쓰기와 문장부호도 비교하며 누적 오타는 지워도 남습니다. 위치별 비교이므로 글자 삽입·삭제는 뒤쪽 일치에도 영향을 줍니다. 붙여넣기·드롭은 측정에 사용할 수 없고 탭을 벗어나면 연습을 중단합니다. 자동 완성 등 키보드 보조 기능에 따라 결과가 달라집니다. 최대 1,000개 표시 글자이며 최소 1초를 측정합니다.

자주 묻는 질문

한글 300타 같은 기존 타자 수와 비교할 수 있나요?

직접 비교하지 마세요. 이 도구는 조합이 끝난 표시 글자·공백·문장부호를 세고, 물리적인 자음·모음 키 횟수를 세지 않습니다. CPM과 WPM의 정의를 결과 가까이에 표시합니다.

모바일에서 측정한 결과가 PC와 다를 수 있나요?

화면 키보드, 자동 완성·자동 수정, 입력 방식이 달라집니다. 이번 연습의 키보드를 직접 선택해 결과에 남기고 같은 문장·기기·조건끼리 비교하세요. 붙여넣기·드롭은 차단하고 다른 탭으로 이동하면 중단합니다.

오타를 지우면 정확도가 다시 100%가 되나요?

현재 맞는 글자 수는 바뀌지만 누적 오타와 새로 입력한 글자는 계속 셉니다. 그래서 실수 후 수정도 정확도에 반영합니다. 조합 중간 자모는 확정 입력으로 중복 계산하지 않습니다.

계산 기준과 참고 자료

  • Monkeytype — 타자 연습과 속도·정확도

    시간·정확도·오타 중심 연습 작업의 비교 기준. 이 도구는 표시 글자와 누적 오타에 대한 별도 계산 정의를 씁니다.

  • MDN — Intl.Segmenter 표시 글자 단위

    NFC 정규화 후 grapheme 분할에 의한 표시 글자 계산
