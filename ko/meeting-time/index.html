계산·파일 생성 기준

도시별 날짜·시각을 비교하고 함께 가능한 회의 시간 찾기.

기준 도시의 현지 날짜·시각 → UTC 시점 → 각 도시의 현지 날짜·시각. 공통 시간은 같은 UTC 구간이 모든 시간대의 가능한 요일·시간 안에 들어가는지 비교합니다.

입력 예시

2026-10-05 09:00 서울은 같은 시점의 뉴욕 10월 4일 20:00, 런던 10월 5일 01:00입니다. 각 도시의 09~18시·월~금 조건으로 다음 72시간의 공통 회의 시각도 찾을 수 있습니다.

서울 2026년 10월 5일 09:00은 뉴욕 10월 4일 20:00, 런던 10월 5일 01:00입니다. 날짜가 같다고 가정하지 않고 도시별 요일도 확인하세요. 공통 검색은 선택한 시점부터 72시간을 15분 간격으로 살피며 모든 도시에서 회의 전체가 가능 시간 안에 있어야 합니다.

사용 방법

  1. 입력된 예시를 쓰거나 필요한 값을 바꾸세요. 추가 설정은 펼쳐서 확인합니다.
  2. 결과를 확인한 뒤 도시·일정·달력·시간 블록을 검토하세요. 오류는 제외하지 않고 수정을 안내합니다.
  3. 결과를 복사하거나 실제 파일을 저장하세요. 가져오기·인쇄는 기기의 지원 기능을 사용합니다.

지원 범위와 한계

1~8개 시간대, 날짜 2000~2100년. 공통 시간은 시작 시점부터 72시간을 15분 간격으로 검색하고 회의 전체를 분 단위로 검사합니다. 가능 시간 창은 자정을 넘지 않습니다. 시간대 데이터는 기기 브라우저의 Intl에 따르므로 최신 법령 변경의 반영 시점은 기기마다 다를 수 있습니다.

자주 묻는 질문

서머타임으로 시각이 겹치거나 사라지면 어떻게 하나요?

존재하지 않는 현지 시각은 시간을 바꾸도록 안내합니다. 두 번 존재하는 시각은 앞·뒤 시점을 직접 선택해야 합니다. 브라우저에 포함된 시간대 데이터 기준이므로 새로 변경된 지역 규칙은 별도로 확인하세요.

도시마다 다른 근무 시간을 설정할 수 있나요?

이 버전은 최대 8개 시간대에 같은 가능한 요일·시간과 15~240분의 회의 길이를 적용합니다. 자정을 넘는 가능 시간 창은 지원하지 않으며 후보가 없으면 조건을 조정하세요.
