녹음·영상 텍스트 변환기

짧은 녹음·영상의 음성을 브라우저에서 인식하고 자막을 수정해 TXT·SRT로 저장하세요.

녹음·영상 텍스트와 자막 만들기

60초·20MB 이하 MP3·WAV·MP4·WEBM. 브라우저가 오디오를 해독할 수 있어야 합니다. 긴 파일은 먼저 자르세요.

Whisper base를 사용합니다. 첫 실행에 약 110MB의 모델·실행 파일을 내려받으며 기기에 따라 수 분 걸릴 수 있습니다. 파일은 업로드하지 않습니다.

예시는 자막 편집용 텍스트입니다. 실제 인식은 파일 선택 후 실행하세요.

파일을 선택하거나 공개 편집 예시를 사용하세요.

원음 확인

파일·자막은 이 페이지 메모리에서만 처리합니다. 새로고침하거나 페이지를 떠나면 지워집니다. 모델만 캐시될 수 있습니다.

자막 검토와 수정

말하지 않은 문장을 만들거나 잘못 인식할 수 있습니다. 원음을 들으며 모든 문장과 시간을 확인하세요. 화자 구분과 번역은 제공하지 않습니다.

사용 방법과 예시

MP3·WAV·MP4·WEBM의 음성을 한국어·영어·일본어로 받아쓰고 편집하는 도구입니다. Whisper base의 추정 결과를 제공하며 정확한 회의록이나 전문 녹취를 보장하지 않습니다.

공개 편집 예시는 0~2초의 “Hello, welcome.”과 2~5초의 “Review this caption.”으로 구성됩니다. SRT에는 각각 00:00:00,000 → 00:00:02,000과 00:00:02,000 → 00:00:05,000이 기록됩니다. 실제 녹음을 선택해 인식하면 추정된 구간을 같은 방식으로 수정할 수 있습니다.

자주 묻는 질문

어떤 파일과 길이를 지원하나요?

60초·20MB 이하 파일을 지원하며 브라우저가 해당 오디오 코덱을 해독할 수 있어야 합니다. 지원하지 않는 영상은 오디오 추출 도구로 먼저 변환하세요. 긴 녹음은 오디오 자르기로 나누고 한 번에 한 파일을 처리합니다.

AI가 틀린 문장을 만들 수도 있나요?

잡음·음악·작은 목소리·침묵에서 누락이나 환각이 생길 수 있습니다. 모든 자막과 시작·종료 시간을 원음과 대조하세요. 화자 구분, 실시간 녹음, 자동 번역은 지원하지 않습니다.

녹음 파일을 서버에 보내나요?

입력 파일과 자막은 업로드하지 않습니다. 사용자가 실행하면 같은 사이트에서 모델과 실행 파일을 내려받아 브라우저에서 처리합니다. 새로고침하거나 이동하면 입력과 결과를 지우며 모델 파일은 캐시에 남을 수 있습니다.

계산 기준과 참고 자료

  • OpenAI — Whisper model card

    Whisper 모델의 언어별 성능 차이와 환각·오인식 한계를 설명합니다. 이 도구는 base 모델을 브라우저에서 실행합니다.

  • Hugging Face — Automatic speech recognition

    브라우저 음성 인식과 추정 자막 시간의 API 참고 자료입니다. 결과의 정확성을 보증하지 않습니다.
