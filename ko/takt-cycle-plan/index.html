수요에 맞는 택트와 실제 사이클을 비교하세요. 가용 시간 안의 완성 수량을 기준으로 병렬 공정 수를 계산하고 완성 불가 조건을 구분합니다.

사용 방법과 예시

택트=가용 분/수요입니다. 공정당 완성 수=floor(가용 분/사이클 분), 병렬 공정 수=ceil(수요/공정당 완성 수)입니다.

택트는 1.5분, 필요 부하는 120%, 병렬 공정은 2개입니다.

동일한 공정을 동시에 시작하고 각 공정에서 완제품을 순서대로 만듭니다. 분할 제작은 허용하지 않습니다. 사이클이 가용 시간보다 길면 완성 불가로 표시하며 인력 권고가 아닙니다. 입력 소수는 유효 숫자 30개·소수 30자리·지수 절댓값 30까지 정확한 분수로 처리합니다. 표시된 소수 결과는 최대 12유효숫자로 반올림하지만 정수 개수는 반올림 오차 없이 결정합니다.
