PX·REM 변환기

기준 글꼴 크기에 따라 픽셀과 rem 값을 변환합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

최소 0.01

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

브라우저의 실제 루트 글꼴을 직접 입력하세요. 기본 예시는 16px입니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

루트 글꼴 크기에 맞춰 px와 rem 변환하기.

rem = px ÷ 루트 글꼴 px

입력 예시

16px / 기준 16px = 1rem

루트 글꼴이 16px이면 24px은 24÷16=1.5rem입니다. 루트가 20px이면 같은 24px도 1.2rem이므로 실제 설정을 확인하세요.

사용 방법

  1. 입력된 예시값을 사용하거나 값, 루트 글꼴 크기 (px), 입력 단위 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

rem과 em은 같은 단위인가요?

rem은 루트 요소의 글꼴 크기를 기준으로 합니다. em은 사용하는 속성과 요소의 글꼴 크기에 따라 기준이 달라질 수 있어 이 도구의 rem 결과를 그대로 em으로 바꾸면 안 됩니다.
