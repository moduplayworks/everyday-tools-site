학점 계산기

4.5·4.3·4.0 만점의 과목별 학점과 성적으로 평균 평점을 계산하세요. P/F 제외와 기존 성적을 반영한 누적 평점을 확인합니다.

학점 계산기 입력
기존 성적 합산 (선택)

P·NP는 평균 제외, F는 0점 반영. 학교별 재수강·환산 규칙은 성적표를 확인하세요.

입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

과목별 이수 학점과 등급 환산점을 가중 합산해 평점을 구하는 작업입니다.

실제 예시

4.5 만점에서 3학점 A+(4.5)와 2학점 B0(3.0)는 (3×4.5+2×3.0)÷5 = 3.90입니다. P 1학점은 이수 학점에는 더하지만 평점의 분모에서 제외합니다.

자주 묻는 질문

P·NP·F 성적은 학점 평균에 어떻게 반영하나요?

P와 NP는 평점에서 제외합니다. P는 이수 학점에 포함하고 NP는 제외합니다. F는 0점으로 평점 분모에 포함하되 이수 학점에는 포함하지 않습니다. 학교 규정이 다르면 공식 성적표를 우선하세요.

기존 평점과 이번 학기 성적으로 누적 평점을 구할 수 있나요?

기존 평점에 반영된 학점과 평점을 추가 설정에 입력하세요. 기존 총점과 이번 총점을 합해 평점 학점 합계로 나눕니다. 기존 평점이 반올림된 값이면 누적 결과도 근삿값입니다. 재수강 대체는 자동 적용하지 않습니다.
