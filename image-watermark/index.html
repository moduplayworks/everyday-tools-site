사진 워터마크 넣기

사진에 글자나 로고를 넣으세요. 위치·크기·불투명도를 확인하고 여러 장을 같은 설정으로 저장합니다.

사진 워터마크 넣기 입력

JPG·PNG·WEBP · 장당 20MB 이하

투명 PNG 권장 · 2MB·400만 화소 이하

크기·글자 색상

첫 사진 미리보기입니다. 저장 결과에서 모든 사진을 확인하세요.

지원 범위와 원본 보관

입력은 장당 2,400만 화소·전체 50MB 이하입니다. 원본 파일은 바꾸지 않습니다. 움직이는 이미지는 정지 이미지로 처리하며 HEIC는 지원하지 않습니다. 결과는 2,400만 화소·한 변 6,000px(합치기 16,000px)까지입니다. 가리기 결과는 PNG로 저장합니다. 원본 메타데이터·편집 기록은 결과에 보존하지 않습니다.

입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

여러 사진에 같은 글자 또는 로고를 상대적으로 같은 위치에 넣는 작업입니다.

실제 예시

가로 1,000px 사진에서 크기 30%를 선택하면 글자나 로고의 가로 폭은 약 300px가 됩니다. 오른쪽 아래 위치는 사진 가장자리에서 짧은 변의 약 3% 간격을 두며, 사진마다 상대 크기를 다시 계산합니다.

자주 묻는 질문

로고 이미지는 어떤 파일을 사용할 수 있나요?

JPG·PNG·WEBP 로고를 지원하며 2MB·400만 화소 이하입니다. 투명 배경은 PNG 또는 WEBP를 사용하세요. 사용할 권리가 있는 글자·로고를 선택하세요.

여러 사진에 워터마크를 넣으면 원본이 덮어써지나요?

원본은 보존하고 새 이미지 또는 ZIP을 만듭니다. 미리보기는 첫 사진이며 저장 결과에서는 모든 사진을 확인할 수 있습니다. 워터마크는 무단 사용이나 제거를 완전히 막는 수단은 아닙니다.
