CSV→JSON 변환기

첫 줄 헤더를 키로 사용해 CSV를 JSON 객체 배열로 변환합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

헤더는 중복되거나 비어 있을 수 없습니다. 각 행의 열 수가 같아야 합니다. 쉼표 구분 CSV를 지원합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

헤더가 있는 쉼표 구분 CSV를 JSON 배열로 바꾸기.

쉼표·따옴표·따옴표 내부 줄바꿈을 파싱, 값은 문자열 유지

입력 예시

name,score / 가,1 → [{"name":"가","score":"1"}]

name,score 헤더 아래 A,10을 넣으면 name이 A, score가 문자열 10인 객체가 됩니다. 따옴표로 감싼 필드 안의 쉼표와 줄바꿈은 한 값으로 처리합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 CSV 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

우편번호 00123의 앞자리 0이 사라지나요?

값을 문자열로 유지하므로 00123을 보존합니다. 숫자나 날짜를 자동 추측하지 않습니다. 헤더가 중복되거나 비어 있거나 행별 열 수가 다르면 오류를 안내합니다.

계산 기준과 참고 자료

  • RFC 8259 — JSON

    JSON 문법과 상호운용 시 숫자 정밀도 고려사항

  • RFC 4180 — CSV

    쉼표 구분, 필드 따옴표와 줄바꿈 규칙. 스프레드시트 수식 보호는 이 도구의 추가 처리입니다.
