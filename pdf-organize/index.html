PDF 페이지 정리

PDF 썸네일을 보며 페이지 순서를 바꾸고 삭제·회전하세요. 원본을 보존하며 정리한 사본을 저장합니다.

PDF 페이지 정리 입력

PDF 1개 · 50MB·200페이지 이하

원본 페이지 번호를 기준으로 표시합니다. 앞·뒤 버튼으로 이동하고 삭제·회전한 뒤 저장하세요.

PDF 지원 범위

암호화·양식 PDF는 지원하지 않습니다. 서명·책갈피·첨부·문서 부가정보 보존은 보장하지 않습니다. 일반 사본으로 작업하세요.

입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

PDF 페이지의 실제 미리보기를 보며 순서·삭제·회전을 편집하는 작업입니다.

실제 예시

원본 1·2·3페이지에서 3페이지를 앞으로 두 번 이동하고 2페이지를 삭제하면 결과는 3·1페이지입니다. 회전 버튼 한 번은 원본 방향에서 시계 방향 90도를 더합니다.

자주 묻는 질문

모바일에서 PDF 페이지 순서를 어떻게 바꾸나요?

썸네일 아래 앞으로·뒤로 버튼을 사용합니다. 한 번에 6페이지씩 보여 주며 이전·다음으로 이동합니다. 첫 페이지는 앞으로, 마지막 페이지는 뒤로 이동할 수 없습니다. 원본 번호는 계속 표시됩니다.

삭제한 페이지를 되돌리고 원본 파일도 유지할 수 있나요?

페이지 순서·삭제·회전 초기화를 누르면 처음 상태로 돌아갑니다. 저장은 새 사본을 생성하므로 원본 파일은 바뀌지 않습니다. 최소 한 페이지를 남겨야 하며 전자서명·책갈피·첨부 보존은 보장하지 않습니다.
