회귀·상관 계산기

x, y 자료로 회귀선·Pearson 상관계수·R²와 잔차를 확인하세요. 산점도와 예측값을 보고 CSV·SVG로 저장합니다.

입력

예시값으로 바로 계산하거나 값을 바꿔 보세요.

한 줄에 x와 y 두 숫자 · 공백·탭·쉼표 구분 · 2~1,000쌍 · 헤더·결측값 제외 불가

특정 x의 예측값

입력 자료 범위 밖이면 외삽으로 표시합니다.

입력은 이 브라우저에서만 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하세요.

계산·풀이 과정
계산 데이터 확인

표시값은 유효숫자 10자리 근사값입니다. CSV·TXT는 표시값을 저장하며 입력값은 주소나 방문 통계에 넣지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산 기준과 사용 방법

두 숫자 자료의 회귀선·상관계수와 잔차 확인하기.

기울기 b=Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² · 절편 a=ȳ−bx̄ · 잔차=y−예측값 · Pearson r=Sxy/√(Sxx·Syy)

입력 예시

(1,2), (2,3), (3,5)의 회귀선은 y=1.5x+1/3입니다. x=4의 예측값은 6.33333…이며 입력 범위 밖의 외삽입니다.

(1,2), (2,3), (3,5)의 평균은 x̄=2와 ȳ=10/3입니다. Sxx=2, Sxy=3이므로 기울기는 1.5, 절편은 1/3입니다. 잔차는 1/6, −1/3, 1/6이며 SSE=1/6입니다. x=4 예측은 19/3이지만 관측한 1~3 범위 밖의 외삽입니다.

사용 방법

  1. 예시값을 사용하거나 직접 숫자를 입력하세요. 표 형식은 한 줄이 한 행입니다.
  2. 결과 확인하기를 누르세요. 잘못된 행은 위치를 표시하고 제외하지 않습니다.
  3. 결과·계산 과정을 확인하고 필요한 결과를 복사하거나 파일로 저장하세요.

한계와 해석

2~1,000쌍, 각 값의 절댓값 1조 이하. 빈 줄만 무시하고 누락값·헤더·잘못된 숫자 행은 오류로 안내합니다. 절편을 포함한 단순 OLS만 지원하며 신뢰구간·인과관계·미래 정확도를 보장하지 않습니다.

자주 묻는 질문

상관계수가 높으면 원인과 결과가 증명되나요?

아닙니다. Pearson r은 입력 표본의 선형 관계를 나타냅니다. 제3의 요인, 표본 선정, 이상치와 외삽 문제를 해결하지 않으며 인과관계나 예측 정확도의 보장이 아닙니다.

누락된 값이나 같은 x만 있는 자료는 어떻게 되나요?

빈 줄만 무시합니다. 누락값·헤더·비숫자가 있는 행은 위치를 알려 수정하게 합니다. 모든 x가 같으면 기울기를 구할 수 없습니다. 모든 y가 같으면 회귀선은 상수지만 r과 R²는 정의되지 않습니다.
