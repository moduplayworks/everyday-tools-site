Guide

안전하게 이어가세요.

1. 강의 시간을 입력하세요

숫자만 입력하면 분으로 계산해요. 60은 60분, 1:30은 1분 30초, 1:00:00은 1시간입니다. 여러 시간을 한 줄에 하나씩 붙여넣을 수도 있어요. 샘플을 불러와 먼저 계산해 보세요.

2. 배속과 일정을 선택하세요

인강 배속 계산기에서 순수 시청 시간을 비교하세요. 완강 계획 계산기에서는 시작일·마감일·가능한 요일과 시간을 정해 하루 분량을 배정할 수 있어요. 완료 여부나 현재까지 본 원본 위치를 입력하고 다시 계산하면 남은 분량만 배정합니다.

3. 계산 버튼을 눌러 저장하세요

정상 계산한 입력은 같은 브라우저에서 복원됩니다. 입력 중인 변경은 계산 버튼을 누르기 전까지 저장하지 않아요. 잘못된 입력과 손상된 백업은 기존 정상 데이터를 덮어쓰지 않습니다. 저장이 차단되어도 계산은 계속할 수 있으니 JSON 백업을 이용하세요.

각 도구는 별도 공간에 저장됩니다. 배속 계산기의 ‘이 강의로 완강 계획 만들기’를 누르고 가져오기를 확인하면 강의 목록과 배속이 복사됩니다. 이후 두 도구의 수정 사항은 자동 동기화되지 않아요.

4. JSON 파일로 백업하고 복원하세요

도구의 ‘JSON 백업’ 버튼으로 현재 유효한 입력을 내려받으세요. 다른 기기나 브라우저에서는 ‘백업 복원’으로 파일을 가져올 수 있어요. 파일 크기는 최대 1MB입니다. 복원은 확인 후 해당 도구의 데이터를 교체합니다.

무료 주소와 정식 도메인의 저장 공간은 달라요. 주소가 바뀌기 전에 파일을 백업하고 새 주소에서 복원하세요. 백업에는 입력한 강의명과 계획이 포함되므로 공유할 때 내용을 확인하세요.

5. 필요 없는 데이터는 삭제하세요

각 도구의 ‘이 도구 초기화’는 해당 도구의 데이터만 지웁니다. 아래 버튼은 이 서비스의 두 도구와 설정을 모두 삭제합니다. 같은 도메인의 다른 서비스 데이터는 삭제하지 않아요.

저장이 되지 않거나 결과가 이상한가요?

비공개 모드, 사이트 저장 차단, 저장 공간 부족 때문에 저장이 실패할 수 있어요. 먼저 JSON 백업을 보관하고 브라우저 설정을 확인하세요. 손상된 데이터를 읽지 못할 때는 조용히 덮어쓰지 않으며, 백업 복원 또는 명시적 초기화로 복구할 수 있습니다. 다른 탭에서 데이터를 수정했으면 현재 입력을 백업한 뒤 새로고침하세요.
