캘린더 일정 파일 만들기

종일·시간 지정·반복 일정을 ICS 파일로 만드세요. 실제 발생 날짜와 시간대를 확인하고 캘린더에 직접 가져옵니다.

입력

입력된 공개 예시로 바로 확인하거나 값을 바꾸세요.

지역/도시 이름 · 예: Asia/Seoul (서울)

반복·장소·설명

서머타임 중복 시각 처리

입력은 브라우저에서만 처리합니다. 새로고침하면 공개 예시로 돌아갑니다.

결과

예시값으로 바로 결과를 확인하세요.

생성할 일정 목록

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·파일 생성 기준

종일·반복 일정을 캘린더에 가져올 ICS 파일 만들기.

현지 날짜·시각을 UTC로 변환 → VEVENT의 DTSTART·DTEND. 종일 일정은 DATE 값과 다음 날의 비포함 종료일. 반복은 날짜별로 계산한 RDATE를 기록합니다.

입력 예시

서울 2026-10-05 10:00~11:00은 UTC 01:00~02:00으로 저장합니다. 종일 일정의 마지막 포함 날짜가 10월 5일이면 ICS의 DTEND는 10월 6일입니다.

서울 2026년 10월 5일 10:00~11:00 일정은 UTC 01:00~02:00으로 저장합니다. 종일 일정에서 마지막 날짜를 10월 5일로 선택하면 그 날짜를 포함하고 파일의 종료 날짜는 10월 6일입니다. 반복 날짜를 하나씩 확인한 뒤 파일을 직접 가져오세요.

사용 방법

  1. 입력된 예시를 쓰거나 필요한 값을 바꾸세요. 추가 설정은 펼쳐서 확인합니다.
  2. 결과를 확인한 뒤 도시·일정·달력·시간 블록을 검토하세요. 오류는 제외하지 않고 수정을 안내합니다.
  3. 결과를 복사하거나 실제 파일을 저장하세요. 가져오기·인쇄는 기기의 지원 기능을 사용합니다.

지원 범위와 한계

한 일정, 반복 최대 100회·마지막 날짜까지 366일. 매일·매주 반복만 지원하고 실제 발생 날짜·UTC 구간을 파일에 고정합니다. 내보낸 뒤 시간대 법령이 바뀌어도 파일이 자동 수정되지 않습니다. 파일 가져오기는 캘린더 앱에서 직접 하며 이메일·초대·계정 연결은 제공하지 않습니다.

자주 묻는 질문

반복 일정의 현지 시각은 유지되나요?

매일·매주 반복은 최대 100회, 마지막 날짜까지 최대 366일입니다. 각 날짜의 현지 시작·끝을 UTC로 변환해 실제 발생 시점을 열거합니다. 서머타임으로 없는 시각이 끼면 전체 입력을 수정하도록 안내합니다.

초대장이 전송되거나 캘린더에 자동 등록되나요?

아닙니다. 파일만 내려받으며 이메일·초대·자동 동기화는 제공하지 않습니다. 가져올 앱에서 발생 날짜를 확인하세요. 입력·파일 내용은 브라우저에서 만들며 결과 공유 시 일정 내용이 포함됩니다.
