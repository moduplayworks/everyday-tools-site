목표 성적 계산기

받은 점수와 반영 비율로 목표 최종 점수에 필요한 남은 평균을 계산하세요. 불가능한 목표와 완료된 평가를 구분합니다.

입력

예시값으로 바로 실행하거나 값을 바꿔 보세요.

0~100, 소수 2자리까지. 모든 평가를 100점 기준으로 입력하세요.

0~100, 소수 2자리까지

0보다 큰 비율, 소수 2자리까지. 전체 완료 평가 합계는 100% 이하.

입력 백업·복원

입력은 저장·자동 동기화하지 않습니다. 새로고침하면 예시값으로 돌아갑니다. JSON 백업에는 이름과 모든 입력이 포함됩니다. 복원은 현재 입력을 교체합니다.

결과

입력된 예시값으로 바로 결과를 확인하세요.

기본 결과 내보내기는 항목 번호를 사용합니다. 이름 포함을 켜면 공유할 내용과 파일에 이름이 들어갑니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산 기준과 사용 방법

이미 받은 점수와 최종 반영 비율로 목표 점수에 필요한 남은 평가 평균 계산.

필요한 남은 평균 = (목표 최종 점수 − 완료 평가의 가중 합계) ÷ 남은 반영 비율

입력 예시

과제 80점이 최종 성적의 20%, 중간고사 90점이 30%이면 이미 확보한 최종 점수는 80×0.2+90×0.3=43점입니다. 목표가 90점이고 남은 비율이 50%라면 (90−43)÷0.5=94점이 필요합니다. 목표 94점은 필요한 남은 점수가 102점이므로 100점 상한에서 달성할 수 없습니다.

사용 방법

  1. 입력된 예시를 사용하거나 설정과 선택한 항목을 수정하세요. 항목 추가로 여러 평가·교재·주제를 순서대로 입력합니다.
  2. 필요 점수 확인를 누르세요. 잘못된 입력은 해당 항목과 필드로 이동해 안내합니다.
  3. 결과를 확인하고 CSV로 저장하세요. 계획은 필요하면 ICS로 가져올 수 있습니다. 입력을 이어서 쓰려면 JSON 백업을 따로 저장하세요.

한계와 해석

모든 평가는 100점 기준으로 환산한 값입니다. 남은 여러 평가의 가중 평균을 구하며 학교의 등급·상대평가·추가점수·반올림 규정은 예측하지 않습니다. 최대 50개 완료 평가, 점수·비율은 소수 2자리까지 입력합니다.

자주 묻는 질문

남은 시험이 여러 개면 모두 94점을 받아야 하나요?

94점은 남은 평가 전체의 가중 평균 조건입니다. 한 평가가 낮아도 다른 평가가 높은 점수와 반영 비율로 보완할 수 있습니다. 개별 시험 점수 조합은 이 조건을 기준으로 따로 확인하세요.

A등급이나 학교의 성적 반올림도 계산하나요?

100점 기준으로 환산한 가중치만 계산합니다. 등급 경계·상대평가·추가점수·학교의 반올림 규정은 반영하지 않습니다. 목표 점수를 실제 수업 기준에 맞춰 입력하세요.
