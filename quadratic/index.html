이차방정식 계산기

ax²+bx+c=0의 판별식과 실근 또는 켤레복소근을 구합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

소수 결과는 유효숫자 12자리까지 표시합니다. 단위는 입력값끼리 통일해 주세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

이차방정식의 판별식과 실근·복소근 구하기.

D = b²−4ac, x = (−b ± √D) ÷ 2a

입력 예시

x²−3x+2=0의 근 = 1, 2

x²−3x+2=0은 a=1, b=−3, c=2로 입력합니다. 판별식은 1이고 두 근은 1과 2로, 대입하면 각각 원래 식이 0이 됩니다.

사용 방법

  1. 입력된 예시값을 사용하거나 a, b, c 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

판별식이 음수면 계산이 실패한 것인가요?

아닙니다. 실수 범위의 근은 없지만 복소수 범위에서는 두 근이 있습니다. 이 도구는 허수 단위 i를 사용해 표시합니다. a=0이면 이차방정식이 아니므로 받지 않습니다.
