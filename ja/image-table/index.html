表の写真をExcelに変換

均等な表の写真をセルごとに読み取り、修正してXLSX・CSVで保存します。韓国語・英語OCRをブラウザーで処理します。

写真と認識設定

JPG・PNG・WEBP · 12MB・一辺6,000px・1,200万画素以下。大きな写真は最大2,200px・400万画素に縮小します。

各セルが1行で行高・列幅が均等な傾きのない表のみ対応します。先に表の外枠に沿って切り抜いてください。1～12行、1～8列、合計48セルまで。結合セル・傾いた表は非対応です。

公開サンプルを編集するか写真を選択してください。認識前でもサンプル結果を保存できます。

よくある質問

表の構造を自動で検出しますか？

いいえ。指定した行数・列数で写真を均等に分割し、各セルを読み取ります。不規則な表は小さく切り抜くか、セルを手動で修正してください。

数値や数式はExcelの値になりますか？

XLSXの全セルは文字列で、先頭の0や数式に似た文字も保持します。計算に使う場合はExcelで確認後に数値へ変換してください。CSVの数式開始文字はアポストロフィで保護するため、元の表示と異なる場合があります。

写真や結果をサーバーへ送信しますか？

写真と結果はブラウザー内だけで処理します。同じサイトからOCRと言語データのみ取得します。再読み込みで結果は消去されます。

計算基準と参考資料

  • Tesseract.js — ブラウザOCR API Workerの設定

    ブラウザのWorkerで画像を認識し、worker・core・言語ファイルのパスを同じサイトに固定するAPI。認識結果の正確性は保証されません。
