ZIPを圧縮する

複数のファイルを一つの ZIP にまとめる。圧縮方式と ZIP 名前を指定し、元のファイルを保持したコピーを保存する。

ZIPを圧縮する入力

ファイル1〜200個 · 全体50MB以下

選択したファイル
圧縮方式

写真・動画のように圧縮されたファイルはサイズがほとんど変わらない可能性があります。暗号化ZIPを作成しません。

元のファイルは変更されません。ブラウザで処理し、再読み込みすると作業が初期化されます。

結果

ファイルを選択し、実行してください。

個人情報の説明

使用方法と処理基準

複数のファイルを一つの ZIP ファイルにまとめてコピーとして保存する作業である。

実際の例

メモ用のTXTファイルと写真のPNGを選び、archive.zipとして保存すると、2つの元ファイルは同じ名前でZIPに格納されます。通常の圧縮を選んでも、すでに圧縮済みの写真や動画はほとんど小さくならない場合があります。

よくある質問

ZIPパスワードを設定するか、フォルダ全体を入れることは可能ですか？

現在はファイル選択で一般的な ZIP を作成し、暗号化やフォルダ選択機能は提供されていません。選択した元のファイルは変更されません。ファイル名が重複した場合は名前を変更するか、ファイル名一括変更ツールを使用してください。

圧縮速度とサイズを選択できますか？

一般圧縮はDeflateを使用し、圧縮なしで保存方式で迅速に圧縮されます。ファイル200件・全体50MBまでサポートし、処理中に中止可能です。
