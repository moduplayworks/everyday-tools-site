動画から必要な部分のみを保存してください

ファイルを選択するか、サンプル動画から開始し、開始・終了時間を入力すると短い動画に再エンコードされます。例えば4秒の動画の0〜2秒を切ると約2秒のファイルが作成されます。

ブラウザが動画を再生しながら再デコーディングします

保存形式とコーデックはブラウザによって MP4 または WebM に変わります。元の内容や形式・画質が同じであるとは保証できず、端末によっては時間がかかる場合があります。結果を再生して確認してください。4K動画は最大 1920px に縮小して保存されます。

個人情報と制限

選択した動画はアップロードされたりサーバーに送信されません。最大100MB・10分間の動画で0.5〜30秒の区間を処理し、ブラウザタブを閉じると進行中の作業は終了します。端末のメモリやブラウザのサポートにより、一部のファイルは処理されない場合があります。

よくある質問

映像区間を切り取り時、元のファイルも変更されますか？

元は修正されません。選択した部分を別ファイルとして再コーデックし、ダウンロードします。入力動画はブラウザ内で処理されます。

切り出した映像の画質と長さは元のものと同じですか？

設定した開始・終了時間に基づき画素間の長さが決まりますが、ブラウザの再コーディングによりフレーム境界に応じて若干異なる場合があります。最大長は1,920px、30フレーム/秒で表示され、4K原稿は縮小されることがあります。ファイルサイズや無損失出力の保証はありません。

MP4・WebM・MOVの両方を開けますか？

ファイルコンテナだけでなく、動画コーデックも現在のブラウザでサポートされている必要があります。開けないファイルは別のブラウザや標準MP4(H.264)·WebM(VP8)ファイルに戻して選択してください。出力はブラウザがサポートするMP4またはWebMです。

選択した動画やファイル名をサーバーに送信しますか？

いいえ。動画とファイル名はブラウザのローカル処理にのみ使用されます。使用統計にはツールの使用実態のみ記録され、ファイル内容・名前・選択した区間は含まれません。

計算基準と参考資料

  • MDN — MediaRecorder

    ブラウザがサポートするコンテナ・コデックでキャプチャストリームを再コーデックします。サポートされる形式と出力品質はブラウザによって異なります。

  • MDN — Canvas captureStream

    現在の映像フレームをローカル Canvasに描き、ブラウザ内の録画用ストリームとしてキャプチャします。

  • MDN — AudioContext createMediaElementSource

    映像要素の音声をローカル Web Audio ストリームに接続し、映像と共に再コーディングします。

  • WebKit — MediaRecorder API

    WebKit実装ではキャンバス・Web Audioストリームの録画と形式機能の検出を説明します。現在の機器のコーデックサポート状況は実行中の機能検出によって判断されます。
