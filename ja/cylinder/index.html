円柱の体積計算機

半径・高さで円柱の体積と表面積を計算します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

最小 0

最小 0

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

小数結果は有効数字12桁まで表示されます。単位は入力値同士で統一してください。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

計算・変換基準

円柱の体積と全体の表面積を計算する

体積＝πr²h, 表面積＝2πr(r+h)

入力例

半径2、高さ3: 体積 ≈ 37.6991118431

半径2、高さ5の場合、体積は20πで表面積は28πです。表面積は側面に上下面の円を二つ加えた値です。

使用方法

  1. 入力された例の値を使用するか、半径、高さの項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

蓋のない容器の面積もすぐに表示できますか？

表示される面積は両側の底面を含みます。一方が開いた容器の場合は、円の一つの面積πr²を差し引く必要があり、壁の厚さや接続部の余裕は計算に含まれません。
