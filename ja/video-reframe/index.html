映像の画面比率変更

動画の画面比率を縦型または正方形に変更し、元のフレームをカットしたり、余白に収める作業

MP4・WebM・MOV・最大100MB・60秒。動画はこのブラウザで処理されます。

例えば映像で最初の実行を確認できます。

出力設定

中央を切り取りは画面外を捨て、全体を表示する際は比率を維持し、残りの部分に暗い余白を入れます。

映像の画面比率変更をブラウザで実行してください

640×360横画面で縦9:16を選択すると、縦フレームが作成されます。中央切り取りは左右領域を捨て、全画面表示は動画全体を縮小し、残りの空間を暗い余白で埋めます。被写体に沿って画面を移動しないので、結果を確認した後、保存してください。

新しい動画で再エンコードします

選択したファイルをサーバーにアップロードしません。新しいコンテナとコーデックで保存されるため、入力形式、画質、ファイルサイズが異なる可能性があります。予想サイズと元データを比較し、結果を直接再生して確認してください。

切り取りは画面の中央を基準に外側の領域を削除します。全体表示では元の動画を縮小して暗い余白を追加します。移動可能な被写体の追跡や自動再構成は行いません。

ファイルとデバイスの制限

最大100MB・60秒の動画で実行します。ブラウザがサポートする保存形式を検出し、MP4またはWebM形式で出力します。エンコーディング中はタブを開いておいてください。端末のメモリとコーデックのサポートに応じて、一部のファイルが処理されない可能性があります。

よくある質問

画面比率を変更すると、人物や物体の位置も自動的に変化しますか？

自動追跡は行いません。中央切り出しはフレームの中央を基準に切り出し、全表示は元データを維持し空白を追加します。

垂直を動画に変換すると画面が切れるですか？

全て表示を選択すると全てのシーンを表示し、残りの部分を暗い余白で埋めます。画面を埋めるを選択すると、比率が合わない端を中央基準で切り取ります。

自分の動画はどこで処理されますか？

動画はサーバーにアップロードせず、ブラウザで新しいフレームにエンコードされます。端末の性能とブラウザがサポートする保存形式に依存して、結果の画質と処理時間が異なります。

計算基準と参考資料

  • MDN — MediaRecorder

    ブラウザがサポートするコンテナ・コデックでキャプチャストリームを再コーデックします。サポートされる形式と出力品質はブラウザによって異なります。

  • MDN — Canvas captureStream

    現在の映像フレームをローカル Canvasに描き、ブラウザ内の録画用ストリームとしてキャプチャします。

  • WebKit — MediaRecorder API

    WebKit実装ではキャンバス・Web Audioストリームの録画と形式機能の検出を説明します。現在の機器のコーデックサポート状況は実行中の機能検出によって判断されます。
