ファイルのSHA-256・SHA-512を計算し、期待値と比較してください。大きなファイルも分割して読み、処理中にキャンセルできます。

使用方法と処理基準

ファイルバイトのSHA-2ハッシュを計算し、与えられた期待値と比較する作業です。

実際の例

UTF-8テキストabcのSHA-256はba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015adです。内容が同じであれば、ファイル名が異っても同じアルゴリズムのハッシュは同じです。

よくある質問

ハッシュが一致したら、ファイルが安全だという意味ですか？

入力した期待値と計算結果が同じことを意味します。期待値は信頼できる配布ルートで確認する必要があります。ハッシュの一致だけでは悪意のあるコードや配布者の身元を保証することはできません。

大きなファイルもサーバーにアップロードせずに確認できますか？

ファイルを最大2GBまでブラウザの作業スレッドで1MBずつ分割して読み込みます。全ファイルを一度にメモリに読み込むことはせず、キャンセルすると作業スレッドが終了します。計算時間は機器の性能とファイルサイズに依存します。
