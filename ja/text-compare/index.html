テキスト行の比較

2つのテキストの同じ行位置を比較して変更された行を探します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

行を挿入した後、後ろの行も変更されたように見えます。最小編集距離に基づくdiffではなく、位置別比較です。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

計算・変換基準

2つのテキストを同じ行番号のもので比較します。

同じ位置の行が異なる場合、前後の値を表示します

入力例

2番目の行 b → c の変更を表示

元の2行目がBで、修正版の2行目がCの場合、その位置を変更として表示します。同じ行は差異リストから除外されます。

使用方法

  1. 入力された例の値を使用するか、元の項目、比較するテキストの項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

一行を挿入したが、後ろのすべての行が変わったと表示されますか？

可能です。このツールは同じ位置を比較するため、挿入後の行番号がすべて下にシフトします。コード変更の最小差を探す専門的なdiffアルゴリズムとは異なります。
