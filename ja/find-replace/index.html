テキストの一括置換

検索文字列を指定して、すべての一致部分を新しい文字列に置き換えます。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

最大50,000文字。入力と結果はこのページのメモリで処理され、保存されません。改行はLFで統一されます。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

広告

広告設定

Adsterra 広告を許可すると、広告配信事業者が IP アドレスやブラウザー情報などを処理する場合があります。拒否してもツールはそのまま利用できます。

広告を許可するか選択してください。

個人情報の説明

計算・変換基準

大文字と小文字を区別し、同じ文字列をすべて置き換えます。

正規表現でない文字列全体の一致は大文字小文字を区別して置換する

入力例

りんごジュース → ぶどうジュース

「apple apple」からappleをpearに変えると「pear pear」になります。文字列全体で一致しない部分を置き換えます。

使用方法

  1. 入力された例の値を使用するか、元の項目、検索する文字列、変更する文字列の項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

点やマークを正規表現のように使用できますか？

申し上げます。点は実際の点、星印は実際の星印を探します。大文字と小文字を区別するため、Aを変更してもaは残り、空文字列は受け取りません。
