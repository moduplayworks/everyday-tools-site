動画サイズの縮小

映像の解像度とコーディングビットレートを調整して、より小さなファイルを作成し、実際の出力サイズを比較する作業

MP4・WebM・MOV・最大100MB・60秒。動画はこのブラウザで処理されます。

例えば映像で最初の実行を確認できます。

出力設定

予想サイズはエンコーディングビットレートに応じた推定値です。実際のサイズと画質は映像内容・ブラウザに依存します。

ブラウザで動画サイズの縮小を実行してください

公開例 動画は 640×360px、約 4秒です。基本のバランス設定は最大 720pを目標ですが、小さな元データは拡大しません。実際の圧縮率は動画の動き、ブラウザのエンコーダ、入力コーデックに依存し、元データよりもファイルサイズが大きくなることもあります。

新しい動画で再エンコードします

選択したファイルをサーバーにアップロードしません。新しいコンテナとコーデックで保存されるため、入力形式、画質、ファイルサイズが異なる可能性があります。予想サイズと元データを比較し、結果を直接再生して確認してください。

ビットレート設定は出力サイズの推定に使用する目標値です。ブラウザインコーダがこれを正確に守る、または常に小さなファイルを作成するとは限りません。

ファイルとデバイスの制限

最大100MB・60秒の動画で実行します。ブラウザがサポートする保存形式を検出し、MP4またはWebM形式で出力します。エンコーディング中はタブを開いておいてください。端末のメモリとコーデックのサポートに応じて、一部のファイルが処理されない可能性があります。

よくある質問

希望するファイルサイズを正確に指定できますか？

目標ファイルサイズを保証しません。画面の予測値は設定したビットレートで計算した参考値であり、実際のサイズは再生後に測定します。より小さくしたい場合は、低品質を再選択して比較してください。

圧縮すると画質が必ず改善されるか、ファイルが小さくなるか？

申し上げます。動画をブラウザで新たにエンコードすると結果が大きくなったり、元のものよりぼやけたりすることがあります。保存前に結果を再生し、元のものとサイズを比較してください。

動画がサーバーにアップロードされましたか？

いいえ。例ファイルのみ同じサイトからダウンロードし、ユーザーが選択した動画はブラウザメモリで処理されます。統計にはツールを成功裏に使用したという情報のみ送信され、ファイル名や動画内容は含まれません。

計算基準と参考資料

  • MDN — MediaRecorder

    ブラウザがサポートするコンテナ・コデックでキャプチャストリームを再コーデックします。サポートされる形式と出力品質はブラウザによって異なります。

  • MDN — Canvas captureStream

    現在の映像フレームをローカル Canvasに描き、ブラウザ内の録画用ストリームとしてキャプチャします。

  • MDN — AudioContext createMediaElementSource

    映像要素の音声をローカル Web Audio ストリームに接続し、映像と共に再コーディングします。

  • WebKit — MediaRecorder API

    WebKit実装ではキャンバス・Web Audioストリームの録画と形式機能の検出を説明します。現在の機器のコーデックサポート状況は実行中の機能検出によって判断されます。
