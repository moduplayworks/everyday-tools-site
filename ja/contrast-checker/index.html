計算・変換基準

文字色と背景色のWCAGテキスト対比度を確認します。

比較率 = (明るい相対照度+0.05)/(暗い相対照度+0.05)

入力例

黒と白 = 21:1

黒#000000と白#FFFFFFの比率は21:1です。通常のテキストAA基準では4.5:1、大きなテキストAA基準では3:1がそれぞれ別途表示されます。

使用方法

  1. 入力された例値を使用するか、文字HEX、背景HEX項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

比率が満たされていれば、ウェブアクセシビリティが全て満足されますか？

いいえです。不透明な単色の2つのテキスト比較のみを検査します。実際の背景画像、透明度、状態別色、キーボード操作などは別途確認が必要です。境界値は切り上げ前の比率で判定されます。

大きなテキストはどのようなサイズを意味しますか？

WCAGの大文字基準では、一般フォントは18pt以上、太字フォントは14pt以上です。約24 CSS pxまたは太字では18.67 CSS pxに相当し、実際のフォントと表示状態も確認してください。
