▦117 / ファイル・圧縮

ZIPを圧縮する

複数のファイルを一つの ZIP にまとめる。圧縮方式と ZIP 名前を指定し、元のファイルを保持したコピーを保存する。

▦118 / ファイル・圧縮

圧縮ファイルの解凍

ZIP内のファイルリストを確認し、必要なファイルのみをダウンロードしてください。ブラウザで解凍可能で、RAR・7z・パスワード付きZIPはサポートしていません。

▦119 / ファイル・圧縮

ファイルハッシュの確認

ファイルのSHA-256・SHA-512を計算し、期待値と比較してください。大きなファイルも分割して読み、処理中にキャンセルできます。

▦120 / ファイル・圧縮

ファイル名を一括変更

複数のファイルに連続する番号を付けたり、名前を置き換える。変更後の名前を事前に確認し、ZIP コピーとして保存する。
