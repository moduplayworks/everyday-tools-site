圧縮ファイルの解凍

ZIP内のファイルリストを確認し、必要なファイルのみをダウンロードしてください。ブラウザで解凍可能で、RAR・7z・パスワード付きZIPはサポートしていません。

ファイルハッシュの確認

ファイルのSHA-256・SHA-512を計算し、期待値と比較してください。大きなファイルも分割して読み、処理中にキャンセルできます。
