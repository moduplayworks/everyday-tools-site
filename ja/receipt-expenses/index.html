レシート写真から支出CSV

レシート写真から日付・合計の候補を読み取り、店舗・通貨を入力します。原本と照合・修正して支出CSVを保存します。写真は端末内で処理します。

領収書の写真と設定

最大5枚、1枚12MB・合計36MB。JPG・PNG・WEBP、一辺6,000px・1,200万画素以下。

写真はブラウザー内で処理します。初回認識時に同じサイトからOCR資料を取得します。日本語OCRは非対応です。再読み込みで写真と結果は消去されます。

公開サンプルを編集するか写真を選択してください。サンプルも確認後にCSV保存できます。

原本の確認と支出一覧

年が明記された日付と合計表示の金額のみを候補にします。複数候補は空欄です。店舗名・通貨は推測しません。日付・店舗名・金額・通貨を原本と照合してください。明細抽出・通貨換算・税務検証はありません。

KRW・JPYは整数、USD・EUR・GBPは小数第2位まで。桁区切りのカンマなしで入力してください。

新しい写真を選択しました。前の結果は保存できません。読み取りを実行してください。

数式のように始まる店舗名には先頭にアポストロフィを付けるため、出力文字列が変わる場合があります。すべての表計算アプリで同じ保護を保証しません。

よくある質問

写真の金額は自動で確定しますか？

いいえ。OCRは合計や日付を誤読する場合があります。小計・税・釣銭と最終支払額を区別し、原本を確認してください。不明な候補は空欄または修正し、未確認の行は出力できません。

日本語のレシートも認識しますか？

写真認識は現在、韓国語・英語のみです。日本語画面の提供は日本語OCR対応を意味しません。ぼけやしわで誤読する場合があります。手書き・品目の自動分類・税務申告には対応しません。

写真や支出情報はどこに保存されますか？

選択した写真と修正内容は現在のページのメモリ内で処理します。ファイル名・写真・OCR原文を分析やURLに送信せず、再読み込みで消去します。ダウンロードしたCSVは端末に残ります。

計算基準と参考資料

  • Tesseract.js — ブラウザOCR API Workerの設定

    ブラウザのWorkerで画像を認識し、worker・core・言語ファイルのパスを同じサイトに固定するAPI。認識結果の正確性は保証されません。

  • OWASP — CSV式の挿入

    スプレッドシートが式で解釈可能なフィールドについて、Excelで再保存する際の保護処理が異なる可能性があることを説明します。このツールは保護用タブを付け、後続プログラムで値が変更される可能性があることを通知します。
