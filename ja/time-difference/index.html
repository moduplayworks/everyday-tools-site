日付・時間 52

時間差計算機

開始・終了時間の間の時間を計算し、零時を超える場合を処理します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

暦とシーズンタイムがなく、24時間の時間を計算します。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

広告

広告設定

Adsterra 広告を許可すると、広告配信事業者が IP アドレスやブラウザー情報などを処理する場合があります。拒否してもツールはそのまま利用できます。

広告を許可するか選択してください。

個人情報の説明

計算・変換基準

開始時刻と終了時刻の間の経過分を計算します。

終了時刻－開始時刻、次の日は24時間加算

入力例

23:00から次の日01:30まで = 2時間30分

23:30から01:15までの間は、次の日を選択すると1時間45分になります。同じ日を選択すると終了が早くなるため、入力を修正するよう案内されます。

使用方法

  1. 入力された例の値を使用するか、開始時刻、終了時刻、終了日の項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

開始と終了が同じなら0時間か24時間ですか？

同じ日付を選択すると0時間、次の日付を選択すると24時間です。日付とシーズン制は計算せず、固定の24時間の時計基準です。
