よくある質問

どの貼り付け形式をサポートしていますか？

タブで区切られたスプレッドシートのテーブル、またはカンマで区切られたCSVを選択します。ダブルクエーサーで囲まれたセルの区切り文字や改行、二度書かれたクエーサーを読みます。最初の行をヘッダーとして設定するか選択でき、不足しているセルは空欄として補完します。ヘッダーを含む101行・20列、セル2,000文字、入力100,000文字までの対応が可能です。

携帯電話でもセルを編集できますか？

行と列を選択した後、選択したセルを編集するため、広い入力テーブルを横にスライドする必要はありません。前回・次回行の移動、行・列の追加と削除、列ごとの左・中央・右の並べ替えが提供されます。最終編集は最大10段階まで戻ることができます。貼り付け内容が変更された場合は再度読み込む必要があります。

HTML・行の改行・Markdown記号はどのようになっていますか？

セルの HTML Markdown 記号はテキストとして表示されます。セル内の行の改行は <br> で出力され、表示の有無は使用するサービスの HTML 許可設定に依存します。ツール内の表のプレビューは元のセルの行の改行を表示します。出力は Markdown ファイルであり、スプレッドシートの式は実行されません。
