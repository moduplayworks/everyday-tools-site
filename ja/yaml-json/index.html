使用方法と処理基準

YAML 1.2設定とJSONドキュメントのタイプを確認し、双方向で変換するツールです。

実際の例

YAML name: ツール、active: true、id: 9007199254740993を変換すると、nameは文字列、activeはブール値、idは切り捨てられない数値としてJSONに表れます。yesはYAML 1.2では文字列です。JSONからYAMLに変換する際は、キーと文字列に二重引用符を付けてyes、nullなどの文字のタイプが変わらないようにします。

よくある質問

どのYAMLタイプをサポートしていますか？

YAML 1.2 coreは文字列・数値・ブール値・null・配列・文字列キーオブジェクトをサポートします。数値・複合オブジェクトキー、.inf・.nan、ユーザー定義タグ・オブジェクト生成タグ、マージキー<<、YAML 1.1および複数のドキュメントストリームはエラーとして通知されます。重複するキーも静かに上書きされません。

注釈・アンカーと大きな数字は保持されますか？

JSONには注釈やアンカー表現がないため、削除するか独立した値として展開し、処理指示を提供します。循環別名は拒否され、拡張は50回・全体的に10,000個の値まで制限されます。大きな整数と小数は元の数値精度を保持しますが、改行・ダブルクオーテーション・16進数表記は変更されることがあります。

文書のサイズ制限と保存方法は何ですか？

入力は100,000文字以下、変換の深さは80以下、出力は1,000,000文字以下です。別のWorkerの実行は3秒、モジュールの準備は10秒まで待ちます。エラーやキャンセル時は以前の正常な結果を保持します。結果を確認した後、JSON・YAMLファイルに保存し、入力はブラウザのストレージに保存されません。
