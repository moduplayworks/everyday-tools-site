計算・変換基準

オフセット・ぼやけ・割れによりbox-shadowコードを作成。

box-shadow: x y blur spread color

入力例

0px 4px 12px 0px #000000

横方向のずれ0、縦方向のずれ4、ぼかし8、広がり0にすると、下方向にずれたぼかし影になります。単位はすべてpxです。

使用方法

  1. 入力された例値を使用するか、横移動px、縦移動px、ぼかしpx、拡大px、HEX色項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

明るさと暗さの違いは何ですか？

明るさは影の輪郭を増減させ、暗さは境界を滑らかにします。負の明るさは可能ですが、暗さの半径は0以上でなければなりません。このツールは単一の外部影を生成します。
