IPサブネット計算機（IPv4・IPv6）

IPv4・IPv6アドレスとCIDRプリフィックスからネットワーク、アドレス範囲、アドレス数を計算します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

整数 · 最小 0 · 最大 128

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

IPv4では/0〜/30の一般的なホスト数からネットワークアドレスとブロードキャストアドレスを除きます。/31・/32はRFC 3021のポイントツーポイント・単一アドレスの前提を使います。IPv6では正規化したネットワーク、CIDR全範囲、アドレス数を計算し、使用可能ホスト数やブロードキャストアドレスは示しません。どちらの系列も、プライベート・予約済み・特殊用途アドレスの分類、ルーティング可否、実機の動作は判定しません。%eth0などのIPv6ゾーン識別子は入力できません。

計算・変換基準

IPv4またはIPv6アドレスとCIDRプリフィックスを入力して、属するネットワークと範囲を計算します。

ネットワーク = アドレス AND プリフィックスマスク；最終アドレス = ネットワーク OR ホストマスク；アドレス数 = 2^(アドレスのビット数 − プリフィックス長)

入力例

192.168.1.37/24 → ネットワーク 192.168.1.0・一般的なホスト数 254；2001:db8:1234:5678::42/64 → ネットワーク 2001:db8:1234:5678::・範囲内のアドレス数 18,446,744,073,709,551,616

IPv4 192.168.1.37/24のネットワークは192.168.1.0、範囲は192.168.1.0〜192.168.1.255で、一般的なホスト数は254です。IPv6 2001:db8:1234:5678::42/64の範囲は2001:db8:1234:5678::〜2001:db8:1234:5678:ffff:ffff:ffff:ffffで、アドレス数は2^64、つまり18,446,744,073,709,551,616です。IPv6の結果は使用可能ホスト数ではなく、数学的なCIDRアドレス範囲です。

使用方法

  1. 入力例を使うか、IPアドレス（IPv4またはIPv6）とCIDRプリフィックス長（IPv4 /0〜/32・IPv6 /0〜/128）を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

/24プリフィックスは何を意味するか？

IPv4 32ビットの前半24ビットはネットワークプリフィックスを意味します。残りの8ビットからネットワークとブロードキャストアドレスを除いた254個を一般的なホスト数として表示します。

/31と/32のホスト数はどのように計算しますか？

/31はRFC 3021に基づくポイントツーポイントリンクという仮定の下で2つのアドレスをホストとして扱います。/32は単一のIPv4ホストパスで1つのアドレスを扱います。ネットワーク機器の設定は該当する機器のドキュメントを確認してください。

個別IPか認定IPか教えていただけますか？

この計算機は入力した値のCIDR範囲のみを計算します。私設・予約・特殊用途のアドレスか、実際のネットワークに割り当て可能かを判断しません。

IPv6にはブロードキャストアドレスや使用可能なホスト数がありますか？

IPv6にブロードキャストアドレスはありません。結果のアドレス数はプリフィックスが定めるCIDR全範囲です。各アドレスを実際のインターフェースに割り当てられるか、ルーティングできるかは判定しません。

IPv6アドレスの%eth0ゾーン識別子も計算しますか？

いいえ。ゾーン識別子はリンクローカルアドレスのネットワークインターフェースの文脈を示すもので、アドレスビットの計算には含めません。%eth0のような接尾辞を付けずにIPv6アドレスを入力してください。

計算基準と参考資料

  • RFC 4632 — Classless Inter-domain Routing (CIDR)

    IPv4プリフィックスの長さとCIDRアドレス範囲を説明します。計算機は入力アドレスの32ビットマスク・ネットワーク・最後のアドレスを計算します。

  • RFC 3021 — 31-Bit Prefixes on IPv4 Point-to-Point Links

    リンクのピークポイントから /31の2つのアドレスをホストアドレスとして解釈し、指向放送を使用しない条件を説明します。

  • RFC 4291 — IP Version 6 Addressing Architecture

    IPv6アドレスが128ビットであり、アドレスプリフィックスの長さが0〜128ビットで、ブロードキャストアドレスがないことを示します。範囲計算は割り当てやルーティングの適合性を判定しません。

  • RFC 5952 — A Recommendation for IPv6 Address Text Representation

    IPv6アドレスは小文字の16進数で表記し、省略可能な先行0を除去して、最長の0列を圧縮します。同じ長さの列がある場合は先の列を使います。パーサーは有効なIPv4埋め込み表記も受け付けます。
