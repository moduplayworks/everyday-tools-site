比例式計算機

A:B = C:Xの比例式で、Xを計算します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

小数結果は有効数字12桁まで表示されます。単位は入力値同士で統一してください。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

広告

広告設定

Adsterra 広告を許可すると、広告配信事業者が IP アドレスやブラウザー情報などを処理する場合があります。拒否してもツールはそのまま利用できます。

広告を許可するか選択してください。

個人情報の説明

計算・変換基準

比例式 A:B=C:Xで不明な値を求める。

X = B × C ÷ A

入力例

2:3 = 8:12

2:3=10:Xの場合、X=3×10÷2=15です。同じ位置に同じ種類の量を置くことで比例式が保たれます。

使用方法

  1. 入力された例値を使用するか、A, B, C項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

材料の量を増やす際に比例式を使用できますか？

2人分に300gの材料を5人分に増やすと、A=2, B=300, C=5に入れ750gが得られます。調理時間まで同じ比率で増えるという意味ではありません。
