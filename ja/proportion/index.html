計算・変換基準
比例式 A:B=C:Xで不明な値を求める。
X = B × C ÷ A
入力例
2:3 = 8:12
2:3=10:Xの場合、X=3×10÷2=15です。同じ位置に同じ種類の量を置くことで比例式が保たれます。
使用方法
  1. 入力された例値を使用するか、A, B, C項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問
材料の量を増やす際に比例式を使用できますか？
2人分に300gの材料を5人分に増やすと、A=2, B=300, C=5に入れ750gが得られます。調理時間まで同じ比率で増えるという意味ではありません。
Aに0を入力できないのはなぜですか？
X = B × C ÷ Aで計算するため、Aが0だと割り算が定義できません。Aには0以外の値を入力し、対応する量を同じ位置に置いてください。
初期例のXはどのように計算しますか？
初期値A=2、B=3、C=8では、X=3×8÷2=12です。最初の量が2から8へ4倍になるため、対応する3も4倍の12になります。
