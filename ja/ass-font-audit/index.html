ASSフォントの確認方法

V4+スタイルのFontnameと台詞の\fn・\rタグを読みます。文字部分で使うフォントと未使用スタイルを区別し、描画命令部分はフォント使用に数えません。

選択したTTF・OTFのfamily nameとtypographic family nameを読み、大文字・小文字を区別せず照合します。インストール済み検索、フォントのダウンロード、ASS添付の抽出は行いません。

公開サンプルではExample Sans、Example Mono、Example Serifの3書体を使います。ファイル未選択でも使用一覧を確認でき、選択後はファイル内のfamily nameと照合します。

UTF-8のV4+ ASS、スタイル500件、使用フォント500件まで対応します。未定義スタイルや不正なフォントタグはエラーになります。変形アニメーション内のフォント変更は非対応です。ASS全体の構文検査や再生機能ではありません。

よくある質問

一致しないフォントはパソコンにもないのですか？

いいえ。選択したTTF・OTF内のフォント名と一致しなかったという意味です。インストール済みフォントは検索せず、ファイル名から書体を判定しません。

名前が一致すれば動画でも正しく表示されますか？

保証できません。文字の対応範囲、太字・斜体、プレイヤーの代替フォントや描画差は確認しません。実際の再生結果も確認してください。

対応するASSとフォントファイルは？

UTF-8のV4+ ASSのスタイル・台詞とfn・rタグを調べます。通常のTTF・OTF名前テーブルに対応し、TTC・WOFF、添付フォント抽出、インストール済み検索は非対応です。

計算基準と参考資料

  • Aegisub — ASSフォント・スタイルタグ

    fnによるフォント変更、rによるスタイル初期化、描画モードの公式説明です。本ツールはフォント依存関係を調べるもので、ASS再生は実装しません。

  • Microsoft — OpenType名前テーブル

    照合に使うfamily name ID 1とtypographic family name ID 16の定義です。名前の一致は文字対応や描画成功を意味しません。
