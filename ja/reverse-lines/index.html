行の順序を逆にする

最後の行から最初の行までリストの順序を逆にします。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

最大50,000文字。入力と結果はこのページのメモリで処理され、保存されません。改行はLFで統一されます。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

計算・変換基準

リストの最後の行から逆順に配置します。

配列の順序のみ逆に変更します。

入力例

1 / 2 / 3 → 3 / 2 / 1

第一、第二、第三行を逆転すると、第三、第二、第一の順序になります。行内の文字の順序は変わりません。

使用方法

  1. 入力された例の値を使用するか、リストの項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

降順の並べ替えと行の逆順は同じですか？

申し訳ありません。反転処理では現在の位置のみを反転し、文字や数字のサイズを比較することはありません。元の空行も一つの行にまとめられます。
