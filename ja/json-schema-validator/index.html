JSON Schema検証ツール

Draft 2020-12スキーマの型・必須項目・範囲・パターン規則にJSONが従うか、ブラウザーで確認できます。値は送信せず、外部参照も取得しません。

JSON Schema検証ツールの入力

各入力は100,000文字・深さ100・値20,000個まで · 外部$refはダウンロードしません。formatは参考情報で、自動検証しません。

スキーマとJSONはブラウザーワーカー内で処理し、保存・送信しません。レポートにJSONの値やオブジェクトキーは含まれません。

検証結果

例が入力されています。すぐに検証するか内容を編集してください。

使用例と処理基準

例のスキーマはnameを必須の空でない文字列、ageを0以上の整数として要求します。{"name":"Mina","age":28}は両方の規則に適合します。ageを負数や文字列に変えると、最初に失敗したキーワードを表示します。レポートには入力値やオブジェクトキーを露出する可能性があるJSONパスを含めません。

よくある質問

どのJSON Schemaバージョンに対応していますか？

JSON Schema Draft 2020-12のCore・Validationキーワードを使用します。$refと$dynamicRefは入力スキーマ内の#で始まるローカル参照のみを解決し、URLにはアクセスしません。他のドラフトとカスタム語彙には対応していません。

format: emailやdateも検証しますか？

いいえ。Draft 2020-12ではformatは既定でアノテーションです。このページはformatの検証を無効にしているため、メールの到達可能性や業務上の日付の妥当性は確認しません。

入力・数値・実行時間の制限は何ですか？

スキーマとデータはそれぞれ100,000文字、深さ100、値20,000個までです。重複キーとJavaScriptの安全な範囲を超える整数は拒否されます。JSONの数値はJavaScriptの浮動小数点として処理し、検証はワーカー内で2秒後に中断します。

エラーレポートに入力値は含まれますか？

入力値・実データ・オブジェクトキー・JSONパスはレポートや分析イベントに含めません。最初のエラーのスキーマキーワードのみ表示します。検証はブラウザー内で処理し、保存・送信しません。

計算基準と参考資料

  • JSON Schema — Draft 2020-12仕様

    Draft 2020-12 Core・Validation語彙の参考資料です。このツールはformatをアノテーションとして扱い、入力スキーマ内のローカル参照のみを解決します。

  • Ajv — JSON Schemaのセキュリティ上の考慮事項

    ユーザースキーマのコンパイルやpattern・uniqueItemsによる実行時間のリスクを説明しています。このツールは入力上限、単一エラー、専用ワーカー、実行時間制限で処理を制限します。
