順列・組み合わせ計算機

異なるn個の中からr個を選ぶ順列と組み合わせを計算します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

整数 · 最低 0 · 最高 200

整数 · 最低 0 · 最高 200

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

重複選択は許可されません。BigIntの整数演算で計算します。

計算・変換基準

区別する順列と区別しない組み合わせの比較。

nPr=n!/(n−r)!, nCr=nPr/r!

入力例

5個の中から2個：配列20、組み合わせ10

5人から2人を選ぶと組み合わせは10通りです。2人に異なる役割を与えると順序が重要になり、配列は20通りになります。

使用方法

  1. 入力された例の値を使用するか、全体的なn、選択されたrの項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

同じ対象を複数回選択した重複組み合わせも計算されますか？

計算しません。このツールは、n種類の異なる対象から重複なくr個を選ぶもので、rはn以下でなければなりません。0個を選ぶ場合は1つだけ計算します。
