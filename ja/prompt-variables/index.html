プロンプト変数の置換

{{name}}変数とJSON文字列値を使ってプロンプトを埋め、値のない変数と未使用キーを確認できます。

入力

編集可能な英語の構文例です。

結果

編集可能な例ですぐに実行できます。

対応構文と処理方法

再利用するプロンプトの{{name}}に指定した文字列を一度だけ代入し、不足値と未使用キーを確認します。完成結果では、一部のメール・トークン・キー形式を任意でローカル検出し、伏せたコピー用下書きを作成できます。ただし、個人情報や秘密情報を完全に検出するものではありません。AIモデルへ内容は送信しません。

変数名は空白なしで英字・下線で始まり、英字・数字・下線の64文字以下です。値は同じ大文字・小文字の名前をキーとするJSON文字列です。同じ名前は同じ値に置換します。挿入した値の{{other}}、$&、HTMLは再解釈せずそのまま残します。

入力例

公開例ではtoneにshort、topicにa daily walking planを入れ、Write a short summary about a daily walking plan.を生成します。topicを削除するとプレビューに{{topic}}が残り、不足一覧に表示します。すべての値がある場合だけ完成結果として扱います。

サポート範囲と限界

上限はテンプレート20,000文字・記法500個、JSON50,000文字・キー100個・各値20,000文字、結果100,000文字です。重複キーとプロトタイプ予約キーは対応しません。条件・繰り返し・関数・入れ子パス・空白入り変数記法・二重括弧のエスケープには対応しません。コード評価やAIリクエストは行いません。

入力と結果はブラウザ内でのみ処理します。保存やURL・統計への送信は行わず、ページ移動や更新で公開例に戻ります。

よくある質問

JSON値に数値やオブジェクトを使えますか？

値は文字列のみ対応します。数値をテキストにする場合は二重引用符で囲んでください。オブジェクト・配列は自動変換せず、意図しない代入を防ぎます。

不足値や未使用キーはどうなりますか？

値がなければ元の{{name}}を残し、未完成と案内します。未使用キーは一覧に表示しますが結果へ挿入しません。元のテンプレートとJSONは自動変更しません。

他のテンプレートエンジンやAIサービスと同じ構文ですか？

このツールが明記する{{name}}の一度の置換だけを適用します。Jinja・Mustacheの全構文や特定AIサービスの変数規則は実装しません。使用先の規則も確認してください。

完成したプロンプトの機密情報をすべて検出できますか？

いいえ。この限定的なブラウザ内パターン検査は、一部のメール形式、選択した秘密キー名の後の値、Bearerトークン、JWT形式、PEM秘密鍵ブロックのみを確認します。独自のキー、電話番号、国民識別番号などを見落とし、通常の文章を検出することもあります。一致がなくても安全とは限らないため、原文とコピー用下書きを確認してください。

計算基準と参考資料

  • IETF RFC 8259 — JSONデータ形式

    JSON文字列・オブジェクト・エスケープ表記の基準です。変数名と一度の置換規則はこのツールで別途定義します。

  • IETF RFC 5322 — Internet Message Format

    メールアドレス構文の標準資料です。このツールの単純なASCIIパターンはRFC 5322アドレスを完全に解析せず、有効性も証明しません。

  • IETF RFC 6750 — OAuth 2.0 Bearer Token Usage

    Bearer認証方式とトークン転送の標準資料です。このツールはトークン形式の文字列を検出するだけで、有効性や権限を確認しません。

  • IETF RFC 7519 — JSON Web Token (JWT)

    JWT形式の標準資料です。このツールは一部のcompact形式のみを検出し、署名・クレーム・有効期限を検証しません。

  • IETF RFC 7468 — Textual Encodings of PKIX, PKCS, and CMS Structures

    PEMテキストブロック表記の標準資料です。このツールは一部の秘密鍵ブロック表示のみを検出し、鍵の構文や使用可否を検証しません。
