対応構文と処理方法

Claude Desktopのローカルstdio設定の主要なJSON形式、またはMCP 2026-07-28リクエストの必須envelopeメタデータをブラウザー内で確認します。コマンド実行、パッケージのインストール、サーバー接続、秘密値の送信は行いません。

Claude Desktop設定モードでは、mcpServers配下の各サーバーのcommand・args・env形式とWindowsパスのエスケープを確認します。MCP 2026-07-28リクエストモードでは、JSON-RPC 2.0のリクエスト項目、params._meta内のプロトコルバージョンとclientCapabilities形式を確認し、廃止された初期化ハンドシェイクのメソッドを表示します。公開例は現行改訂版のtools/listリクエストです。

入力例

Claude Desktop設定モードには、ローカルサーバー1個、args文字列1個、env文字列値1個の公開例があります。MCP 2026-07-28リクエストモードに切り替えると、公式仕様に沿ったtools/list例が表示され、params._meta内のprotocolVersionとclientCapabilitiesを確認します。例のリクエストはサーバーへ送信しません。

サポート範囲と限界

JSONは50,000文字以下です。設定モードの上限はサーバー1〜50個、command 2,048文字、args 200個・各2,048文字、env 100個・値8,192文字です。リクエストモードではJSON-RPC envelopeと現行改訂版の必須メタデータの一部だけを確認し、メソッド別の全スキーマは検査しません。HTTP MCP-Protocol-Versionヘッダーと本文の一致、接続・サーバー応答、認証、コマンド実行、安全性は確認しません。入力値を結果に再表示しません。

入力と結果はブラウザ内でのみ処理します。保存やURL・統計への送信は行わず、ページ移動や更新で公開例に戻ります。

よくある質問

VS CodeやCursor設定も検査しますか？

Claude Desktop設定モードは、mcpServersの基本的なローカルstdio形式だけに対応します。リクエストモードではMCP 2026-07-28の共通envelopeだけを確認し、他クライアントのローカル設定ファイル形式は検査しません。

MCP 2026リクエスト検査では何を確認しますか？

JSON-RPC 2.0の基本リクエスト形式とparams._meta内の現行protocolVersion、clientCapabilitiesオブジェクトを確認します。initializeとnotifications/initializedは旧ハンドシェイク方式として表示します。メソッド別の全スキーマや、サーバーがすべてのバージョンに対応するかは確認しません。

必須項目が合っていれば接続も成功しますか？

いいえ。貼り付けた本文の静的なリクエスト形式だけを確認します。HTTPバージョンヘッダーの一致、通信、認証、メソッド別スキーマ、サーバー応答は確認せず、設定モードでもコマンドは実行しません。

設定やリクエストの秘密値は結果に表示されますか？

結果に入力したサーバー名・コマンド・環境変数の値・リクエストID・メソッド・メタデータを再表示しません。処理はブラウザー内だけで行い、入力を保存したり統計やURLに送信したりしません。
