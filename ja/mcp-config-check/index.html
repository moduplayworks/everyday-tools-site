MCP設定JSONチェック

Claude Desktopのローカルstdio設定のJSON構文、command・args・env構造、Windowsパスのエスケープを実行せずに確認します。

入力

実行しない架空の設定例です。

結果

編集可能な例ですぐに実行できます。

対応構文と処理方法

Claude Desktop設定のJSON構文とローカルstdioサーバーの主な値の型を確認するツールです。コマンド実行、パッケージのインストール、サーバー接続、秘密値の送信は行いません。

mcpServers内の各サーバーで、commandは空でない文字列、任意のargsは文字列配列、任意のenvは文字列値のオブジェクトかを検査します。重複JSONキーと予約されたプロトタイプキーは拒否します。JSON内のWindowsパスではバックスラッシュを二重にします。commandの制御文字はエラー、argsのパスらしい制御文字は原文確認の案内に留めます。

入力例

公開例にはローカルサーバー1個、args文字列1個、env文字列値1個があります。結果には件数と対応範囲を表示し、nodeやserver.jsは実行しません。env値を数値に変えると文字列が必要というエラーになります。

サポート範囲と限界

JSON50,000文字、サーバー1〜50個まで処理します。各サーバーはcommand2,048文字、args200項目・各2,048文字、env100項目・各値8,192文字までです。command・args・env以外のサーバーフィールドは対象外と案内します。他のトップレベル設定は件数のみ表示し検査しません。VS Code・Cursor・リモートHTTP設定、ファイルの存在、コマンドの安全性、権限、通信成功は確認しません。

入力と結果はブラウザ内でのみ処理します。保存やURL・統計への送信は行わず、ページ移動や更新で公開例に戻ります。

よくある質問

VS CodeやCursor設定も検査しますか？

現在はClaude DesktopのmcpServersローカルstdio基本形のみ対応します。他のクライアントのserversキーやリモートURLは、一般的な誤りと断定せず対象外と案内します。

通過すれば安全に接続できますか？

いいえ。文字列や配列などの静的な型のみ確認します。パス・実行権限・依存関係・パッケージの信頼性・サーバー応答は別途確認してください。このツールは設定をインストール・実行しません。

APIキーやコマンド内容が結果に残りますか？

結果にはサーバー名・コマンド・引数・環境変数値の代わりに件数と一般案内だけを表示します。入力はブラウザ内で処理し保存しません。初期化・更新・ページ移動で公開例に戻ります。
