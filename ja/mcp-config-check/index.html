対応構文と処理方法

Claude Desktopのローカル設定、MCP 2026リクエストenvelope、MCP Appsのツール宣言とUIリソースメタデータをブラウザーで静的に確認します。コマンドやHTMLを実行せず、MCPサーバーにも接続しません。入力値を結果や統計に送信しません。

Claude Desktop設定モードでは、mcpServers配下のサーバーのcommand・args・env形式とWindowsパスのエスケープを確認します。MCP 2026-07-28リクエストモードでは、JSON-RPCリクエストenvelopeとparams._meta内の現在のプロトコルバージョンおよびclientCapabilitiesを確認します。MCP Appsツールモードではtools/listのツールオブジェクト1件から_meta.ui.resourceUriとvisibilityを確認し、UIリソースモードではresources/readのcontents項目1件からui:// URI・HTML MIME形式・テキストまたはbase64コンテンツ・任意のCSPと権限を確認します。

入力例

MCP Appsツールモードには、_meta.ui.resourceUriがui://リソースを指す例があります。UIリソースモードでは、同じURI、text/html;profile=mcp-app形式、CSPと権限の例を含むresources/readのcontents項目が表示されます。2つのJSONは個別に確認し、実際のサーバーでURIがつながるかは確認しません。

サポート範囲と限界

JSONは50,000文字以下です。設定モードはサーバー1〜50件、command 2,048文字、argsは最大200件で各2,048文字、envは最大100件で各値8,192文字までです。リクエストモードはenvelopeの一部のみ確認します。Appsモードではツールとリソースのcontents項目を別々に確認するため、URIの一致やサーバー上のリソースの存在は確認しません。HTML5文法、HTMLの実行、ホストごとのCSP許可、接続、メソッド別の完全なスキーマ、認証も確認しません。コマンドは実行せず、入力値は結果に再表示しません。

入力と結果はブラウザ内でのみ処理します。保存やURL・統計への送信は行わず、ページ移動や更新で公開例に戻ります。

よくある質問

MCP AppsツールモードにはどのJSONを貼り付けますか？

tools/list結果のtools配列から、確認するツールオブジェクトを1件貼り付けます。_meta.ui.resourceUriはMCP Apps UIリソースを指すui:// URIにしてください。

UIリソースモードにはどのJSONを貼り付けますか？

resources/read結果のcontents配列から、UIリソース項目を1件貼り付けます。URIはui://で始まり、mimeTypeはtext/html;profile=mcp-appにしてください。HTMLは実行しません。

ツールとリソースのURIが実際につながるか確認しますか？

いいえ。2つのJSONは個別に確認するため、resourceUriが実際のサーバーに存在するか、ツールとリソースのURIが一致するかは試験しません。サーバーやホストには接続しません。

CSPやブラウザー権限の安全性も確認しますか？

現在のMCP Apps仕様に基づき、CSPの文字列配列、権限名とオブジェクト形式のみ確認します。ドメインの安全性、HTMLコード、ホストごとのCSP適用、ユーザーの権限承認は確認しません。

貼り付けた設定やHTMLはどこへ送信されますか？

送信しません。JSON検査はブラウザー内で実行します。サーバー名・URI・HTML・CSP値などの入力内容を結果に再表示したり、統計やURLに含めたりしません。

計算基準と参考資料

  • MCP公式文書 — Claude Desktopのローカルサーバー接続

    Claude DesktopのmcpServers・command・args・envとWindows JSONパス表記の参照資料です。このツールは実行・インストール・接続を行いません。

  • Model Context Protocol公式仕様 — 2026-07-28メッセージとバージョンメタデータ

    現行改訂版のJSON-RPCメッセージ、リクエストごとのprotocolVersion・clientCapabilitiesメタデータ、initializeハンドシェイクの廃止を確認する資料です。このツールは必須envelopeの一部だけを静的に検査します。

  • MCP Apps公式仕様 — 2026-01-26

    MCP Appsのui://リソースURIとtext/html;profile=mcp-app MIME形式、ツールの_meta.ui.resourceUri・visibility、リソースのCSP・権限メタデータの配置と対応フィールドの参考資料です。このツールはサーバー接続やHTML実行を検査しません。
