    よくある質問

    似た写真や文書も見つかりますか？

    いいえ。ファイル全体のバイトが同じ場合だけ一致します。見た目が同じ写真でもメタデータ・圧縮・サイズが異なれば別物です。名前・日付・見た目の類似性では判定しません。

    重複ファイルは自動削除されますか？

    原本は読み取りのみで、削除や変更をしません。追加コピーの容量は選択項目に基づく算術的な推定で、別々の実ファイルや回収可能なディスク容量を保証しません。

    どのファイルとサイズを検査できますか？

    直接選択した最大 100 ファイル、各 50MiB、合計 250MiB に対応し、空ファイルも検査します。フォルダーやドライブ全体は探索しません。保存したレポートにはファイル名が含まれるため、共有前に確認してください。

    計算基準と参考資料

    • noble-hashes — Incremental hashing

      ファイルを分割して読み、SHA-256 を逐次更新する実装の根拠です。同じハッシュの候補もバイト比較で再確認します。

    • MDN — SubtleCrypto.digest

      digest API がストリーミング入力に対応しないことを説明しています。このツールは全ファイルのバッファーではなく逐次ハッシュと分割比較を使用します。
