CSV→JSON 変換器

最初の行のヘッダーをキーとしてCSV JSONオブジェクトの配列に変換します。

入力

例の値が入力されています。直接確認するか、値を変更してみてください。

Ctrl または ⌘ + Enter で実行

入力はブラウザで処理されます。再読み込みすると例の値に戻ります。

結果

入力された例値を直接使用して結果を確認するか、値を変更してみてください。

ヘッダーは重複したり空になったりすることはできません。各行の列数は同じでなければなりません。カンマ区切りのCSVをサポートします。

結果を共有

ツールリンクと結果テキストを一緒に共有します。結果にはURLを入れません。以下の内容を確認して共有してください。

計算・変換基準

ヘッダーがあるカンマ区切りのCSV JSON配列に変換してください。

カンマ・ダブルクオーテーション・ダブルクオーテーション内の行の区切りをパースし、値は文字列として保持します

入力例

name,score / A,1 → [{"name":"A","score":"1"}]

name,scoreヘッダーの下にA,10を入れると、nameはA、scoreは文字列10のオブジェクトになります。カッコで囲まれたフィールド内のカンマと改行は1つの値として処理されます。

使用方法

  1. 入力された例値を使用するか、CSV項目を変更してください。
  2. 結果を確認を押して下の結果を確認してください。
  3. 必要なら、結果をコピーして取り出すことができます。

よくある質問

郵便番号00123の先頭の0が消えますか？

値を文字列として保持するため、00123が保持されます。数字や日付は自動で推測されません。ヘッダーが重複している、空である、または行ごとの列数が異なる場合はエラーを通知します。

計算基準と参考資料

  • RFC 8259 — JSON

    JSON構文と相互運用時の数値精度の考慮事項

  • RFC 4180 — CSV

    カンマ区切り、フィールドのダブルクオーテーションと行の区切り規則。スプレッドシート式の保護はこのツールの追加処理です。
