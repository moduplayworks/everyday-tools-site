PDF 페이지 번호 넣기

PDF에 시작 번호·위치를 정해 쪽번호를 넣으세요. 표지 등 제외 페이지를 지정하고 새 사본을 저장합니다.

PDF 페이지 번호 넣기 입력

PDF 1개 · 50MB·200페이지 이하

제외 페이지·글자 설정

남은 선택 페이지에 문서 순서대로 연속 번호를 넣습니다. 기존 본문 위에 검정 번호를 추가하며 여백을 새로 만들지는 않습니다.

PDF 지원 범위

암호화·양식·서명 필드가 있는 PDF는 지원하지 않습니다. 전자서명 효력·첨부·책갈피 등 부가정보 보존은 보장하지 않습니다. 저장한 사본의 번호와 본문을 확인하세요.

파일은 브라우저에서 처리합니다. 원본은 유지되며 새로고침하면 작업이 초기화됩니다.

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

원본 PDF의 선택 페이지에 연속 쪽번호를 실제 텍스트로 추가하는 작업입니다.

실제 예시

5페이지 문서에서 전체 페이지를 선택하고 1을 제외한 뒤 시작 번호 1을 넣으면 원본 2~5쪽에 1~4가 들어갑니다. 마지막 번호 표시를 켜면 1 / 4부터 4 / 4까지 표시합니다.

자주 묻는 질문

쪽번호 제외 페이지와 시작 숫자는 어떻게 적용되나요?

페이지 선택에서 지정한 페이지 중 제외 페이지를 빼고 문서 순서대로 번호를 넣습니다. 제외한 페이지는 PDF에 그대로 남습니다. 숫자는 선택한 시작 번호부터 연속으로 증가합니다.

쪽번호가 본문을 가리거나 회전한 페이지에서 어긋나지 않나요?

번호는 보이는 페이지 가장자리에서 18pt 안쪽의 선택한 위치에 검정색으로 추가됩니다. 기존 여백을 늘리지 않으므로 본문과 겹칠 수 있습니다. 90도 단위 회전과 자르기 영역을 반영하며 저장한 사본의 모든 해당 페이지를 확인하세요.
