유니코드 이스케이프 변환

문자열을 UTF-16 \uXXXX 표현으로 바꾸거나 복원합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

이모지는 서로게이트 쌍 두 개로 표현됩니다. 디코딩은 \uXXXX 형태의 연속 입력만 받습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

문자를 UTF-16 이스케이프 문자열로 바꾸기.

UTF-16 코드 단위마다 4자리 16진수 이스케이프

입력 예시

가 → \uac00

한글 가는 UTF-16 코드 단위 AC00으로 표현됩니다. 기본 다국어 평면 밖의 문자는 하나의 글자여도 두 코드 단위로 표현될 수 있습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 입력, 방향 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

이모지 하나가 두 개의 이스케이프로 나오는 이유는 무엇인가요?

UTF-16이 일부 문자를 서로게이트 쌍으로 표현하기 때문입니다. 이 도구의 디코딩 입력은 연속된 역슬래시 u와 4자리 16진수 형식이며 임의의 JavaScript 코드를 실행하지 않습니다.
