압축파일 풀기

ZIP 안의 파일 목록을 확인하고 필요한 파일만 내려받으세요. 브라우저에서 해제하며 RAR·7z·암호 ZIP은 지원하지 않습니다.

압축파일 풀기 입력

ZIP 1개 · 50MB 이하 · RAR·7z·암호 ZIP 제외

선택한 파일
파일명 인코딩·지원 범위

인코딩을 바꾸면 ZIP을 다시 선택하세요. UTF-8 표시가 있는 이름은 항상 UTF-8로 읽습니다. 저장·Deflate 방식만 지원하며 ZIP64·분할·링크는 제외합니다. 해제 크기: 파일당 50MB·전체 100MB·200개 이하. 파일을 자동 실행하지 않습니다.

원본 파일은 바뀌지 않습니다. 브라우저에서 처리하며 새로고침하면 작업이 초기화됩니다.

결과

파일을 선택하고 실행하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

지원하는 ZIP 안의 파일을 검사한 후 선택한 항목을 해제하는 작업입니다.

실제 예시

docs/a.txt와 photo.png가 들어 있는 ZIP에서 a.txt만 선택하면 그 파일만 내려받습니다. 여러 항목을 고르면 폴더 구조를 유지한 ZIP과 개별 다운로드를 함께 제공합니다.

자주 묻는 질문

어떤 압축파일과 파일명 인코딩을 지원하나요?

저장·Deflate 방식의 일반 ZIP을 지원합니다. UTF-8 표시가 있는 이름은 UTF-8로 읽고, 표시가 없으면 기본 UTF-8 또는 선택한 CP949·Windows-1252를 사용합니다. RAR·7z·암호화·분할·ZIP64·심볼릭 링크는 지원하지 않습니다.

압축을 풀면 파일이 자동으로 실행되거나 원래 폴더에 저장되나요?

자동 실행이나 원본 폴더 쓰기를 하지 않습니다. 사용자가 누른 파일만 다운로드하며 개별 다운로드에는 번호와 기본 파일명을 붙입니다. 최대 200개, 해제 파일당 50MB·전체 100MB입니다. 경로·크기·CRC 검사는 악성코드 검사가 아닙니다.
