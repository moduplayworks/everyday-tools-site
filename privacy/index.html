개인정보 처리 안내

안내 기준일: 2026년 10월 2일

강의와 계획 입력

강의명·길이·시청 위치·배속·공부 일정은 브라우저에서 계산합니다. 입력값을 URL, 분석 이벤트, 운영자의 서버로 전송하는 기능은 구현하지 않습니다. 사용자 계정과 이메일을 직접 수집하지 않습니다.

사진·파일 입력

사진 배경 제거는 이미지 파일을 브라우저 워커에서 처리합니다. 첫 사용 때 같은 사이트의 인물 분리 모델과 실행 파일을 내려받으며, 선택한 사진·파일명은 이 요청이나 분석 이벤트에 포함하지 않습니다. 업로드·계정 저장·기기 간 동기화는 없습니다. 결과와 입력은 페이지를 떠나거나 초기화하면 메모리에서 해제되며, 저장한 PNG는 사용자가 직접 관리합니다.

브라우저 저장

계산 완료 시 각 도구의 입력을 localStorage에 저장합니다. 도구 간 전달에는 같은 탭의 sessionStorage를 사용합니다. 기록은 해당 브라우저·주소에 한정되며 기기 간 자동 동기화는 없습니다. 브라우저 데이터를 지우면 삭제될 수 있습니다. 사용 안내에서 JSON 백업과 삭제 방법을 확인하세요.

접속 정보와 방문 통계

호스팅 제공자는 웹 요청을 처리하는 과정에서 IP 주소 등 접속 정보를 처리할 수 있습니다. 따라서 모든 데이터가 외부로 전송되지 않는 서비스라고 표현하지 않습니다.

이용 통계 수집을 허용하면 Google Analytics 4를 사용합니다. 거절하거나 선택하지 않으면 GA 스크립트를 불러오지 않으며 도구는 그대로 사용할 수 있습니다.

수집 항목은 페이지 주소·제목, 유입 사이트, 브라우저·기기 정보, 방문과 이용 시간, 도구 종류와 사용 여부, 계산·계획 생성·백업 작업 여부입니다. 강의명·시간·배속·일정·붙여넣은 글·파일 내용은 보내지 않습니다. 페이지 주소의 검색 매개변수와 해시는 제거하고 유입 주소는 사이트 주소까지만 전달합니다.

Google이 네트워크 요청에 필요한 IP 주소 등을 처리하며, 데이터는 해외 서버에서 처리될 수 있습니다. 자동 폼 수집, 사용자 ID, 광고 개인화 신호와 Google Signals는 사용하지 않습니다. Google 개인정보처리방침을 확인할 수 있습니다.

GA의 사용자·이벤트 데이터 보관은 2개월로 설정합니다. 합산된 표준 보고서에는 이 기간이 적용되지 않을 수 있습니다. 선택은 이 브라우저에 최대 180일 저장하며, 허용 시 도구 전용 분석 쿠키를 최대 180일 사용합니다. 페이지 아래 ‘이용 통계 설정’에서 언제든 거절로 변경할 수 있습니다. 거절하면 추가 GA 수집을 중단하고 도구 전용 분석 쿠키를 삭제합니다. 이미 전송된 데이터가 자동 삭제되는 것은 아닙니다.

분석 동의는 광고 동의와 별개입니다. 전체 브라우저 데이터 삭제는 사용 안내에서 할 수 있습니다. 통계 관련 문의와 삭제 요청은 문의 경로를 이용해 주세요.

광고

현재 광고는 비활성화되어 있으며 광고 스크립트를 불러오지 않습니다. 활성화 전에 제공자·동의 요건과 이 안내를 검토합니다.

문의와 외부 서비스

문의 페이지의 외부 경로를 이용하면 해당 서비스의 개인정보 정책이 적용됩니다. 공개 게시판에는 개인 정보를 게시하지 마세요. 운영 정책이나 외부 스크립트가 바뀌면 이 안내를 갱신합니다.
