개인정보 처리 안내

안내 기준일: 2026년 10월 2일

강의와 계획 입력

강의명·길이·시청 위치·배속·공부 일정은 브라우저에서 계산합니다. 입력값을 URL, 분석 이벤트, 운영자의 서버로 전송하는 기능은 구현하지 않습니다. 사용자 계정과 이메일을 직접 수집하지 않습니다.

브라우저 저장

계산 완료 시 각 도구의 입력을 localStorage에 저장합니다. 도구 간 전달에는 같은 탭의 sessionStorage를 사용합니다. 기록은 해당 브라우저·주소에 한정되며 기기 간 자동 동기화는 없습니다. 브라우저 데이터를 지우면 삭제될 수 있습니다. 사용 안내에서 JSON 백업과 삭제 방법을 확인하세요.

접속 정보와 방문 통계

호스팅 제공자는 웹 요청을 처리하는 과정에서 IP 주소 등 접속 정보를 처리할 수 있습니다. 따라서 모든 데이터가 외부로 전송되지 않는 서비스라고 표현하지 않습니다.

현재 애플리케이션의 별도 방문 통계 스크립트는 비활성화되어 있습니다.

광고

현재 광고는 비활성화되어 있으며 광고 스크립트를 불러오지 않습니다. 활성화 전에 제공자·동의 요건과 이 안내를 검토합니다.

문의와 외부 서비스

문의 페이지의 외부 경로를 이용하면 해당 서비스의 개인정보 정책이 적용됩니다. 공개 게시판에는 개인 정보를 게시하지 마세요. 운영 정책이나 외부 스크립트가 바뀌면 이 안내를 갱신합니다.
