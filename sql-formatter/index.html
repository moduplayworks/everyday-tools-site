SQL 정렬

PostgreSQL·MySQL 등 방언에 맞게 SQL을 정렬하세요. 들여쓰기와 키워드 대소문자를 고르며 쿼리는 실행하지 않습니다.

SQL 정렬 입력

최대 100,000자 · Ctrl/⌘ + Enter로 실행 · 데이터베이스에 실행하지 않습니다.

들여쓰기·키워드 대소문자

입력은 이 탭에서 처리하며 저장·전송하지 않습니다. 공유에는 요약만 포함됩니다.

결과

입력 후 실행하세요.

변환 결과·직접 복사
처리 기준·변환 시 달라진 점
결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

SQL 방언에 따라 공백과 키워드 표시를 정리하는 도구입니다.

실제 예시

select name, count(*) as total from visits where source='newsletter' group by name;를 키워드 대문자·공백 2칸으로 정렬하면 SELECT, FROM, WHERE, GROUP BY 절이 줄별로 구분됩니다. newsletter 문자열 내용은 그대로 유지됩니다. 결과를 데이터베이스로 전송하거나 실행하지 않습니다.

자주 묻는 질문

어떤 방언을 고를 수 있나요?

표준 SQL, PostgreSQL, MySQL, SQLite, SQL Server, BigQuery, MariaDB, Oracle, Spark, Snowflake를 선택할 수 있습니다. 작성한 쿼리에 맞는 방언을 선택하세요. 저장 프로시저나 세미콜론 외 구분자 변경은 지원하지 않습니다.

정렬 성공은 SQL이 올바르다는 뜻인가요?

아닙니다. 공백·키워드 정렬 도구이며 전체 SQL 문법 검증기나 실행 계획 분석기가 아닙니다. 테이블 존재 여부·권한·성능·실행 결과를 알 수 없습니다. 문자열·주석·플레이스홀더를 포함한 출력은 직접 검토하세요.

입력과 결과를 저장하나요?

이 탭의 메모리에서 처리하며 자동 저장·전송하지 않습니다. 입력 100,000자, 출력 1,000,000자까지 지원합니다. 변환을 취소할 수 있고 오류가 나도 이전 정상 결과는 유지됩니다. 결과는 SQL 파일로 내려받거나 복사할 수 있습니다.
