JSON 정렬·검증기

JSON 문법을 검사하고 들여쓰기 또는 압축 형식으로 정리합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

JSON 숫자는 JavaScript Number 범위를 사용합니다. 정확한 큰 정수는 문자열로 입력하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

JSON 문법 검사와 들여쓰기 정리하기.

JSON.parse로 검증 후 JSON.stringify로 직렬화

입력 예시

{"a":1}을 2칸 들여쓰기로 정리

객체의 키와 문자열은 큰따옴표로 감싸야 합니다. {"a":1}은 유효하지만 {'a':1}은 JSON이 아니며 주석이나 마지막 쉼표도 허용하지 않습니다.

사용 방법

  1. JSON, 출력 형식 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

긴 숫자 ID를 정리했는데 값이 달라질 수 있나요?

JavaScript Number로 표현할 수 없는 큰 정수는 파싱 과정에서 정밀도를 잃을 수 있습니다. 식별자는 따옴표로 감싼 문자열로 다루세요. 이 도구는 원문 숫자 표기를 그대로 보존하는 파서가 아닙니다.

중복된 JSON 키도 오류로 찾나요?

이 도구는 JSON.parse의 동작을 따르므로 같은 객체에 같은 키가 반복되면 마지막 값이 남을 수 있습니다. 중복 키 탐지나 원문 보존이 필요한 검증에는 사용하지 마세요.
