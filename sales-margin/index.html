판매 마진 계산기

상품 원가·판매가·수수료·배송비로 입력 비용 반영 건당 이익과 목표 마진 판매가를 계산합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 0 · 최대 1000000000000

정수 · 최소 1 · 최대 1000000000000

최소 0 · 최대 100

정수 · 최소 0 · 최대 1000000000000

최소 0 · 최대 99.99

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

수수료율은 직접 입력합니다. 표시된 이익은 입력한 상품 원가·판매자 부담 배송비·비율 수수료만 뺀 추정치이며 다른 정액 비용·부가세·반품은 반영하지 않습니다. 모든 금액을 같은 부가세 기준으로 입력하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

원가·판매자 부담 배송비·직접 입력한 판매 수수료를 반영한 건당 이익과 판매가 기준 마진을 확인하고 목표 마진 가격을 구합니다..

입력 비용 반영 건당 이익 = 판매가 − 원가 − 배송비 − 판매가 × 수수료율; 목표 판매가 = 올림((원가 + 배송비) ÷ (1 − 수수료율 − 목표 마진율))

입력 예시

원가 5,000원 · 판매가 10,000원 · 수수료 10% · 배송비 500원 · 목표 마진 20%

원가 5,000원, 판매가 10,000원, 수수료율 10%, 판매자 부담 배송비 500원이면 수수료 1,000원을 뺀 건당 이익은 3,500원이고 판매가 기준 마진은 35%입니다. 목표 마진 20%를 맞추는 최소 판매가는 (5,000+500)÷(1−0.10−0.20)을 올림한 7,858원입니다. 수수료율은 판매가 기준으로 직접 입력합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 상품 원가 (원), 판매가 (원), 판매 수수료율 (%), 판매자 부담 배송비 (원), 목표 마진율 (%) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

마진율과 원가 대비 인상률은 어떻게 다른가요?

마진율은 이익을 판매가로 나누고, 원가 대비 인상률은 이익을 원가로 나눕니다. 분모가 다르므로 같은 퍼센트가 아닙니다.

판매 수수료율은 어디에서 가져오나요?

플랫폼이나 결제 방식별 요율을 직접 입력하세요. 현재 요율을 자동 수집하지 않으며 정액 수수료·광고비·반품 비용도 따로 넣지 않습니다.

부가세를 포함한 최종 순이익인가요?

아닙니다. 원가·판매가·배송비를 같은 부가세 기준으로 입력해야 하며 세금과 입력하지 않은 비용은 반영하지 않습니다. 결과는 회계상 순이익이나 세무 계산이 아닙니다.
