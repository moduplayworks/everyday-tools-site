데이터 용량 단위 변환기

데이터 용량 값을 다른 단위로 바꾸고 단위별 결과를 비교합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

최소 0

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

B는 바이트, bit는 비트입니다. KB는 1,000B, KiB는 1,024B입니다. 결과는 유효숫자 12자리까지 표시합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

MB·MiB·비트·바이트 용량 비교하기.

변환값 = 입력값 × 입력 단위의 기준 배율 ÷ 출력 단위의 기준 배율

입력 예시

1 B = 8 bit

1KiB는 1,024B이고 1KB는 1,000B입니다. 같은 숫자라도 접두어에 i가 있는지에 따라 결과가 달라집니다.

사용 방법

  1. 입력된 예시값을 사용하거나 값, 입력 단위 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

인터넷 속도의 Mbps를 MB로 바로 읽어도 되나요?

아닙니다. 소문자 b는 비트, 대문자 B는 바이트이며 1B=8bit입니다. Mbps는 초당 비트 수라서 용량을 구하려면 전송 시간도 필요합니다.
