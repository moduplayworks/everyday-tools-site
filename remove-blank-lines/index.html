텍스트 56

빈 줄 제거

내용이 없는 줄과 공백만 있는 줄을 제거합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

내용 없는 빈 줄을 한 번에 없애기.

공백을 제거했을 때 빈 문자열인 줄 제외

입력 예시

사과 + 빈 줄 + 배 → 두 줄

A, 빈 줄, B를 각각 줄로 입력하면 A와 B 두 줄만 남습니다. 공백이나 탭만 있는 줄도 빈 줄로 봅니다.

사용 방법

  1. 텍스트 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

내용이 있는 줄의 앞뒤 공백도 잘라내나요?

아닙니다. 빈 줄인지 판단할 때만 공백을 무시하며 남겨진 줄의 원래 내용은 유지합니다. 내용 줄의 공백도 지우려면 줄 앞뒤 공백 정리를 사용하세요.
