움짤 만들기

MP4·WebM 영상에서 짧은 구간을 골라 움직이는 GIF로 만드세요. 5초·50프레임 이하, 크기와 재생 속도를 조절하고 브라우저에서 저장합니다.

영상 구간

GIF 만들기 입력

MP4·WebM · 최대 25MB · 10분 이하 · 영상은 브라우저에서 처리합니다. 파일을 고르지 않고 바로 누르면 편집 가능한 예시 GIF가 만들어집니다. 재생 시간이 표시되지 않는 WebM은 미리보기에서 확인하세요.

0.1~5초 구간을 선택하세요. 끝 시각은 영상 길이를 넘을 수 없습니다.

움짤 만드는 방법과 예시

MP4·WebM 영상에서 원하는 구간을 골라 공유할 수 있는 애니메이션 GIF 사본 만들기.

파일을 선택하지 않고 시작하면 320×180px 예시가 만들어집니다. 기본 2초 구간과 초당 8프레임은 16프레임을 만듭니다. GIF의 프레임 간격은 1/100초 단위로 저장되므로 프레임당 약 0.13초, 전체 재생 길이는 약 2.08초입니다. 실제 영상은 MP4·WebM 파일을 선택해 시작·끝 시각을 조절하세요. 재생 길이를 기록하지 않는 WebM은 미리보기에서 직접 확인할 수 있습니다.

지원 범위와 제한

MP4·WebM 영상을 선택하고 시작·끝 시각, 출력 긴 변 240·320·480px, 초당 5·8·10프레임을 고릅니다. 파일은 25MB·10분·한 변 3,840px·829만 화소 이하, 선택 구간은 최대 5초, 출력은 최대 50프레임·20MB입니다. 출력은 비율을 유지해 줄이며 색상은 최대 256색으로 변환됩니다. 재생 길이를 기록하지 않은 WebM은 미리보기에서 길이를 확인하고 앞 10분 안의 구간을 입력하세요. 영상의 회전 표시와 코덱 지원은 브라우저에 따라 다를 수 있습니다. HDR·색상·투명도·소리는 보존하지 않습니다. 인코딩 중 탭을 닫거나 취소하면 결과를 만들지 않습니다.

자주 묻는 질문

MP4와 WebM이면 모두 열리나요?

파일 확장자만으로 코덱 지원을 보장할 수는 없습니다. 브라우저가 영상 코덱을 열 수 있어야 하며, 지원하지 않는 파일은 선택 단계에서 안내합니다. 일부 WebM은 재생 길이를 기록하지 않습니다. 이 경우 미리보기로 확인한 뒤 앞 10분 이내의 구간을 직접 입력하세요. 재생할 수 없는 파일은 MP4 또는 WebM으로 다시 저장해 보세요.

움짤에 소리와 원본 색상이 보존되나요?

GIF는 무음이고 프레임당 최대 256색을 사용합니다. 긴 변 크기를 줄일 수 있으며 색상·밝기·움직임이 원본과 달라질 수 있습니다. 투명 영상·HDR·회전 메타데이터는 보존하지 않으므로 결과 미리보기를 확인하세요.

영상이나 파일명이 공유 링크에 들어가나요?

영상과 파일명은 브라우저 메모리에서만 사용하며 서버로 업로드하거나 저장하지 않습니다. 공유 문구에는 도구 링크, 출력 크기와 프레임 수만 포함됩니다. GIF 파일은 직접 저장해 공유하세요. 페이지를 떠나면 입력·미리보기·결과가 지워집니다.
