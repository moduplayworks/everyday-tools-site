UUID 생성기

무작위 UUID v4 식별자를 필요한 개수만큼 생성합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 1 · 최대 100

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

브라우저에서 UUID v4 식별자 생성하기.

crypto.randomUUID로 RFC 9562 UUID v4 생성

입력 예시

형식: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx

UUID v4는 하이픈을 포함한 8-4-4-4-12 형태의 16진수 문자열입니다. 여러 개를 만들면 한 줄에 하나씩 복사할 수 있습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 개수 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

UUID는 중복이 절대로 없고 비밀번호로도 쓸 수 있나요?

충돌 가능성이 매우 낮은 식별자지만 절대적 중복 불가를 보장하지는 않습니다. 데이터베이스의 고유 제약은 별도로 두세요. UUID를 인증 비밀값으로 취급하는 설계도 별도 검토가 필요합니다.
