줄 앞뒤 문자 붙이기

각 줄의 앞과 뒤에 고정 문자를 일괄 추가합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

모든 줄에 같은 접두사나 접미사 붙이기.

결과 줄 = 접두사 + 원본 줄 + 접미사

입력 예시

사과 → [사과]

접두사 “[”, 접미사 “]”를 넣으면 A와 B는 각각 [A], [B]가 됩니다. 파일 목록에 고정 문구를 붙일 때 사용할 수 있습니다.

사용 방법

  1. 목록, 앞에 붙일 문자, 뒤에 붙일 문자 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

따옴표를 붙이면 JSON이나 CSV가 완성되나요?

그렇지 않습니다. 줄 내부 따옴표나 구분자를 이스케이프하지 않는 단순 문자열 결합입니다. 유효한 JSON·CSV가 필요하면 전용 변환기를 사용하세요.
