입력

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

최대 5,000개 숫자를 지원합니다. 표본 표준편차는 자료가 두 개 이상이어야 합니다.

계산·변환 기준

수치 자료의 모집단·표본 분산과 표준편차를 구합니다.

모분산 = 편차 제곱합 ÷ n, 표본분산은 ÷ (n−1)

입력 예시

2, 4, 4, 4, 5, 5, 7, 9의 모집단 표준편차 = 2

사용 방법

  1. 숫자 목록 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

어떤 기준으로 결과가 나오나요?
