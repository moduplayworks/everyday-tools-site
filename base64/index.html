Base64 인코딩·디코딩

UTF-8 텍스트를 표준 Base64로 변환하거나 원문으로 복원합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

Base64는 암호화가 아닙니다. 디코딩은 유효한 UTF-8 텍스트만 지원합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

UTF-8 텍스트를 Base64로 인코딩하고 복원하기.

UTF-8 바이트와 Base64를 서로 변환

입력 예시

Hello → SGVsbG8=

영문 A의 UTF-8 바이트를 Base64로 표현하면 QQ==입니다. 한글도 UTF-8 바이트로 변환한 뒤 처리하므로 ASCII 전용 방식과 구분하세요.

사용 방법

  1. 입력, 방향 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

Base64 문자열로 바꾸면 비밀을 숨길 수 있나요?

아닙니다. 누구나 디코딩할 수 있는 표현 방식입니다. 이 도구는 바이너리 파일이 아닌 유효한 UTF-8 텍스트의 복원을 지원하며 암호화나 서명 검증을 하지 않습니다.

Base64와 Base64url은 똑같이 입력할 수 있나요?

이 도구는 표준 Base64 알파벳을 사용하는 브라우저 디코더를 이용합니다. URL 안전형의 하이픈·밑줄을 사용하는 문자열과 구분하세요. 올바른 UTF-8 텍스트가 아니면 복원하지 않습니다.
