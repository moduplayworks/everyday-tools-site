사진을 PDF로

사진 순서·용지·여백을 정해 하나의 PDF로 묶으세요. 브라우저에서 처리하고 미리보기 후 새 사본을 저장합니다.

사진을 PDF로 입력

JPG·PNG·WEBP 1~20장 · 전체 50MB

여백·사진 처리 안내

비율 유지, 한 페이지에 사진 한 장. 투명 배경은 흰색으로, 사진은 JPG 품질 92%로 다시 저장합니다. 장당 20MB·2,400만 화소·한 변 6,000px까지입니다. 사진 크기 용지는 방향 설정 대신 사진 비율을 사용합니다.

파일은 브라우저에서 처리합니다. 원본은 유지되며 새로고침하면 작업이 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

여러 사진을 원하는 순서와 용지 크기로 하나의 PDF에 배치하는 작업입니다.

실제 예시

가로 사진 2장을 A4·사진에 맞춤·여백 10mm로 만들면 가로 A4 두 페이지가 됩니다. 사진은 비율을 유지하며 각 페이지에 한 장씩 들어갑니다.

자주 묻는 질문

사진 순서와 PDF 용지를 바꿀 수 있나요?

선택 목록의 앞으로·뒤로 버튼으로 순서를 바꿀 수 있습니다. A4와 Letter는 세로·가로·사진에 맞춤을 선택합니다. 사진 크기 용지는 96dpi 기준으로 사진 비율을 사용하고 여백을 더합니다.

PDF로 만들면 원본 화질과 투명 배경은 어떻게 되나요?

사진 방향을 반영한 뒤 JPG 품질 92%로 다시 인코딩합니다. 투명한 부분은 흰색으로 채웁니다. 무손실 변환이나 원본 메타데이터 보존을 제공하지 않으며 원본 사진 파일은 바뀌지 않습니다.
