텍스트 줄바꿈 넣기

긴 줄을 지정한 글자 묶음 수마다 줄바꿈합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 1 · 최대 1000

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

단어 경계와 관계없이 보이는 글자 묶음 수로 나눕니다. 기존 줄바꿈은 유지합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

문자 묶음 개수마다 강제 줄바꿈 넣기.

유니코드 grapheme 묶음 기준으로 각 줄을 분할

입력 예시

abcdef를 3글자마다 → abc / def

ABCDE를 2글자씩 나누면 AB, CD, E의 세 줄이 됩니다. 기존 줄바꿈은 유지한 채 각 줄을 따로 나눕니다.

사용 방법

  1. 입력된 예시값을 사용하거나 텍스트, 한 줄 글자 수 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

이모지와 단어가 중간에서 잘릴 수 있나요?

눈에 보이는 문자 묶음 단위로 분할해 결합 이모지의 내부를 나누지 않도록 합니다. 단어 경계는 고려하지 않으므로 단어는 여러 줄에 걸쳐 나뉠 수 있습니다.
