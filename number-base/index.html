진법 변환기

정수를 2·8·10·16진수 표현으로 변환합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

음수도 지원합니다. 소수는 제외하며 최대 1,000자리까지 입력할 수 있습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

큰 정수를 2·8·10·16진수로 변환하기.

BigInt 정수로 파싱 후 각 진법 문자열로 출력

입력 예시

10진수 255 = 16진수 ff

10진수 255는 2진수 11111111, 8진수 377, 16진수 FF입니다. 같은 정수를 다른 숫자 체계로 표현한 것입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 정수, 입력 진법 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

소수나 0x 접두사를 붙인 값도 변환되나요?

소수는 지원하지 않습니다. 선택한 진법의 숫자만 입력하고 0x·0b 같은 접두사는 제외하세요. 정수는 BigInt로 처리하며 음수와 최대 1,000자리 입력을 지원합니다.
