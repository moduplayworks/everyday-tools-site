텍스트 일괄 바꾸기

찾을 문자열을 지정해 모든 일치 부분을 새 문자열로 바꿉니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

대소문자를 구분해 같은 문자열 모두 교체하기.

정규식이 아닌 문자열 전체 일치를 대소문자 구분해 교체

입력 예시

사과 주스 → 포도 주스

“apple apple”에서 apple을 pear로 바꾸면 “pear pear”가 됩니다. 문자열 전체에서 겹치지 않는 일치 부분을 교체합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 원본, 찾을 문자열, 바꿀 문자열 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

점이나 별표를 정규식처럼 사용할 수 있나요?

아닙니다. 점은 실제 점, 별표는 실제 별표를 찾습니다. 대소문자를 구분하므로 A를 바꿔도 a는 남으며 빈 찾기 문자열은 받지 않습니다.

계산 기준과 참고 자료

이 도구의 계산식과 적용 범위는 위 설명에 공개되어 있습니다. 예시는 입력값을 공식에 대입하거나 명시된 문자열·달력 처리 규칙을 따라 확인할 수 있습니다.
