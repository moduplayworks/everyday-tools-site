파비콘 만들기

사진을 크기별 PNG·ICO 아이콘 묶음으로 만드세요. 여백·배경·가운데 자르기를 선택하고 매니페스트와 설치 태그를 함께 저장합니다.

입력과 설정

JPG·PNG·WEBP 1장 · 20MB·2,400만 화소 이하 · HEIC 제외

사진을 선택하거나 예제를 사용하세요.

여백·배경

여백 0~30%. Apple용 180px 이미지는 투명 영역에 흰색을 채웁니다.

선택한 사진 보기

결과

입력 후 실행하면 결과가 표시됩니다.

사이트에 넣을 태그·안내
결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사진·입력값은 저장하거나 업로드하지 않습니다. 새로고침·페이지 이동 전에 결과를 저장하세요.

처리 방법과 기준

사용자 사진을 정사각형 아이콘 크기별로 렌더링하고 웹사이트 설치 파일 묶음을 생성하는 도구입니다.

실제 예시

320×240 사진을 전체 유지·여백 0%로 32px 아이콘으로 만들면 내용은 32×24px이고 위아래에 4px씩 여백이 생깁니다. 가운데 자르기를 선택하면 정사각형을 채우면서 양옆이 잘립니다.

자주 묻는 질문

ZIP에는 어떤 파일이 들어 있나요?

16·32·48·180·192·256·512px PNG 7개, 16·32·48·256px를 담은 PNG 압축 ICO, site.webmanifest, head-tags.txt, README.txt가 들어 있습니다. 원본 사진 파일은 포함하지 않습니다.

사이트에 어떻게 적용하나요?

ZIP을 풀어 파일을 사이트 루트에 놓고 head-tags.txt의 태그를 HTML head에 넣으세요. 하위 폴더에 배치하면 href 경로를 수정하고 매니페스트의 Website 이름도 바꾸세요. 이 파일만으로 완전한 PWA가 만들어지는 것은 아닙니다.

투명도·잘림·호환성에 제한이 있나요?

전체 유지 또는 가운데 자르기, 바깥 여백 0~30%, 투명·흰색·사용자 배경색을 선택합니다. Apple용 180px는 투명 영역을 흰색으로 채웁니다. 작은 원본 확대는 선명해지는 기능이 아닙니다. PNG 압축 ICO는 아주 오래된 Windows나 편집기에서 열리지 않을 수 있습니다.
