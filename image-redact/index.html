사진 모자이크·가리기

사진의 선택 영역을 검정색으로 덮거나 모자이크하세요. 여러 영역을 지정하고 가린 PNG 사본을 저장합니다.

사진 모자이크·가리기 입력

JPG·PNG·WEBP · 장당 20MB 이하

민감한 내용은 검정 가림으로 충분히 넓게 덮으세요. 모자이크는 내용 추정을 막는 방법이 아닙니다.

드래그 또는 숫자로 영역을 선택하세요.

선택 영역 숫자로 입력 (px)

파란 테두리는 선택 중인 영역입니다. 가리기 버튼을 눌러야 저장 결과에 적용됩니다.

지원 범위와 원본 보관

입력은 장당 2,400만 화소·전체 50MB 이하입니다. 원본 파일은 바꾸지 않습니다. 움직이는 이미지는 정지 이미지로 처리하며 HEIC는 지원하지 않습니다. 결과는 2,400만 화소·한 변 6,000px(합치기 16,000px)까지입니다. 가리기 결과는 PNG로 저장합니다. 원본 메타데이터·편집 기록은 결과에 보존하지 않습니다.

입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

결과

입력 후 결과를 확인하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

사용 방법과 처리 기준

사진에서 공개하지 않을 직사각형 영역을 픽셀로 덮거나 모자이크하는 작업입니다.

실제 예시

왼쪽 20px·위 10px부터 100×50px 영역을 선택하고 선택 영역 가리기를 누르면 해당 영역이 적용됩니다. 검정 가림은 선택한 픽셀을 불투명 검정으로 새로 그리며, 결과에는 파란 선택 테두리가 들어가지 않습니다.

자주 묻는 질문

모자이크와 검정 가림은 개인정보 보호에서 어떤 차이가 있나요?

모자이크는 색과 구조가 남아 내용이 추정될 수 있습니다. 민감한 내용은 검정 불투명 가림으로 충분히 넓게 덮고 저장 결과를 직접 확인하세요. 선택 밖의 얼굴·문자나 반사 등은 자동으로 찾거나 가리지 않습니다.

가린 영역을 수정하거나 원본을 되돌릴 수 있나요?

현재 화면에서는 영역 삭제나 모든 가림 지우기로 다시 편집할 수 있습니다. 저장한 PNG의 검정 가림 영역에는 원본 픽셀 대신 검정 픽셀이 들어갑니다. 원본 파일은 별도로 유지되므로 원본을 함께 공유하지 않도록 확인하세요.
