부가세 계산기

여러 거래의 공급가액이나 부가세 포함 금액에서 부가세와 합계를 계산합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

최소 0 · 최대 100

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

기본 10%는 국세청의 일반과세자 표준세율 예시입니다. 간이과세 계산, 면세·영세율 여부, 매입세액 공제와 세금 신고액은 판단하지 않습니다. 각 입력 줄을 별도 거래로 보고 세액을 원 단위 반올림합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

여러 거래의 공급가액에 부가세를 더하거나 세금 포함 총액에서 공급가액과 세액을 나누어 확인합니다..

공급가액 기준: 부가세 = 반올림(공급가액 × 세율); 포함액 기준: 공급가액 = 반올림(포함액 × 100 ÷ (100 + 세율)); 줄별 세액을 합산

입력 예시

공급가액 10,000원과 20,000원 · 10% → 부가세 합계 3,000원 · 거래 금액 합계 33,000원

공급가액 10,000원과 20,000원에 10%를 적용하면 부가세 합계는 3,000원, 거래 금액 합계는 33,000원입니다. 부가세 포함 총액 11,000원은 공급가액 10,000원과 세액 1,000원으로 나뉩니다. 각 줄을 별도 거래로 보고 세액을 원 단위로 반올림합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 거래 금액 (원, 한 줄에 하나씩), 세율 (%), 입력 금액 기준 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

부가세가 포함된 금액에서 세액을 어떻게 구하나요?

세율을 r이라고 할 때 공급가액은 포함 총액 × 100 ÷ (100 + r)로 계산한 뒤 원 단위 반올림합니다. 세액은 입력 총액에서 공급가액을 뺍니다.

기본 세율 10%는 모든 사업자와 거래에 적용되나요?

아닙니다. 10%는 국세청이 안내하는 일반과세자 표준세율입니다. 간이과세, 면세, 영세율과 거래별 적용 여부를 이 계산기가 판정하지 않으므로 실제 기준을 확인하세요.

이 결과로 부가가치세 신고를 할 수 있나요?

아닙니다. 매입세액 공제, 업종별 부가가치율, 공제·가산과 신고 규칙을 반영하지 않는 금액 분해 도구입니다.

계산 기준과 참고 자료

  • 국세청 — 부가가치세 개요

    일반과세자 표준세율 10%와 간이과세·면세 등 유형 차이를 설명하는 국세청 자료. 계산기는 10%를 예시 기본값으로 쓰며 과세 대상이나 신고세액을 판정하지 않습니다.
