압력 단위 변환기

압력 값을 다른 단위로 바꾸고 단위별 결과를 비교합니다.

입력

최소 0

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

atm은 표준대기압 101,325Pa, psi는 제곱인치당 파운드힘입니다. 결과는 유효숫자 12자리까지 표시합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

Pa·kPa·bar·atm·psi 압력 단위 바꾸기.

변환값 = 입력값 × 입력 단위의 기준 배율 ÷ 출력 단위의 기준 배율

입력 예시

1 Pa = 0.001 kPa

표준대기압 1atm은 101,325Pa이고 101.325kPa입니다. 같은 압력 기준의 수치끼리 단위만 바꾸는 계산입니다.

사용 방법

  1. 값, 입력 단위 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

게이지압을 절대압으로도 바꿔 주나요?

아닙니다. 게이지압과 절대압은 기준점이 다릅니다. 이 도구는 입력값의 기준을 그대로 유지하므로 주변 대기압을 더하거나 빼는 작업은 별도로 해야 합니다.
