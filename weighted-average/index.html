가중평균 계산기

값과 중요도에 해당하는 가중치를 입력해 가중평균을 구합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

소수 결과는 유효숫자 12자리까지 표시합니다. 단위는 입력값끼리 통일해 주세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

점수와 비중을 반영한 평균 구하기.

가중평균 = Σ(값 × 가중치) ÷ Σ가중치

입력 예시

80×1과 100×3의 가중평균 = 95

80에 가중치 2, 100에 가중치 1을 주면 (80×2+100×1)÷3=약 86.6667입니다. 각 줄에 값과 가중치를 한 쌍씩 입력하세요.

사용 방법

  1. 입력된 예시값을 사용하거나 값, 가중치 (한 줄에 한 쌍) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

가중치의 합이 꼭 100이어야 하나요?

아닙니다. 가중치의 상대적인 비율을 사용하므로 2와 1, 20과 10은 같은 결과입니다. 가중치는 0 이상이어야 하고 합계는 0보다 커야 합니다.
