행렬 계산기

행렬 덧셈·뺄셈·곱·전치·행렬식·역행렬·RREF를 계산하세요. 행 소거 과정과 수치 허용오차를 확인합니다.

입력

예시값으로 바로 계산하거나 값을 바꿔 보세요.

한 줄이 한 행 · 공백·탭·쉼표로 숫자 구분 · 천 단위 쉼표·분수·기호식 제외

수치 허용오차

해·역행렬 판정은 실수 근사값입니다. 거의 특이한 입력은 허용오차를 바꿔 비교하세요.

입력은 이 브라우저에서만 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하세요.

계산·풀이 과정
계산 데이터 확인

표시값은 유효숫자 10자리 근사값입니다. CSV·TXT는 표시값을 저장하며 입력값은 주소나 방문 통계에 넣지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산 기준과 사용 방법

행렬의 연산 결과와 행 소거 과정을 확인하기.

곱 Cᵢⱼ=ΣₖAᵢₖBₖⱼ · 역행렬 [A|I]→[I|A⁻¹] · 행렬식: 행 교환 부호와 소거 피벗·행 크기의 곱

입력 예시

A=[[1,2],[3,4]]의 행렬식은 −2이며 역행렬은 [[−2,1],[1.5,−0.5]]입니다. A와 B의 곱은 [[19,22],[43,50]]입니다.

A의 행이 1 2와 3 4이면 det(A)=1×4−2×3=−2입니다. 역행렬은 [[−2,1],[1.5,−0.5]]이며 A와 곱하면 단위행렬이 됩니다. B의 행을 5 6과 7 8로 입력한 곱의 첫 칸은 1×5+2×7=19입니다.

사용 방법

  1. 예시값을 사용하거나 직접 숫자를 입력하세요. 표 형식은 한 줄이 한 행입니다.
  2. 결과 확인하기를 누르세요. 잘못된 행은 위치를 표시하고 제외하지 않습니다.
  3. 결과·계산 과정을 확인하고 필요한 결과를 복사하거나 파일로 저장하세요.

한계와 해석

각 행렬은 최대 8×8. 실수만 지원합니다. 역행렬·행렬식은 정사각행렬만 계산합니다. 특이성은 작은 행렬식 자체가 아닌 정규화한 피벗의 허용오차로 판정합니다.

자주 묻는 질문

곱셈과 덧셈에서 필요한 크기는 어떻게 다른가요?

덧셈과 뺄셈은 두 행렬의 행·열 수가 모두 같아야 합니다. 곱셈은 A의 열 수와 B의 행 수가 같아야 하며 결과 크기는 A의 행 수×B의 열 수입니다.

행렬식이 작으면 역행렬이 없나요?

작다는 이유만으로 판단하지 않습니다. 이 도구는 행별 계수 크기를 정규화하고 선택한 허용오차로 피벗을 판정합니다. 거의 특이한 행렬은 실수 근사 오차에 민감하며 조건수 추정이 크면 안내합니다.
