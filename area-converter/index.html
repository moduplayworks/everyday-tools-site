넓이 단위 변환기

넓이 값을 다른 단위로 바꾸고 단위별 결과를 비교합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

최소 0

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

평은 400/121 m², acre는 국제 foot 기준 4046.8564224 m²입니다. 결과는 유효숫자 12자리까지 표시합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

제곱미터·제곱피트·평 면적 바꾸기.

변환값 = 입력값 × 입력 단위의 기준 배율 ÷ 출력 단위의 기준 배율

입력 예시

1 m² = 10000 cm²

1m=100cm이므로 1m²=10,000cm²입니다. 이 도구의 평 기준 400/121m²를 적용하면 30평은 약 99.1736m²입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 값, 입력 단위 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

평 변환이 공급면적과 전용면적의 차이도 계산하나요?

아닙니다. 입력한 면적 수치의 단위만 바꿉니다. 공급·전용처럼 포함하는 공간이 다른 면적을 비교하려면 원자료의 면적 종류부터 맞춰야 합니다.

계산 기준과 참고 자료

이 도구의 계산식과 적용 범위는 위 설명에 공개되어 있습니다. 예시는 입력값을 공식에 대입하거나 명시된 문자열·달력 처리 규칙을 따라 확인할 수 있습니다.
