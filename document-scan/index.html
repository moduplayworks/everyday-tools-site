문서 사진 스캔 보정

사진의 네 모서리를 조정해 문서를 곧게 펴세요. 밝은 종이 자동 탐색과 여러 장 PNG·PDF 저장을 지원합니다.

문서 사진

JPG·PNG 정지 사진 1~10장 · 장당 20MB, 전체 50MB · 한 변 6,000px·2,400만 화소 이하

사진을 선택하거나 공개 예시로 시작하세요.

1→2→3→4 순서로 종이 모서리에 놓으세요. 점을 드래그하거나 선택 후 방향키로 1%, Shift+방향키로 0.1%씩 조정할 수 있습니다.

모서리 위치를 숫자로 조정
1. 왼쪽 위
2. 오른쪽 위
3. 오른쪽 아래
4. 왼쪽 아래
출력 비율·크기·색상

사진·파일명·좌표는 브라우저에서만 처리합니다. 새로고침·페이지 이동 시 입력과 결과가 지워집니다.

보정된 문서

모서리를 확인한 뒤 보정·PDF 만들기를 누르세요.

원본은 변경하지 않습니다. PDF는 이미지로 구성되며 검색 가능한 글자나 OCR은 포함하지 않습니다. 공유에는 사진·문서 내용·파일명을 넣지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

문서 사진 스캔 보정 방법

입력 예시

640×480px 공개 예시에서 어두운 배경 위의 밝은 종이를 자동 탐색한 뒤 네 모서리를 확인하세요. A4 세로 비율을 선택하면 문서를 약 210:297 직사각형으로 펴며, 예시 2장은 순서대로 2페이지 PDF가 됩니다. 앞뒤 이동 후 다시 생성하면 새 순서가 반영됩니다.

사진에서 왼쪽 위·오른쪽 위·오른쪽 아래·왼쪽 아래의 네 점을 지정하면 원근 변환으로 문서를 직사각형으로 펴고, 이웃 픽셀을 보간합니다. 서로 교차하거나 겹친 모서리는 오류로 안내합니다. 기본값은 사진 전체이며, 종이 영역은 직접 확인해 선택하세요.

자동 찾기는 어두운 배경 위에서 가장 큰 밝은 영역을 찾는 제한적인 탐색입니다. 밝은 배경·그림자·색종이·여러 문서·회전이 큰 사진에서는 실패하거나 잘못 잡을 수 있습니다. 탐색 후 반드시 모서리를 확인하세요. 실패하면 기존 좌표를 유지하며 수동으로 조정할 수 있습니다.

변 길이로 추정한 비율은 실제 종이 비율을 보장하지 않습니다. 실제 A4·Letter 세로 문서라면 해당 비율을 선택하세요. 곡면·렌즈 왜곡·흐린 글자를 복원하는 기능은 없습니다. 결과는 확대하지 않고 지정한 긴 변 이내로 줄이며, 투명 픽셀은 흰색으로 처리합니다. 전체 결과는 2,400만 화소·이미지 합계 75MB·PDF 100MB 이하입니다.

페이지 선택 후 앞으로·뒤로 이동하면 PDF 순서도 바뀝니다. 각 페이지는 PNG로, 전체 문서는 PDF로 저장할 수 있습니다. 사진의 촬영정보와 파일명은 새 파일에 복사하지 않습니다. HEIC·WEBP·움직이는 PNG는 지원하지 않습니다.

자주 묻는 질문

자동 모서리 탐색은 모든 사진에서 되나요?

아닙니다. 어두운 배경 위에서 가장 큰 밝은 종이를 찾는 제한적인 방식입니다. 밝은 배경·그림자·색종이·여러 문서에서는 실패하거나 다른 물체를 선택할 수 있습니다. 네 점을 직접 조정하거나 숫자 입력을 사용하고, 탐색 후에도 모서리를 확인하세요.

문서 내용이 서버로 전송되거나 PDF에서 검색되나요?

사진·좌표·문서 내용은 브라우저에서만 처리하며 저장하지 않습니다. PDF에는 보정한 이미지가 들어가고 OCR이나 검색 가능한 글자는 포함하지 않습니다. 새로고침·페이지 이동 시 입력과 결과가 지워집니다.

종이의 실제 비율은 어떻게 맞추나요?

사진 속 변 길이만으로 실제 종이 비율을 정확히 알 수는 없습니다. A4 또는 Letter 세로 문서라면 해당 비율을 고르세요. 비율이 다른 문서는 기본 추정값을 확인해 사용하세요. 휘어진 종이나 렌즈 왜곡은 이 평면 보정으로 복원하지 못합니다.
