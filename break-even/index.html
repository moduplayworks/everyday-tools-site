손익분기점 계산기

기간 고정비·개당 판매가·변동비로 손익분기 판매량과 그때의 매출을 계산합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 0 · 최대 1000000000000

정수 · 최소 1 · 최대 1000000000000

정수 · 최소 0 · 최대 1000000000000

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

단일 제품과 일정한 단가를 가정한 추정치입니다. 모든 금액을 같은 부가세 기준으로 입력하세요. 세금이나 입력하지 않은 비용은 반영하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

같은 기간의 고정비와 개당 판매가·변동비로 손실이 나지 않는 최소 판매 단위를 확인합니다..

손익분기 수량 = 올림(기간 고정비 ÷ (개당 판매가 − 개당 변동비))

입력 예시

월 고정비 1,200,000원 · 판매가 15,000원 · 변동비 8,000원 → 172개

월 고정비 1,200,000원을 개당 판매가 15,000원에서 변동비 8,000원을 뺀 7,000원으로 나누면 171.43개입니다. 낱개 판매를 가정해 172개로 올림합니다. 이때 매출은 2,580,000원, 입력 비용 합계는 2,576,000원입니다. 다품목·할인·수수료와 입력하지 않은 비용은 계산하지 않습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 기간 고정비 (원), 개당 판매가 (원), 개당 변동비 (원) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

손익분기 판매량은 왜 올림하나요?

낱개 단위로 판매한다고 가정해 비용을 충당할 수 있는 다음 정수 단위로 올립니다. 소수 단위 상품·서비스는 실제 청구 단위에 맞춰 해석해야 합니다.

판매가가 개당 변동비보다 낮으면 어떻게 되나요?

판매할 때마다 고정비를 회수할 금액이 남지 않아 이 입력으로는 손익분기 수량을 계산할 수 없습니다.

부가세나 플랫폼 수수료도 포함되나요?

모든 금액을 같은 부가세 기준으로 입력해야 합니다. 세금과 수수료는 자동 계산하지 않으므로 개당 변동비에 직접 포함해야 합니다.
