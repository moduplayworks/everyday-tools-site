오디오·영상 도구

동영상 자르기

영상 파일에서 시작 시각과 끝 시각을 지정해 짧은 구간의 새 파일을 만드는 작업

MP4·WebM·MOV · 최대 100MB·10분. 영상은 이 브라우저에서 처리합니다.

예시 영상으로 바로 시작할 수 있어요.

0.5~30초 구간을 저장해요. 길이는 영상 재생 시간 안이어야 합니다.

자른 영상

동영상 저장
결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

동영상에서 필요한 구간만 저장하세요

파일을 고르거나 예시 영상으로 시작해 시작·끝 시각을 입력하면 짧은 영상으로 다시 인코딩합니다. 예를 들어 4초 영상의 0~2초를 자르면 약 2초짜리 파일이 만들어집니다.

브라우저가 영상을 재생하며 다시 인코딩합니다

저장 형식과 코덱은 브라우저에 따라 MP4 또는 WebM으로 달라집니다. 원본과 형식·화질이 같다고 보장할 수 없으며, 기기에 따라 시간이 더 걸릴 수 있습니다. 결과를 재생해 확인하세요. 4K 영상은 최대 1920px로 줄여 저장합니다.

개인정보와 제한

선택한 영상은 업로드하거나 서버로 보내지 않습니다. 최대 100MB·10분 영상에서 0.5~30초 구간을 처리하며, 브라우저 탭을 닫으면 진행 중 작업은 끝납니다. 기기의 메모리나 브라우저 지원에 따라 일부 파일은 처리되지 않을 수 있습니다.

자주 묻는 질문

영상 구간을 자를 때 원본 파일도 바뀌나요?

원본은 수정하지 않습니다. 선택한 부분을 별도 파일로 재인코딩해 다운로드하며, 입력 영상은 브라우저 안에서 처리합니다.

잘라낸 영상의 화질과 길이는 원본과 같나요?

구간 길이는 지정한 시작·끝 시각을 따르지만, 브라우저 재인코딩 때문에 프레임 경계에 따라 조금 달라질 수 있습니다. 최대 긴 변 1,920px·초당 30프레임으로 출력하며, 4K 원본은 축소될 수 있습니다. 파일 크기나 무손실 출력을 보장하지 않습니다.

MP4·WebM·MOV를 모두 열 수 있나요?

파일 컨테이너뿐 아니라 영상 코덱도 현재 브라우저가 지원해야 합니다. 열 수 없는 파일은 다른 브라우저나 표준 MP4(H.264)·WebM(VP8) 파일로 다시 선택하세요. 출력은 브라우저가 지원하는 MP4 또는 WebM입니다.

선택한 영상이나 파일 이름을 서버로 보내나요?

아니요. 영상과 파일 이름은 브라우저의 로컬 처리에만 사용합니다. 사용 통계에는 도구 사용 사실만 기록하며 파일 내용·이름·선택한 구간은 포함하지 않습니다.

계산 기준과 참고 자료

  • MDN — MediaRecorder

    브라우저가 지원하는 컨테이너·코덱으로 캡처 스트림을 재인코딩합니다. 지원 형식과 출력 품질은 브라우저에 따라 달라집니다.

  • MDN — Canvas captureStream

    현재 영상 프레임을 로컬 Canvas에 그리고 브라우저 내 녹화용 영상 스트림으로 캡처합니다.

  • MDN — AudioContext createMediaElementSource

    영상 요소의 소리를 로컬 Web Audio 스트림에 연결해 영상과 함께 다시 인코딩합니다.

  • WebKit — MediaRecorder API

    WebKit 구현에서 캔버스·Web Audio 스트림 녹화와 형식 기능 감지를 설명합니다. 현재 기기의 코덱 지원 여부는 실행 중 기능 감지합니다.
