사용 예시와 처리 기준

평일 오전 9시 30분을 선택하면 30 9 * * 1-5가 생성됩니다. 분·시·일자·월·요일 순서이며, 다음 다섯 실행 시각은 이 기기의 시간대로 표시합니다. 서버의 시간대가 다르면 실제 실행 시각도 달라집니다.

자주 묻는 질문

모든 클라우드의 크론 표현식과 호환되나요?

아닙니다. Cronie/Vixie 계열 사용자 crontab의 다섯 필드 형식입니다. 일부 클라우드 작업 스케줄러와 Quartz는 필드 개수·초 단위·요일 규칙이 다릅니다. 붙여넣기 전에 사용하는 서비스 문서를 확인하세요.

다음 실행 예시는 서버에서도 같은 시각인가요?

예시는 브라우저 기기의 현지 시간대에서 계산합니다. 실제 cron 데몬의 시간대와 같을 때에만 시각이 일치합니다. Cronie는 서머타임으로 존재하지 않는 현지 시각을 건너뛰고, 반복되는 현지 시각에는 두 번 실행할 수 있습니다. 다른 구현의 동작은 해당 서비스 문서를 확인하세요.

매월 31일을 선택하면 2월에는 언제 실행되나요?

해당 달에 31일이 없으면 실행되지 않습니다. 날짜를 월말로 자동 이동하지 않습니다. 매월 말일 실행이 필요하면 사용하는 cron 구현의 별도 문법이나 다음 달 계산 방법을 확인하세요.

매 7분처럼 아무 간격이나 만들 수 있나요?

분 간격은 60을 나누는 일정한 주기만 제공합니다. 크론의 단계 값은 해당 필드 안에서 반복되므로 */7은 매시간 처음부터 다시 세어 실제 경과 간격이 항상 7분이지 않습니다. 일정한 시간 간격이 필요하면 별도 실행 간격을 지원하는 스케줄러를 사용하세요.

생성된 크론식을 그대로 설치하면 실행되나요?

아닙니다. 이 도구는 실행 시각을 나타내는 다섯 필드만 생성하므로 뒤에 실제 명령어를 추가해야 합니다. /etc/crontab과 /etc/cron.d 형식은 사용자 이름 필드도 요구합니다.
