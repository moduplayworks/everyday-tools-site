마크다운 미리보기

마크다운 문서를 화면으로 확인하고 HTML·MD로 저장하세요. 사용자 HTML은 실행하지 않고 외부 이미지는 불러오지 않습니다.

마크다운 미리보기 입력

최대 100,000자 · Ctrl/⌘ + Enter로 실행 · HTML 실행·외부 이미지 요청 없음

입력은 이 탭에서 처리하며 저장·전송하지 않습니다. 공유에는 요약만 포함됩니다.

사용 방법과 처리 기준

마크다운을 외부 리소스 없이 읽고 HTML 사본을 만드는 도구입니다.

실제 예시

# 제목과 **굵게**, 목록, 코드 블록, 파이프 표를 입력한 뒤 미리보기를 누르면 문서 모양으로 확인할 수 있습니다. <script> 같은 직접 입력한 HTML은 글자로 표시합니다. ![사진](https://example.com/photo.png)은 사진 설명과 주소로 표시하며 해당 서버에 이미지를 요청하지 않습니다.

자주 묻는 질문

지원하는 마크다운과 차이는 무엇인가요?

markdown-it의 기본 문법인 제목·목록·인용·강조·코드·링크와 표·취소선을 지원합니다. 수식·각주·Mermaid·작업 목록 확장은 포함하지 않습니다. 미리보기의 제목 수준은 도구 화면 구조에 맞춰 조정하지만 HTML 사본에는 원래 제목 수준을 유지합니다.

HTML과 이미지·링크는 어떻게 처리하나요?

사용자 HTML은 실행하지 않고 텍스트 노드로 표시합니다. 이미지·영상·스크립트·외부 글꼴을 불러오지 않습니다. 로그인 정보가 없는 HTTP(S) 링크만 명시적으로 누를 수 있는 새 탭 링크가 됩니다. 상대 주소와 다른 프로토콜은 글자로 표시합니다. 이미지 자리표시는 HTML 사본에도 유지됩니다.

어떤 파일을 받을 수 있나요?

원본 Markdown과 미리보기와 같은 내용을 담은 독립 HTML 파일을 저장할 수 있습니다. HTML에는 외부 요청·스크립트를 막는 정책을 넣습니다. 다른 서비스에 원본 MD를 붙이면 그 서비스의 렌더링 정책이 적용됩니다. 입력은 100,000자, 미리보기는 최대 20,000개 구성 요소로 제한합니다.
