여행 환전 예산 계산기

원화 예산, 직접 입력한 환율과 수수료 우대율로 예상 외화 수령액을 계산합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 1 · 최대 1000000000000

최소 0.000001 · 최대 1000000000

최소 0 · 최대 100

최소 0 · 최대 100

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

실시간 환율이 아닙니다. 수수료 우대율은 입력한 별도 수수료율의 할인 비율로 계산합니다. 은행별 고객 환율·수수료·현찰 단위는 다릅니다. 이미 수수료가 반영된 고객 환율을 넣으면 이중 반영을 막기 위해 수수료율을 0%로 입력하세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

여행에 쓸 총 원화 예산에서 직접 입력한 환율과 별도 수수료·우대 가정으로 예상 외화 수령액을 계산합니다..

적용 수수료율 = 입력 수수료율 × (1 − 우대율); 환전 원금 = 총 예산 ÷ (1 + 적용 수수료율); 예상 외화 = 환전 원금 ÷ 입력 환율

입력 예시

예산 100,000원 · 환율 1,400원/USD · 수수료 1.75% · 우대 50% → 수수료 약 867원 · 약 70.81 USD

예산 100,000원, 입력 환율 1,400원/USD, 별도 수수료율 1.75%, 우대율 50%를 넣으면 적용 수수료율은 0.875%입니다. 원화 예산을 수수료 포함액으로 보고 원금 99,133원, 수수료 867원, 예상 수령액 70.81 USD로 표시합니다. 실제 고객 환율이 이미 수수료를 포함하면 수수료율은 0%로 입력합니다.

사용 방법

  1. 입력된 예시값을 사용하거나 수수료 포함 원화 예산 (원), 환율 (원 / 외화 1단위), 별도 환전 수수료율 (%), 수수료 우대율 (%), 외화 코드 (예: USD) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

환율 우대율은 어떻게 계산에 반영되나요?

입력한 별도 수수료율을 우대율만큼 낮추는 단순 가정입니다. 은행의 환전 우대는 기준환율과 고객환율의 차이에 적용될 수 있으며 실제 은행 조건과 다릅니다.

지금 은행에서 실제로 받는 금액인가요?

아닙니다. 실시간 환율·은행별 매입/매도율·현찰 단위는 자동 조회하지 않습니다. 거래 직전 금융기관의 적용 환율과 수수료를 확인하세요.

고객 환율에 수수료가 포함되어 있으면 어떻게 입력하나요?

이미 적용 수수료가 반영된 환율을 입력하고 별도 수수료율을 0%로 두면 이 계산에서 수수료를 다시 더하지 않습니다.

계산 기준과 참고 자료

  • 한국은행 — 외환 매매기준율 안내

    은행이 기준환율에 수수료 등을 반영해 고객 환율을 정하며 은행별 고객 환율이 다를 수 있다는 설명. 계산기는 사용자 입력 환율·별도 수수료 가정만 적용하고 실제 고시환율은 가져오지 않습니다.
