오디오 형식 변환

브라우저에서 읽을 수 있는 오디오를 WAV 또는 현재 기기가 지원하는 녹음 형식으로 변환

MP3·M4A·WAV·OGG 등 · 50MB·3분 이하. WAV 저장은 MP3·WAV 입력, 압축 저장은 브라우저 지원 형식을 사용합니다.

파일을 고르지 않고 실행하면 공개 예시를 사용합니다.

저장 설정

WAV PCM은 MP3·WAV 입력을 안전하게 검사해 저장합니다. 다른 입력은 현재 기기가 지원하는 압축 형식을 선택하세요.

처리 결과

입력을 바꾼 뒤 다시 실행하기 전까지는 이전 결과입니다.

오디오 형식 변환 사용 방법

3초 공개 예시 음원을 선택 없이 변환하면 WAV 또는 현재 브라우저가 지원하는 압축 형식으로 저장합니다. 압축 형식은 재생 시간만큼 걸리고 128kbps가 기본 음질입니다. 결과에 실제 형식·재생 시간·파일 크기를 표시합니다.

지원 형식으로 다시 인코딩합니다

WAV는 브라우저에서 PCM 16-bit로 저장합니다. 압축 형식은 MediaRecorder가 지원한다고 보고한 형식만 표시하며, 실제 인코딩 자원 부족으로 실패할 수 있습니다. 압축 변환은 재생 시간만큼 걸리고 샘플레이트·채널·메타데이터가 달라질 수 있습니다.

파일과 기기 제한

최대 50MB·3분 입력을 브라우저에서 처리합니다. MP3 파일을 읽어 변환할 수 있어도 MP3 출력은 보장하지 않습니다. 결과 형식과 실제 재생을 확인하고 저장하세요.

자주 묻는 질문

MP3를 M4A나 WebM으로 바꿀 수 있나요?

MP3·M4A·WAV·OGG 등 브라우저가 재생할 수 있는 입력을 받습니다. 압축 출력은 MediaRecorder가 현재 기기에서 지원한다고 보고한 형식만 표시합니다. WAV PCM 16-bit 출력은 디코딩 전에 채널과 메모리를 안전하게 확인할 수 있는 MP3·WAV 입력만 지원합니다. MP3 출력은 보장하지 않습니다.

음질 설정의 kbps가 결과 크기를 보장하나요?

아닙니다. 압축 형식에서 선택하는 값은 인코더에 전달하는 비트레이트 목표이며 실제 크기·코덱·재생 호환성을 보장하지 않습니다. 결과를 재생하고 파일 크기를 확인하세요.

변환 중 기다려야 하나요?

WAV 출력은 입력을 디코딩한 뒤 바로 PCM 파일을 만듭니다. 압축 출력은 오디오를 실시간으로 재생하며 기록하므로 재생 시간에 가까운 대기 시간이 필요합니다. 최대 입력은 50MB·3분입니다.

계산 기준과 참고 자료

  • MDN — Web Audio API 전체 파일 디코딩

    완전한 파일을 AudioBuffer로 디코딩하고 AudioContext 샘플레이트로 다시 샘플링하는 동작. 이 구현은 입력 길이·파일 크기·채널 수를 제한합니다.

  • MDN — AudioContext 미디어 요소 연결

    선택한 로컬 오디오·동영상 요소의 오디오를 브라우저 오디오 그래프와 스트림 대상으로 연결합니다. 영상 프레임은 오디오 출력에 포함하지 않습니다.

  • MDN — MediaRecorder 형식 지원 확인과 녹음

    기기별 MediaRecorder 출력 형식을 먼저 확인하는 기준. 지원 보고가 실제 인코딩 성공이나 리소스 여유를 보장하지는 않습니다.

  • Microsoft Learn — RIFF 리소스 교환 파일 형식

    WAV 컨테이너의 RIFF 청크 기반 구조를 참고합니다. 내보내기는 16-bit PCM이며 앨범·ID3 메타데이터를 보존하지 않습니다.
