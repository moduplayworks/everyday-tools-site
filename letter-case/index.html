영문 대소문자 변환

영문 문자의 대문자·소문자·단어 첫 글자 대문자를 변환합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

영문 문장의 대문자·소문자 바꾸기.

선택한 대소문자 규칙을 각 문자 또는 단어에 적용

입력 예시

Hello world → HELLO WORLD

Hello World를 대문자로 바꾸면 HELLO WORLD, 소문자로 바꾸면 hello world입니다. 한글에는 대소문자 구분이 없어 같은 글자로 남습니다.

사용 방법

  1. 텍스트, 변환 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

단어 첫 글자 모드가 영어 제목의 문법까지 맞추나요?

아닙니다. 먼저 소문자로 만든 뒤 영문 단어 경계의 첫 글자를 대문자로 바꾸는 단순 규칙입니다. 약어·고유명사·관사에 대한 편집 규칙은 직접 검토하세요.
