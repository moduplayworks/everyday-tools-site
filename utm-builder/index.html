검색어·콘텐츠 구분 (선택)

이 5개 UTM 값은 입력 내용으로 교체합니다. 빈 선택값은 기존 주소에서도 삭제합니다. 다른 쿼리 값과 #위치는 유지합니다. 대소문자를 자동 변경하지 않습니다.

사용 예시와 처리 기준

주소 https://example.com/guide?lang=ko#start에 source=newsletter, medium=email, campaign=autumn_launch를 넣으면 lang=ko와 #start를 유지한 채 utm_source, utm_medium, utm_campaign이 추가됩니다. 한글·공백·&는 쿼리 값으로 인코딩하므로 새 매개변수로 잘못 나뉘지 않습니다.

자주 묻는 질문

기존 UTM과 다른 쿼리는 어떻게 되나요?

소문자 utm_source·utm_medium·utm_campaign·utm_term·utm_content 5개는 새 입력으로 교체하며 같은 키의 중복도 하나로 정리합니다. term·content가 비어 있으면 기존 값도 삭제합니다. 다른 쿼리 값과 #위치는 유지하지만 URL 직렬화 때문에 인코딩 표기는 달라질 수 있습니다. 서명된 주소에는 주의하세요.

입력 이름에 규칙이 있나요?

source·medium·campaign은 필수, term·content는 선택입니다. 대소문자를 구분하며 자동 소문자 변환을 하지 않습니다. 팀에서 newsletter, email처럼 일관된 이름을 정하세요. 각 값은 500자 이하이며 이메일·실명 같은 개인정보를 넣지 마세요.

이 링크만 만들면 통계가 수집되나요?

아니요. 도착 사이트에 적절한 분석 설정이 있어야 캠페인 유입을 측정할 수 있습니다. 이 도구는 HTTP(S) 주소를 작성하며 접속·추적 테스트를 하지 않습니다. 완성된 주소는 직접 복사하거나 TXT로 저장할 수 있습니다.
