여행·모임 정산 계산기

여러 결제자와 지출별 참여자의 비용을 나누세요. 균등·비중·직접 금액, 환불과 이미 보낸 금액을 반영해 남은 송금액을 계산합니다.

지출 입력

공개 예시 3명·2개 지출입니다. 바로 정산하거나 한 지출씩 바꿔 보세요.

지출 편집

KRW·JPY는 정수, USD·EUR는 소수 2자리. 통화를 바꿔도 환전하지 않습니다.

나눌 사람·배분 방식

동률인 나머지 최소 단위는 참여자 순서대로 배분합니다.

환불·지출 삭제

환불은 결제 순액과 부담액에서 빼며, 송금 기록과 구분합니다.

참여자 이름·추가·삭제

2~20명. 추가한 사람은 기존 지출에 자동 포함되지 않습니다. 연결된 지출·송금이 있으면 삭제할 수 없습니다.

이미 보낸 금액 기록

직접 확인한 송금만 기록하세요. 이 사이트는 송금을 실행하거나 은행 내역을 확인하지 않습니다. 최대 50개.

백업·복원·입력 관리

최대 1MB. 백업에는 실명·지출·송금 기록이 들어갑니다. 가져오기는 검사 후 현재 입력을 교체합니다. 자동 저장·동기화는 제공하지 않습니다.

이름·금액은 브라우저에서만 계산합니다. 페이지 이동·새로고침 시 지워지니 필요하면 파일로 백업하세요.

정산 결과

입력된 공개 예시로 바로 정산할 수 있습니다.

송금 제안은 개인별 잔액을 유지하며 경로를 정리합니다. 실제 결제 상대와 다를 수 있고, 송금 횟수가 수학적으로 최소라는 보장은 없습니다.

기본값은 참여자 번호입니다. 이름을 포함하면 다른 사람에게 전달될 수 있으니 내용을 확인하세요. 지출 이름은 공유하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

여러 사람의 지출을 정산하는 방법

지출마다 결제자와 비용을 나눌 참여자를 고르세요. 결제자가 한 명이면 총금액을 전부 결제한 것으로 계산하며, 여러 사람이 결제했다면 각각의 금액 합계가 총금액과 같아야 합니다. 균등, 정수 비중, 직접 부담 금액 중에서 배분합니다. 직접 부담액의 합계도 지출과 같아야 합니다.

계산식과 나머지 처리

각 사람의 잔액 = 결제·환불 순액 − 부담액 + 이미 보낸 금액 − 이미 받은 금액. 양수는 받을 금액, 음수는 보낼 금액입니다. 지출별 비중 배분액을 최소 단위로 내림한 뒤 남는 단위를 소수 나머지가 큰 순서로 배분하고, 동률이면 참여자 순서를 사용합니다. 통화마다 모든 잔액의 합계는 0입니다.

입력 예시

민수가 세 사람의 식사 60,000원을 결제하고, 지은이 지은·서연의 카페 12,000원을 결제했다면 총비용은 72,000원입니다. 부담은 민수 20,000원, 지은·서연 각 26,000원이고, 지은은 민수에게 14,000원, 서연은 민수에게 26,000원을 보내면 잔액이 0이 됩니다. 이미 보낸 금액을 기록하면 남은 송금 제안만 다시 계산합니다.

지원 범위

참여자 2~20명, 지출·환불 1~100개, 이미 보낸 송금 50개를 지원합니다. 한 금액은 해당 통화의 최소 단위 1조 이하입니다. KRW·JPY는 소수 0자리, USD·EUR는 소수 2자리로 계산하고 통화끼리 더하거나 환전하지 않습니다. 환불이 지출보다 크면 순비용이 음수일 수 있습니다. 이 기록은 영수증·세금 계산이나 실제 금융 거래 확인이 아닙니다.

남은 송금은 보내야 할 사람과 받아야 할 사람을 참여자 순서로 연결합니다. 경로를 정리해도 각 사람의 잔액은 그대로입니다. 관계별 채무를 법적으로 판단하거나 서로 동의한 거래 조건을 바꾸는 기능은 아니므로 제안한 경로를 함께 확인하세요.

자주 묻는 질문

지출마다 참여자가 달라도 되나요?

네. 각 지출에서 비용을 나눌 사람을 선택하세요. 결제자는 비용을 나누는 사람과 달라도 됩니다. 한 지출을 여러 사람이 결제했다면 각각의 결제 금액도 입력할 수 있습니다.

1원이나 1센트가 남으면 어떻게 나누나요?

각 몫을 최소 단위로 내리고 남는 단위를 소수 나머지가 큰 사람부터 배분합니다. 나머지가 같으면 참여자 순서를 사용합니다. 합계는 지출과 정확히 일치합니다.

실제 결제한 사람과 송금받는 사람이 다르게 나올 수 있나요?

모임 전체의 잔액을 통화별로 모아 경로를 정리하므로 서로 비용을 직접 공유하지 않은 사람끼리 연결될 수 있습니다. 각자의 잔액은 유지하지만 제안한 경로에 대해 함께 확인해야 합니다. 송금 횟수의 수학적 최솟값을 보장하지 않습니다.

환전·자동 송금·기기 간 동기화도 되나요?

제공하지 않습니다. KRW·JPY는 정수, USD·EUR는 소수 2자리로 통화별로 따로 계산합니다. 입력은 메모리에만 있고, 같은 JSON 백업을 가져오면 이어서 정산할 수 있습니다.

계산 기준과 참고 자료

  • Splitwise — 지출 배분 방식

    균등·개별 금액·비중 배분의 작업 기준. 이 도구는 별도의 최소 단위 배분 규칙을 사용합니다.

  • Splitwise — 잔액과 송금 경로 정리

    개인별 잔액을 유지하며 경로를 정리하고 통화를 별도로 계산하는 개념. 이 도구의 경로 알고리즘과 횟수 최솟값을 증명하는 자료는 아닙니다.
