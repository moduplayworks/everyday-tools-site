ZIP 압축하기

여러 파일을 하나의 ZIP으로 묶으세요. 압축 방식과 ZIP 이름을 정하고 원본을 유지한 사본을 저장합니다.

선택한 파일
압축 방식

사진·영상처럼 이미 압축된 파일은 크기가 거의 줄지 않을 수 있습니다. 암호화 ZIP은 만들지 않습니다.

원본 파일은 바뀌지 않습니다. 브라우저에서 처리하며 새로고침하면 작업이 초기화됩니다.

사용 방법과 처리 기준

여러 파일을 하나의 ZIP 파일에 담아 사본으로 저장하는 작업입니다.

실제 예시

메모 TXT와 사진 PNG를 선택하고 archive.zip으로 저장하면 두 원본 파일이 같은 이름으로 ZIP 안에 들어갑니다. 일반 압축을 선택해도 이미 압축된 사진·영상은 크기가 거의 줄지 않을 수 있습니다.

자주 묻는 질문

ZIP에 암호를 걸거나 폴더를 통째로 넣을 수 있나요?

현재는 파일 선택으로 일반 ZIP을 만들며 암호화나 폴더 선택 기능은 제공하지 않습니다. 선택한 원본 파일은 바꾸지 않습니다. 파일 이름이 중복되면 이름을 바꾸거나 파일명 일괄 변경 도구를 사용하세요.

압축 속도와 크기를 선택할 수 있나요?

일반 압축은 Deflate를 사용하고, 압축 없이 묶기는 저장 방식으로 빠르게 묶습니다. 파일 200개·전체 50MB까지 지원하며 처리 중 취소할 수 있습니다.
