PDF 용량 줄이기

PDF의 글자·링크·양식을 살리는 구조 최적화와 화질을 선택하는 이미지 압축을 비교하세요. 결과 크기와 첫 페이지를 확인한 뒤 브라우저에서 저장합니다.

144dpi·JPG 품질 82%로 다시 그립니다. 글자 선택·검색, 링크, 양식, 책갈피, 첨부와 전자서명은 결과에 남지 않습니다. 저장 전 첫 페이지와 파일 크기를 비교하세요.

PDF를 줄이는 두 가지 방식

문서 구조 유지

PDF 구조를 다시 저장해 선택 가능한 글자, 표준 양식 필드와 링크를 유지합니다. 이미 최적화된 파일은 크기가 그대로이거나 커질 수 있습니다. 용량 감소를 보장하지 않으며, 결과 크기를 확인하고 저장 여부를 결정하세요.

화질을 골라 이미지 압축

페이지를 흰 배경 JPG로 다시 만들어 파일 크기를 낮춥니다. 글자와 도형도 이미지가 되므로 선택·검색할 수 없고 링크·양식·책갈피·첨부·전자서명은 유지되지 않습니다. 작은 글자는 흐려질 수 있어 원본과 결과를 비교한 뒤 저장한 PDF를 확대해 확인하세요. OCR은 수행하지 않습니다.

실제 예시

예시 PDF에는 선택 가능한 글자, 입력란, 링크와 이미지 페이지가 들어 있습니다. ‘구조 유지’를 선택하면 글자와 양식·링크를 보존한 채 PDF 구조를 다시 저장합니다. ‘용량 우선’을 선택하면 144dpi JPG 페이지로 바꾸어 눈에 보이는 모양을 유지하는 대신 글자 선택·링크·양식 기능을 제거합니다. 두 방법 모두 결과 파일의 바이트 크기를 원본과 직접 비교해 줄지 않았거나 오히려 커진 경우도 그대로 알립니다.

암호화·손상 PDF는 열리지 않을 수 있습니다. 구조 유지 방식은 최대 200페이지, 이미지 압축은 최대 50페이지·1억 2,000만 출력 화소입니다. 파일과 결과는 브라우저에서 처리하며 서버로 전송하지 않습니다.

자주 묻는 질문

PDF 압축 후 글자·링크·입력란을 계속 쓸 수 있나요?

‘구조 유지·글자 보존’은 PDF 객체 구조를 다시 저장하므로 텍스트·표준 AcroForm·링크를 확인하며 기능을 유지하는 방식입니다. 파일마다 결과가 다르고 용량이 늘 수도 있습니다. ‘용량 우선·화질 선택’은 각 페이지를 JPG 이미지로 평면화해 텍스트 선택·검색, 링크, 입력란, 책갈피, 첨부와 전자서명을 보존하지 않습니다. 서명된 원본은 편집하지 말고 결과 사본을 직접 확인하세요.

이미지 압축에서 글자가 흐려지지 않나요?

이미지 압축은 96dpi 또는 144dpi와 JPG 품질로 각 페이지를 다시 그립니다. 작은 글자와 가는 선은 흐려질 수 있으므로 화면의 첫 페이지 비교와 저장한 PDF를 확대해 확인하세요. OCR은 수행하지 않으며 이미지 안의 글자는 검색할 수 없습니다.

PDF 파일이 외부 서버로 전송되나요?

파일 읽기·변환은 브라우저 안에서 처리합니다. 파일 이름·내용을 URL이나 사용 통계로 보내지 않습니다. 50MB까지 열 수 있으며 구조 유지 방식은 200페이지, 이미지 압축은 50페이지와 전체 1억 2,000만 화소까지 지원합니다. 암호화·손상 PDF는 열리지 않을 수 있습니다.
