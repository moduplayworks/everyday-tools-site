피타고라스 계산기

직각삼각형에서 두 직각변으로 빗변의 길이를 구합니다.

입력

최소 0

최소 0

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

소수 결과는 유효숫자 12자리까지 표시합니다. 단위는 입력값끼리 통일해 주세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

직각삼각형의 두 직각변으로 빗변 구하기.

빗변=√(a²+b²)

입력 예시

직각변 3과 4: 빗변 = 5

서로 수직인 변이 6과 8이면 빗변은 √(36+64)=10입니다. 사각형의 가로·세로로 대각선을 구하는 데도 같은 계산을 씁니다.

사용 방법

  1. 직각변 a, 직각변 b 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

어떤 삼각형의 두 변에도 사용할 수 있나요?

아닙니다. 입력한 두 변 사이의 각도가 90도일 때만 이 결과가 빗변입니다. 일반 삼각형은 다른 조건이 필요하고, 세 변으로 넓이를 구하려면 삼각형 넓이 도구를 사용하세요.
