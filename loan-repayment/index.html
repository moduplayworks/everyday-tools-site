대출 상환 계산기

대출 원금과 입력 금리·기간으로 원리금균등·원금균등 월별 상환표를 비교합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 1 · 최대 1000000000000

최소 0 · 최대 100

정수 · 최소 1 · 최대 600

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

월초 원금에 연 금리÷12를 적용하고 이자는 회차별 원 단위 반올림합니다. 수수료·보증료·세금·보험·변동금리·상환일수·중도상환은 제외한 원금·이자 시나리오입니다. 마지막 회차는 잔액을 갚도록 조정하며 금융회사 상환표나 대출 추천이 아닙니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

입력한 원금·연 금리·개월과 상환 방식으로 원금과 이자의 회차별 상환 시나리오를 확인합니다..

월 금리 r = 연 금리 ÷ 1,200; 원리금균등 월 납입액 = 원금 × r ÷ (1 − (1+r)^−개월); 원금균등 월 원금 = 원금의 정수 균등 배분

입력 예시

대출 1억 원 · 연 4% · 360개월 · 원리금균등 → 월 원리금 약 477,415원

1억 원을 연 4%, 360개월 원리금균등으로 계산하면 월 원리금은 약 477,415원입니다. 월 금리는 연 금리를 12로 나눈 값이며 회차 이자는 남은 원금에 적용합니다. 표는 원 단위 반올림을 적용해 마지막 회차를 잔액에 맞춥니다.

사용 방법

  1. 입력된 예시값을 사용하거나 상환 방식, 대출 원금 (원), 연 금리 (%), 기간 (개월) 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

원리금균등과 원금균등은 어떻게 다른가요?

원리금균등은 매월 원금과 이자의 합계를 비슷하게 유지하고, 원금균등은 매월 원금을 나누어 갚아 초반 납입액이 더 큽니다. 이자는 회차 시작 시 남은 원금과 입력한 월 금리로 계산합니다.

은행의 실제 월 납입액과 일치하나요?

아닙니다. 상환일, 일수 계산, 금리 변동, 수수료, 보증료, 보험·세금과 원 단위 처리 방식은 대출 계약마다 다릅니다. 결과는 일정한 입력 금리의 원금·이자만 반영한 예시입니다.

월 납입액에 보증료나 보험료가 포함되나요?

포함되지 않습니다. 원금과 이자만 합산합니다. 실제 상환 일정과 전체 납부액은 금융회사의 설명서와 상환표에서 확인하세요.

계산 기준과 참고 자료

  • Consumer Financial Protection Bureau — 대출 상환과 원금·이자 배분

    고정 금리·원금·기간에 따른 월 원리금 산식의 공공 안내와 대출 총 납부액에 세금·보험 등이 추가될 수 있다는 설명. 계산기는 입력 금리÷12와 원 단위 회차 반올림을 사용하는 별도 추정입니다.
