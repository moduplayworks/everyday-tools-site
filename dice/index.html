주사위 굴리기

원하는 면 수의 주사위를 여러 개 굴리고 합계를 확인합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

정수 · 최소 2 · 최대 1000

정수 · 최소 1 · 최대 100

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

면 수와 개수를 정해 가상 주사위 굴리기.

각 주사위마다 1~면 수의 균등 정수 난수

입력 예시

6면체 3개: 각 결과는 1~6, 합계는 3~18

6면 주사위 2개는 각각 1~6을 뽑아 개별 결과와 합계를 보여 줍니다. 같은 눈이 나오는 것도 정상적인 결과입니다.

사용 방법

  1. 입력된 예시값을 사용하거나 면 수, 주사위 개수 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

주사위 두 개의 합 2부터 12까지는 모두 같은 확률인가요?

아닙니다. 각 주사위의 눈은 균등하지만 합은 조합 수에 따라 다릅니다. 예를 들어 합 7은 여섯 조합, 합 2는 한 조합으로 만들 수 있습니다.
