비례식 계산기

A:B = C:X 비례식의 미지수 X를 계산합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

소수 결과는 유효숫자 12자리까지 표시합니다. 단위는 입력값끼리 통일해 주세요.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

비례식 A:B=C:X에서 모르는 값 구하기.

X = B × C ÷ A

입력 예시

2:3 = 8:12

2:3=10:X이면 X=3×10÷2=15입니다. 같은 위치에 같은 종류의 양을 놓아야 비례식이 유지됩니다.

사용 방법

  1. A, B, C 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

재료 양을 늘릴 때 비례식을 쓸 수 있나요?

2인분에 300g인 재료를 5인분으로 늘린다면 A=2, B=300, C=5로 넣어 750g을 얻습니다. 조리 시간까지 같은 비율로 늘어난다는 뜻은 아닙니다.
