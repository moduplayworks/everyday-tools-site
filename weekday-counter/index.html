요일별 날짜 수 계산기

기간에 월요일부터 일요일까지 각각 몇 번 포함되는지 확인합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

공휴일과 관계없이 달력의 요일을 셉니다. 최대 기간 10년입니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

기간에 월요일부터 일요일이 각각 몇 번인지 세기.

시작일과 종료일을 모두 포함해 각 요일을 집계

입력 예시

2026-10-02~12일: 금·토·일·월은 각 2회

월요일부터 다음 일요일까지 양 끝을 포함한 7일은 각 요일이 한 번씩입니다. 시작일을 하루 앞선 일요일로 바꾸면 일요일만 두 번이 됩니다.

사용 방법

  1. 시작일, 종료일 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

요일별 수를 출근일 수로 사용해도 되나요?

이 결과는 공휴일이나 휴무를 무시한 달력 집계입니다. 특정 요일 수업 횟수를 파악하는 데 사용할 수 있지만 실제 출근일은 평일 도구에서 제외 날짜까지 반영하세요.
