PDF 합치기

PDF 파일의 순서를 바꾸고 하나로 합치세요. 최대 20개·200페이지를 브라우저에서 처리하고 병합한 사본을 저장합니다.

PDF 합치기 입력

2~20개 · 전체 50MB·200페이지 이하. 파일 목록의 순서로 합칩니다.

    암호화·양식 PDF는 지원하지 않습니다. 서명·책갈피·첨부 보존이 필요한 문서는 일반 사본으로 작업하세요.

    입력과 파일은 이 브라우저에서 처리합니다. 새로고침하면 초기화됩니다.

    결과

    입력 후 결과를 확인하세요.

    결과 공유

    도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

    사용 방법과 처리 기준

    여러 일반 PDF의 페이지를 원하는 파일 순서로 모아 새 문서를 만드는 작업입니다.

    실제 예시

    2페이지 PDF와 3페이지 PDF를 이 순서로 선택하면 총 5페이지가 됩니다. 파일 옆의 위·아래 버튼으로 순서를 바꿀 수 있습니다. 원본 파일은 바뀌지 않습니다.

    자주 묻는 질문

    PDF를 합칠 때 암호나 서명이 있으면 어떻게 되나요?

    암호화·손상 PDF와 양식 필드가 있는 PDF는 오류를 표시합니다. 전자서명·첨부·책갈피 보존은 지원하지 않으므로 일반 문서 사본으로 작업하고 결과를 확인하세요.

    PDF 병합 중 페이지 수나 파일 수 제한이 있나요?

    2~20개 파일, 전체 50MB·200페이지까지 지원합니다. 파일을 순서대로 처리하며 취소 버튼을 누르면 작업을 중단합니다. 파일을 서버에 보내지 않습니다.
