평일 수 계산기

기간 내 월~금 날짜 수를 세고 직접 입력한 휴일을 제외합니다.

입력

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

법정 공휴일을 자동 적용하지 않습니다. 필요한 공휴일은 직접 입력하세요. 최대 기간 10년입니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

기간 중 주말과 지정 휴일을 뺀 평일 수 구하기.

시작·종료일 포함, 토·일 및 직접 입력한 제외 날짜 제거

입력 예시

2026-10-02~12일: 휴일 입력 없으면 평일 7일

2026-10-05 월요일부터 10-11 일요일까지는 기본 5평일입니다. 10-09를 제외 날짜로 입력하면 4일이 됩니다. 실제 휴일은 직접 반영해야 합니다.

사용 방법

  1. 시작일, 종료일, 제외 날짜 (YYYY-MM-DD, 한 줄에 하나) 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

한국의 법정공휴일과 대체공휴일이 자동으로 빠지나요?

자동으로 빠지지 않습니다. 토요일·일요일만 기본 제외하며 공휴일, 회사 휴무, 개인 휴가를 날짜별로 입력하세요. 시작일과 종료일도 조건에 맞으면 포함합니다.

주말인 제외 날짜를 넣으면 두 번 빠지나요?

아닙니다. 날짜마다 주말 여부와 제외 목록을 함께 확인하므로 중복 입력이나 주말 제외로 일수를 두 번 빼지 않습니다.
