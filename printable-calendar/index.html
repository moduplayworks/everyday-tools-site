인쇄용 달력 만들기

월과 시작 요일을 골라 메모가 있는 달력을 만드세요. PNG·SVG로 저장하거나 A4 가로로 인쇄합니다.

입력

입력된 공개 예시로 바로 확인하거나 값을 바꾸세요.

제목·시작 요일·날짜 메모

결과의 날짜를 누르면 해당 날짜 메모를 편집합니다. 다른 달의 메모도 새로고침 전까지 유지됩니다.

입력은 브라우저에서만 처리합니다. 새로고침하면 공개 예시로 돌아갑니다.

결과

예시값으로 바로 결과를 확인하세요.

전체 시간 블록

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·파일 생성 기준

메모와 시작 요일을 고른 월별 달력 인쇄·이미지 저장.

월 첫날의 요일과 선택한 주 시작일 차이 → 앞쪽 빈 칸 → 해당 월의 날짜와 사용자 메모 배치

입력 예시

2026년 10월 1일은 목요일입니다. 월요일 시작 달력은 앞쪽에 월·화·수 세 칸을 비우며 10월 31일까지 표시합니다. 2월은 선택한 연도의 윤년 여부를 반영합니다.

2026년 10월은 1일이 목요일입니다. 월요일 시작을 고르면 앞에 빈칸 3개가 들어갑니다. 결과의 날짜를 눌러 메모를 편집하고 다시 확인하세요. 2024년 2월은 29일, 2100년 2월은 28일까지 표시합니다.

사용 방법

  1. 입력된 예시를 쓰거나 필요한 값을 바꾸세요. 추가 설정은 펼쳐서 확인합니다.
  2. 결과를 확인한 뒤 도시·일정·달력·시간 블록을 검토하세요. 오류는 제외하지 않고 수정을 안내합니다.
  3. 결과를 복사하거나 실제 파일을 저장하세요. 가져오기·인쇄는 기기의 지원 기능을 사용합니다.

지원 범위와 한계

2000~2100년, 한 달씩 인쇄·PNG·SVG 저장. 메모는 날짜당 28자·최대 366개이며 칸에 모두 배치합니다. 공휴일·음력·국가별 휴일은 제공하지 않습니다. 메모는 브라우저 메모리에서만 유지되고 새로고침하면 공개 예시로 돌아갑니다.

자주 묻는 질문

공휴일도 자동 표시되나요?

공휴일 자료는 포함하지 않습니다. 필요한 날짜에 직접 메모를 넣으세요. 한 날짜의 메모는 최대 28자이며 다른 달의 메모도 새로고침 전까지 유지합니다.

인쇄와 PNG 저장이 다르면 어떻게 하나요?

PNG·SVG와 인쇄는 마지막 확인 결과를 사용합니다. 인쇄는 A4 가로에 맞춘 이미지이며 브라우저의 여백·머리글·배율 설정에 따라 달라질 수 있습니다. 입력은 새로고침하면 공개 예시로 돌아옵니다.
