비밀번호 생성기

영문 대소문자·숫자·기호가 포함된 무작위 비밀번호를 만듭니다.

입력

정수 · 최소 8 · 최대 128

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

생성한 비밀번호가 포함됩니다. 실제 사용하는 비밀번호는 다른 사람에게 공유하지 마세요.

계산·변환 기준

문자 종류를 섞은 무작위 비밀번호 만들기.

거부 샘플링 난수로 각 문자 선택, 네 문자 종류를 모두 포함

입력 예시

16자리 생성 시 대문자·소문자·숫자·기호 포함

길이를 지정하면 대문자·소문자·숫자·기호가 각각 최소 한 개 포함된 문자열을 만듭니다. 눈으로 혼동하기 쉬운 일부 문자는 후보에서 제외합니다.

사용 방법

  1. 길이 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

생성한 비밀번호는 어디에 저장되나요?

사이트에는 저장되지 않아 새로고침하면 사라집니다. 사용할 서비스의 길이·기호 규칙을 확인하고 본인이 사용하는 비밀번호 관리자에 보관하세요. 출력과 클립보드가 다른 사람에게 보이지 않도록 하세요.

계산 기준과 참고 자료

  • W3C — Web Cryptography

    브라우저 난수 API. 개별 추첨 결과의 공정성을 인증하는 자료는 아닙니다.
