중복 줄 빈도 계산

각 줄이 몇 번 등장했는지 집계하고 많은 순서로 보여줍니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

중복 줄마다 몇 번 나오는지 세기.

완전히 같은 줄의 빈도를 합산

입력 예시

사과 / 배 / 사과 → 사과 2회

A, B, A를 한 줄씩 입력하면 A는 2회, B는 1회입니다. 결과는 빈도가 높은 줄부터 표시하므로 중복된 항목을 먼저 확인할 수 있습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 입력 텍스트 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

줄 앞뒤 공백과 대소문자는 합쳐서 세나요?

합치지 않습니다. 줄 전체가 정확히 같아야 같은 항목이며 빈 줄도 집계됩니다. 먼저 공백을 정리하거나 빈 줄을 제거하면 비교 기준을 바꿀 수 있습니다.

계산 기준과 참고 자료

이 도구의 계산식과 적용 범위는 위 설명에 공개되어 있습니다. 예시는 입력값을 공식에 대입하거나 명시된 문자열·달력 처리 규칙을 따라 확인할 수 있습니다.
