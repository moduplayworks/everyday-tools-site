인강 배속 계산기

여러 인강의 시간을 합산하고 1.25·1.5·2배속 시청 시간과 절약 시간을 계산하세요. 최대 300개 강의를 무료로 계산합니다.

배속 계산기에서 가져온 강의가 있어요.

적용하면 이 도구의 강의 목록과 배속을 교체합니다. 날짜 설정은 유지하고, 기존 계획은 다시 계산합니다.

01   강의 입력

숫자는 분, 1:30은 1분 30초예요. MM:SS·H:MM:SS 지원 (90:00 = 90분).

시간 여러 개 붙여넣기

현재 목록 뒤에 추가합니다. 빈 줄은 건너뛰고, 오류가 있으면 전체 입력을 유지합니다.

같은 브라우저에서 이어서 사용할 수 있어요. 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.

어떻게 계산하나요?

인강 시청 시간은 원본 강의 시간의 합계를 배속으로 나눈 값입니다. 60분 강의를 1.5배속으로 들으면 40분이 걸립니다. 이 계산기는 여러 강의의 총 시청 시간과 절약 시간을 한 번에 계산합니다.

시청 시간 = 원본 강의 시간의 합계 ÷ 배속
절약 시간 = 원본 시간 − 시청 시간

60분 강의를 1.5배속으로 들으면 40분이 걸리고 20분을 절약해요. 45분과 30분 강의를 1.25배속으로 들으면 총 60분이 걸립니다. 1배속보다 느리게 들으면 추가 소요 시간을 표시합니다.

계산할 때 알아두세요

최대 300개 강의, 강의당 1초~24시간을 지원합니다. 배속은 0.5~3.0까지 입력할 수 있어요. 강의명은 선택 사항이며 최대 100자입니다. 중간 계산은 반올림하지 않고 최종 결과만 초 단위로 올립니다. 예를 들어 1초 강의 3개를 2배속으로 들으면 실제 1.5초를 2초로 표시해요.

순수 재생 시간만 계산하며 필기·복습·일시정지는 포함하지 않습니다. 실제 공부 시간을 고려하려면 완강 계획 계산기를 사용하세요.

자주 묻는 질문

1시간 강의를 1.5배속이나 2배속으로 들으면 몇 분인가요?

1.5배속은 60 ÷ 1.5 = 40분, 2배속은 60 ÷ 2 = 30분입니다. 각각 원본보다 20분, 30분을 절약합니다. 필기와 일시정지 시간은 포함하지 않습니다.

1:30과 90:00은 어떻게 입력되나요?

1:30은 1분 30초이고, 90:00은 90분입니다. 숫자 90만 입력해도 90분으로 해석합니다. 1시간 30분은 90 또는 1:30:00으로 입력하세요.

여러 강의의 시간을 어떻게 합산하나요?

강의마다 길이를 한 행씩 입력하거나, 시간 여러 개 붙여넣기에 한 줄당 하나씩 넣으세요. 최대 300개 강의의 원본 시간을 먼저 합산한 다음 공통 배속을 적용합니다. 잘못된 행은 위치와 원인을 표시합니다.

소수점 시간과 24시간을 넘는 결과는 어떻게 표시하나요?

중간 계산은 반올림하지 않고 최종 시간만 초 단위로 올립니다. 1초 강의 3개를 2배속으로 들으면 실제 1.5초를 2초로 표시합니다. 총시간이 24시간을 넘어도 시간의 합계를 유지합니다.

필기·복습까지 포함한 공부 시간도 계산할 수 있나요?

이 도구의 결과는 순수 재생 시간입니다. 완강 계획 계산기로 강의 목록을 전달하면 추가 시간 비율과 공부 가능한 날짜를 반영해 하루 학습량을 계산할 수 있습니다.
