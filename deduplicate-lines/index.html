중복 줄 제거

동일한 줄의 첫 등장만 남기고 중복 항목을 정리합니다.

입력

예시값이 입력되어 있습니다. 바로 확인하거나 값을 바꿔 보세요.

Ctrl 또는 ⌘ + Enter로 실행

입력은 브라우저에서 처리합니다. 새로고침하면 예시값으로 돌아갑니다.

결과

입력된 예시값으로 바로 결과를 확인하거나 값을 바꿔 보세요.

최대 50,000자. 입력과 결과는 이 페이지 메모리에서 처리하며 저장하지 않습니다. 줄바꿈은 LF로 통일합니다.

결과 공유

도구 링크와 결과 텍스트를 함께 공유합니다. 결과는 URL에 넣지 않습니다. 아래 내용을 확인하고 공유하세요.

계산·변환 기준

동일한 텍스트 줄을 한 개씩만 남기기.

줄 문자열이 완전히 같으면 첫 번째만 유지

입력 예시

사과 / 바나나 / 사과 → 사과 / 바나나

A, B, A를 각각 줄로 넣으면 처음 등장한 순서대로 A, B가 남습니다. 정렬하지 않으므로 원본에서 먼저 나온 순서를 유지할 수 있습니다.

사용 방법

  1. 입력된 예시값을 사용하거나 입력 텍스트 항목을 바꾸세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

같아 보이는 줄이 왜 중복으로 제거되지 않나요?

대소문자와 공백을 포함한 전체 문자열을 정확히 비교합니다. A와 a, A와 뒤에 공백이 붙은 A는 다릅니다. 필요하면 공백 정리나 유니코드 정규화를 먼저 하세요.
