글자수 세기

공백 포함·제외 글자 수, UTF-8 바이트, 단어와 줄 수를 바로 확인하세요. 입력한 글은 저장하거나 전송하지 않습니다.

글 입력

최대 100,000자까지 입력할 수 있습니다. 이모지는 입력 제한에서 여러 자리로 셀 수 있습니다. 글은 이 화면에서만 처리하며 저장하거나 전송하지 않습니다.

내 글의 길이

공백 포함 글자 수

0자
공백 제외
0자
UTF-8 바이트
0 bytes
단어 (어절)
0개
줄 수
0줄

화면에 보이는 글자 묶음이 기준입니다. 공백 포함에는 줄바꿈도 포함하며, 공백 제외는 띄어쓰기·탭·줄바꿈을 뺍니다. 제출 사이트의 자체 기준과 다를 수 있습니다.

어떻게 계산하나요?

한글·영문·이모지 등 눈에 보이는 글자 묶음을 한 글자로 셉니다. 예를 들어 “안녕 A”는 공백 포함 4자, 제외 3자이며 UTF-8로는 8바이트입니다.

공백 제외 글자 수 = 띄어쓰기·탭·줄바꿈 등 공백을 제거한 글자 수
UTF-8 바이트 = 글을 UTF-8로 인코딩했을 때의 크기

Windows의 줄바꿈과 단독 CR은 LF로 통일해 한 글자로 계산합니다. 한글은 보통 3바이트, 영문은 보통 1바이트입니다. 조합형 문자와 이모지는 글자 수와 바이트가 크게 다를 수 있습니다. 입력 제한은 브라우저의 UTF-16 입력 단위 기준입니다.

자주 묻는 질문

자기소개서 제출 사이트와 글자 수가 다른 이유는 무엇인가요?

제출 사이트는 이모지·결합 문자·줄바꿈 처리나 바이트 인코딩 기준이 다를 수 있습니다. 이 도구는 보이는 글자 묶음과 UTF-8를 기준으로 하므로 실제 제출 화면의 제한도 확인하세요.

단어와 줄 수는 어떻게 세나요?

단어 수는 공백으로 구분한 어절 수입니다. 빈 글은 0줄이며, 줄바꿈으로 나뉜 빈 줄과 마지막 빈 줄도 각각 한 줄로 셉니다.

붙여넣은 글이 저장되거나 외부로 전송되나요?

글은 이 페이지의 메모리에서만 계산하고 localStorage·분석 이벤트·URL에 넣지 않습니다. 새로고침하면 사라집니다. 방문 통계나 광고의 처리는 개인정보 안내에서 별도로 확인할 수 있습니다.
