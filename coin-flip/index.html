동전 던지기

동전을 여러 번 던져 앞면·뒷면 결과와 횟수를 집계합니다.

입력

입력은 브라우저에서 처리합니다. 새로고침하면 사라집니다.

결과

값을 입력하거나 예시를 불러온 뒤 결과를 확인하세요.

브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

계산·변환 기준

동전을 여러 번 던져 앞면·뒷면 결과와 횟수를 집계합니다.

각 시행에서 0 또는 1을 독립 추출

입력 예시

10회 던지면 앞면+뒷면 횟수 = 10

사용 방법

  1. 던질 횟수 항목을 입력하세요.
  2. 결과 확인하기를 누르고 아래 결과를 확인하세요.
  3. 필요하면 결과 복사로 가져갈 수 있습니다.

자주 묻는 질문

어떤 기준으로 결과가 나오나요?

각 시행에서 0 또는 1을 독립 추출. 브라우저 Web Crypto 난수를 사용합니다. 생성 결과는 저장하지 않으며 추첨의 공정성을 공적으로 인증하지 않습니다.

입력한 내용은 저장되나요?

이 도구의 입력과 결과는 페이지 메모리에서 처리하며 저장하거나 URL·통계 이벤트에 넣지 않습니다. 새로고침 전에 필요한 결과를 복사하세요.
